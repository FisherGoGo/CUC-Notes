# N3小单元训练 05：电车与外出

目标：练习描述交通路线、时间限制和突发情况，并通过短阅读判断行动顺序。

## 本单元句型

- までに：在...之前
- てしまう：遗憾完成
- しかない：只好...
- ようだ：好像...
- ばいい：该...就好
- ところだった：差点...

## 热身词句

- **終電**：末班车。例：終電に乗り遅れました。
- **乗り換え**：换乘。例：新宿で乗り換えます。
- **遅れる**：迟到，晚点。例：電車が十分遅れています。
- **改札**：检票口。例：改札の前で待っています。
- **路線**：线路。例：この路線はとても便利です。
- **間違える**：弄错。例：乗る電車を間違えました。

## 句子翻译

1. 请在八点之前到检票口。（提示：までに）
2. 我好像坐错电车了。（提示：ようだ / てしまう）
3. 如果赶不上末班车，就只好坐出租车。（提示：なければ / しかない）
4. 请告诉我在哪里换乘比较好。（提示：ばいい）
5. 我差点把包忘在车站。（提示：ところだった）
6. 因为电车晚点，我可能会迟到十分钟。（提示：ので / かもしれない）

## 阅读理解

今日は友達と映画を見る約束がありました。七時までに映画館に着かなければならなかったので、私は少し早めに家を出ました。しかし、途中で乗り換える駅を間違えてしまい、反対方向の電車に乗ってしまいました。

すぐに気がついて次の駅で降りましたが、このままでは間に合わないようでした。駅員さんにどの電車に乗ればいいか聞くと、急行に乗れば早く着くと教えてくれました。少し走りましたが、映画が始まる前に着くことができました。

词汇提示：反対方向：相反方向 / 急行：快车 / 駅員：车站工作人员

1. 作者为什么早一点出门？
   - 想买东西
   - 七点前必须到电影院
   - 要去学校
   - 电车停运
2. 作者犯了什么错误？
   - 忘带票
   - 弄错换乘站并坐反方向
   - 忘记约定
   - 迟到一小时
3. 作者向谁询问路线？
   - 朋友
   - 司机
   - 站员
   - 店员
4. 最后作者怎么样了？
   - 没赶上电影
   - 电影开始前到了
   - 回家了
   - 改看别的电影

## 输出小练习

用日语写 2-3 句：如果坐错电车，你会怎么做？

## 参考答案

1. 八時までに改札に来てください。
2. 乗る電車を間違えてしまったようです。
3. 終電に間に合わなければ、タクシーに乗るしかありません。
4. どこで乗り換えればいいか教えてください。
5. かばんを駅に忘れるところでした。
6. 電車が遅れているので、十分ぐらい遅れるかもしれません。

### 阅读答案

1. 七点前必须到电影院。文中说「七時までに映画館に着かなければならなかった」。
2. 弄错换乘站并坐反方向。文中有「乗り換える駅を間違えてしまい、反対方向」。
3. 站员。文中说「駅員さんに...聞く」。
4. 电影开始前到了。最后说「映画が始まる前に着くことができました」。

### 输出参考

電車を間違えたら、次の駅で降ります。駅員さんにどの電車に乗ればいいか聞くつもりです。
