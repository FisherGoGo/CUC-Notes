# TRY N4 语法 5 天复习计划

用途：用 5 天快速完成 TRY N4 核心语法补底，为后续 N3 语法、阅读和听力扫清基础障碍。  
范围：已生成的 TRY N4 第 02-10 课，共 9 个单元、93 条语法。  
原则：N4 只做冲刺补底，不慢学，不扩展太多课外内容。

## 总目标

完成本计划后，应达到：

- 能说出 93 条语法中 A 级语法的基本意思。
- 看到语法能判断前面接什么形。
- 能区分核心易混点：
  - `そうだ / ようだ / らしい`
  - `たら / と / ば / なら`
  - `てある / ておく`
  - `ことにする / ことになる`
  - `てくれる / てもらう / ていただく`
  - `てはいけない / なくてもいい`
- 每课练习题正确率达到 70% 以上。
- 阅读拆句时能找出主干，不被长修饰语卡住。

## 每天学习流程

每课都按这个顺序学：

1. 看 `本课目标` 和 `考试优先级`。
2. A 级语法必须掌握意思和接续，B 级至少能看懂。
3. 每条语法只抓四件事：意思、接续、例句、考试注意。
4. 做 `阅读拆句训练`，重点找句子主干和语法作用。
5. 做 `本课练习`，错题直接标在文件里或单独记到错题本。
6. 看 `答案与解析`，只复盘错题和犹豫题。
7. 勾选 `复习清单`，没勾上的内容第二天先补。

单课建议：

| 环节 | 时间 |

## N4 核心混淆速查

| 混淆组 | 判断方法 |
| --- | --- |
| `そうだ / ようだ / らしい` | `そうだ` 看起来或听说，取决于接续；`ようだ` 根据现场线索；`らしい` 根据听到的信息或情况判断 |
| `たら / と / ば / なら` | `たら` 条件广；`と` 自然结果、机器、路线；`ば` 强调条件；`なら` 承接话题 |
| `てある / ておく` | `てある` 是准备后的结果状态；`ておく` 是提前做准备 |
| `ことにする / ことになる / ことになっている` | 自己决定 / 外部安排或结果 / 规则或预定 |
| `てくれる / てもらう / ていただく` | 对方为我做 / 我请别人做 / 礼貌地请别人做 |
| `てはいけない / なくてもいい` | 禁止做 / 不必做 |
| `ために / ように` | 明确目的 / 为达到状态、能力或避免某事 |
| `お～する / お～になる / お～ください` | 我方动作谦让 / 对方动作尊敬 / 请求对方动作 |
