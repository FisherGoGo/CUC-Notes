# 名词的性

- 阳性：部分 -ь，辅音、-й。
- 阴性：-а，-я，部分 -ь。
- 中性：-о，-е，-мя。

# 名词的数

1. 阳性辅音结尾名词：辅音加 -ы。
2. 七音后接辅音时，把辅音变为 -и。
3. 阴性：-а 变为 -ы，-я 变为 -и。
4. 中性：-о 变为 -а，-е 变为 -я。
5. 阳性：-й 变为 -и，-ь 变为 -и。

# 名词第四格

1. 阳性非动物名词：不变。
2. 阳性动物名词：辅音结尾加 -а，-й 变 -я，-ь 变 -я。
3. 阴性名词：-а 变 -у，-я 变 -ю，-ь 结尾不变。
4. 中性名词：都不变。

## 物主代词

物主代词的变化取决于后边接的名词。

| 中文 | 阳性 | 阴性 | 中性 | 复数 |
| --- | --- | --- | --- | --- |
| 我的 | мой | моя | моё | мои |
| 你的 | твой | твоя | твоё | твои |
| 我们的 | наш | наша | наше | наши |
| 你们的 | ваш | ваша | ваше | ваши |

他的、她的、他们的不变：

| 中文 | 俄语 |
| --- | --- |
| 他的 | его |
| 她的 | её |
| 他们的 | их |

# 动词变位

## 第一变位

一般是 -ать 结尾，一般是把 -ть 换成其他形式，由我、你、他（它、她）、我们、你们、他们来变。

| 人称 | 变化 |
| --- | --- |
| я（我） | -ю / -у |
| ты（你） | -ешь |
| он / она / оно（他 / 她 / 它） | -ет |
| мы（我们） | -ем |
| вы（你们） | -ете |
| они（他们） | -ют / -ут |
## 第二变位

一般是 -ить 结尾，也是根据前边代词变化。

| 人称 | 变化 |
| --- | --- |
| я（我） | -ю / -у |
| ты（你） | -ишь |
| он / она / оно（他 / 她 / 它） | -ит |
| мы（我们） | -им |
| вы（你们） | -ите |
| они（他们） | -ят / -ат |
