# N3小单元训练 06：餐厅预约

目标：练习礼貌请求、预约变更、说明人数时间，并通过阅读理解预约问题。

## 本单元句型

- てもよろしいでしょうか：可以...吗
- ていただけますか：能请您...吗
- 予定：预定/计划
- ことになっている：安排为...
- そうだ：听说
- なら：如果是...

## 热身词句

- **予約**：预约。例：七時に予約しました。
- **人数**：人数。例：人数を変更したいです。
- **禁煙席**：禁烟座。例：禁煙席は空いていますか。
- **都合**：方便，情况。例：今日は都合が悪いです。
- **変更する**：更改。例：時間を変更してもいいですか。
- **確認**：确认。例：予約内容を確認します。

## 句子翻译

1. 请问，可以把预约时间改到七点吗。（提示：てもよろしいでしょうか）
2. 能请您帮我确认一下人数吗。（提示：ていただけますか）
3. 如果是禁烟座，我想预约靠窗的位置。（提示：なら / たい）
4. 听说这家店周末很拥挤。（提示：そうだ）
5. 我们安排六个人一起去吃饭。（提示：ことになっている）
6. 不好意思，我想取消今天的预约。（提示：たい / 予約）

## 阅读理解

来週の日曜日、友達の誕生日を祝うためにレストランを予約しました。最初は四人の予定でしたが、あとから二人も来られることになったので、人数を変更しなければなりませんでした。その店は週末とても混むそうなので、早めに電話しました。

店員さんに確認してもらうと、六人用の席はまだ空いていました。ただし、窓側の席は予約でいっぱいで、店の奥の席になると言われました。私は友達に相談してから、六人でその席を予約することにしました。

词汇提示：祝う：庆祝 / 奥：里面 / 相談する：商量

1. 作者为什么预约餐厅？
   - 庆祝生日
   - 面试
   - 学习会
   - 欢迎老师
2. 人数发生了什么变化？
   - 四人变六人
   - 六人变四人
   - 二人取消
   - 没有变化
3. 作者为什么早打电话？
   - 店快关门
   - 周末很拥挤
   - 想点菜
   - 朋友催促
4. 最后预约了哪里的座位？
   - 窗边
   - 店里面
   - 吧台
   - 没有预约

## 输出小练习

用日语写 2-3 句：你给餐厅打电话预约时会说什么？

## 参考答案

1. 予約の時間を七時に変更してもよろしいでしょうか。
2. 人数を確認していただけますか。
3. 禁煙席なら、窓側の席を予約したいです。
4. この店は週末とても混むそうです。
5. 六人で食事に行くことになっています。
6. すみません、今日の予約をキャンセルしたいです。

### 阅读答案

1. 庆祝生日。文中说「友達の誕生日を祝うため」。
2. 四人变六人。最初四人，后来又有两人能来。
3. 周末很拥挤。文中说「週末とても混むそうなので」。
4. 店里面。文中说「店の奥の席になる」。

### 输出参考

日曜日の七時に四人で予約したいです。できれば禁煙席をお願いしたいのですが、空いていますか。
