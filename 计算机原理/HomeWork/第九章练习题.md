# 第九章练习题

## 1. 8253 计数过程中装入新初值

**题目：** 若 8253 处于计数过程中，CPU 要对它装入新的初值，下列说法正确的是（ ）。

**选项：**

- A. 8253 允许编程，并改变当前的计数过程
- B. 8253 禁止编程
- C. 8253 允许编程，是否影响当前的计数过程随工作方式而变
- D. 8253 允许编程，但不改变当前的计数过程

**答案：D**

**解析：** 8253 在计数过程中允许 CPU 重新写入计数初值。新写入的初值通常先进入计数初值寄存器，不会立刻打断当前正在进行的计数过程，而是在规定时机装入计数单元后生效。

**干扰项分析：**

- A 错，重新写入初值不等于立即改变当前计数过程。
- B 错，8253 在计数过程中并非禁止编程。
- C 容易误选，虽然不同方式的装入时机有差别，但本题强调“当前计数过程”，按题意应选 D。

> 易错点：允许编程和立即改变当前计数过程不是一回事。

## 2. 8253 对 GATE 信号的采样时刻

**题目：** 8253 通常在（ ）门控信号 GATE 被采样。

**选项：**

- A. `WR` 信号的上升沿
- B. 时钟脉冲的上升沿
- C. `WR` 信号的下降沿
- D. 时钟脉冲的下降沿

**答案：B**

**解析：** 8253 的门控信号 `GATE` 通常在 `CLK` 的上升沿被采样，用来决定当前计数器是否允许计数或触发相应工作过程。

**干扰项分析：**

- A、C 错，`WR` 与 CPU 写操作有关，不是采样 `GATE` 的时钟。
- D 错，时钟下降沿常与计数减 1 联系在一起，不是本题问的 `GATE` 采样沿。

> 易错点：`GATE` 采样在 `CLK` 上升沿；计数减 1 常考 `CLK` 下降沿。

## 3. 8253 二进制计数最大初始值

**题目：** 8253 计数器二进制计数时所能容纳的最大初始值为（ ）。

**选项：**

- A. 10000
- B. 9999
- C. 65536
- D. 65535

**答案：C**

**解析：** 8253 每个计数器是 16 位。二进制计数时，写入 `0000H` 并不表示 0，而是表示最大计数值 `65536`。

**干扰项分析：**

- A、B 是十进制或 BCD 计数中容易混淆的数值。
- D 是 16 位无符号数最大编码 `FFFFH` 的值，但 8253 二进制计数最大初值按 `0000H` 表示 `65536`。

> 易错点：8253 中 `0000H` 表示 65536，不是 0，也不是 65535。

## 4. 初始化后能连续计数的工作方式

**题目：** 下列工作方式中，8253 初始化编程后能连续计数的是（ ）。

**选项：**

- A. 方式 0
- B. 方式 5
- C. 方式 2
- D. 方式 1

**答案：C**

**解析：** 方式 2 是频率发生器方式，计数到终值后会自动重新装入初值并继续计数，因此能连续工作。

**干扰项分析：**

- A 方式 0 为计数结束中断方式，通常是一次性计数过程。
- B 方式 5 为硬件触发选通信号方式，偏一次性触发输出。
- D 方式 1 为硬件可重触发单稳方式，不是连续自动重复计数。

> 易错点：方式 2 和方式 3常用于周期性输出；本题选项中只有方式 2。

## 5. 8253 的定时与计数

**题目：** 8253 的定时与计数（ ）。

**选项：**

- A. 从各自的控制端口设置
- B. 是两种不同的工作方式
- C. 定时只加脉冲信号，不设计算值
- D. 实质相同，只是所加的计数脉冲要求不同

**答案：D**

**解析：** 定时和计数本质上都是对输入脉冲做减 1 计数。定时通常输入固定频率时钟脉冲，用计数值换算时间；计数通常输入外部事件脉冲，用来统计事件次数。

**干扰项分析：**

- A 错，8253 的计数器由控制字设置，不是定时和计数各有独立控制端口。
- B 错，定时和计数不是 8253 的两种工作方式分类，8253 的工作方式是方式 0 到方式 5。
- C 错，定时也必须设置计数初值。

## 6. 8253 计数器减 1 的时刻

**题目：** 8253 计时器在（ ）做减 1 计数。

**选项：**

- A. `WR` 信号的上升沿
- B. 时钟脉冲的上升沿
- C. `WR` 信号的下降沿
- D. 时钟脉冲的下降沿

**答案：D**

**解析：** 8253 的计数器通常在 `CLK` 的下降沿进行减 1 计数。

**干扰项分析：**

- A、C 错，`WR` 是写控制信号，不是计数脉冲。
- B 容易与 `GATE` 采样时刻混淆。

> 易错点：`GATE` 在时钟上升沿采样，计数器在时钟下降沿减 1。

## 7. 8253 的写命令

**题目：** 8253 有三条写命令，分别是 ①、②、③。

**答案：** ① 控制字命令；② 计数初值命令；③ 锁存命令

**解析：**

```text
控制字命令：设置计数器编号、读写格式、工作方式和计数制
计数初值命令：向指定计数器写入计数初值
锁存命令：在计数过程中锁存当前计数值，便于 CPU 读取
```

> 易错点：锁存命令不是把新初值写入计数器，而是把当前计数值暂存下来供读取。

## 8. 定时或延时的实现方法

**题目：** 在微机应用系统中，实现定时或延时可采用三种方法实现：①、②、③。

**答案：** ① 软件延时；② 硬件定时；③ 中断定时

**解析：**

```text
软件延时：靠程序循环等待，占用 CPU，精度较低
硬件定时：由定时器/计数器完成，精度较高
中断定时：定时器到时发出中断，CPU 响应服务程序，效率较高
```

## 9. 8253 方式 3 输出波形

**题目：** 8253 工作于方式 3 时，当计数初值为 ① 数时，输出 OUT 为对称方波；当计数初值为 ② 数时，输出 OUT 为近似对称方波。

**答案：** ① 偶数；② 奇数

**解析：** 方式 3 是方波发生器。计数初值为偶数时，高、低电平持续时间相等，输出对称方波；计数初值为奇数时，高、低电平持续时间相差一个时钟周期，因此输出近似对称方波。

> 易错点：方式 3 的“对称/近似对称”取决于计数初值是偶数还是奇数。

## 10. 计数器 2 初始化和读取当前计数值

**题目：** 对计数器 2 初始化，使其工作于方式 2，采用 BCD 码计数，计数初值为 8050，设 8253 的端口地址为 `84H~87H`。

### (1) 编写初始化程序

**答案：**

```asm
MOV AL, 0B5H
OUT 87H, AL
MOV AL, 50H
OUT 86H, AL
MOV AL, 80H
OUT 86H, AL
```

**解析：** 端口地址为 `84H~87H`，所以计数器 0、1、2 和控制端口分别为 `84H`、`85H`、`86H`、`87H`。

控制字分析：

```text
SC1SC0 = 10     选择计数器 2
RW1RW0 = 11     先写低字节，后写高字节
M2M1M0 = 010    方式 2
BCD = 1         BCD 计数
```

因此控制字为 `10110101B = B5H`。计数初值 `8050` 是 BCD 数，先写低字节 `50H`，再写高字节 `80H`。

### (2) 计数过程中读出当前计数值

**答案：**

```asm
MOV AL, 80H
OUT 87H, AL
IN  AL, 86H
MOV BL, AL
IN  AL, 86H
MOV BH, AL
```

**解析：** 计数过程中读取当前值时，应先发锁存命令。`80H = 10000000B` 表示锁存计数器 2 当前值。由于初始化时采用先低后高的读写格式，所以读取时先读低字节，再读高字节。

## 11. 8253 初始化程序

**题目：** 系统中有一片 8253，其端口地址分别为 `A28H`、`A2AH`、`A2CH`、`A2EH`。试对 8253 编写初始化程序。计数器 0 高 8 位计数，计数值为 6000，BCD 计数，设置为方式 3；计数器 2 高、低 8 位计数，计数值为 1000，二进制计数，设置为方式 2。

**答案：**

```asm
; 计数器 0：方式 3，BCD 计数，只写高字节，初值 6000
MOV DX, 0A2EH
MOV AL, 27H
OUT DX, AL
MOV DX, 0A28H
MOV AL, 60H
OUT DX, AL

; 计数器 2：方式 2，二进制计数，先写低字节，后写高字节
MOV DX, 0A2EH
MOV AL, 0B4H
OUT DX, AL
MOV DX, 0A2CH
MOV AL, 0E8H
OUT DX, AL
MOV AL, 03H
OUT DX, AL
```

**解析：**

计数器 0 控制字：

```text
SC1SC0 = 00     选择计数器 0
RW1RW0 = 10     只写高字节
M2M1M0 = 011    方式 3
BCD = 1         BCD 计数
```

所以控制字为 `00100111B = 27H`。BCD 数 `6000` 只写高字节时写入 `60H`。

计数器 2 控制字：

```text
SC1SC0 = 10     选择计数器 2
RW1RW0 = 11     先写低字节，后写高字节
M2M1M0 = 010    方式 2
BCD = 0         二进制计数
```

所以控制字为 `10110100B = B4H`。十进制 `1000 = 03E8H`，先写低字节 `E8H`，再写高字节 `03H`。

## 12. 8253 定时器 0 连接图

**题目：** 8253 的定时器 0 连接如图 1 所示，试回答下列问题：

1. 定时器 0 工作于何种工作方式？工作方式的名称是什么？
2. 写出定时器 0 的计数初值。

![8253 定时器 0 连接图](../assets/9-12.png)

**答案：**

1. 定时器 0 工作于方式 2，名称为频率发生器方式。
2. 计数初值为 `5000`，即 `1388H`。

**解析：** 图中 `GATE0` 接高电平，`OUT0` 平时为高电平，到终值时输出一个低电平脉冲，然后自动重新装入初值继续计数，这是方式 2 的典型输出特征。

输入时钟周期为 `400 ns`，输出周期为 `2 ms`，方式 2 中：

$$
T_{OUT}=N \times T_{CLK}
$$

所以：

$$
N=\frac{2ms}{400ns}=\frac{2 \times 10^{-3}}{400 \times 10^{-9}}=5000
$$

十进制 `5000` 换算成十六进制为 `1388H`。

> 易错点：图中输出是周期性窄低脉冲，不是高低各半的方波，所以应判断为方式 2，而不是方式 3。
