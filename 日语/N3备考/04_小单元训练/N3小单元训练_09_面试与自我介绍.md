# N3小单元训练 09：面试与自我介绍

目标：练习表达经验、理由、礼貌说明和计划，并通过阅读理解面试准备。

## 本单元句型

- 経験がある：有经验
- ために：为了...
- ようと思う：打算...
- ことができる：能够...
- だけでなく：不仅...
- ていただきたい：希望对方...

## 热身词句

- **面接**：面试。例：明日アルバイトの面接があります。
- **経験**：经验。例：接客の経験があります。
- **長所**：优点。例：私の長所はまじめなところです。
- **志望理由**：应聘理由。例：志望理由を考えました。
- **接客**：待客服务。例：接客の仕事に興味があります。
- **履歴書**：简历。例：履歴書をきれいに書きました。

## 句子翻译

1. 我明天有便利店打工的面试。（提示：面接）
2. 我虽然没有经验，但很想学习接客。（提示：が / たい）
3. 为了面试，我提前写好了简历。（提示：ために / ておく）
4. 我想不仅提高日语，也提高沟通能力。（提示：だけでなく / たい）
5. 如果可以的话，我希望您看看我的简历。（提示：ていただきたい）
6. 我打算在入职前记住店里的规则。（提示：前に / ようと思う）

## 阅读理解

明日、駅前のカフェでアルバイトの面接を受けます。私は接客の経験がありませんが、日本語で人と話す機会を増やしたいと思い、この仕事に応募しました。面接で慌てないように、志望理由と自分の長所をノートにまとめておきました。

先輩に履歴書を見てもらうと、「経験がないことを心配しすぎなくてもいい。その代わり、何を学びたいかをはっきり言ったほうがいい」とアドバイスされました。私は日本語だけでなく、丁寧な話し方も身につけたいと伝えるつもりです。

词汇提示：応募する：应聘 / 慌てる：慌张 / 身につける：掌握

1. 作者要面试什么工作？
   - 咖啡店打工
   - 图书馆工作
   - 学校助教
   - 餐厅厨师
2. 作者为什么应聘？
   - 工资高
   - 想增加用日语交流的机会
   - 离家近
   - 朋友推荐
3. 作者为面试提前做了什么？
   - 买衣服
   - 整理志望理由和长处
   - 练习做咖啡
   - 请假
4. 先辈给了什么建议？
   - 隐瞒无经验
   - 明确说明想学什么
   - 不要带简历
   - 只谈工资

## 输出小练习

用日语写 2-3 句：面试时你会怎样介绍自己的优点？

## 参考答案

1. 明日コンビニのアルバイトの面接があります。
2. 経験はありませんが、接客をぜひ勉強したいです。
3. 面接のために、履歴書を書いておきました。
4. 日本語だけでなく、コミュニケーション能力も高めたいです。
5. よろしければ、私の履歴書を見ていただきたいです。
6. 仕事を始める前に、店のルールを覚えようと思います。

### 阅读答案

1. 咖啡店打工。文中说「駅前のカフェでアルバイト」。
2. 想增加用日语交流的机会。文中说「日本語で人と話す機会を増やしたい」。
3. 整理志望理由和长处。文中说「ノートにまとめておきました」。
4. 明确说明想学什么。文中说「何を学びたいかをはっきり言ったほうがいい」。

### 输出参考

私の長所は、まじめに続けられるところです。経験はまだ少ないですが、新しいことを早く覚えたいです。
