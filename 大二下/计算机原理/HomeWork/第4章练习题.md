# 第四章练习题

## 1. 关系运算伪指令表达式

**题目：** 执行下面程序段后：

```asm
NUM=60
MOV BX, NUM LE 50
```

`BX` 的内容是（ ）。

**选项：**

- A. `1`
- B. `0FFFFH`
- C. `0`
- D. `50`

**答案：C**

**解析：** `LE` 表示“小于等于”。因为 `NUM=60`，判断 `60 <= 50` 为假，所以表达式结果为 `0`，执行后 `BX=0`。

> 易错点：汇编表达式中的关系运算结果为真时常用全 1 表示，假时为 0。本题条件为假，所以是 0。

## 2. 计算机能直接执行的语言

**题目：** 计算机内部，计算机能够直接执行的程序语言是（ ）。

**选项：**

- A. C 语言
- B. 汇编语言
- C. 机器语言
- D. 高级语言

**答案：C**

**解析：** CPU 硬件只能直接识别和执行机器语言，也就是二进制机器指令。汇编语言和高级语言都必须先翻译成机器语言。

> 易错点：汇编语言接近机器语言，但仍然需要汇编器翻译，不能被硬件直接执行。

## 3. `DW` 数据定义与偏移地址

**题目：** 已知伪指令：

```asm
VAR DW 8, 156, $+2, 9, 7
```

若汇编 `VAR` 分配的偏移地址是 `0011H`，汇编 `0015H` 单元的内容是（ ）。

**选项：**

- A. `09H`
- B. `17H`
- C. `07H`
- D. `15H`

**答案：B**

**解析：** `DW` 定义字数据，每个数据占 2 字节。8086 采用小端存储，低字节放低地址。

`VAR` 从 `0011H` 开始：

```text
0011H-0012H：0008H
0013H-0014H：009CH  ; 156 十进制 = 009CH
0015H-0016H：$+2
```

汇编到第三个字数据时，当前位置 `$=0015H`，所以 `$+2=0017H`。按小端存储：

```text
0015H：17H
0016H：00H
```

因此 `0015H` 单元内容为 `17H`。

> 易错点：`$` 表示当前位置计数器；`DW` 占 2 字节，且字数据小端存储。

## 4. `DUP` 嵌套数据定义

**题目：** 使用 8086 汇编语言的伪指令定义：

```asm
VAR DB 2 DUP (1,2,3 DUP (3),2 DUP (1,0))
```

则在 `VAR` 存储区的前 11 个字节单元的内容是（ ）。

**选项：**

- A. `2,1,2,3,3,2,1,0,2,1,0`
- B. `1,2,3,3,3,2,1,0,1,2`
- C. `1,2,3,3,3,1,0,1,0,1,2`
- D. `1,2,3,3,2,1,0,1,2,3,1`

**答案：C**

**解析：** 先展开括号内的一组：

```text
1, 2, 3 DUP(3), 2 DUP(1,0)
= 1, 2, 3, 3, 3, 1, 0, 1, 0
```

外层 `2 DUP(...)` 表示整组重复 2 次。前 11 个字节为：

```text
1,2,3,3,3,1,0,1,0,1,2
```

> 易错点：`n DUP(...)` 是把括号里的整体重复 n 次；嵌套时先展开内层，再展开外层。

## 5. `LENGTH` 运算符

**题目：** 数据定义 `BUF DB 'AB3C5'`，执行指令 `MOV CL, LENGTH BUF` 后，`CL` 的内容是（ ）。

**选项：**

- A. `1`
- B. `3`
- C. `2`
- D. `5`

**答案：A**

**解析：** 按本课程平台口径，`LENGTH` 对普通变量定义返回变量项的重复次数；没有使用 `DUP` 重复定义时，长度取 `1`。因此 `LENGTH BUF=1`，执行后 `CL=1`。

> 易错点：直觉上字符串 `'AB3C5'` 有 5 个字符，但本题平台考的是汇编运算符 `LENGTH` 的课程定义，不是字符串字符数。

## 6. `SIZE` 运算符

**题目：** 数据定义：

```asm
BUF DW 5, 2, 3
```

执行指令 `MOV CL, SIZE BUF` 后，`CL` 的内容是（ ）。

**选项：**

- A. `4`
- B. `6`
- C. `3`
- D. `2`

**答案：D**

**解析：** 按本课程平台口径：

```text
SIZE = LENGTH * TYPE
```

```
TYPE 变量名 = 这个变量每个元素的字节数
```

`BUF DW 5,2,3` 中，`TYPE BUF=2`，而普通定义未使用 `DUP` 时 `LENGTH BUF=1`，所以：

```text
SIZE BUF = 1 * 2 = 2
```

因此 `CL=2`。

> 易错点：这里不要把 3 个字数据的总字节数 6 当作平台答案；本题按课程平台的 `SIZE` 定义取 2。

## 7. 字数据的小端存储

**题目：** 若定义 `DATA DW 200BH`，执行 `MOV BL, BYTE PTR DATA` 指令后，`BL` 的内容是 ①。

**答案：** ① `0BH`

**解析：** `DATA DW 200BH` 是一个字数据。8086 采用小端存储：

```text
低地址：0BH
高地址：20H
```

`BYTE PTR DATA` 取的是 `DATA` 起始地址处的一个字节，也就是低字节 `0BH`。

> 易错点：字数据 `200BH` 在内存中不是先放 `20H`，而是先放低字节 `0BH`。

## 8. 串操作 `REP MOVSB`

**题目：** 已知 `(DS)=(ES)`，执行下列指令后：

```asm
BUF DB 1,3,4,5,6,7,9,8,9,10,11
MOV CX,10
MOV SI,OFFSET BUF+9
LEA DI,BUF+10
STD
REP MOVSB
MOV BX,OFFSET BUF
MOV AX,[BX]
```

`AX` 的内容是 ①，`CX` 的内容是 ②。

**答案：** ① `0101H` ② `0000H`

**解析：** `STD` 使 `DF=1`，串操作后 `SI`、`DI` 递减。`REP MOVSB` 重复 10 次，从 `BUF+9` 开始向 `BUF+10` 搬移，每次复制 1 字节并向低地址推进。

MOVSB：把 SI 的东西复制到 DI，然后若 DF=1，则 SI-- DI-- ，否则 SI++ DI++

结果会把 `BUF+0` 到 `BUF+9` 的内容整体向后复制一位，最终前两个字节都变为 `01H`。随后：

```asm
MOV AX,[BX]
```

从 `BUF` 起始处取一个字。8086 小端存储，低地址字节为 `01H`，高地址字节也为 `01H`，所以 `AX=0101H`。`REP` 执行完后 `CX=0000H`。

> 易错点：`STD` 后串操作地址递减；`REP MOVSB` 会把 `CX` 减到 0。

## 9. 指令序列跟踪

**题目：** 执行下列指令段后，`3004H` 单元的内容是 ①，`BX` 的内容是 ②，`CF` 是 ③。

```asm
ORG 3000H
DB 11H,12H,13H,15H,17H

MOV BX,3000H
STC
ADC BX,1
SAL BL,1
INC BYTE PTR [BX]
```

**答案：** ① `18H` ② `3004H` ③ `0`

**解析：**

初始内存：

```text
3000H=11H, 3001H=12H, 3002H=13H, 3003H=15H, 3004H=17H
```

执行过程：

```text
MOV BX,3000H  -> BX=3000H
STC           -> CF=1
ADC BX,1      -> BX=3000H+1+CF=3002H
SAL BL,1      -> BL=02H 左移 1 位，BL=04H，所以 BX=3004H，CF=0
INC [BX]      -> [3004H]=17H+1=18H，INC 不影响 CF
```

所以 `3004H` 单元内容为 `18H`，`BX=3004H`，`CF=0`。

> 易错点：`ADC` 要加上原来的 `CF`；`INC` 不影响 `CF`。

## 10. `OFFSET`、`EQU` 与存储内容

**题目：** 设数据段定义如下：

```asm
DSEG SEGMENT
ORG 0100H
X1 DB 25,'35'
X2 DW ?
Y1 EQU X1
Y2 EQU $-Y1
DSEG ENDS
```

回答：

1. 执行 `MOV BX, OFFSET X1` 后，`BX` 的内容。
2. 汇编后 `Y2` 的值。
3. 执行 `MOV AL, Y1+1` 后，`AL` 的内容。

**答案：** ① `0100H` ② `5` ③ `33H`

**解析：** `ORG 0100H` 后，`X1` 从偏移地址 `0100H` 开始。`X1 DB 25,'35'` 占 3 个字节：

```text
0100H：25 十进制 = 19H
0101H：字符 '3' = 33H
0102H：字符 '5' = 35H
```

`X2 DW ?` 占 2 字节，所以当前位置 `$` 到 `0105H`。`Y1 EQU X1`，因此：

```text
Y2 = $ - Y1 = 0105H - 0100H = 5
```

`MOV AL, Y1+1` 取的是 `X1+1` 处的字节，也就是字符 `'3'` 的 ASCII 码 `33H`。

> 易错点：`'35'` 是两个字符，占两个字节，分别是 `33H` 和 `35H`，不是十进制 35。

`Y1 EQU X1` = `define Y1 X1`
## 11. CBW、LEA 与字访问

**题目：** 执行下列指令段后：

```asm
VR1 DB 86H
VR2 DW 2005H,0021H,849EH

MOV AL,VR1
CBW
LEA BX,VR2
MOV DX,4[BX]
SUB AX,DX
```

`AX` 的内容是 ①，`DX` 的内容是 ②。

**答案：** ① `7AE8H` ② `849EH`

**解析：** `MOV AL,VR1` 后 `AL=86H`。`CBW` 将 `AL` 符号扩展到 `AX`，因为 `86H` 最高位为 1，所以：

```text
AX = FF86H
```

`VR2` 是字数组：

```text
VR2+0：2005H
VR2+2：0021H
VR2+4：849EH
```

因此 `MOV DX,4[BX]` 后 `DX=849EH`。最后：

```text
AX = FF86H - 849EH = 7AE8H
```

> 易错点：`CBW` 是按符号扩展，不是把 AH 清零，操作后 AX 从 `0086H` 变成 `FF86H`；` 4[BX]` 访问的是 ` VR2 ` 的第 3 个字。`LEA` 是取 `VR2` 的偏移地址。`4[BX]` 是 `[BX+4]` 

## 12. 循环程序跟踪

**题目：** 执行下列程序后，分析有关寄存器的内容：

```asm
CSEG SEGMENT
ASSUME CS:CSEG,DS:CSEG,SS:CSEG
ORG 100H
BEGIN:
    MOV AX, 02H
    MOV BX, 03H
    MOV DX, 05H
    MOV CX, 06H
    CLC
L20:
    INC AX
    ADC BX, AX
    SHR DX, 1
    LOOPNE L20
CSEG ENDS
END BEGIN
```

**答案：**

```text
AX = 0005H
BX = 0010H
CX = 0003H
DX = 0000H
CY = 1
```

**解析：** `LOOPNE` 每次使 `CX-1`，并在 `CX != 0` 且 `ZF=0` 时继续循环。程序执行 3 次循环后停止，关键结果为：

```text
第 1 次：AX=0003H, BX=0006H, DX=0002H, CX=0005H
第 2 次：AX=0004H, BX=000AH, DX=0001H, CX=0004H
第 3 次：AX=0005H, BX=0010H, DX=0000H, CX=0003H, CF=1
```

第 3 次 `SHR DX,1` 时，`DX=0001H` 右移，最低位 1 移入 `CF`，结果 `DX=0000H`，同时 `ZF=1`，所以 `LOOPNE` 不再跳转。

> 易错点：`LOOPNE` 同时看 `CX` 和 `ZF`；`SHR` 会让移出的最低位进入 `CF`。

## 13. `TYPE`、`LENGTH`、`SIZE`

**题目：** 对于下面的数据定义，各条 `MOV` 指令执行后，请填写相关寄存器内容。

```asm
TABLE1 DD 02H, 04H, 06H
TABLE2 DW 12 DUP(0)
TABLE3 DB 'CLASS'

MOV AX, TYPE TABLE1
MOV BX, LENGTH TABLE1
MOV CX, LENGTH TABLE2
MOV DX, SIZE TABLE2
MOV SI, LENGTH TABLE3
```

**答案：**

```text
AX = 0004H
BX = 0001H
CX = 000CH
DX = 0018H
SI = 0001H
```

**解析：**

- `TYPE TABLE1=4`，因为 `DD` 每个元素占 4 字节。
- 按平台口径，普通非 `DUP` 定义的 `TABLE1`，`LENGTH=1`。
- `TABLE2 DW 12 DUP(0)`，`LENGTH=12=000CH`，`TYPE=2`。
- `SIZE TABLE2 = LENGTH * TYPE = 12 * 2 = 24 = 0018H`。
- `TABLE3 DB 'CLASS'` 未使用 `DUP`，平台口径 `LENGTH=1`。

> 易错点：本课程平台对普通字符串定义的 `LENGTH` 取 1；带 `DUP` 时才按重复次数取值。

## 14. 求 3 个无符号字数据最大值的程序

**题目：** 设内存中有 3 个互不相等的无符号字数据，分别存放在 `DATA` 开始的字单元中，编程将其中的最大值存放在 `MAX` 单元中。

**参考程序：**

```asm
DSEG SEGMENT
DATA DW 4321H, 7658H, 9B00H
MAX  DW ?
DSEG ENDS

CSEG SEGMENT
ASSUME CS:CSEG, DS:DSEG
START:
    MOV AX, DSEG
    MOV DS, AX

    LEA SI, DATA
    MOV AX, [SI]

    MOV BX, [SI+2]
    CMP AX, BX
    JAE NEXT1
    MOV AX, BX

NEXT1:
    MOV BX, [SI+4]
    CMP AX, BX
    JAE NEXT2
    MOV AX, BX

NEXT2:
    MOV MAX, AX

    MOV AH, 4CH
    INT 21H
CSEG ENDS
END START
```

**解析：** 这段程序先假设第一个数最大，把它送入 `AX`；再依次与第二、第三个字数据比较。如果 `AX` 小于当前比较值，就更新 `AX`。最后把 `AX` 中保存的最大值送入 `MAX`。

> 易错点：题目说明是“无符号字数据”，所以比较时应使用无符号条件转移，如 `JAE`、`JB` 等；不要用有符号比较的 `JGE`、`JL`。
