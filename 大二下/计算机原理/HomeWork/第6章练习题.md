# 第六章练习题

## 1. 中断向量表求类型号和入口地址

**题目：** 有一 8086 系统的中断向量表，在 `0000H:0038H` 单元开始依次存放 `56H`、`0CEH`、`12H` 和 `0F8H` 四个字节，该向量对应的中断类型码和中断服务程序的入口地址分别为（ ）。

**选项：**

- A. `0FH, 0CE56H:0F812H`
- B. `0FH, 0F812H:0CE56H`
- C. `0EH, 0CE56H:0F812H`
- D. `0EH, 0F812H:0CE56H`

**答案：D**

**解析：** 每个中断向量占 4 字节，向量表入口地址为：

$$
类型码 \times 4
$$

所以：

$$
0038H / 4 = 0EH
$$

中断向量中前 2 字节是偏移地址，后 2 字节是段地址，且 8086 采用小端存储：

```text
偏移地址：56H, CEH -> CE56H
段地址：12H, F8H -> F812H
```

因此入口地址为 `F812H:CE56H`。

> 易错点：内存中低字节在前；真正的入口地址通常写作“段地址:偏移地址”。

## 2. 非屏蔽中断类型号来源

**题目：** 8086 CPU 响应非屏蔽中断，其中断类型号是由（ ）的。

**选项：**

- A. 外设提供
- B. CPU 自动产生
- C. 中断控制器 8259 提供
- D. 指令码中给定

**答案：B**

**解析：** 8086 的非屏蔽中断 `NMI` 的中断类型号固定为 `2`，由 CPU 内部自动产生，不需要外设或 8259A 提供类型号。

> 易错点：`INTR` 可屏蔽中断的类型号可由外部中断控制器提供；`NMI` 的类型号固定为 2。

## 3. 由中断向量表位置求中断类型号

**题目：** 某中断程序入口地址值填写在中断向量表的 `0084H~0087H` 存储单元中，则该中断对应的中断类型号一定是（ ）。

**选项：**

- A. `21H`
- B. `23H`
- C. `20H`
- D. `84H`

**答案：A**

**解析：**

$$
类型号 = 0084H / 4 = 21H
$$

> 易错点：中断向量表中每个入口占 4 字节，所以入口起始地址除以 4 才是类型号。

## 4. 中断类型号对应的向量表地址

**题目：** 8086/8088 中断类型号为 `50H` 的中断服务程序入口地址存放在中断向量表中的起始地址是（ ）。

**选项：**

- A. `0000:0140H`
- B. `DS:0050H`
- C. `0000:0050H`
- D. `DS:0140H`

**答案：A**

**解析：**

$$
50H \times 4 = 140H
$$

中断向量表固定在物理地址 `00000H~003FFH`，因此该向量入口起始地址为 `0000:0140H`。

> 易错点：类型号不是向量表偏移地址，必须先乘以 4。

## 5. 中断向量表地址范围

**题目：** 在 8086 系统中，规定中断向量表存放于内存中（ ）所在地址的内存单元。

**选项：**

- A. `80000H~803FFH`
- B. `0FF00H~0FFFFH`
- C. `00000H~003FFH`
- D. `7F000H~7F3FFH`

**答案：C**

**解析：** 8086 中断向量表从物理地址 `00000H` 开始，共 256 个中断向量，每个向量 4 字节：

$$
256 \times 4 = 1024B = 400H
$$

所以地址范围是 `00000H~003FFH`。

> 易错点：中断向量表在最低 1KB 内存空间。

## 6. 两片 8259A 级联可管理的中断数

**题目：** 两片 8259A 连接成级联缓冲方式可管理（ ）个可屏蔽中断。

**选项：**

- A. 9
- B. 16
- C. 15
- D. 8

**答案：C**

**解析：** 一片 8259A 有 8 个中断请求输入。两片级联时，主片要占用一个输入端连接从片，所以总数为：

$$
7 + 8 = 15
$$

> 易错点：两片不是简单相加成 16，因为主片要拿出 1 路接从片。

## 7. 单片 8259A 管理的中断级数

**题目：** 一片中断控制器 8259A 能管理（ ）级硬件中断。

**选项：**

- A. 8
- B. 2
- C. 10
- D. 64

**答案：A**

**解析：** 8259A 有 `IR0~IR7` 共 8 个中断请求输入端，因此单片能管理 8 级硬件中断。

> 易错点：64 是最多级联扩展时可形成的请求源数量，不是单片 8259A 的输入数。

## 8. `INT n` 指令中断

**题目：** `INT n` 指令中断是（ ）。

**选项：**

- A. 可用 IF 标志位屏蔽的
- B. 由外部设备请求产生
- C. 通过软件调用的内部中断
- D. 由系统断电引起的

**答案：C**

**解析：** `INT n` 是软件中断指令，由程序主动调用，对应的类型码 `n` 在指令中给出。

> 易错点：`INT n` 不是外设发出的中断请求，也不受 `IF` 屏蔽。

## 10. 查询传送方式的前置操作

**题目：** 在查询传送方式中，CPU 要对外设进行读出或写入操作前，必须先对外设（ ）。

**选项：**

- A. 发读/写命令
- B. 进行状态检测
- C. 发控制命令
- D. 发 I/O 端口地址

**答案：B**

**解析：** 查询传送方式下，CPU 需要不断读取外设状态，判断外设是否准备好，只有状态满足条件后才进行数据读写。

> 易错点：查询方式的关键词是“先查状态，再传数据”。

## 11. 8086 可处理的中断数量

**题目：** 8086 的中断系统可处理 ① 个不同的中断。

**答案：** ① `256`

**解析：** 8086 用 8 位中断类型码表示中断类型，因此可表示：

$$
2^8 = 256
$$

个不同中断。

> 易错点：每个中断类型对应一个 4 字节中断向量。

## 12. CPU 与外设交换的信息类型

**题目：** CPU 通过接口与外设之间交换的信息包括数据信息、状态信息和 ①，这三种信息通常都是通过 CPU 的 ② 总线来传输的。

**答案：** ① 控制信息 ② 数据

**解析：** CPU 与外设交换的信息有三类：

```text
数据信息：真正要输入/输出的数据
状态信息：外设是否忙、是否准备好等状态
控制信息：启动、停止、读写方式等控制命令
```

这些信息进入 CPU 或由 CPU 输出时，通常都经过数据总线传送。

> 易错点：状态信息和控制信息虽然名字不是“数据”，但在总线上仍常通过数据总线传输。

## 13. `OUT DX,AL` 的总线控制信号

**题目：** CPU 在执行 `OUT DX, AL` 指令时，`M/IO` 引脚为 ① 电平，`\overline{RD}` 引脚为 ② 电平，`\overline{WR}` 引脚为 ③ 电平。

**答案：** ① 低 ② 高 ③ 低

**解析：** `OUT DX,AL` 是 I/O 写操作。最小模式下：

```text
M/IO = 0       表示 I/O 操作
\overline{RD} = 1  读信号无效
\overline{WR} = 0  写信号有效
```

> 易错点：带横线的 `RD`、`WR` 是低电平有效；写操作时 `WR` 为低。

## 14. 类型 2 中断入口地址

**题目：** 若在 `0000:0008H` 开始的 4 个字节中分别存放的是 `12H`、`22H`、`36H`、`45H`，则对应的中断类型号为 2 的中断服务程序入口地址为 ①。

**答案：** ① `4536H:2212H`

**解析：** 类型 2 的向量表入口地址为：

$$
2 \times 4 = 8
$$

即从 `0000:0008H` 开始。前两个字节构成偏移地址，后两个字节构成段地址：

```text
偏移：12H,22H -> 2212H
段址：36H,45H -> 4536H
```

入口地址写作段地址:偏移地址，所以是 `4536H:2212H`。

> 易错点：向量表中存储顺序是 IP 低字节、IP 高字节、CS 低字节、CS 高字节。

## 15. 中断类型码与内部中断

**题目：** 中断系统可处理多个不同的中断，每个中断对应一个 ① 码。CPU 根据某条指令或某个状态标志的设置而产生的中断称为 ② 中断。

**答案：** ① 类型 ② 内部

**解析：** 8086 中每个中断都有一个中断类型码，用来索引中断向量表。由 CPU 内部执行指令或内部条件触发的中断称为内部中断，例如 `INT n`、溢出中断等。

> 易错点：外部中断来自 CPU 外部引脚；内部中断来自 CPU 执行指令或内部状态。

## 16. 程序控制方式的分类

**题目：** 微机系统中数据传送的控制方式有三种，其中程序控制方式的数据传送又分为无条件传送、① 和中断传送。

**答案：** ① 查询传送

**解析：** 程序控制方式下，数据传送由程序控制，常见方式包括无条件传送、查询传送和中断传送。查询传送通过反复检测外设状态决定是否进行传输。

> 易错点：查询传送会浪费 CPU 时间；中断传送能减少 CPU 主动等待。

## 17. 中断向量占用字节数

**题目：** 中断向量是中断服务程序的入口地址，每个中断向量占 ① 个字节。

**答案：** ① `4`

**解析：** 8086 中断服务程序入口地址由 `CS:IP` 组成，其中 `IP` 2 字节，`CS` 2 字节，共 4 字节。

> 易错点：向量表一个入口不是 2 字节，而是 4 字节。

## 18. 可屏蔽中断与不可屏蔽中断优先级

**题目：** 可屏蔽中断的优先级比不可屏蔽中断的优先级 ①。

**答案：** ① 低

**解析：** 不可屏蔽中断 `NMI` 用于紧急事件，不能被 `IF` 标志屏蔽，优先级高于可屏蔽中断 `INTR`。

> 易错点：`IF` 只能屏蔽 `INTR`，不能屏蔽 `NMI`。

## 19. 程序查询方式和中断方式中 CPU 的地位

**题目：** 简述 CPU 在程序查询方式和中断方式中所处的地位。

**答案：**

程序查询方式中，CPU 处于主动地位。CPU 必须不断读取并检测外设状态，确认外设准备好后才进行数据传送。

中断方式中，CPU 处于被动/主导结合的地位。CPU 平时执行自己的程序，外设准备好后主动提出中断请求，CPU 响应后转去执行中断服务程序。

> 易错点：查询方式浪费 CPU 时间；中断方式让外设“准备好了再叫 CPU”。

## 20. CPU 与外设之间的数据传送方式

**题目：** CPU 与外设之间有哪几种传送方式？各有什么特点？

**答案：**

- 无条件传送：最简单，默认外设始终就绪，CPU 直接读写，不检测状态。
- 查询传送：CPU 通过程序不断查询外设状态，外设准备好后再传送；硬件简单，但浪费 CPU 时间。
- 中断传送：外设准备好后向 CPU 发中断请求，CPU 响应后传送；减少 CPU 等待，提高利用率，但需要中断控制和现场保护。
- DMA 传送：数据在内存和外设之间直接传送，不经过 CPU 的寄存器；速度快，适合大批量数据传送，但需要 DMA 控制器接管总线。

> 易错点：DMA 不是 CPU 一条条搬数据，而是 DMA 控制器控制总线直接搬运。

## 21. 中断及其中断处理过程

**题目：** 什么是中断？简述中断的处理过程。

**答案：** 中断是 CPU 在执行当前程序时，由于内部或外部事件的请求，暂时停止当前程序，转去执行相应服务程序，处理完后再返回原程序继续执行的过程。

中断处理过程通常包括：

```text
中断请求 -> 中断判优 -> 中断响应 -> 保护现场 -> 执行中断服务程序 -> 恢复现场 -> 中断返回
```

> 易错点：保护现场和恢复现场是为了让 CPU 能回到原程序继续正确执行。

## 22. 8259A 类型码、IR 输入端和向量内容

**题目：** 若 8086 系统采用单片 8259A，其中断类型码为 `42H`，试问其中断向量表的中断向量地址是多少？这个中断源应连向 IRR 的哪一个输入端？若中断服务程序的入口地址为 `CB08H:4C11H`，则其向量区对应的 4 个单元的值依次为多少？

**答案：**

```text
中断向量地址：0000:0108H
IR 输入端：IR2
4 个单元依次为：11H, 4CH, 08H, CBH
```

**解析：** 中断类型码为 `42H`，向量表入口地址为：

$$
42H \times 4 = 108H
$$

所以中断向量地址是 `0000:0108H`。

8259A 的中断类型码低 3 位对应 `IR0~IR7`：

```text
42H = 0100 0010B
低 3 位 = 010B = 2
```

所以连接 `IR2`。

入口地址 `CB08H:4C11H` 中：

```text
IP = 4C11H
CS = CB08H
```

按小端顺序存入向量表：

```text
11H, 4CH, 08H, CBH
```

> 易错点：向量表中先存偏移 IP，再存段地址 CS，并且每个字都是低字节在前。

## 23. DMA 工作方式的主要特点

**题目：** 简述 DMA 工作方式的主要特点。

**答案：** DMA 方式的主要特点是数据在内存与外设之间直接高速传送，不经过 CPU 内部寄存器。传送过程中由 DMA 控制器接管总线控制权，从而提高大批量数据传输效率，并释放 CPU 的计算资源。

> 易错点：DMA 仍然需要 CPU 初始化传送参数，但正式传送时主要由 DMA 控制器完成。

## 24. 8259A 的 ICW2 作用

**题目：** 8259A 的 `ICW2` 设置了中断类型码的哪几位？说明对 8259A 分别设置 `ICW2` 为 `30H`、`38H` 有什么差别？

**答案：** `ICW2` 用于设置中断类型码的高 5 位，即 `D7~D3`；低 3 位由 8259A 根据中断请求输入端 `IR0~IR7` 自动填入。

若 `ICW2=30H`：

```text
IR0~IR7 对应类型码：30H~37H
```

若 `ICW2=38H`：

```text
IR0~IR7 对应类型码：38H~3FH
```

> 易错点：`ICW2` 不是给某一个 IR 端指定完整类型码，而是给一组 8 个中断类型码指定基址。
