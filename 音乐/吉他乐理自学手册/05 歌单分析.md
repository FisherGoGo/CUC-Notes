# 05 歌单分析

这个文件用来长期积累参考歌。目标不是完整扒谱，而是从每首歌里提取一个能马上用于写歌的素材。

## 使用方法

每首歌只记录 20-30 分钟内能听出来的东西。不要因为没法完整扒谱就停下来。

最低要求：

- 写出大致调性；
- 写出主歌或副歌的一组和弦；
- 记录最好听的 2 小节；
- 写一个“我可以改写成什么”。

## 分析模板

```markdown
## 歌名 - 乐队

- 调性：
- 调弦/capo：
- BPM：
- 主歌级数：
- 副歌级数：
- 最值得学的 2 小节：
- 吉他编配：
- 我可以改写成：
```
