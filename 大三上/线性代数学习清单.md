# 线性代数暑假学习清单

> 目标：用 2～3 周复习到能看懂图形学、数字图像处理和 NLP 中的矩阵公式，并能用 NumPy 实现核心操作。
>
> 原则：先理解几何意义，再做基础题，最后用代码验证；不以刷证明题和偏题为目标。

## 开始前

- [ ] 安装或确认可用 Python、Jupyter Notebook 与 NumPy
- [ ] 新建一个练习 Notebook：每个主题至少写 2 个例子
- [ ] 准备一张 A4 公式速查表，学习中持续补充

---

## 第一部分：向量与矩阵基础

### 向量、内积与几何

- [ ] 理解向量的加法、数乘、长度与单位向量
- [ ] 会计算点积，并能用它判断夹角、正交和相似度
- [ ] 理解向量投影的几何意义，并会计算投影
- [ ] 用 NumPy 实现点积、范数与投影

**课程连接**：图形学中的方向与光照；NLP 中词向量相似度。

### 矩阵与线性变换

- [ ] 会做矩阵加法、乘法、转置和分块理解
- [ ] 理解矩阵乘向量是一次线性变换，而不只是算式
- [ ] 能解释矩阵乘法的顺序为什么重要
- [ ] 用二维点演示缩放、旋转、错切和镜像
- [ ] 理解齐次坐标，并会写出二维/三维平移矩阵

**课程连接**：计算机图形学的模型、观察、投影变换。

---

## 第二部分：线性方程组与向量空间

### 线性方程组

- [ ] 会用高斯消元把矩阵化为行阶梯形
- [ ] 能判断方程组有唯一解、无解或无穷多解
- [ ] 理解主元、自由变量和增广矩阵
- [ ] 知道逆矩阵何时存在，并会用它求小规模方程组的解
- [ ] 使用 `numpy.linalg.solve` 解方程组，并理解它比显式求逆更合适

### 向量空间、基与维数

- [ ] 理解线性组合、张成、子空间
- [ ] 会判断线性无关与线性相关
- [ ] 理解基、坐标与维数
- [ ] 知道秩表示什么，并理解秩与独立列的关系
- [ ] 能说清列空间、零空间分别描述什么

**课程连接**：特征表示、图像矩阵，以及模型参数中的有效自由度。

---

## 第三部分：正交、最小二乘与分解

### 正交与最小二乘

- [ ] 理解正交基为何能简化计算
- [ ] 会使用 Gram–Schmidt 正交化
- [ ] 理解最小二乘是在寻找“误差最小的近似解”
- [ ] 会推导并使用正规方程的形式
- [ ] 了解 QR 分解比直接求正规方程更稳定

**课程连接**：数据拟合、回归、降噪。

### 特征值与特征向量

- [ ] 理解特征向量是“变换后方向不变”的向量
- [ ] 会计算 2×2 矩阵的特征值和特征向量
- [ ] 理解对角化的意义：换一组基后让变换更简单
- [ ] 知道实对称矩阵的特征向量可以正交
- [ ] 用 NumPy 的 `eig` / `eigh` 验证计算结果

**课程连接**：PCA、图像处理中的变换、图模型与网络分析。

### SVD 与 PCA

- [ ] 理解 SVD：任何矩阵都可以看成旋转/缩放/再旋转
- [ ] 知道奇异值描述不同方向上的信息强弱
- [ ] 用 SVD 完成一张灰度图的低秩近似/压缩
- [ ] 理解 PCA 的目标是保留方差最大的方向
- [ ] 能说清 PCA 的基本步骤：中心化 → 分解 → 选主成分 → 投影

**课程连接**：数字图像压缩与降噪、机器学习特征降维。

---

## 第四部分：面向下学期的补充

- [ ] 复习多元函数偏导、梯度和链式法则（为深度学习做准备）
- [ ] 了解卷积可写成矩阵运算，但不必手推大型 Toeplitz 矩阵
- [ ] 了解傅里叶变换的矩阵/基函数视角（为图像处理做预热）
- [ ] 使用 PyTorch 创建张量，完成矩阵乘法、广播与自动求导各一个例子

## 结业自测

- [ ] 能向别人解释“矩阵是线性变换”
- [ ] 能手算一个 2×2 矩阵的特征值与特征向量
- [ ] 能解释投影、最小二乘、PCA 与 SVD 的用途
- [ ] 能用 NumPy 完成：解方程组、求特征分解、SVD 图像压缩
- [ ] 能看懂图形学中的旋转/投影矩阵，或深度学习代码中的张量乘法
