> 适用对象：中传数字媒体技术大二学生，已有 ACM/ICPC 竞赛基础，目标为中国科学技术大学软件工程方向研究生。
>
> 更新时间：2026-06-04
>
> 重要说明：招生政策每年可能变化，最终以中国科学技术大学研究生招生在线、当年硕士招生简章、专业目录、复试细则为准。

## 0. 先给结论

目标可以先按 **中国科学技术大学 225 软件学院 085405 软件工程（专业学位）常规班** 准备。

我当前应按下面这组初试科目长期准备：

- 101 思想政治理论
- 201 英语一
- 301 数学一
- 408 计算机学科专业基础综合

这意味着备考核心不是单独找“中科大软件工程自命题资料”，而是打标准的 **英一 + 数一 + 408** 硬仗。

结合我的情况：

- 优势：ACM/ICPC 竞赛基础较好，数据结构、算法、代码实现、机试意识会比普通同学强。
- 短板：考研流程不熟；计算机组成、操作系统、计算机网络等 408 核心课还需要系统补；数学一需要长期投入。
- 总策略：大二下到大三上补基础，大三寒假正式进入考研主线，大三暑假开始高强度强化，大四上冲刺。

## 1. 考研基本流程

### 1.1 考研分为两段

1. **初试**：全国统一考试，通常在每年 12 月下旬。
2. **复试**：初试过线后由学校学院组织，通常在次年 3 月左右。

初试决定能不能进复试，复试决定最终能不能录取。

### 1.2 我需要重点关注的信息

- 报考学校：中国科学技术大学
- 报考院系：225 软件学院
- 报考专业：085405 软件工程
- 学习方式：全日制
- 入学方式：统考
- 初试科目：政治、英语一、数学一、408
- 复试内容：以当年软件学院复试细则为准

### 1.3 时间线

| 时间 | 任务 |
|---|---|
| 大二下 - 大三上 | 确认目标、补数学和计科基础、了解考研流程 |
| 大三寒假 | 正式进入数学一和 408 第一轮 |
| 大三下 3-6 月 | 一轮复习：数学基础 + 408 基础 + 英语长期积累 |
| 暑假 7-8 月 | 强化期：数学刷题、408 建体系、英语阅读训练 |
| 大四上 9-10 月 | 查看当年招生简章，完成预报名/正式报名，政治开始强化 |
| 大四上 11 月 | 网上确认，真题套卷，查漏补缺 |
| 大四上 12 月 | 初试冲刺 |
| 次年 2 月 | 查分，判断复试/调剂策略 |
| 次年 3 月 | 复试准备与复试 |

## 3. 各科备考策略

## 3.1 数学一

数学一通常是最耗时间、最拉分的科目之一。

### 内容范围

- 高等数学
- 线性代数
- 概率论与数理统计

### 当前策略

不要一开始就追求难题，先把概念和计算能力补起来。

优先补：

1. 极限、连续、导数、积分
2. 多元函数微积分
3. 级数
4. 线代：矩阵、向量、特征值、二次型
5. 概率：随机变量、分布、期望方差、常见统计量

### 注意事项

- 数学不是看懂就会，必须大量手算。
- 视频课只是输入，刷题和订正才是训练。
- 错题按“概念错 / 计算错 / 方法不会 / 审题错”分类。
- 数一范围大，不要误看只适合数二的经验贴。

---

## 3.2 英语一

英语一靠长期积累，短期突击收益有限。

### 备考重点

1. 单词：每天背，不断档。
2. 长难句：能拆主干、从句、修饰结构。
3. 阅读：真题是核心材料。
4. 作文：后期形成自己的模板。
5. 翻译、新题型、完形：中后期专项训练。

### 我的注意点

我正在准备 JLPT N3，有语言学习习惯，但考研英语一和日语考级完全不同。考研英语最重要的是阅读逻辑和长难句，不是单纯背词。

### 阶段安排

- 现在开始：每天背单词。
- 大三上：开始精读早年真题阅读。
- 大三下：系统做阅读，积累长难句。
- 暑假后：阅读真题二刷，开始作文和翻译。
- 11-12 月：作文模板、套卷节奏、错题复盘。

## 3.3 408 计算机学科专业基础综合

408 包括四门：

1. 数据结构
2. 计算机组成原理
3. 操作系统
4. 计算机网络

### 我的优势和短板

优势：

- 数据结构和算法基础应该相对强。
- 代码实现能力、复杂度分析、图论、DP 等竞赛能力对数据结构部分有帮助。

短板：

- 408 的数据结构不是纯竞赛算法，常考概念、存储结构、复杂度、树图结构、排序查找等基础细节。
- 计算机组成原理、操作系统、计算机网络需要从课程体系开始补。
- 408 是选择题 + 综合题，要求概念严谨，不是只会写代码就行。

### 学习顺序建议

推荐顺序：

1. 数据结构
2. 计算机组成原理
3. 操作系统
4. 计算机网络
5. 四科综合刷题

也可以按学校课程同步调整，但不要拖到大三暑假才第一次接触组成、OS、网络。

### 408 重点提醒

- 数据结构：不要只按竞赛难度理解，要回到教材定义。
- 组成原理：重视数据表示、指令系统、CPU、存储系统、I/O。
- 操作系统：进程线程、调度、同步互斥、死锁、内存管理、文件系统。
- 计算机网络：OSI/TCP-IP、链路层、网络层、传输层、应用层。
- 408 真题非常重要，要反复刷、反复归纳。

## 3.4 政治

政治不建议太早投入大量时间。

### 时间安排

- 大三下以前：基本不用系统复习。
- 暑假后：开始听基础/强化。
- 9-10 月：选择题训练。
- 11-12 月：肖八、肖四、腿姐/徐涛等冲刺资料，主攻选择题和大题背诵。

### 注意事项

- 政治前期不要抢数学和 408 时间。
- 选择题决定基础分，大题后期集中背。
- 时政内容必须看当年资料。

## 4. 基于我个人情况的能力建设清单

### 4.1 现在最该补的课

按优先级：

1. 高等数学 / 线性代数 / 概率论
2. 数据结构的考研表述体系
3. 计算机组成原理
4. 操作系统
5. 计算机网络
6. 数据库、软件工程、编译原理等扩展课

数据库虽然不属于 408，但对软件工程学习、项目、复试交流、就业都很重要，可以在不挤占主线的情况下补。

### 4.2 ACM 经验怎么转化成考研优势

可以转化为：

- 数据结构理解优势
- 机试优势
- 代码表达优势
- 复试项目/竞赛经历亮点
- 学习强度和抗压能力优势

但要注意：

- 竞赛不能替代 408。
- 不要因为算法强就轻视组成、OS、网络。
- 复试时要能把竞赛经历讲成“解决问题能力”，而不是只报奖项。

### 4.3 项目建议

为了复试和就业，建议至少做 1-2 个能讲清楚的项目：

1. CF/AtCoder 刷题辅助平台
   - 题目抓取
   - 标签筛选
   - 随机组题
   - 用户提交思路
   - LLM 辅助判断思路完整性
   - 错题本和训练计划

2. 校园课程笔记/资料管理系统
   - Markdown 笔记管理
   - 搜索
   - 标签
   - 知识图谱
   - GitHub 同步

3. 简单分布式/后端项目
   - 用户系统
   - 数据库
   - 缓存
   - 日志
   - Docker 部署

项目目标不是堆功能，而是复试时能讲清楚：

- 为什么做
- 架构怎么设计
- 遇到什么问题
- 怎么优化
- 学到了什么

## 8. 注意事项

### 8.1 关于目标院校

- 中科大难度不低，要尽早准备。
- 不要只看“软件工程专硕”四个字就低估难度。
- 要持续关注是否有招生名额、考试科目、复试规则变化。
- 特色化创新试点班如果只接收推免，就不要按统考目标投入。

### 8.2 关于学习方法

- 不要收藏很多资料但不做题。
- 不要只看视频不输出。
- 不要用 ACM 的优势掩盖基础课短板。
- 不要等到大三暑假才开始 408。
- 数学和 408 要长期稳定投入。

### 8.3 关于学校课程

我本科是数字媒体技术，和纯计科相比，可能有些经典 CS 课程不够系统。学校课程不能完全等同于考研复习，要主动补：

- 计算机组成原理
- 操作系统
- 计算机网络
- 数据库
- 软件工程

### 8.4 关于竞赛

竞赛仍然有价值，但大三后要控制投入。

建议：

- 保留高质量训练，不要无目的刷题。
- 适当参加比赛，保持代码能力。
- 不要让竞赛挤占数学一和 408 主线。

### 8.5 关于心态

- 考研不是智商赛，是长期执行赛。
- 前期不要用“今天学了多久”安慰自己，要看“今天解决了什么问题”。
- 中后期不要频繁换资料。
- 不要每天和别人比较进度，只和自己的计划比较。
