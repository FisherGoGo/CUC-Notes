# 第3章 8086/8088 寻址方式

> 本章只整理 8086/8088 的寻址方式。常用指令已单独拆到《第3章 8086-8088指令系统》。

## 8086/8088 的寻址方式

### 寻址方式概念（重点）

一条汇编语言指令需要关注两个问题：

- 这条指令要进行什么操作。
- 操作对象是什么，操作结果放在哪里。

**操作数的寻址方式**就是寻找操作数所在位置的方法。

换句话说，CPU 执行指令时，除了要知道“做什么操作”，还要知道“拿谁来操作”。这个“操作数”可能直接写在指令里，也可能在寄存器里，或者在内存某个地址里。寻址方式就是说明操作数从哪里找。

例如：

```asm
MOV AX, 5
```

这里 `5` 直接写在指令中，是立即寻址。

```asm
MOV AX, BX
```

这里操作数在寄存器 `BX` 中，是寄存器寻址。

```asm
MOV AX, [2000H]
```

这里操作数在内存地址 `2000H` 对应的单元中，是直接寻址。

### 七种寻址方式（必考）

8086/8088 常见寻址方式有七种：

| 寻址方式 | 含义 | 典型例子 |
|---|---|---|
| 立即寻址 | 操作数直接写在指令中 | `MOV AX, 306AH` |
| 寄存器寻址 | 操作数在寄存器中 | `MOV AX, BX` |
| 直接寻址 | 操作数的偏移地址直接写在指令中 | `MOV AX, [1000H]` |
| 寄存器间接寻址 | 操作数地址在寄存器中 | `MOV AX, [BX]` |
| 基址寻址和变址寻址 | 寄存器 + 位移量形成有效地址 | `MOV AX, [SI+3000H]` |
| 基址变址寻址 | 基址寄存器 + 变址寄存器 + 位移量形成有效地址 | `MOV AX, 8[BX+SI]` |
| 固定寻址 | 操作数位置由指令隐含规定 | `DAA`、`MUL BL` |

> 易错：寻址方式不是“找指令的位置”，而是“找操作数的位置”。

### 立即寻址（重点）

- **立即寻址**：操作数直接包含在指令中，这种操作数称为**立即数**。
- 立即数可以是 8 位数值：`00H~FFH`。
- 立即数也可以是 16 位数值：`0000H~FFFFH`。
- 常用于给寄存器或存储单元赋值。

例：

```asm
MOV AL, 80H      ; 将 80H 送入 AL
MOV AX, 306AH    ; 将 306AH 送入 AX
```

注意：

- 立即数作为操作数时，这种寻址方式称为立即寻址。
- 立即数本身就在指令里，所以其实不用再“寻址”。
- **立即数只能作为源操作数，不能作为目的操作数。**

> 易错：`MOV 80H, AL` 这种写法错误，因为立即数不能作为目的操作数。

### 寄存器寻址（重点）

- **寄存器寻址**：操作数在 CPU 内部寄存器中。
- 指令直接指出使用哪个寄存器。

常见寄存器：

| 类型 | 寄存器 |
|---|---|
| 8 位寄存器 | AH、AL、BH、BL、CH、CL、DH、DL |
| 16 位寄存器 | AX、BX、CX、DX、SI、DI、BP、SP |
| 段寄存器 | CS、DS、SS、ES |

例：

```asm
MOV AL, BL      ; 将 BL 的内容送入 AL
MOV BX, AX      ; 将 AX 的内容送入 BX
```

错误例子：

```asm
MOV AL, BX      ; 错误，AL 是 8 位，BX 是 16 位，位数不匹配
```

> 易错：寄存器之间传送数据时，源操作数和目的操作数的位数要一致。

### 直接寻址（重点）

- **直接寻址**：操作数在内存中，指令中直接给出操作数所在内存单元的偏移地址。
- 地址可以是数值形式，也可以用符号表示。
- 用符号表示的地址称为**符号地址**。

例：

```asm
MOV AX, [1000H]
```

含义：从默认数据段 `DS` 中，偏移地址为 `1000H` 的内存单元取数据，送入 `AX`。

默认情况：

- 直接寻址默认段寄存器是 `DS`。
- 可以用**段前缀**改变默认段。

例：

```asm
MOV AX, BUFA       ; 默认 BUFA 在 DS 数据段中
MOV AX, ES:BUFA    ; 使用段前缀 ES，BUFA 在附加段中
```

注意：

- 如果偏移地址用数值形式表示，一般加方括号，如 `[1000H]`。
- 如果偏移地址用符号地址表示，可以不加方括号。

> 易错：直接寻址给出的是偏移地址，不是完整物理地址；默认段基址来自 DS。

### 寄存器间接寻址（重点）

- **寄存器间接寻址**：操作数在内存中，内存单元的偏移地址存放在寄存器中。
- 可作为间址寄存器的有：`BX、SI、DI、BP`。

默认段寄存器：

| 间址寄存器 | 默认段寄存器 |
|---|---|
| BX、SI、DI | DS |
| BP | SS |

可以使用段前缀改变默认段。

例：

```asm
MOV AX, [BX]
```

若 `(DS)=2000H`，`(BX)=1000H`，则访问数据段物理地址 `21000H、21001H` 两个单元，内容送入 `AX`。

```asm
MOV CX, [BP]
```

若 `(SS)=4000H`，`(BP)=1000H`，则访问堆栈段物理地址 `41000H、41001H` 两个单元，内容送入 `CX`。

```asm
MOV AX, ES:[SI]
```

若 `(ES)=3000H`，`(SI)=1000H`，则访问附加段物理地址 `31000H、31001H` 两个单元，内容送入 `AX`。

> 易错：`[BX]、[SI]、[DI]` 默认用 DS；`[BP]` 默认用 SS。

### 基址寻址和变址寻址（重点）

- 有效地址由寄存器内容加上指令中给出的 8 位或 16 位位移量构成。

```text
有效地址 = BX/BP/SI/DI + 8/16 位位移量
```

区分：

| 使用寄存器 | 寻址方式 |
|---|---|
| BX、BP | 基址寻址 |
| SI、DI | 变址寻址 |

默认段寄存器：

| 寄存器 | 默认段 |
|---|---|
| BX、SI、DI | DS |
| BP | SS |

可用段前缀改变默认段。

例：

```asm
MOV AX, [BP+3000H]
MOV AX, [SI+3000H]
```

> 易错：只要有效地址中使用 `BP`，默认段寄存器就是 `SS`；使用 `BX、SI、DI` 默认是 `DS`。

### 基址变址寻址（重点）

- **基址变址寻址**：有效地址由基址寄存器加变址寄存器，再加可选位移量构成。

```text
有效地址 = BX/BP + SI/DI + 8/16 位位移量
```

默认段寄存器：

| 情况 | 默认段 |
|---|---|
| 使用 BX | DS |
| 使用 BP | SS |

可用段前缀改变默认段。

适用于数组或表格存取。

例：

```asm
MOV AX, 8[BX+SI]      ; 默认操作数在数据段 DS 中
MOV BX, -6[BP+DI]     ; 默认操作数在堆栈段 SS 中
MOV BX, ES:[BP+DI]    ; 使用段前缀 ES，操作数在附加段中
```

> 易错：基址变址寻址中，默认段主要看基址寄存器：有 `BP` 默认 `SS`，用 `BX` 默认 `DS`。

### 固定寻址（了解）

- **固定寻址**又叫**隐含寻址**。
- 指令码中不直接写出操作数地址。
- 操作数地址由指令本身隐含规定。

例：

```asm
DAA
```

十进制调整指令，隐含对 `AL` 中的内容进行十进制调整，结果仍放在 `AL` 中。

```asm
MUL BL
```

表示 `AL × BL`，结果存放在 `AX` 中。这里 `AL` 和 `AX` 都是由 `MUL` 指令隐含规定的。

> 易错：固定寻址不是没有操作数，而是操作数位置不用写出来，由指令默认规定。
