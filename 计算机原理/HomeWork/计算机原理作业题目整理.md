## 第 2 章作业：8086 基础、存储器、总线与时序

### 核心考点

- 8086 与 8088 的地址总线、数据总线、存储空间。
- BIU / EU 结构与寄存器。
- 8086 最小模式下的控制信号：`M/IO`、`RD`、`WR`、`DT/R`。
- 存储器访问时序、READY 插入等待周期。
- 存储器分段与物理地址计算。
- CPU 引脚信号：`HOLD`、`HLDA`、`RESET`、`INTR`、`NMI`。

### 题目索引

1. 判断 8086 最大工作频率对应芯片型号。
2. 判断 8086 CPU 中属于 EU 的部件。
3. 判断 8086 标志寄存器中的状态标志。
4. READY 信号导致等待周期插入的位置。
5. 判断属于 BIU 的寄存器：`CS`、`DS`、`BP`、`IP`。
6. 最小模式读存储器总线周期中 `M/IO`、`RD`、`WR` 的状态组合。
7. 最小模式读 I/O 端口周期中 `WR`、`M/IO`、`RD` 的状态组合。
8. 最小模式存储器写周期中 `M/IO`、`RD`、`DT/R` 的状态组合。
9. 判断 8086 CPU 中能参与物理地址形成的寄存器。
10. 判断 CPU 访问内存时 `RD`、`WR` 有效对应的状态周期。
11. 8086/8088 的处理器组成：总线接口部件 BIU 和执行部件 EU。
12. 8086 复位信号引脚与有效电平：`RESET`，高电平有效。
13. `PUSH` 与 `POP` 对栈指针的影响方向。
14. 最大方式下请求/响应总线的信号线：`RQ/GT0`、`RQ/GT1`。
15. CPU 内部参与算术与逻辑运算的部件：运算器 / ALU。
16. DMA 操作相关总线请求与响应信号：`HOLD`、`HLDA`。
17. `ALE` 信号用于锁存地址。
18. 物理地址 `23201H` 与 `2FE0H:001BH` 判断逻辑地址可行性。
19. 由物理地址 `13140H ~ 1419FH` 推导可行段地址范围。
20. 由物理地址 `120A0H ~ 1249FH` 推导可行段地址范围。
21. 8086 时钟频率 5MHz、总线周期与等待周期数量计算。

## 第 3 章作业：8086 指令系统、标志位、寻址与栈

### 核心考点

- 条件转移：`JNO`、`JNC`。
- 无条件转移：`JMP BX`。
- 逻辑运算：`MOV`、`NOT`、`XOR`、`OR`。
- 标志位影响：`INC`、`CLC`、`STC`、`ADD`、`RCR`。
- 栈操作：`PUSH`、`POP`、`PUSHF`、`POPF`。
- 段地址、偏移地址、物理地址换算。
- 寻址方式：立即、寄存器、直接、寄存器间接、基址/变址/相对寻址。
- BCD 调整：`DAA`。

### 题目索引

1. 已知：

   ```asm
   ADD AL, BL
   JNO L1
   JNC L2
   ```

   判断不同 `AL`、`BL` 初值下程序转向 `L2` 的情况。

2. 若 `(BX)=1224H`、`(IP)=3478H`，执行 `JMP BX` 后寄存器变化。

3. 执行：

   ```asm
   MOV AL, BL
   NOT AL
   XOR AL, BL
   OR  BL, AL
   ```

   求 `(AL)`、`(BL)`。

4. 设 `(SS)=238BH`、`(SP)=0100H`，执行 `PUSH BX` 和 `PUSHF` 后，求堆栈顶部物理地址。

5. `INC` 指令不影响的标志位：`CF`。

6. 能够将 `CF` 置 1 的指令：`STC`。

7. 将变量 `BUF` 的偏移地址送入 `DI` 的指令：`LEA DI, BUF`。

8. 判断哪些指令会影响标志位，例如 `ADD AL, AH`。

9. 已知某操作数物理地址为 `4117AH`，判断可能的段地址和偏移地址组合。

10. 已知 `(SS)=2000H`、`(SP)=2000H`、`(BX)=283FH`，指令 `CALL WORD PTR [BX]` 的机器代码为 `1234H`，起始地址为 `1000H`，求执行后内存单元 `21FFFH` 内容。

11. 设 `(AX)=0B53FH`，执行 `ADD AH, AL` 后判断 `CF`、`OF`、`ZF`。

12. 假定 `(SP)=0200H`、`(AX)=2A57H`，执行 `PUSH AX` 后，数据 `2AH` 和 `57H` 的偏移地址。

13. 假定 `(SP)=0100H`、`(AX)=2107H`，执行 `PUSH AX` 后，存放数据 `21H` 的偏移地址。

14. 若 `(AX)=-15H`，要得到 `(AX)=15H` 应执行：`NEG AX`。

15. 设 `AL=82H`、`CF=1`，执行 `RCR AL,1` 后求 `AL` 与 `CF`。

16. 将累加器 `AX` 清零的错误指令辨析：`CMP AX,AX` 只比较，不保存清零结果。

17. 已知寄存器：

   ```text
   DS=2000H, SS=1500H, ES=3000H,
   SI=00F0H, BX=1000H, BP=0020H
   ```

   分析：

   ```asm
   MOV AX, [BP+20H]
   MOV AX, [SI+50H]
   MOV AX, 8[BX][SI]
   ```

   截图中填空结果包括：

   - `[BP+20H]`：寄存器相对寻址，物理地址 `15040H`。
   - `[SI+50H]`：寄存器相对寻址，物理地址 `20140H`。
   - `8[BX][SI]`：相对基址变址寻址，物理地址 `210F8H`。

18. 设 `(AX)=0219H`，分析程序段执行后 `AX`、`CF`、`AF`：

   ```asm
   MOV CH, AH
   ADD AL, AH
   DAA
   XCHG AL, AH
   ADC AL, 25H
   DAA
   XCHG AH, AL
   HLT
   ```

   截图中结果：`AX=2721H`、`CF=0`、`AF=0`。

19. 执行：

   ```asm
   MOV AX, 2255H
   MOV CL, 2
   ROL AX, CL
   DEC AX
   MOV CX, 16
   MUL CX
   HLT
   ```

   截图中结果：`AH=95H`、`AL=30H`、`DX=0008H`、`CF=1`。

20. 已知寄存器同第 17 题，分析：

   ```asm
   MOV AX, DS:[0100H]
   MOV AX, ES:[SI]
   MOV AX, [BP][SI]
   ```

   截图中填空结果包括：直接寻址 `20100H`、寄存器间接寻址 `300F0H`、基址变址寻址 `15110H`。

21. 分析：

   ```asm
   MOV SP, 5000H
   PUSHF
   POP AX
   OR AL, 01H
   PUSH AX
   POPF
   ```

   截图中结果：`SP=5000H`、`CF=1`。

22. 分析：

   ```asm
   MOV AL, 200
   SHR AL, 1
   MOV BL, AL
   MOV CL, 2
   SHR AL, CL
   ADD AL, BL
   ```

   截图中结果：`AL=7DH`、`BL=64H`、`CF=0`。

23. 指出指令中源操作数寻址方式：

   ```asm
   MOV AL, BL
   MOV AX, BUFA
   MOV AL, 22H
   MOV AX, ES:[SI]
   MOV BX, [BX+SI+6]
   ```

## 第 4 章作业：汇编程序结构、数据定义与程序跟踪

### 核心考点

- `NUMB`、`DB`、`DUP`、`LENGTH`、`OFFSET`。
- 循环控制、条件转移与数组处理。
- 变量地址与物理地址推导。
- 数据段、代码段、附加段声明。
- 表驱动与查表程序。

### 题目索引

1. 程序：

   ```asm
   NUMB=66
   MOV BX, NUM_LE 50
   ```

   判断 `BX` 内容。

2. 判断二进制数、计算机中的补码表示相关概念。
3. 已知数据段中变量定义，判断 `VAR` 偏移地址。
4. 根据 `DB` / `DUP` 定义，判断变量数组中元素内容。
5. 已知 `BUF DB 'ABC'`，分析 `MOV CL, LENGTH BUF` 后 `CL` 内容。
6. 已知 `BUF DW 5,2,3`，分析 `MOV CL, SIZE BUF` 后 `CL` 内容。
7. 已知 `DATA DW 200BH`，分析 `MOV BL, BYTE PTR DATA` 后 `BL` 内容。
8. 程序循环加法与 `LOOP` 分析，求 `AX` 与 `CX`。
9. 数组累加 / 进位相关程序，求 `AX`、`DX`、`CF`。
10. 数据段定义 `BSEG SEGMENT`，结合 `X`、`Y`、`Z` 数组和 `SUM` 变量分析 `MOV SUM, AL` 执行结果。
11. 循环统计程序：根据 `BUF1`、`BUF2`、`CL` 等，求 `AX`、`DX`。
12. 数据段与代码段程序跟踪：根据 `BEGIN`、`AGAIN`、`LOOP`，求 `AX`、`CX`、`DX`、`CF` 等。
13. 表地址与查表程序：`TABLE1`、`TABLE2`、`TABLE3`，分析 `XLAT` 与 `MOV` 后寄存器结果。
14. 编写程序：统计 `DATA SEGMENT` 中满足条件的数据个数或求和。

## 第 5 章作业：存储器系统与地址译码

### 核心考点

- DRAM 地址复用、行地址与列地址。
- 内存与外存的速度、容量、成本关系。
- ROM、EPROM、SRAM、DRAM 的性质。
- 存储芯片容量换算。
- 存储器芯片片选、地址线数量、芯片数量。
- 用译码器实现地址空间分配。

### 题目索引

1. CPU 访问由 256K x 1bit DRAM 构成的 512K x 8bit 存储系统，求 CPU 地址引脚数与 DRAM 地址引脚数。
2. 内存与外存速度、容量、价格关系判断。
3. EPROM 不同于 ROM 的原因。
4. 半导体存储器分类：`SRAM`、`DRAM`、`ROM`。
5. 若 2K x 1bit RAM 构成 4K x 16bit 存储器，求芯片数量。
6. 若 1K x 1bit RAM 构成 4K x 16bit 存储器，求芯片数量。
7. 判断断电后仍能保存信息的存储器组合。
8. 存储容量计算：地址线与字长分别对应程序/数据容量。
9. 用 32K x 4bit 存储芯片构成字长 16bit 的存储系统，求容量与芯片数。截图中填空：`16KB`、`13`。
10. 计算机内存一般由只读存储器和随机存储器构成。
11. 用 16K x 2bit 芯片构成 16 位字长存储系统，求容量与芯片数量。
12. 某系统地址线 16 根，使用 SRAM 2114，问最大存储容量和芯片数。
13. 8088 系统用 6264 芯片扩展存储器，结合地址译码图分析。
14. 用 4 片 16 位地址线、16 位字长存储器设计 4K RAM，并计算地址线、芯片数和寻址范围。
15. 根据 EPROM 连接图判断容量与地址空间。截图中答案含：`4KB`、`A800H-BFFFH`。
16. 用 4 片 16K x 8bit 芯片扩展存储器，设计系统并计算容量、地址线和芯片选择。

6. LED 静态显示电路中，结合端口地址和段码表推导显示字符。
7. 8255A 数据传送工作方式判断。
