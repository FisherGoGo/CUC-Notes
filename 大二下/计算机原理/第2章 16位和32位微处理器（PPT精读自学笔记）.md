## 0. 先把本章看成一个问题链

本章不是在孤立背寄存器、引脚和芯片型号，而是在回答同一个核心问题：

```text
8086/8088 的内部寄存器只有 16 位
  -> 但系统要访问 1MB 内存、64KB I/O 端口
  -> 所以用分段机制形成 20 位物理地址
  -> 又因为引脚数量有限，地址/数据/状态要分时复用
  -> 为了提高执行效率，BIU 负责取指和总线访问，EU 负责译码执行
  -> 在系统层面，再用最小/最大模式组织单处理器或多处理器系统
```

期末最容易出的不是长篇概念默写，而是：

- 给段寄存器和偏移地址，算物理地址。
- 问 8086 和 8088 的区别。
- 问 BIU/EU 各自做什么，为什么能并行。
- 问 FLAGS 中 CF、ZF、SF、OF、IF、DF、TF 的含义。
- 问时钟周期、总线周期、指令周期的层级关系。
- 问 ALE、READY、INTR、NMI、HOLD/HLDA、MN/MX 等引脚作用。
- 问最小模式和最大模式各靠哪些芯片组成。

## 1. 8086/8088 的定位

### 1.1 8086 是什么 [必考]

8086 是 Intel 的 16 位微处理器，内部按 16 位组织，外部有 16 根数据线、20 根地址线。

它能直接处理 8 位或 16 位数据，能寻址：

```text
20 根地址线 -> 2^20 个字节 -> 1MB 内存空间
16 位 I/O 端口地址 -> 2^16 个端口 -> 64KB I/O 空间
```

PPT 中还给出几个硬件特征：

| 项目 | 8086 |
|---|---|
| 电源 | 单一 +5V |
| 封装 | 40 引脚双列直插式 |
| 时钟频率 | 5MHz 到 10MHz |
| 最快指令执行时间 | 约 0.4 微秒 |
| 数据线 | 16 根 |
| 地址线 | 20 根 |

### 1.2 8088 是什么 [必考]

8088 常被称为“准 16 位微处理器”。

它的内部寄存器、运算器、内部数据总线仍然按 16 位设计，但外部数据总线只有 8 位。设计目的主要是兼容 Intel 原有的 8 位外围接口芯片。

| 对比点 | 8086 | 8088 |
|---|---|---|
| 内部结构 | 16 位 | 16 位 |
| 外部数据总线 | 16 位 | 8 位 |
| 地址线 | 20 根 | 20 根 |
| 指令预取队列 | 6 字节 | 4 字节 |
| 与 8 位外设兼容性 | 较弱 | 较强 |
| 执行同一程序速度 | 较快 | 通常较慢 |

> 易错：8088 不是 8 位 CPU。它内部仍是 16 位，只是外部数据总线为 8 位，所以外部存取次数更多，速度会慢一些。

## 2. CPU 内部结构：BIU 和 EU

### 2.1 为什么要分成 BIU 和 EU [重点]

传统做法是“取指令 -> 执行指令 -> 再取下一条”，CPU 经常要等内存。8086/8088 将 CPU 内部分成两个相对独立的功能部件：

| 部件  | 全称                        | 一句话理解                   |
| --- | ------------------------- | ----------------------- |
| BIU | Bus Interface Unit，总线接口部件 | 负责和外部世界打交道：取指、读写内存和 I/O |
| EU  | Execution Unit，执行部件       | 负责执行指令：译码、运算、修改寄存器和标志   |

这样 EU 执行当前指令时，BIU 可以提前从内存取后续指令放入队列，形成简单流水线。

### 2.2 CPU 结构总图 [必考]

先把 8086/8088 CPU 内部看成两个协作部门。PPT 原图如下：

![图2.1 8086微处理器内部结构框图](assets/ch2-fig2-1-8086-cpu-structure.png)

读图时按这条线理解：

```text
BIU 对外：形成 20 位物理地址，访问内存/I/O，预取指令
EU  对内：从指令队列取指，译码执行，使用寄存器和 ALU 运算
两者并行：EU 执行当前指令时，BIU 尽量提前取后续指令
```

这张图也能解释几个常考点：

- 段寄存器、IP、地址加法器在 BIU 中，所以物理地址形成属于 BIU 的工作。
- AX、BX、CX、DX、SP、BP、SI、DI 和 FLAGS 在 EU 中，所以运算和标志更新属于 EU 的工作。
- 指令预取队列夹在 BIU 和 EU 之间，是两者并行工作的关键缓冲区。

> 易错：BIU 不是“只负责取指令”，它还负责内存和 I/O 的实际总线访问；EU 也不是“只负责 ALU”，它还包括指令译码、通用寄存器和标志寄存器管理。

### 2.3 BIU：总线接口部件 [必考]

BIU 的功能：

- 负责 CPU 与内存或 I/O 端口之间传送指令或数据。
- 从内存取指令，送入指令队列缓冲器。
- 当 EU 执行指令需要访问内存或 I/O 时，BIU 负责实际总线读写。
- 将 EU 的操作结果写回指定内存单元或 I/O 端口。

BIU 的组成：

| 组成 | 作用 |
|---|---|
| 段寄存器 CS、DS、SS、ES | 保存当前逻辑段的段基址 |
| 指令指针寄存器 IP | 保存下一条将要取出的指令偏移地址 |
| 地址加法器 | 用“段基址 × 16 + 偏移地址”形成 20 位物理地址 |
| 指令预取队列 | 暂存 BIU 预取来的指令 |
| 总线控制逻辑 | 控制地址、数据、状态信息的分时传送 |

### 2.4 指令预取队列 [重点]

| CPU | 指令预取队列长度 |
|---|---:|
| 8086 | 6 字节 |
| 8088 | 4 字节 |

预取队列采用先进先出原则。一般情况下，EU 执行完一条指令后，可以直接从队列取下一条指令，从而减少等待内存的时间。

流水线管理要点：

- 当队列未满且总线空闲时，BIU 自动预取后续指令。
- EU 需要访问内存或 I/O 时，会请求 BIU 完成外部访问。
- 如果遇到转移、调用、返回等改变程序流的指令，原队列内容可能被清空，BIU 从新的目标地址重新取指。

> 易错：预取队列提高效率，但不改变程序执行语义。遇到跳转后，队列中旧路径上的指令不能继续执行。

### 2.5 EU：执行部件 [必考]

EU 的功能：

- 负责指令译码、执行和数据运算。
- 向 BIU 提供偏移地址。
- 管理通用寄存器和标志寄存器。

EU 的组成：

| 组成 | 作用 |
|---|---|
| ALU | 做 8 位和 16 位算术/逻辑运算，也可参与形成有效地址 |
| 标志寄存器 FR | 记录运算状态和控制执行方式 |
| 通用寄存器 | AX、BX、CX、DX、SP、BP、SI、DI |
| 数据暂存寄存器 | 协助 ALU 暂存参与运算的数据 |
| EU 控制电路 | 对指令译码，产生控制信号 |

## 3. 8086/8088 寄存器结构

### 3.1 数据寄存器 AX、BX、CX、DX [必考]

这 4 个寄存器都是 16 位，并且可以拆成高 8 位和低 8 位独立使用。

| 16 位寄存器 | 高 8 位 | 低 8 位 | 典型用途 |
|---|---|---|---|
| AX | AH | AL | 累加器，常用于算术运算、I/O、乘除默认操作数 |
| BX | BH | BL | 基址寄存器，常参与寻址 |
| CX | CH | CL | 计数器，常用于循环次数、移位次数 |
| DX | DH | DL | 数据寄存器，常用于大数乘除、高位结果、I/O 端口地址 |

> 易错：AX、BX、CX、DX 可以整体作为 16 位用，也可以分 AH/AL 等 8 位用；但 SP、BP、SI、DI 不能拆成高低 8 位寄存器。

### 3.2 指针和变址寄存器 [重点]

| 寄存器 | 全称 | 典型含义 |
|---|---|---|
| SP | Stack Pointer | 栈顶偏移地址 |
| BP | Base Pointer | 常用于访问堆栈中的数据区 |
| SI | Source Index | 源变址寄存器，常用于串操作源地址 |
| DI | Destination Index | 目的变址寄存器，常用于串操作目的地址 |
| IP | Instruction Pointer | 下一条指令的偏移地址 |

IP 由 BIU 用于取指令。CPU 取指时，通常会随着取出的字节数自动增加；转移、调用、返回等指令会改变 IP，从而改变程序执行流向。

> 易错：不能用普通 `MOV IP, ...` 直接修改 IP。程序流通常通过 JMP、CALL、RET、中断等方式改变。

### 3.3 段寄存器 [必考]

| 段寄存器 | 全称 | 默认用途 |
|---|---|---|
| CS | Code Segment | 代码段 |
| DS | Data Segment | 数据段 |
| SS | Stack Segment | 堆栈段 |
| ES | Extra Segment | 附加数据段 |

四个段寄存器分别指明当前可寻址的四个逻辑段。修改段寄存器内容，就能把对应段映射到 1MB 存储空间的不同位置。不同段可以相互独立，也可以部分或完全重叠。

## 4. FLAGS 标志寄存器

8086/8088 的标志寄存器 FR 是 16 位，但实际使用 9 位，分为状态标志和控制标志。

### 4.1 状态标志：反映运算结果 [必考]

| 标志 | 位 | 名称 | 什么时候为 1 |
|---|---:|---|---|
| CF | D0 | Carry Flag，进位/借位标志 | 无符号加法最高位有进位，或无符号减法最高位有借位 |
| PF | D2 | Parity Flag，奇偶标志 | 结果低 8 位中 1 的个数为偶数 |
| AF | D4 | Auxiliary Carry Flag，辅助进位标志 | D3 向 D4 有进位，或 D4 向 D3 有借位 |
| ZF | D6 | Zero Flag，零标志 | 运算结果为 0 |
| SF | D7 | Sign Flag，符号标志 | 与结果最高位相同 |
| OF | D11 | Overflow Flag，溢出标志 | 有符号数运算结果超出可表示范围 |

CF 和 OF 是最容易混的两个：

| 标志 | 面向的数 | 判断对象 | 例子中的含义 |
|---|---|---|---|
| CF | 无符号数 | 最高位是否进位/借位 | 8 位无符号数超过 255，或减法不够减 |
| OF | 有符号数 | 结果是否超出有符号范围 | 8 位有符号数超过 +127 或小于 -128 |

> 易错：CF=1 不一定 OF=1，OF=1 也不一定 CF=1。CF 看无符号进/借位，OF 看有符号溢出。

### 4.2 控制标志：控制 CPU 行为 [重点]

| 标志 | 位 | 名称 | 含义 |
|---|---:|---|---|
| IF | D9 | Interrupt Enable Flag，中断允许标志 | IF=1 时 CPU 可响应可屏蔽中断 INTR；IF=0 时不响应 INTR |
| DF | D10 | Direction Flag，方向标志 | DF=0 串操作地址递增；DF=1 串操作地址递减 |
| TF | D8 | Trap Flag，陷阱/单步标志 | TF=1 时进入单步执行方式，便于调试 |

相关指令：

| 指令 | 作用 |
|---|---|
| STI | IF 置 1，开中断 |
| CLI | IF 清 0，关中断 |
| STD | DF 置 1，串操作递减 |
| CLD | DF 清 0，串操作递增 |

> 易错：NMI 是非屏蔽中断，不受 IF 控制；INTR 是可屏蔽中断，是否响应要看 IF。

## 5. 存储器分段与物理地址

### 5.1 为什么要分段 [必考]

8086/8088 有 20 根地址线，可以访问 1MB 内存。但 CPU 内部许多地址相关寄存器只有 16 位，只能表达 64KB 范围。

解决办法是分段：

```text
1MB 物理内存
  -> 划分为若干逻辑段
  -> 每段最大 64KB
  -> 段寄存器给出段基址
  -> 偏移地址给出段内位置
```

### 5.2 逻辑地址、段基址、偏移地址 [必考]

| 名称 | 含义 |
|---|---|
| 段首址 | 一个段第一个存储单元的 20 位物理地址，最低 4 位一定为 0 |
| 段基址 | 段首址的高 16 位，存放在段寄存器中 |
| 偏移地址 | 段内存储单元距离段首址的偏移量，也称有效地址 EA |
| 逻辑地址 | 程序中常用的地址形式，写作“段基址:偏移地址” |
| 物理地址 | CPU 实际访问存储器时使用的 20 位地址 |

核心公式：

```text
物理地址 = 段基址 × 16 + 偏移地址
```

也可以理解为：

```text
物理地址 = 段寄存器内容左移 4 位 + 16 位偏移
```

例题：

```text
(CS) = 4232H
(IP) = 0066H

物理地址 = 4232H × 10H + 0066H
        = 42320H + 0066H
        = 42386H
```

> 易错：段基址不是段首址本身，而是段首址的高 16 位。算物理地址时必须先乘 16，也就是左移 4 位。

### 5.3 逻辑地址不唯一 [高频]

一个物理地址是唯一的，但逻辑地址可以不唯一。

例如物理地址 `12345H` 可以写成：

```text
1233H:0015H -> 12330H + 0015H = 12345H
1234H:0005H -> 12340H + 0005H = 12345H
```

> 易错：不要说“一个物理地址只能对应一个逻辑地址”。这句话是错的。

### 5.4 默认段寄存器约定 [必考]

| 操作类型 | 默认段寄存器 | 默认偏移 |
|---|---|---|
| 取指令 | CS | IP |
| 堆栈操作 | SS | SP |
| 一般数据访问 | DS | 有效地址 EA |
| BP 参与寻址 | SS | 有效地址 EA |
| 串操作源 | DS | SI |
| 串操作目的 | ES | DI |

> 易错：BP 默认配 SS，不是 DS。串操作目的地址默认是 ES:DI。

## 6. 堆栈

### 6.1 堆栈是什么 [重点]

堆栈是按后进先出原则管理的存储区域。8086/8088 中，堆栈段由 SS 指明段基址，栈顶由 SP 指明偏移地址。

```text
栈顶物理地址 = SS × 16 + SP
```

PUSH 和 POP 是两个基本操作：

| 操作 | 字操作时 SP 变化 | 含义 |
|---|---|---|
| PUSH | SP 先减 2，再写入数据 | 入栈 |
| POP | 先读出数据，再 SP 加 2 | 出栈 |

> 易错：8086 堆栈通常向低地址方向增长。PUSH 不是先写再加 SP，而是 SP 减小后写入。

### 6.2 PPT 例题如何看

PPT 给了一个栈操作片段：

```asm
SS = 1050H
SP = 0008H
AX = 1234H

PUSH AX
POP AX
POP BX
```

前两条可确定：

```text
初始栈顶物理地址 = 1050H × 10H + 0008H = 10508H

PUSH AX:
SP = 0006H
1234H 被压入 SS:0006H 开始的位置

POP AX:
AX 重新得到 1234H
SP = 0008H
```

最后 `POP BX` 会从当前 `SS:0008H` 所指位置再弹出一个字到 BX，SP 变为 `000AH`。如果没有给出该位置原来的内存内容，就不能确定 BX 的具体值。

## 7. 时钟周期、总线周期、指令周期

### 7.1 三个周期的层级关系 [必考]

```text
时钟周期/T 状态 < 总线周期 < 指令周期
```

| 周期 | 含义 |
|---|---|
| 时钟周期 | CPU 工作的最小时间单位，也叫 T 状态或节拍脉冲 |
| 总线周期 | CPU 通过总线对内存或 I/O 进行一次输入/输出所需时间 |
| 指令周期 | 执行一条指令所需时间，包括取指、分析、执行 |

PPT 给出的例子：8086 主频为 5MHz 时，一个时钟周期为：

```text
T = 1 / 5MHz = 0.2 微秒 = 200ns
```

### 7.2 基本总线周期 [必考]

8086 的一个基本总线周期通常由 4 个 T 状态组成：

| T 状态 | 主要动作 |
|---|---|
| T1 | CPU 输出地址，ALE 有效，外部锁存地址 |
| T2 | 地址撤离复用总线，CPU 发出读/写等控制信号 |
| T3 | 数据传输准备，CPU 采样 READY |
| T4 | 完成读入或写出，结束总线周期 |

如果外设或存储器太慢，READY=0，CPU 会在 T3 后插入一个或多个等待周期 `Tw`，直到 READY=1，再进入 T4。

> 易错：READY 不是“准备好了就插入等待”，而是 READY=0 时插入等待周期。

## 8. 8086/8088 引脚信号

### 8.1 为什么引脚要复用 [重点]

8086 只有 40 条引脚，却要传送 20 位地址、16 位数据和若干状态/控制信息。因此许多引脚采用分时复用：在不同 T 状态传不同信息。

最典型的是 `AD15~AD0`：

```text
T1：输出地址低 16 位
T2~T4：作为双向数据线
```

这也解释了为什么系统需要地址锁存器：T1 之后总线上的地址会消失，必须用 ALE 控制外部锁存器把地址保存下来。

### 8.2 最小/最大模式选择 MN/MX [必考]

`MN/MX` 是模式选择输入引脚。

| MN/MX | 工作模式 | 系统特点 |
|---|---|---|
| 1，接 +5V | 最小模式 | 单处理器系统，控制信号主要由 CPU 自己给出 |
| 0，接 GND | 最大模式 | 多处理器/协处理器系统，许多控制信号由 8288 总线控制器产生 |

> 易错：最小模式不是“性能最低”，最大模式也不是“地址空间最大”。这里的“最小/最大”主要指系统配置复杂度和是否适合多处理器/协处理器。

### 8.3 最小模式常见引脚 [必考]

| 信号 | 方向 | 作用 |
|---|---|---|
| AD15~AD0 | 双向/三态 | 地址/数据复用。T1 传地址，T2~T4 传数据 |
| A19/S6~A16/S3 | 输出/三态 | T1 输出高 4 位地址，T2~T4 输出状态 |
| /BHE/S7 | 输出/三态 | T1 指示高 8 位数据线 D15~D8 是否有效，低电平有效 |
| ALE | 输出 | 地址锁存允许，T1 有效，通知 8282 锁存地址 |
| /RD | 输出 | 低电平表示读内存或 I/O |
| /WR | 输出 | 低电平表示写内存或 I/O |
| M/IO | 输出 | 8086 中 1 表示访问存储器，0 表示访问 I/O |
| RESET | 输入 | 高电平有效复位，至少维持 4 个时钟周期 |
| READY | 输入 | 高电平表示外设/存储器准备好；为 0 时插入 Tw |
| NMI | 输入 | 非屏蔽中断，上升沿有效，不受 IF 控制 |
| INTR | 输入 | 可屏蔽中断，高电平有效，是否响应看 IF |
| /INTA | 输出 | 中断响应，低电平有效，通常产生两个负脉冲 |
| HOLD | 输入 | 其他总线主控部件请求占用总线 |
| HLDA | 输出 | CPU 同意让出总线的响应 |
| DT/R | 输出 | 控制 8286 数据传输方向 |
| /DEN | 输出 | 数据允许，低电平有效，选通数据收发器 |
| TEST | 输入 | 与 WAIT 指令配合，用于硬件同步 |
| CLK | 输入 | 系统时钟 |
| VCC/GND | 电源 | +5V 和接地 |

说明：上表中的 `/` 表示低电平有效。PPT 原图中的上横线在文本提取时可能丢失，所以复习时要特别留意低有效信号。

### 8.4 中断相关信号 [重点]

| 信号 | 类型 | 是否受 IF 控制 | 响应时机 |
|---|---|---|---|
| NMI | 非屏蔽中断 | 不受 IF 控制 | 当前指令结束后响应 |
| INTR | 可屏蔽中断 | IF=1 才响应 | 每个指令周期最后一个 T 状态采样 |
| /INTA | 中断响应输出 | CPU 发给外设 | 两个连续负脉冲 |

`/INTA` 两个负脉冲的作用：

1. 第一个脉冲通知外设：你的中断请求已被 CPU 接受。
2. 第二个脉冲要求外设把中断类型码放到数据总线上。

### 8.5 HOLD/HLDA [高频]

HOLD 和 HLDA 用于总线保持，也就是让其他总线主控部件临时占用总线。

```text
外部部件拉高 HOLD
  -> CPU 在当前总线周期结束时响应
  -> CPU 拉高 HLDA
  -> CPU 让地址/数据/控制总线进入浮空状态
  -> 外部部件使用总线
  -> 外部部件释放 HOLD
  -> CPU 拉低 HLDA，恢复总线控制
```

> 易错：CPU 不是一收到 HOLD 就立刻停在半个总线周期中间，而是在当前总线周期结束时让出总线。

### 8.6 8088 的引脚差异 [重点]

8088 与 8086 的主要差别来自外部数据总线宽度：

- 8088 外部一次只传 8 位数据。
- 8088 的 `AD7~AD0` 是地址/数据复用线。
- 8088 的 `A15~A8` 只输出地址，不再像 8086 的 `AD15~AD8` 那样双向传数据。
- 8086 的 `M/IO` 在 8088 上变为 `IO/M`，含义方向相反。
- 8086 的 `/BHE/S7` 在 8088 上变成状态信号 `SS0`。

> 易错：8088 没有 16 位外部数据总线，所以不需要像 8086 那样用 /BHE 指示高 8 位数据线有效。

## 9. 最小模式与最大模式系统组成

### 9.1 最小模式系统 [必考]

最小模式用于单处理器系统。此时系统总线控制信号主要由 8086/8088 自己直接给出。

典型外接芯片：

| 芯片 | 作用 | 为什么需要 |
|---|---|---|
| 8284A | 时钟发生器 | 提供系统时钟，并同步 READY、RESET |
| 8282 | 地址锁存器 | 将 T1 出现的地址锁存，保持整个总线周期稳定 |
| 8286 | 数据收发器/总线驱动器 | 增强数据总线驱动能力，并控制数据方向 |

8282 要点：

- 8086 地址/数据线复用，T1 后地址就会从总线上消失。
- ALE 有效时，8282 把地址锁存下来。
- 8086 除 20 位地址外，`/BHE` 也要锁存，所以通常需要 3 片 8282。

8286 要点：

- 8286 是 8 位双向三态缓冲器。
- 8086 是 16 位数据总线，所以若使用 8286 做数据驱动，通常需要 2 片。
- `DT/R` 控制传输方向，`/DEN` 选通数据传送。

### 9.2 最大模式系统 [重点]

最大模式用于多处理器或协处理器系统。此时许多控制信号不由 8086 直接产生，而由 8288 总线控制器根据 CPU 状态信号产生。

最大模式中常见部件：

| 部件 | 作用 |
|---|---|
| 8288 总线控制器 | 根据 8086 的状态信号产生系统总线控制命令 |
| 8087 协处理器 | 浮点运算协处理器 |
| 8089 I/O 处理器 | 可作为 I/O 协处理部件 |

最大模式常见信号：

| 信号 | 作用 |
|---|---|
| S2、S1、S0 | 总线周期状态信号，供 8288 解码生成控制命令 |
| QS1、QS0 | 指令队列状态信号，便于 8087 等跟踪指令队列 |
| RQ/GT | 总线请求/允许信号，供协处理器等请求使用总线 |
| /LOCK | 总线封锁信号，低电平时表示 CPU 独占总线 |

> 易错：最大模式不是让 8086 自己产生更多控制信号，而是把很多总线控制交给 8288。

## 10. 复位、启动与总线读写

### 10.1 复位和启动 [必考]

RESET 引脚高电平有效。

PPT 给出的要求：

- RESET 至少维持 4 个时钟周期。
- 初次加电复位时，高电平维持时间不小于 50 微秒。
- 复位后，8086/8088 从 `FFFF0H` 处开始执行指令。
- `FFFF0H` 通常放一条无条件转移指令，跳到系统初始化程序入口。

常见解释：

```text
复位后：
CS = FFFFH
IP = 0000H

物理地址 = FFFFH × 10H + 0000H
        = FFFF0H
```

> 易错：复位后不是从 00000H 执行，而是从 FFFF0H 执行。

### 10.2 总线读/写操作 [重点]

总线读操作：CPU 从存储器或 I/O 端口读取数据。  
总线写操作：CPU 将数据写入存储器或 I/O 端口。

最小模式下读写信号通常由 CPU 直接给出：

| 操作 | 关键信号 |
|---|---|
| 读 | `/RD` 有效 |
| 写 | `/WR` 有效 |
| 存储器访问 | M/IO=1 |
| I/O 访问 | M/IO=0 |

最大模式下读写控制命令通常由 8288 根据 `S2~S0` 状态信号产生。

### 10.3 中断响应操作 [重点]

当 8086/8088 从 INTR 引脚收到外部中断请求，并且 IF=1 时，CPU 会在执行完当前指令后执行中断响应时序。

中断响应的核心逻辑：

```text
INTR = 1 且 IF = 1
  -> 当前指令执行完
  -> CPU 输出 /INTA 响应信号
  -> 外设在第二个 /INTA 脉冲后给出中断类型码
  -> CPU 根据类型码转入中断服务程序
```

### 11.1 数字必须记住

| 数字 | 含义 |
|---:|---|
| 40 | 8086/8088 引脚数 |
| 16 | 8086 内部数据宽度；8086 外部数据总线宽度 |
| 8 | 8088 外部数据总线宽度 |
| 20 | 8086/8088 地址线数 |
| 1MB | 20 位地址线可寻址内存空间 |
| 64KB | 每个逻辑段最大大小；I/O 端口空间大小 |
| 6 字节 | 8086 指令预取队列 |

| 4 个 T 状态 | 基本总线周期 T1~T4 |
| FFFF0H | 复位后开始执行的物理地址 |

### 11.2 高频对比

| 对比 | 关键差异 |
|---|---|
| BIU vs EU | BIU 管总线和取指；EU 管译码执行和运算 |
| 8086 vs 8088 | 内部都 16 位；8086 外部 16 位，8088 外部 8 位 |
| CF vs OF | CF 看无符号进/借位；OF 看有符号溢出 |
| INTR vs NMI | INTR 可屏蔽，受 IF 控制；NMI 非屏蔽，不受 IF 控制 |

| 最小模式 vs 最大模式 | 最小模式单处理器，CPU 直接给控制信号；最大模式多处理器/协处理器，8288 产生控制命令 |

## 12. 自测题

### 12.1 选择/判断型

1. 8088 被称为准 16 位微处理器，是因为它的内部结构为 16 位，但外部数据总线为 8 位。  
答案：对。

2. 8086 的指令预取队列为 4 字节，8088 为 6 字节。  
答案：错。8086 为 6 字节，8088 为 4 字节。

3. 一个物理地址只能对应一个逻辑地址。  
答案：错。物理地址唯一，但逻辑地址可以不唯一。

4. NMI 不受 IF 标志控制，INTR 受 IF 标志控制。  
答案：对。

5. READY=0 时，CPU 会插入等待周期 Tw。  
答案：对。

### 12.2 简答型

1. 为什么 8086/8088 需要地址加法器？

答：因为 CPU 内部地址相关寄存器多为 16 位，只能表示 64KB 范围；但 8086/8088 有 20 根地址线，要访问 1MB 内存。地址加法器将段基址左移 4 位后与 16 位偏移地址相加，形成 20 位物理地址。

2. 简述 BIU 和 EU 的分工。

答：BIU 负责与外部总线交互，包括取指、读写内存和 I/O、形成物理地址、控制总线；EU 负责指令译码、执行、算术逻辑运算、管理通用寄存器和标志寄存器。两者可并行工作，BIU 预取指令，EU 执行指令，提高效率。

3. 说明 `4232H:0066H` 对应的物理地址。

答：物理地址 = 4232H × 10H + 0066H = 42320H + 0066H = 42386H。

4. 为什么需要 ALE 和地址锁存器？

答：8086/8088 部分引脚采用地址/数据复用，一个总线周期 T1 输出地址，T2~T4 改为传输数据。如果不锁存，外部芯片在后续阶段就得不到稳定地址。ALE 在 T1 有效，控制 8282 等地址锁存器保存地址。

### 12.3 综合题

题：已知 8086 系统中 `(SS)=1050H`，`(SP)=0008H`，`(AX)=1234H`，执行：

```asm
PUSH AX
POP AX
POP BX
```

问前三步中 SP 和 AX 如何变化？BX 是否能确定？

答：

```text
初始：SP=0008H，AX=1234H
PUSH AX：SP 先减 2，变为 0006H；将 1234H 压入栈
POP AX：从 SS:0006H 弹出 1234H 到 AX；SP 加 2，变为 0008H；AX=1234H
POP BX：从 SS:0008H 弹出一个字到 BX；SP 加 2，变为 000AH
```

由于题目没有给出 `SS:0008H` 原来的内存内容，所以 BX 的具体值不能确定。
