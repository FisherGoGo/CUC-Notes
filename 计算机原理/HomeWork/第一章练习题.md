# 第一章练习题

## 1. 数据总线的作用

**题目：** 数据总线的作用是（ ）。

**选项：**

- A. 确定 CPU 要访问的内存单元或 I/O 端口的地址
- B. 传输计算机的电源信号
- C. 控制计算机各部件的工作
- D. 在 CPU 与内存储器或 I/O 设备之间交换信息

**答案：D**

**解析：** 数据总线用于在 CPU、内存储器和 I/O 设备之间传送数据，也就是完成信息交换。CPU 读内存、写内存、读端口、写端口时，真正被传送的数据都经过数据总线。

**干扰项分析：**

- A 是地址总线的作用。地址总线负责指出 CPU 要访问哪个内存单元或哪个 I/O 端口。
- B 不是系统总线中数据总线的功能，电源信号由供电线路提供。
- C 是控制总线的作用。控制总线负责传送读、写、中断、时钟等控制信号。

> 易错点：三类总线要分清：地址总线“找位置”，数据总线“传内容”，控制总线“发命令/管时序”。

## 2. 总线的组成

**题目：** 连接计算机各部件的一组公共通信线称为总线，它由（ ）组成。

**选项：**

- A. 地址总线和数据总线
- B. 数据总线和控制总线
- C. 地址总线、数据总线和控制总线
- D. 地址总线和控制总线

**答案：C**

**解析：** 系统总线通常由三部分组成：地址总线、数据总线和控制总线。地址总线指出访问位置，数据总线传送数据，控制总线传送读写、中断、时钟等控制信号。

**干扰项分析：**

- A 少了控制总线，无法表达读、写等控制动作。
- B 少了地址总线，CPU 无法指出要访问哪个存储单元或 I/O 端口。
- D 少了数据总线，无法完成实际数据交换。

> 易错点：题干问“总线由什么组成”，标准答案是三类总线都要有：地址总线、数据总线、控制总线。

## 3. 补码减法

**题目：** 已知 $[X]_{\text{补}}=00110011B$，$[Y]_{\text{补}}=11000100B$，求 $[X-Y]_{\text{补}}$ 的值是（ ）。

**选项：**

- A. 00110011B
- B. 01101111B
- C. 01111111B
- D. 10000000B

**答案：B**

**解析：**

$[X]_{\text{补}}=00110011B$，最高位为 0，所以 $X=00110011B=51$。

$[Y]_{\text{补}}=11000100B$，最高位为 1，所以 $Y$ 是负数。求其绝对值：对 `11000100B` 按位取反得 `00111011B`，再加 1 得 `00111100B=60`，因此 $Y=-60$。

所以：

$$
X-Y=51-(-60)=111
$$

把 111 转成 8 位二进制：

$$
111=01101111B
$$

因此 $[X-Y]_{\text{补}}=01101111B$。

**干扰项分析：**

- A 是 $X$ 本身，不是 $X-Y$。
- C 是 127，像是把结果误算成了 8 位正数最大值附近。
- D 是 8 位补码中的 $-128$，不是本题结果。

> 易错点：补码中最高位为 1 不代表直接按无符号数计算。`11000100B` 表示的是负数 $-60$，所以 $X-Y$ 实际变成 $51+60$。

## 4. 不同进制数大小比较

**题目：** 下列数中最小的数为（ ）。

**选项：**

- A. $(52)_8$
- B. $(50)_{10}$
- C. $(111001)_2$
- D. $(2B)_{16}$

**答案：A**

**解析：** 比较不同进制数的大小时，先统一转换为十进制。

$$
(52)_8=5 \times 8 + 2=42
$$

$$
(50)_{10}=50
$$

$$
(111001)_2=1 \times 32+1 \times 16+1 \times 8+0 \times 4+0 \times 2+1=57
$$

$$
(2B)_{16}=2 \times 16 + 11=43
$$

所以四个数分别是 42、50、57、43，最小的是 $(52)_8$。

**干扰项分析：**

- B 是 50，比 42 大。
- C 的二进制位数较多，转换后为 57。
- D 中 `B` 表示十进制 11，所以 $(2B)_{16}=43$，只比 A 大 1。

> 易错点：十六进制中的 `B` 等于 11，不是字母或十进制中的某个独立符号；比较大小前一定先统一进制。

## 5. 8 位补码的最小值

**题目：** 设寄存器的内容为 `10000000`，若它等于 -128，则为（ ）。

**选项：**

- A. ASCII 码
- B. 反码
- C. 原码
- D. 补码

**答案：D**

**解析：** 在 8 位有符号补码表示中，最高位为符号位，`10000000B` 表示最小负数 $-128$。8 位补码的表示范围是：

$$
-128 \sim +127
$$

因此寄存器内容 `10000000` 若被解释为 -128，它采用的是补码表示。

**干扰项分析：**

- A ASCII 码用于表示字符，不用于直接表示整数 -128。
- B 8 位反码中 `10000000B` 表示 $-127$，不是 -128。
- C 8 位原码中 `10000000B` 表示 $-0$，不是 -128。

> 易错点：8 位补码中 `10000000B` 是一个特殊值，表示 $-128$；原码和反码中这个编码不表示 $-128$。

## 6. 不同进制数大小比较

**题目：** 下列无符号数中，其值最大的数是（ ）。

**选项：**

- A. $(227)_8$
- B. $(152)_{10}$
- C. $(10010101)_2$
- D. $(96)_{16}$

**答案：B**

**解析：** 无符号数比较大小时，先统一转换为十进制。

$$
(227)_8=2 \times 8^2+2 \times 8+7=151
$$

$$
(152)_{10}=152
$$

$$
(10010101)_2=128+16+4+1=149
$$

$$
(96)_{16}=9 \times 16+6=150
$$

四个数分别为 151、152、149、150，所以最大的是 $(152)_{10}$。

**干扰项分析：**

- A 转换后为 151，只比 B 小 1。
- C 转换后为 149。
- D 转换后为 150。

> 易错点：不同进制的“位数”和“表面大小”不能直接比较，必须先统一进制。

## 7. ASCII 码大小

**题目：** 下列字符中，ASCII 码值最小的是（ ）。

**选项：**

- A. `A`
- B. `x`
- C. `Y`
- D. `a`

**答案：A**

**解析：** ASCII 码中，大写字母排在小写字母之前；大写字母内部按字母顺序递增，小写字母内部也按字母顺序递增。常见值为：

```text
A = 65
Y = 89
a = 97
x = 120
```

因此 ASCII 码值最小的是 `A`。

**干扰项分析：**

- B `x` 是小写字母，ASCII 码值较大。
- C `Y` 虽然也是大写字母，但排在 `A` 后面。
- D `a` 是小写字母，ASCII 码值大于所有大写字母。

> 易错点：ASCII 中不是按“字母本身的感觉”比较，而是按编码值比较；一般记住 `0-9` < `A-Z` < `a-z`。

## 8. 补码求真值

**题目：** 已知 $[X]_{\text{补}}=10111000$，其真值为（ ）。

**选项：**

- A. -73
- B. -71
- C. -72
- D. -75

**答案：C**

**解析：** 最高位为 1，说明这是 8 位补码表示的负数。负数补码求真值时，可以“按位取反再加 1”得到绝对值。

```text
补码：10111000
取反：01000111
加 1：01001000
```

$$
(01001000)_2=64+8=72
$$

所以 $X=-72$。

**干扰项分析：**

- A、B、D 都是符号判断正确但绝对值计算错误。
- 若把 `10111000` 当作无符号数，会得到 184，这不是本题问的补码真值。

> 易错点：补码负数求真值时，不是直接把后 7 位转成十进制再加负号，而是对整个 8 位编码取反加 1 求绝对值。

## 9. 裸机的含义

**题目：** 通常所说的“裸机”指的是（ ）。

**选项：**

- A. 未装备任何软件的计算机
- B. 不带输入输出设备的计算机
- C. 计算机主机暴露在外
- D. 只装备有操作系统的计算机

**答案：A**

**解析：** “裸机”指只有硬件系统、没有安装任何软件的计算机。这里的软件既包括操作系统，也包括应用软件。

**干扰项分析：**

- B 错在把裸机理解成缺少外设。裸机强调没有软件，不是没有输入输出设备。
- C 是字面误解，和计算机组成原理中的“裸机”概念无关。
- D 已经安装了操作系统，因此不再是裸机。

> 易错点：裸机不是“没有外设的机器”，而是“没有软件支撑的硬件机器”。

## 10. CPU 的组成

**题目：** 计算机中的 CPU 指的是（ ）。

**选项：**

- A. 运算器、控制器和主存
- B. 运算器和控制器
- C. 控制器
- D. 运算器

**答案：B**

**解析：** CPU 是中央处理器，主要由运算器和控制器组成。运算器负责算术运算和逻辑运算，控制器负责取指令、分析指令并发出控制信号。

**干扰项分析：**

- A 把主存也算进 CPU 了。主存属于存储器系统，不属于 CPU。
- C 只包含控制器，不完整。
- D 只包含运算器，也不完整。

> 易错点：计算机硬件五大部件包括运算器、控制器、存储器、输入设备、输出设备；其中 CPU = 运算器 + 控制器。

## 11. 机内加减运算采用的编码

**题目：** 计算机内进行加、减法运算时常采用什么（ ）。

**选项：**

- A. 反码
- B. 原码
- C. 补码
- D. ASCII 码

**答案：C**

**解析：** 计算机中加减运算通常采用补码表示。使用补码后，减法可以转化为加法，例如：

$$
X-Y = X + (-Y)
$$

这样运算器可以用同一套加法电路完成加法和减法，简化硬件设计。

**干扰项分析：**

- A 反码虽然也能表示负数，但存在正零和负零，不利于统一运算。
- B 原码符号位和数值位分开处理，加减运算规则较复杂。
- D ASCII 码用于字符编码，不用于数值加减运算。

> 易错点：补码的核心优势是把减法统一成加法，同时 0 的表示唯一。

## 12. 控制总线的作用

**题目：** 计算机系统总线中，可用于传送读、写信号的是（ ）。

**选项：**

- A. 数据总线
- B. 控制总线
- C. 以上都不对
- D. 地址总线

**答案：B**

**解析：** 读信号、写信号属于控制信号，用于控制 CPU 与内存或 I/O 设备之间的数据传送方向和操作类型，因此通过控制总线传送。

**干扰项分析：**

- A 数据总线传送数据内容，不传送读、写控制命令。
- C 错，因为控制总线正是用来传送这类信号的。
- D 地址总线传送地址信息，用于指出访问位置。

> 易错点：读、写、中断、时钟、复位等属于控制信号；地址总线找位置，数据总线传内容，控制总线发命令。

## 13. ASCII 码最大值

**题目：** 下列字符中，ASCII 码值最大的是（ ）。

**选项：**

- A. `y`
- B. `a`
- C. `D`
- D. `9`

**答案：A**

**解析：** ASCII 码中，数字字符、大写字母、小写字母的常见顺序为：

```text
0-9 < A-Z < a-z
```

对应常见 ASCII 值：

```text
9 = 57
D = 68
a = 97
y = 121
```

所以 ASCII 码值最大的是 `y`。

**干扰项分析：**

- B `a` 是小写字母，但排在 `y` 前面。
- C `D` 是大写字母，ASCII 值小于小写字母。
- D `9` 是数字字符，ASCII 值小于字母。

> 易错点：字符 `9` 不是数值 9，它的 ASCII 码是 57；做 ASCII 题时比较的是编码值，不是字符含义。

## 14. 完整计算机系统的组成

**题目：** 完整的计算机系统是由（ ）组成的。

**选项：**

- A. 主机与外设
- B. ALU 与控制器
- C. CPU 与存储器
- D. 硬件系统与软件系统

**答案：D**

**解析：** 一个完整的计算机系统由硬件系统和软件系统组成。硬件系统提供物理基础，软件系统负责管理硬件并完成具体任务，两者缺一不可。

**干扰项分析：**

- A 只描述硬件系统的一种划分，没有包括软件系统。
- B 是 CPU 内部核心部件的组成，不是完整计算机系统。
- C 只包含部分硬件，也没有包括输入输出设备和软件。

> 易错点：如果题目问“完整的计算机系统”，答案必须包含硬件和软件；如果只问“计算机硬件系统”，才考虑主机、外设等硬件划分。

## 15. 计算机硬件系统的组成

**题目：** 计算机硬件系统应包括（ ）。

**选项：**

- A. 运算器、存储器、控制器
- B. 主机和实用程序
- C. 主机与外围设备
- D. 配套的硬件设备和软件系统

**答案：C**

**解析：** 计算机硬件系统通常由主机和外围设备组成。主机一般包括 CPU、主存储器等核心部件；外围设备包括输入设备、输出设备、外存储器等。

**干扰项分析：**

- A 只列出了部分硬件，缺少输入设备、输出设备等外围设备。
- B 实用程序属于软件，不属于硬件系统。
- D 同时包含硬件和软件，描述的是完整计算机系统，而不是硬件系统。

> 易错点：“完整计算机系统”=硬件系统+软件系统；“计算机硬件系统”=主机+外设。

## 16. 地址总线的发出者

**题目：** 地址总线由（ ）发出，用来确定 CPU 要访问的内存单元或 I/O 端口的地址。

**选项：**

- A. 内存储器
- B. I/O 设备
- C. 硬盘
- D. CPU

**答案：D**

**解析：** CPU 主动发出地址信息，通过地址总线指出要访问的内存单元或 I/O 端口。地址总线通常是单向的，方向是从 CPU 指向存储器或 I/O 接口。

**干扰项分析：**

- A 内存储器根据地址被访问，一般不主动发出地址。
- B I/O 设备是被 CPU 选中的访问对象，不是地址总线的发出者。
- C 硬盘属于外存设备，不负责发出 CPU 地址总线信号。

> 易错点：地址总线通常单向，由 CPU 发出；数据总线通常双向，用于读写数据。

## 17. MIPS 的含义

**题目：** 计算机运算速度的单位是 MIPS，其含义是（ ）。

**选项：**

- A. 每分钟处理百万个字符
- B. 每分钟执行百万条指令
- C. 每秒钟处理百万个字符
- D. 每秒钟执行百万条指令

**答案：D**

**解析：** MIPS 是 Million Instructions Per Second 的缩写，表示“每秒执行百万条指令”，常用来衡量计算机的指令执行速度。

**干扰项分析：**

- A、C 把衡量对象误写成字符处理数量。
- B 把时间单位误写成“每分钟”，MIPS 中的 S 指 Second，即“秒”。

> 易错点：MIPS 中的 I 是 Instructions，即指令；S 是 Second，即秒。

## 18. 当前制造计算机采用的电子器件

**题目：** 目前制造计算机所采用的电子器件是（ ）。

**选项：**

- A. 超导材料
- B. 中规模集成电路
- C. 晶体管
- D. 超大规模集成电路

**答案：D**

**解析：** 现代计算机主要采用超大规模集成电路（VLSI）制造。计算机的发展经历了电子管、晶体管、中小规模集成电路、大规模/超大规模集成电路等阶段。

**干扰项分析：**

- A 超导材料不是目前通用计算机制造的主要电子器件。
- B 中规模集成电路属于较早阶段。
- C 晶体管是第二代计算机的主要器件，不是现代计算机的主要集成形态。

> 易错点：按计算机代际记忆：第一代电子管，第二代晶体管，第三代集成电路，第四代大规模和超大规模集成电路。

## 19. 三组总线中的双向总线

**题目：** 在微机的三组总线中，（ ）是双向的。

**选项：**

- A. 地址总线
- B. 控制总线
- C. 数据总线
- D. 以上都不是

**答案：C**

**解析：** 数据总线用于 CPU 与内存、I/O 设备之间交换数据。CPU 读数据时，数据从内存或 I/O 设备传向 CPU；CPU 写数据时，数据从 CPU 传向内存或 I/O 设备，因此数据总线是双向的。

**干扰项分析：**

- A 地址总线通常由 CPU 发出，是单向的。
- B 控制总线中不同控制信号方向可能不同，但在三组总线的常见考法中，双向总线指数据总线。
- D 错，因为数据总线就是双向的。

> 易错点：地址总线负责“CPU 指向哪里”，常按单向理解；数据总线负责“内容来回传”，所以是双向。

## 20. 计算机硬件能直接识别和执行的语言

**题目：** 计算机硬件能直接识别和执行的只有（ ）。

**选项：**

- A. 符号语言
- B. 高级语言
- C. 机器语言
- D. 汇编语言

**答案：C**

**解析：** 计算机硬件只能直接识别和执行机器语言，也就是由二进制机器指令组成的语言。汇编语言和高级语言都必须经过汇编、编译或解释等过程，转换成机器语言后才能被 CPU 执行。

**干扰项分析：**

- A 符号语言不是硬件可直接执行的二进制机器指令。
- B 高级语言需要编译或解释后才能执行。
- D 汇编语言虽然接近机器语言，但仍需汇编成机器码。

> 易错点：汇编语言“接近机器”，但不是“机器能直接执行”；硬件直接执行的只有机器语言。
