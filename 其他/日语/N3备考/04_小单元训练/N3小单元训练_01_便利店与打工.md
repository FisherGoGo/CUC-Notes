# N3小单元训练 01：便利店与打工

目标：练习把日常工作安排、请求、原因说明翻成自然的 N3 日语，并通过短阅读抓住原因、顺序和人物态度。

## 本单元句型

- ておく：提前做好准备
- ようにする：尽量做到/养成习惯
- たら：如果/之后
- ので：客观说明原因
- ていただけませんか：礼貌请求
- わけではない：并不是...

## 热身词句

- **シフト**：排班，班次。例：来週のシフトを確認しました。
- **レジ**：收银台。例：レジでお客さんを待ちます。
- **品出し**：上货，补货。例：夕方は飲み物の品出しをします。
- **在庫**：库存。例：在庫が少ないので、店長に伝えました。
- **交代する**：换班，交接。例：六時に先輩と交代します。
- **間に合う**：来得及。例：急げば、五時のバスに間に合います。

## 句子翻译

1. 因为明天早上要打工，所以我打算今晚早点睡。（提示：ので / つもり）
2. 请你在客人来之前，把收银台附近打扫一下。（提示：前に / てください）
3. 如果库存不够，请马上告诉店长。（提示：たら / てください）
4. 我尽量在上班前确认当天的排班。（提示：ようにする / 前に）
5. 我不是不想帮忙，只是今天身体不太舒服。（提示：わけではない / だけ）
6. 不好意思，可以请您再说明一次换班时间吗。（提示：ていただけませんか）

## 阅读理解

私は駅前のコンビニでアルバイトをしています。平日は授業があるので、仕事に入るのはたいてい夕方六時からです。店に着いたら、まずその日のシフトを確認し、レジの周りをきれいにしておきます。夕方はお客さんが多く、弁当や飲み物がすぐ少なくなるため、品出しも大切な仕事です。

先週、新しく入った後輩が、在庫の場所が分からなくて困っていました。私は全部を代わりにやるのではなく、どこを見ればいいかを説明しました。最初は時間がかかっても、自分でできるようになったほうがいいと思ったからです。仕事が終わった後、後輩に「説明が分かりやすかったです」と言われて、少し安心しました。

词汇提示：品出し：上货，补货 / 後輩：后辈 / 代わりに：代替，替别人

1. 作者通常什么时候开始打工？
   - 早上六点
   - 下午六点
   - 下课前
   - 周末上午
2. 作者到店后首先做什么？
   - 整理便当
   - 给店长打电话
   - 确认当天排班
   - 教后辈收银
3. 作者为什么没有替后辈全部做完？
   - 因为作者很忙
   - 因为店长不允许
   - 因为希望后辈自己学会
   - 因为库存已经足够
4. 读完文章，作者的态度最接近哪一个？
   - 觉得后辈很麻烦
   - 对说明被理解感到安心
   - 不想继续打工
   - 觉得品出し不重要

## 输出小练习

用日语写 2-3 句：如果你在便利店打工，开始工作前会提前做什么？

## 参考答案

1. 明日の朝アルバイトがあるので、今晩は早く寝るつもりです。
2. お客さんが来る前に、レジの近くを掃除しておいてください。
3. 在庫が足りなかったら、すぐ店長に伝えてください。
4. 仕事に入る前に、その日のシフトを確認するようにしています。
5. 手伝いたくないわけではなく、今日は体の調子があまりよくないだけです。
6. すみません、交代する時間をもう一度説明していただけませんか。

### 阅读答案

1. 下午六点。文中说「仕事に入るのはたいてい夕方六時からです」。
2. 确认当天排班。文中说「まずその日のシフトを確認し」。
3. 因为希望后辈自己学会。文中说「自分でできるようになったほうがいいと思ったからです」。
4. 对说明被理解感到安心。最后一句「少し安心しました」直接说明了作者的感受。

### 输出参考

仕事に入る前に、まずシフトを確認します。お客さんが多い時間の前に、レジの周りをきれいにしておきたいです。
