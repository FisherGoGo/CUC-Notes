# 408 计算机考研初步指南

> 更新时间：2026-07-16  
> 目标院校：中山大学、中国科学技术大学软件学院、哈尔滨工业大学计算机相关专业  
> 报考偏好：以专业学位硕士（专硕）为主，学硕仅作为备选。  
> 当前定位：初步资料与共同知识底座，后续应随目标年份招生目录更新。

## 先说结论

你的判断基本正确：如果报考的专业课都是 **408 计算机学科专业基础**，那么大约七八成的备考内容可以共用，核心都是：

1. 思想政治理论；
2. 英语；
3. 数学；
4. 408：数据结构、计算机组成原理、操作系统、计算机网络；
5. 复试所需的 C/C++ 编程、数据结构实现和专业基础。

但三校并不是完全相同，最大的差别是：

- 学硕通常采用英语（一）+ 数学（一）；
- 中山大学部分计算机类专硕、中科大软件学院软件工程专硕采用英语（二）+ 数学（二）；
- 哈工大 2026 年计算学部的计算机技术、软件工程等专硕仍采用英语（一）+ 数学（一）；
- 复试形式和附加科目不同，中科大和中山大学尤其需要重视程序设计或上机能力。

由于目前以专硕为主，目标可以先收缩为：

- 中山大学：085404 计算机技术、085405 软件工程、085410 人工智能等 408 专硕；
- 中国科学技术大学：225 软件学院 085405 软件工程常规班；
- 哈尔滨工业大学：085400 电子信息下的计算机技术、软件工程、人工智能等 408 方向。

在还没有决定是否保留哈工大时，建议先按下面这套“最大公约数”学习：

- 数学基础阶段暂按数一范围学习；
- 英语阅读暂按英一难度训练；
- 完整学习 408；
- 持续练习 C/C++ 和数据结构算法。

这样可以同时保留三校专硕。若后续明确放弃哈工大、只在中山大学专硕和中科大软件学院中选择，再正式切换为英二、数二路线。
