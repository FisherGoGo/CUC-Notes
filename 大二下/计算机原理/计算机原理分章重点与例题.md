## 第一章：计算机系统基础

### 本章考法

- 常规选择题
- 常规填空题
- 一般不作为大题重点

### 重点复习知识点

#### 1. 计算机系统组成

计算机系统通常由硬件系统和软件系统组成。

- 硬件系统：运算器、控制器、存储器、输入设备、输出设备。
- 软件系统：系统软件和应用软件。
- CPU 通常由运算器和控制器组成。

#### 2. 冯·诺依曼结构

核心思想：

- 程序和数据都以二进制形式存放在存储器中。
- 计算机按照程序顺序自动执行指令。
- 计算机由运算器、控制器、存储器、输入设备、输出设备五大部分组成。

#### 3. 常见性能指标

- 字长：CPU 一次能处理的二进制位数。
- 主频：CPU 时钟频率。
- 存储容量：存储器能保存的信息量。
- 指令系统：CPU 能识别和执行的全部指令集合。

### 易错点

> CPU 不等于整个主机。CPU 通常只包括运算器和控制器，主机一般包括 CPU 和主存储器。

### 例题

#### 例题 1：选择题

冯·诺依曼计算机的基本思想是：

A. 数据和程序分开存储  
B. 程序存储和程序控制  
C. 只能执行高级语言程序  
D. 采用十进制进行运算  

**答案：B**

**解析：**冯·诺依曼结构的核心是“存储程序”和“程序控制”，即程序和数据都存储在存储器中，计算机自动按程序执行。

#### 例题 2：填空题

CPU 通常由 ______ 和 ______ 组成。

**答案：运算器；控制器**

## 第二章：微处理器结构、引脚与时序基础

### 本章考法

- 常规选择题
- 常规填空题
- 可能有一道简答题

### 重点复习知识点

#### 1. 特殊功能引脚

老师强调“特殊六个功能引脚”需要重点看。复习时要掌握：

- 引脚名称
- 引脚作用
- 输入还是输出
- 高电平有效还是低电平有效
- 与总线控制、存储器访问、I/O 访问的关系

如果课程讲的是 8086/8088 一类微处理器，老师口中的“特殊功能引脚”常见有两种口径：一种是 CPU 的特殊输入/控制类引脚，如 `READY`、`RESET`、`INTR`、`NMI`、`TEST`、`MN/MX`；另一种是最小模式下常考的总线控制引脚，如 `M/IO`、`RD`、`WR`、`ALE`、`DEN`、`DT/R`。你提到 `M/IO` 大概率考，说明第二种也一定要重点看。

### 常见特殊功能引脚展开

#### `READY`

`READY` 用于解决 CPU 和慢速存储器、慢速外设之间速度不匹配的问题。

- 当外设或存储器来不及完成数据传送时，可以通过 `READY` 让 CPU 插入等待周期。
- `READY` 有效时，CPU 按正常总线周期执行。
- `READY` 无效时，CPU 等待，直到外设或存储器准备好。

常见考法：

- 问 `READY` 的作用。
- 问为什么需要等待周期。

答题模板：

```text
READY 信号用于通知 CPU 外设或存储器是否已经准备好。
当外设速度较慢时，CPU 可以通过 READY 信号插入等待周期，
从而实现 CPU 与慢速外设或存储器之间的同步。
```

#### `RESET`

`RESET` 是复位信号，用于使 CPU 回到初始状态。

- 系统上电或需要重新启动时使用。
- CPU 接收到复位信号后，会清除或初始化内部状态。
- 复位后，CPU 从固定入口地址开始执行程序，具体地址以课件为准。

常见考法：

- 问 `RESET` 的功能。
- 问 CPU 复位后会发生什么。

答题模板：

```text
RESET 是复位输入信号，用于使 CPU 初始化。
复位后 CPU 内部寄存器和控制逻辑进入规定初始状态，
并从指定的启动地址开始取指执行程序。
```

#### `INTR`

`INTR` 是可屏蔽中断请求输入信号。

- 外设可以通过 `INTR` 向 CPU 提出中断请求。
- 是否响应 `INTR` 受中断允许标志影响。
- 如果 CPU 允许中断，并且当前条件满足，就会响应中断请求。

常见考法：

- `INTR` 是可屏蔽中断。
- `INTR` 和 `NMI` 的区别。

答题模板：

```text
INTR 是可屏蔽中断请求信号，外设通过它向 CPU 请求中断服务。
CPU 是否响应 INTR 受中断允许标志控制，因此它可以被屏蔽。
```

#### `NMI`

`NMI` 是非屏蔽中断请求输入信号。

- `NMI` 一般用于紧急事件。
- 它不受普通中断允许标志控制。
- 优先级通常高于普通可屏蔽中断。

常见考法：

- `NMI` 是非屏蔽中断。
- 用于掉电、奇偶校验错误等紧急情况。

答题模板：

```text
NMI 是非屏蔽中断请求信号，通常用于处理紧急事件。
它不受中断允许标志控制，CPU 一般必须响应。
```

#### `TEST`

`TEST` 常与等待指令配合使用，用于测试外部条件。

- CPU 执行等待类指令时，会检查 `TEST` 引脚状态。
- 如果条件不满足，CPU 继续等待。
- 常用于和协处理器或外部设备同步。

常见考法：

- 问 `TEST` 的作用。
- 问它常与什么指令配合。

答题模板：

```text
TEST 是测试输入信号，常与等待指令配合使用。
CPU 可以通过检测 TEST 引脚状态判断外部条件是否满足，
从而实现与外部设备的同步。
```

#### `MN/MX`

`MN/MX` 用于选择 CPU 工作在最小模式还是最大模式。

- 最小模式：系统中通常只有一个 CPU，控制信号由 CPU 自己产生。
- 最大模式：适合多处理器或协处理器系统，需要总线控制器等配合。

常见考法：

- 问 `MN/MX` 的作用。
- 区分最小模式和最大模式。

答题模板：

```text
MN/MX 用于选择 8086 的工作模式。
最小模式适用于单处理器系统，CPU 自己产生主要总线控制信号；
最大模式适用于多处理器或带协处理器系统，部分控制信号由总线控制器产生。
```

### 最小模式下特别常考的控制引脚

#### `M/IO`

`M/IO` 用于区分当前总线操作访问的是存储器还是 I/O 端口。

- 访问存储器时，表示 memory 操作。
- 访问 I/O 端口时，表示 I/O 操作。
- 具体高低电平含义一定以课件为准，因为不同教材写法可能会用 `M/IO` 或 `IO/M`。

常见考法：

- 判断当前是存储器访问还是 I/O 访问。
- 和 `RD`、`WR` 组合判断总线周期类型。

常见组合理解：

```text
M/IO + RD：存储器读或 I/O 读
M/IO + WR：存储器写或 I/O 写
```

答题模板：

```text
M/IO 是存储器/输入输出选择控制信号，
用于指出当前总线周期访问的是存储器还是 I/O 端口。
它通常与 RD、WR 等信号配合，用来确定具体的读写操作类型。
```

#### `RD`

`RD` 是读控制信号。

- CPU 从存储器或 I/O 端口读取数据时有效。
- 它要结合 `M/IO` 判断是存储器读还是 I/O 读。

答题模板：

```text
RD 是读控制信号，表示 CPU 当前要从存储器或 I/O 端口读入数据。
具体读存储器还是读 I/O，需要结合 M/IO 信号判断。
```

#### `WR`

`WR` 是写控制信号。

- CPU 向存储器或 I/O 端口写数据时有效。
- 它要结合 `M/IO` 判断是存储器写还是 I/O 写。

答题模板：

```text
WR 是写控制信号，表示 CPU 当前要向存储器或 I/O 端口写出数据。
具体写存储器还是写 I/O，需要结合 M/IO 信号判断。
```

#### `ALE`

`ALE` 是地址锁存允许信号。

- 8086 的地址线和数据线存在复用情况。
- 总线周期前期线上出现地址，后期线上传送数据。
- `ALE` 用于通知外部锁存器把地址锁存下来。

答题模板：

```text
ALE 是地址锁存允许信号。
由于部分地址线和数据线复用，CPU 在总线周期前期输出地址，
外部锁存器利用 ALE 将地址保存下来，以便后续数据传送时仍能保持地址信息。
```

#### `DEN`

`DEN` 是数据允许信号，用于控制数据总线收发器是否工作。

- 当 CPU 需要通过数据总线传送数据时，`DEN` 有效。
- 它常与 `DT/R` 配合使用。

答题模板：

```text
DEN 是数据允许信号，用于允许数据总线收发器工作。
当 CPU 与存储器或 I/O 端口进行数据传送时，DEN 有效。
```

#### `DT/R`

`DT/R` 用于控制数据传送方向。

- 表示 CPU 是发送数据还是接收数据。
- 与 `DEN` 配合控制数据总线收发器。

答题模板：

```text
DT/R 是数据发送/接收方向控制信号，
用于控制数据总线收发器的数据传送方向，
判断 CPU 当前是向外发送数据还是从外部接收数据。
```

### 这部分最容易考的对比

| 引脚 | 核心作用 | 常见考法 |
|---|---|---|
| `READY` | 插入等待周期，解决速度不匹配 | 为什么慢速外设需要 READY |
| `RESET` | 复位 CPU | 复位后 CPU 进入初始状态 |
| `INTR` | 可屏蔽中断请求 | 和 `NMI` 区分 |
| `NMI` | 非屏蔽中断请求 | 紧急中断，不受普通屏蔽控制 |
| `TEST` | 测试外部条件 | 与等待指令配合 |
| `MN/MX` | 选择最小/最大模式 | 单处理器/多处理器模式区别 |
| `M/IO` | 区分存储器访问和 I/O 访问 | 与 `RD`、`WR` 组合判断总线周期 |
| `ALE` | 锁存地址 | 地址/数据复用时保存地址 |
| `DEN` | 数据总线允许 | 控制收发器是否工作 |
| `DT/R` | 数据方向控制 | 判断发送还是接收 |

### 例题：特殊功能引脚

#### 例题 1：填空题

CPU 通过 ______ 信号区分当前访问的是存储器还是 I/O 端口。

**答案：`M/IO`**

#### 例题 2：选择题

用于解决 CPU 与慢速外设速度不匹配、插入等待周期的信号是：

A. `RESET`  
B. `READY`  
C. `ALE`  
D. `NMI`  

**答案：B**

**解析：**`READY` 用来表示外设或存储器是否准备好。当没有准备好时，CPU 可以插入等待周期。

#### 例题 3：简答题

简述 `INTR` 和 `NMI` 的区别。

**参考答案：**

`INTR` 是可屏蔽中断请求信号，是否响应受中断允许标志控制；`NMI` 是非屏蔽中断请求信号，通常用于紧急事件，不受普通中断允许标志控制。

#### 例题 4：简答题

为什么 8086 系统中需要 `ALE` 信号？

**参考答案：**

因为 8086 的部分地址线和数据线是复用的，在总线周期前期这些引脚输出地址，后期用于传送数据。为了在数据传送阶段仍然保持地址信息，需要用 `ALE` 信号控制外部锁存器，把地址锁存下来。

#### 2. `M/IO` 或类似控制信号

该类信号用于区分当前总线操作访问的是存储器还是 I/O 端口。

常见理解：

- 访问存储器时，信号表示 memory 操作。
- 访问 I/O 端口时，信号表示 I/O 操作。

具体高低电平含义要以课件为准。

#### 3. 时钟周期

时钟周期是 CPU 时钟信号的一个周期，是最基本的时间单位。

常见关系：

```text
时钟周期 = 1 / 时钟频率
```

例如 CPU 主频为 5 MHz，则：

```text
时钟周期 = 1 / 5 MHz = 0.2 us
```

#### 4. 指令周期、总线周期、时钟周期

- 时钟周期：CPU 最基本的时间单位。
- 总线周期：CPU 通过总线完成一次访问存储器或 I/O 端口所需的时间。
- 指令周期：CPU 取出并执行一条指令所需的全部时间。

一般关系：

```text
一条指令周期可以包含一个或多个总线周期；
一个总线周期可以包含多个时钟周期。
```

### 易错点

> 不要把时钟周期、总线周期、指令周期混为一谈。时钟周期最小，总线周期用于一次总线操作，指令周期用于完成一条指令。

### 例题

#### 例题 1：填空题

若 CPU 时钟频率为 10 MHz，则一个时钟周期为 ______ us。

**答案：0.1 us**

**解析：**

```text
T = 1 / f = 1 / 10 MHz = 0.1 us
```

#### 例题 2：简答题

简述时钟周期、总线周期和指令周期的区别。

**参考答案：**

时钟周期是 CPU 时钟信号的一个周期，是最基本的时间单位；总线周期是 CPU 通过总线完成一次存储器或 I/O 访问所需的时间；指令周期是 CPU 取出并执行一条指令所需的全部时间。一条指令周期通常包含一个或多个总线周期，一个总线周期通常包含多个时钟周期。

## 第三、四章：汇编指令与程序设计基础

### 本章考法

- 选择题
- 填空题
- 小程序设计题
- 占比不会太重，但 `MOV`、`IN`、`OUT` 非常重要

### 重点复习知识点

#### 1. `MOV` 指令

`MOV` 指令用于数据传送。

常见形式：

```asm
MOV AX, BX
MOV AL, 80H
MOV AX, [2000H]
MOV [2000H], AX
```

注意：

- 两个操作数位数通常要一致。
- 不能两个操作数同时都是存储器操作数。
- 立即数不能直接送入段寄存器，通常要先送通用寄存器。

#### 2. `IN` 指令

`IN` 用于从 I/O 端口读入数据。

```asm
IN AL, 端口地址
IN AX, 端口地址
```

当端口地址超过 8 位或使用间接寻址时，通常用 `DX` 保存端口地址：

```asm
MOV DX, 端口地址
IN AL, DX
```

#### 3. `OUT` 指令

`OUT` 用于向 I/O 端口输出数据。

```asm
OUT 端口地址, AL
OUT 端口地址, AX
```

常见写法：

```asm
MOV DX, 端口地址
MOV AL, 数据
OUT DX, AL
```

#### 4. 接口程序基本框架

接口类程序通常包括：

1. 写控制字，初始化芯片。
2. 设置端口地址。
3. 输入或输出数据。
4. 必要时循环、延时或判断状态。

### 易错点

> 端口地址经常放在 `DX` 中，数据经常放在 `AL` 中。写程序时可以先把这个框架写出来，至少能拿步骤分。

### 例题

#### 例题 1：判断题

`MOV [2000H], [3000H]` 是合法指令。

**答案：错**

**解析：**`MOV` 指令通常不允许两个操作数同时都是存储器操作数。

#### 例题 2：程序题

向端口 `300H` 输出数据 `55H`。

**参考答案：**

```asm
MOV DX, 300H
MOV AL, 55H
OUT DX, AL
```

#### 例题 3：程序题

从端口 `301H` 读入一个字节到 `AL`。

**参考答案：**

```asm
MOV DX, 301H
IN AL, DX
```

## 第五章：存储器系统

### 本章考法

- 选择题
- 填空题
- 可能有简答题
- 大概率不细考具体芯片

### 重点复习知识点

#### 1. 存储器分类

- RAM：随机存取存储器，可读可写，断电后信息通常丢失。
- ROM：只读存储器，断电后信息通常仍然保存。
- SRAM：速度快，成本高。
- DRAM：容量大，成本低，需要刷新。

#### 2. 地址线、数据线与容量

地址线决定可寻址单元数量。

```text
可寻址单元数 = 2^地址线根数
```

数据线决定每次访问的数据位数。

容量常用计算：

```text
容量 = 存储单元数 × 每个单元位数
```

#### 3. 存储器扩展

常见扩展方式：

- 位扩展：增加数据位数。
- 字扩展：增加存储单元数量。
- 字位扩展：同时增加位数和单元数量。

#### 4. 片选信号

片选用于决定当前访问哪个存储芯片。地址译码电路常用于产生片选信号。

### 易错点

> 地址线增加 1 根，可寻址空间变为原来的 2 倍。数据线增加通常影响一次传送的数据位数，不直接表示地址数量增加。

### 例题

#### 例题 1：计算题

某存储器有 16 根地址线、8 根数据线，求其容量。

**答案：64 KB**

**解析：**

```text
存储单元数 = 2^16 = 65536
每个单元 = 8 bit = 1 Byte
容量 = 65536 Byte = 64 KB
```

#### 例题 2：简答题

简述 RAM 和 ROM 的区别。

**参考答案：**

RAM 是随机存取存储器，可读可写，断电后信息通常丢失；ROM 是只读存储器，通常用于存放固定程序或数据，断电后信息仍能保存。

## 第六章：输入输出与中断系统

### 本章考法

- 选择题
- 填空题
- 简答题
- 中断是重点

### 重点复习知识点

#### 1. 输入输出方式

常见 I/O 控制方式：

- 程序查询方式
- 中断方式
- DMA 方式

#### 2. 程序查询方式

CPU 不断查询外设状态，判断外设是否准备好。

优点：

- 程序简单
- 硬件要求低

缺点：

- CPU 利用率低
- 等待时间长

#### 3. 中断方式

外设需要 CPU 服务时主动提出中断请求，CPU 响应后转去执行中断服务程序。

核心流程：

```text
中断请求 -> 中断响应 -> 保护现场 -> 执行中断服务程序 -> 恢复现场 -> 中断返回
```

#### 4. 中断向量表

中断向量表用于保存中断服务程序的入口地址。

复习重点：

- 中断类型号
- 中断向量
- 中断服务程序入口地址
- 中断向量表位置和查表方式，以课件为准

#### 5. 8259 中断控制器

8259 的作用：

- 接收多个外设的中断请求。
- 管理中断优先级。
- 屏蔽或允许某些中断。
- 向 CPU 提交中断请求。

重点关注：

- 中断请求寄存器
- 中断屏蔽寄存器
- 中断服务寄存器
- 初始化控制字
- 操作控制字

### 易错点

> 中断向量不是中断服务程序本身，而是中断服务程序的入口地址信息。

### 例题

#### 例题 1：简答题

什么是中断？中断方式有什么优点？

**参考答案：**

中断是 CPU 在执行当前程序时，由内部或外部事件提出请求，CPU 暂停当前程序，转去执行相应中断服务程序，处理完成后再返回原程序继续执行的一种机制。中断方式可以减少 CPU 等待外设的时间，提高 CPU 和外设并行工作的效率，并能及时响应外部事件。

#### 例题 2：填空题

中断向量表中存放的是中断服务程序的 ______。

**答案：入口地址**

#### 例题 3：选择题

下列哪项不是 8259 的主要功能？

A. 接收中断请求  
B. 进行中断优先级管理  
C. 进行浮点运算  
D. 屏蔽某些中断请求  

**答案：C**

**解析：**8259 是中断控制器，不负责算术运算。

## 第七章：并行接口 8255

### 本章考法

- 选择题
- 填空题
- 编程题
- 8255 编程题基本必有

### 重点复习知识点

#### 1. 8255 的作用

8255 是可编程并行接口芯片，用于 CPU 与外设之间进行并行数据传送。

#### 2. 8255 的端口

8255 包含：

- A 口
- B 口
- C 口
- 控制口

C 口可以分为：

- C 口高 4 位
- C 口低 4 位

#### 3. 工作方式

方式 0：基本输入输出。

- 最常考。
- 可用于简单并行输入或输出。

方式 1：选通输入输出。

- 带有握手信号。

方式 2：双向传输。

- 主要用于 A 口。

#### 4. 控制字

8255 需要通过控制字设置：

- A 口输入还是输出
- B 口输入还是输出
- C 口高 4 位输入还是输出
- C 口低 4 位输入还是输出
- 工作方式

#### 5. 七段数码管

重点掌握：

- 共阳极和共阴极区别
- 段码
- 位选
- 段选
- 通过 8255 输出段码

### 易错点

> 8255 程序题通常先写控制字到控制口，再向数据口输入或输出数据。不要一上来只写数据输出，忘记初始化。

### 例题

#### 例题 1：填空题

8255 有 A 口、B 口、______ 和控制口。

**答案：C 口**

#### 例题 2：简答题

简述 8255 方式 0 的特点。

**参考答案：**

方式 0 是基本输入输出方式，A 口、B 口以及 C 口高低 4 位都可以作为简单输入或输出端口使用，不需要握手信号，适用于简单外设的数据输入输出。

#### 例题 3：程序题

设 8255 控制口地址为 `303H`，A 口地址为 `300H`。要求将 A 口设置为输出，并向 A 口输出 `55H`。控制字假设为 `80H`，写出程序片段。

**参考答案：**

```asm
MOV DX, 303H
MOV AL, 80H
OUT DX, AL

MOV DX, 300H
MOV AL, 55H
OUT DX, AL
```

#### 例题 4：程序题

通过 8255 A 口向七段数码管输出数字 0 的段码。设 A 口地址为 `300H`，控制口地址为 `303H`，控制字为 `80H`，共阴极数字 0 段码为 `3FH`。

**参考答案：**

```asm
MOV DX, 303H
MOV AL, 80H
OUT DX, AL

MOV DX, 300H
MOV AL, 3FH
OUT DX, AL
```

## 第九章：定时器/计数器 8253

### 本章考法

- 选择题
- 填空题
- 编程题
- 计算题
- 大重点

### 重点复习知识点

#### 1. 8253 的作用

8253 是可编程定时器/计数器，用于产生定时信号、计数信号、频率信号或方波信号。

#### 2. 8253 的结构

8253 内部有 3 个独立计数器：

- 计数器 0
- 计数器 1
- 计数器 2

每个计数器都有：

- 时钟输入端
- 门控输入端
- 输出端
- 计数初值
- 工作方式

#### 3. 控制字

控制字用于设置：

- 选择哪个计数器
- 读写格式
- 工作方式
- 二进制计数还是 BCD 计数

#### 4. 前四种工作方式

方式 0：计数结束中断。

- 计数到 0 后输出信号改变。

方式 1：可编程单稳态。

- 由门控信号触发，产生一定宽度的脉冲。

方式 2：频率发生器。

- 常用于分频，周期性输出脉冲。

方式 3：方波发生器。

- 输出近似方波。

#### 5. 计数初值计算

常用公式：

```text
N = 输入频率 / 输出频率
```

或：

```text
定时时间 = N × 输入时钟周期
N = 定时时间 / 输入时钟周期
```

### 易错点

> 8253 写计数初值时，如果设置为先低字节后高字节，就必须连续写两次：先写低 8 位，再写高 8 位。

### 例题

#### 例题 1：填空题

8253 内部有 ______ 个独立的计数器。

**答案：3**

#### 例题 2：计算题

某 8253 的输入时钟频率为 1 MHz，要求输出 1 kHz 的频率信号，求计数初值。

**答案：1000**

**解析：**

```text
N = 输入频率 / 输出频率
N = 1 MHz / 1 kHz = 1000
```

#### 例题 3：计算题

若输入时钟周期为 `1 us`，要求定时 `10 ms`，求计数初值。

**答案：10000**

**解析：**

```text
N = 定时时间 / 输入时钟周期
N = 10 ms / 1 us = 10000
```

#### 例题 4：程序题

设 8253 控制口地址为 `303H`，计数器 0 地址为 `300H`。要求向控制口写入控制字 `36H`，并向计数器 0 写入计数初值 `1000`。写出程序片段。

`1000` 的十六进制为 `03E8H`，低字节为 `E8H`，高字节为 `03H`。

**参考答案：**

```asm
MOV DX, 303H
MOV AL, 36H
OUT DX, AL

MOV DX, 300H
MOV AL, 0E8H
OUT DX, AL

MOV AL, 03H
OUT DX, AL
```

#### 例题 5：简答题

简述 8253 方式 3 的作用。

**参考答案：**

方式 3 是方波发生器方式，计数器按照设定的计数初值周期性计数，并在输出端产生近似方波信号，常用于产生周期性方波或进行分频。
