# 第二章练习题

## 1. 8086 最大工作模式特点

**题目：** 下列说法中属于 8086 最大工作模式特点的是（ ）。

**选项：**

- A. 由编程进行模式设定
- B. 需要总线控制器 8288
- C. 不需要 8286 收发器
- D. CPU 提供全部的控制信号

**答案：B**

**解析：** 8086 有最小模式和最大模式。最大模式主要用于多处理器或协处理器系统，此时 CPU 不直接给出全部总线控制信号，而是输出状态信号，再由总线控制器 8288 产生相应控制信号。

**干扰项分析：**

- A 错，8086 的工作模式由 `MN/MX` 引脚决定，不是由程序设定。
- C 错，是否使用总线收发器取决于系统设计，不能作为最大模式特点。
- D 是最小模式的特点；最大模式下控制信号主要由 8288 产生。

> 易错点：最小模式适合单处理器系统，CPU 自己给控制信号；最大模式适合多处理器系统，需要 8288 总线控制器。

## 2. 8086 总线接口部件 BIU

**题目：** 在 8086 CPU 中，不属于总线接口部件的是（ ）。

**选项：**

- A. 段地址寄存器
- B. 标志寄存器
- C. 20 位的地址加法器
- D. 指令队列

**答案：B**

**解析：** 8086 CPU 分为总线接口部件 BIU 和执行部件 EU。BIU 负责取指令、形成物理地址、访问存储器和 I/O，包括段寄存器、指令指针 IP、20 位地址加法器和 6 字节指令队列。标志寄存器属于 EU 相关部分，不属于 BIU。

**干扰项分析：**

- A 段地址寄存器属于 BIU。
- C 20 位地址加法器用于形成物理地址，属于 BIU。
- D 指令队列用于预取指令，属于 BIU。

> 易错点：BIU 负责“对外访问和取指”，EU 负责“执行指令和运算”。标志寄存器跟运算结果密切相关，所以不属于 BIU。

## 3. 8086 复位后的执行地址

**题目：** 8086 系统复位后，下列叙述中正确的是（ ）。

**选项：**

- A. 系统此时能响应 INTR 引入的中断
- B. DS 中的值为 FFFFH
- C. 系统此时不能响应 NMI 引入的中断
- D. 系统从 FFFF0H 处开始执行程序

**答案：D**

**解析：** 8086 复位后，`CS=FFFFH`，`IP=0000H`，因此物理地址为：

$$
FFFFH \times 10H + 0000H = FFFF0H
$$

所以 CPU 从物理地址 `FFFF0H` 开始取指执行。

**干扰项分析：**

- A 错，复位后中断允许标志 IF 清 0，通常不能响应可屏蔽中断 INTR。
- B 错，复位后是 `CS=FFFFH`，不是 `DS=FFFFH`。
- C 容易混淆，NMI 是非屏蔽中断，不能用 IF 屏蔽；本题标准确定项是复位入口地址。

> 易错点：复位入口记死：`CS:IP = FFFFH:0000H`，物理地址就是 `FFFF0H`。

## 4. READY 采样与等待周期

**题目：** 若在一个总线周期中，CPU 对 READY 信号进行了 3 次采样，那么该总线周期包含时钟周期的数目为（ ）。

**选项：**

- A. 6
- B. 7
- C. 8
- D. 5

**答案：A**

**解析：** 8086 一个基本总线周期通常包含 `T1`、`T2`、`T3`、`T4` 四个时钟周期。当外设或存储器速度较慢时，CPU 根据 READY 信号插入等待周期 `Tw`。READY 被多次采样说明插入了等待周期；本题给出的 3 次采样对应总线周期共 6 个时钟周期。

```text
T1, T2, T3, Tw, Tw, T4  -> 共 6 个 T 状态
```

**干扰项分析：**

- B、C 多算了等待周期。
- D 少算了一个等待周期或基本 T 状态。

> 易错点：正常总线周期是 4 个 T 状态；READY 不满足时会在 `T3` 和 `T4` 之间插入等待周期。

## 5. 不属于 BIU 的寄存器

**题目：** 8086 CPU 中，不属于 BIU 部分的寄存器是（ ）。

**选项：**

- A. `DS`
- B. `IP`
- C. `BP`
- D. `CS`

**答案：C**

**解析：** BIU 中包括段寄存器 `CS`、`DS`、`SS`、`ES` 和指令指针 `IP` 等。`BP` 是基址指针寄存器，属于执行部件 EU 中的通用寄存器组，不属于 BIU。

**干扰项分析：**

- A `DS` 是段寄存器，属于 BIU。
- B `IP` 用于指示下一条指令偏移地址，属于 BIU。
- D `CS` 是代码段寄存器，属于 BIU。

> 易错点：段寄存器和 IP 属于 BIU；通用寄存器、标志寄存器、ALU 等属于 EU。

## 6. 8086 存储器写总线周期控制信号

**题目：** 在 8086 的存储器写总线周期中，微处理器给出的控制信号（最小模式下）`M/IO`、`\overline{RD}`、`\overline{WR}` 分别是（ ）。

**选项：**

- A. 1,0,1
- B. 0,1,0
- C. 1,1,0
- D. 0,0,1

**答案：C**

**解析：** 存储器写周期表示 CPU 向内存写数据。最小模式下：

```text
M/IO = 1       表示访问存储器
\overline{RD} = 1  读信号无效
\overline{WR} = 0  写信号有效，因为 WR 为低电平有效
```

所以三者分别为 `1,1,0`。

**干扰项分析：**

- A 把读信号置为有效，变成读操作。
- B `M/IO=0` 表示 I/O 操作，不是存储器操作。
- D 同时把存储器/I/O 类型和读写方向都弄错。

> 易错点：带横线的 `RD`、`WR` 是低电平有效；写周期时 `WR=0`，`RD=1`。

## 7. 8086 存储器读总线周期控制信号

**题目：** 在 8086 的存储器读总线周期中，微处理器给出的控制信号（最小模式下）`\overline{WR}`、`M/IO`、`\overline{RD}` 分别是（ ）。

**选项：**

- A. 1,1,0
- B. 1,0,1
- C. 0,0,1
- D. 0,1,0

**答案：A**

**解析：** 存储器读周期表示 CPU 从内存读取数据。最小模式下：

```text
\overline{WR} = 1  写信号无效
M/IO = 1       表示访问存储器
\overline{RD} = 0  读信号有效，因为 RD 为低电平有效
```

所以三者分别为 `1,1,0`。

**干扰项分析：**

- B 是 I/O 类型错误且读信号无效。
- C 表示 I/O 操作且写信号有效。
- D 同时出现读写信号都有效的混乱情况，不符合正常读周期。

> 易错点：题目给信号的顺序是 `WR, M/IO, RD`，不是常见的 `M/IO, RD, WR`，答题时先看顺序。

## 8. 8086 存储器读操作中的方向控制

**题目：** 8086 CPU（最小模式下）在进行存储器读操作时，`M/IO`、`\overline{RD}`、`DT/\overline{R}` 必须是（ ）。

**选项：**

- A. 0,1,0
- B. 1,0,0
- C. 0,0,1
- D. 1,1,0

**答案：B**

**解析：** 存储器读操作中：

```text
M/IO = 1       表示访问存储器
\overline{RD} = 0  读信号有效
DT/\overline{R} = 0 表示 CPU 接收数据
```

因此答案为 `1,0,0`。

**干扰项分析：**

- A `M/IO=0` 表示 I/O 操作。
- C `DT/R=1` 表示 CPU 发送数据，不符合读操作。
- D `RD=1` 表示读信号无效。

> 易错点：`DT/\overline{R}` 中，1 表示发送 Transmit，0 表示接收 Receive；CPU 读内存时当然是接收。

## 9. 8086 指令队列长度

**题目：** 8086 CPU 的指令队列缓冲器由（ ）组成。

**选项：**

- A. 1 字节移位寄存器
- B. 6 字节移位寄存器
- C. 8 字节移位寄存器
- D. 4 字节移位寄存器

**答案：B**

**解析：** 8086 的 BIU 中有 6 字节指令队列，用于预取指令，使取指和执行可以一定程度并行。8088 的指令队列是 4 字节，这一点常和 8086 混考。

**干扰项分析：**

- A 太小，不是 8086 指令队列长度。
- C 容易和其他处理器结构混淆。
- D 是 8088 的指令队列长度，不是 8086。

> 易错点：8086 指令队列 6 字节；8088 指令队列 4 字节。

## 10. 写信号开始有效的状态

**题目：** CPU 访问内存时，`\overline{WR}` 开始有效对应的状态是（ ）。

**选项：**

- A. `T1`
- B. `T4`
- C. `T2`
- D. `T3`

**答案：C**

**解析：** 8086 总线周期中，`T1` 主要用于输出地址；从 `T2` 开始，读写等控制信号有效，用来指示当前总线操作类型。因此内存写周期中，`\overline{WR}` 从 `T2` 开始有效。

**干扰项分析：**

- A `T1` 主要输出地址和地址锁存信号。
- B `T4` 是总线周期结束阶段，控制信号撤销。
- D `T3` 是数据传送阶段，但写信号不是到 `T3` 才开始有效。

> 易错点：总线周期大致记：`T1` 出地址，`T2` 出控制，`T3` 传数据，`T4` 结束恢复。

## 11. 8086/8088 的两个独立功能部件

**题目：** 8086/8088 微处理器被设计为两个独立的功能部件：① 和 ②。

**答案：** ① 总线接口部件（BIU） ② 执行部件（EU）

**解析：** 8086/8088 内部采用 BIU 和 EU 分工结构。BIU 负责取指令、形成物理地址、访问存储器和 I/O；EU 负责指令译码、执行运算和更新标志位。

```text
BIU：对外访问、取指、地址形成
EU ：指令执行、算术逻辑运算、标志处理
```

> 易错点：中文名和英文缩写要能互换：BIU = Bus Interface Unit = 总线接口部件；EU = Execution Unit = 执行部件。

## 12. 8086 复位信号

**题目：** 8086 的复位信号引脚是 ①，有效电平是 ②。

**答案：** ① `RESET` ② 高电平

**解析：** 8086 的复位输入信号为 `RESET`，高电平有效。当 `RESET` 有效时，CPU 被初始化，随后从复位入口地址开始执行程序。

> 易错点：8086 的 `RESET` 是高电平有效；很多带横线的控制信号才是低电平有效。

## 13. 控制标志位

**题目：** 8086/8088 CPU 中与单步操作有关的控制标志位是 ①，与中断操作有关的控制标志位是 ②，与串操作有关的控制标志位是 ③。

**答案：** ① `TF` ② `IF` ③ `DF`

**解析：**

- `TF`：Trap Flag，陷阱标志。用于单步执行。
- `IF`：Interrupt Flag，中断允许标志。控制 CPU 是否响应可屏蔽中断。
- `DF`：Direction Flag，方向标志。控制串操作中地址自动增减方向。

> 易错点：`IF` 只控制可屏蔽中断 INTR，不能屏蔽非屏蔽中断 NMI。

## 14. 最大方式和最小方式选择引脚

**题目：** 8086 CPU 工作在最大方式和最小方式是由引脚 ① 信号的状态决定。

**答案：** ① `MN/\overline{MX}`

**解析：** 8086 通过 `MN/\overline{MX}` 引脚选择工作模式。该引脚为高电平时工作在最小模式，为低电平时工作在最大模式。

```text
MN/MX = 1：最小模式
MN/MX = 0：最大模式
```

> 易错点：最大/最小模式不是靠程序设置，而是由硬件引脚状态决定。

## 15. IF 标志位的作用

**题目：** CPU 内部的中断允许标志位 IF 的作用是禁止 CPU 响应 ①。

**答案：** ① 可屏蔽中断

**解析：** `IF` 是中断允许标志。`IF=1` 时，CPU 可以响应可屏蔽中断 `INTR`；`IF=0` 时，CPU 禁止响应可屏蔽中断。

> 易错点：`IF` 不能禁止非屏蔽中断 `NMI`，只能控制可屏蔽中断。

## 16. DMA 操作相关控制线

**题目：** 在 8086/8088 CPU 中，与 DMA 操作有关的控制线是 ① 和 ②。

**答案：** ① `HOLD` ② `HLDA`

**解析：** DMA 控制器需要占用总线时，通过 `HOLD` 向 CPU 发出总线请求。CPU 允许让出总线后，通过 `HLDA` 发出总线响应。

```text
HOLD：总线保持请求
HLDA：总线保持响应
```

> 易错点：`HOLD` 是请求，`HLDA` 是响应；这两个信号常成对出现。

## 17. ALE 信号的作用

**题目：** 在 8086/8088 的总线周期中，ALE 信号在 ① 期间有效。它是一个 ② 脉冲，用于锁存 ③。

**答案：** ① `T1` ② 正 ③ 地址信息

**解析：** 8086 的地址线和数据线存在复用，例如低 16 位地址和数据共用 `AD0-AD15`。因此在 `T1` 期间地址有效时，需要用 ALE 正脉冲把地址锁存下来，供后续总线周期使用。

```text
T1：地址出现，ALE 有效，锁存地址
T2-T4：地址/数据复用线可用于传送数据
```

> 易错点：ALE 锁存的是地址信息，不是数据信息。

## 18. 段地址、偏移地址和物理地址

**题目：** 写出下列存储器地址的段地址、偏移地址和物理地址。

1. `2302H:013AH`
2. `2FE0H:001BH`

**答案：**

| 序号 | 段地址 | 偏移地址 | 物理地址 |
|---|---|---|---|
| 1 | `2302H` | `013AH` | `2315AH` |
| 2 | `2FE0H` | `001BH` | `2FE1BH` |

**解析：** 8086 物理地址计算公式为：

$$
物理地址 = 段地址 \times 10H + 偏移地址
$$

第 1 个地址：

$$
2302H \times 10H + 013AH = 23020H + 013AH = 2315AH
$$

第 2 个地址：

$$
2FE0H \times 10H + 001BH = 2FE00H + 001BH = 2FE1BH
$$

> 易错点：段地址左移 4 位，相当于乘以 `10H`，不是乘以十进制的 10。

## 19. 4KB 存储器物理地址范围

**题目：** 若某存储器容量为 4KB，在计算机存储系统中，其起始地址为 `101AH:3000H`，请计算出该存储器物理地址的范围。

**答案：** `131A0H ~ 1419FH`

**解析：** 先求起始物理地址：

$$
101AH \times 10H + 3000H = 101A0H + 3000H = 131A0H
$$

4KB 的容量为：

$$
4KB = 4 \times 1024 = 4096 = 1000H
$$

地址范围从起始地址开始，最后一个地址要加容量减 1：

$$
终止地址 = 131A0H + 1000H - 1 = 1419FH
$$

所以物理地址范围为 `131A0H ~ 1419FH`。

> 易错点：终止地址是“起始地址 + 容量 - 1”，不是直接加容量。

## 20. 1KB 存储器物理地址范围

**题目：** 若某存储器容量为 1KB，在计算机存储系统中，其起始地址为 `100AH:2000H`，请计算出该存储器物理地址的范围。

**答案：** `120A0H ~ 1249FH`

**解析：** 先求起始物理地址：

$$
100AH \times 10H + 2000H = 100A0H + 2000H = 120A0H
$$

1KB 的容量为：

$$
1KB = 1024 = 400H
$$

因此终止地址为：

$$
120A0H + 400H - 1 = 1249FH
$$

所以物理地址范围为 `120A0H ~ 1249FH`。

> 易错点：`1KB = 400H` 字节，最后地址要减 1。

## 21. 总线周期时间与 READY 检测次数

**题目：** 设 8086 的时钟频率为 5MHz，总线周期中包含 6 个 `Tw` 等待周期。问：

1. 该总线周期是多少？
2. 该总线周期内对 READY 信号检测了多少次？

**答案：** ① `2us` ② `7 次`

**解析：** 时钟频率为 5MHz，则一个时钟周期为：

$$
T = \frac{1}{5MHz}=0.2us
$$

8086 基本总线周期为 4 个 T 状态，若插入 6 个等待周期，则总 T 状态数为：

$$
4 + 6 = 10
$$

所以该总线周期时间为：

$$
10 \times 0.2us = 2us
$$

READY 的检测次数按“等待周期数 + 1”计算：

$$
6 + 1 = 7
$$

> 易错点：有等待周期时，总线周期时间要把基本的 4 个 T 状态也算进去；READY 检测次数通常比等待周期数多 1。
