# N3小单元训练 02：租房与搬家

目标：练习描述条件、比较选择、请求确认，并通过短阅读抓住租房理由和判断依据。

## 本单元句型

- にとって：对于...
- より：比起...
- ほど...ない：不像...那么...
- たほうがいい：最好...
- かどうか：是否...
- ことにする：决定...

## 热身词句

- **家賃**：房租。例：この部屋は家賃が少し高いです。
- **駅前**：车站前。例：駅前には店がたくさんあります。
- **条件**：条件。例：条件に合う部屋を探しています。
- **日当たり**：采光。例：日当たりがいい部屋に住みたいです。
- **引っ越す**：搬家。例：来月、学校の近くに引っ越します。
- **確認する**：确认。例：空いているかどうか確認します。

## 句子翻译

1. 对学生来说，房租便宜很重要。（提示：にとって）
2. 比起车站前，我更想住在学校附近。（提示：より / たい）
3. 这个房间不像照片里看起来那么宽敞。（提示：ほど...ない）
4. 搬家之前，最好先确认周围是否安静。（提示：前に / たほうがいい / かどうか）
5. 如果采光好的话，我决定租这个房间。（提示：たら / ことにする）
6. 请告诉我这个房间能不能马上入住。（提示：かどうか / てください）

## 阅读理解

来月から大学の近くに住むことになったので、私は部屋を探しています。駅前の部屋は便利ですが、家賃が高く、夜も少しうるさいそうです。一方、学校から歩いて十五分の部屋は、駅前ほど便利ではありませんが、家賃が安く、日当たりもいいです。

昨日、不動産屋に行って二つの部屋を見せてもらいました。最初は駅前の部屋がいいと思っていましたが、実際に見てみると、思ったほど広くありませんでした。もう一つの部屋は少し古いですが、勉強する私にとって静かな環境のほうが大切だと思い、そちらにすることにしました。

词汇提示：不動産屋：房产中介 / 一方：另一方面 / 環境：环境

1. 作者为什么在找房子？
   - 要换工作
   - 要住到大学附近
   - 房租突然上涨
   - 车站太远
2. 车站前的房间有什么问题？
   - 采光不好
   - 太旧
   - 房租贵且晚上有点吵
   - 不能马上入住
3. 作者最后选择了哪种房间？
   - 车站前的房间
   - 学校步行十五分钟的房间
   - 更宽的新房间
   - 没有决定
4. 作者最重视什么？
   - 离车站最近
   - 房间最新
   - 安静的学习环境
   - 附近有商店

## 输出小练习

用日语写 2-3 句：你找房子时最重视什么条件？

## 参考答案

1. 学生にとって、家賃が安いことは大切です。
2. 駅前より、学校の近くに住みたいです。
3. この部屋は写真で見たほど広くありません。
4. 引っ越す前に、周りが静かかどうか確認したほうがいいです。
5. 日当たりがよかったら、この部屋を借りることにします。
6. この部屋にすぐ入れるかどうか教えてください。

### 阅读答案

1. 要住到大学附近。开头说「大学の近くに住むことになった」。
2. 房租贵且晚上有点吵。文中说「家賃が高く、夜も少しうるさい」。
3. 学校步行十五分钟的房间。最后说「そちらにすることにしました」，指后一间。
4. 安静的学习环境。文中说「静かな環境のほうが大切」。

### 输出参考

部屋を探すとき、家賃と静かさを大切にしたいです。駅から少し遠くても、勉強しやすい部屋のほうがいいです。
