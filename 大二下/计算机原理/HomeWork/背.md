**答案：** ① 查询传送

## 19. 程序查询方式和中断方式中 CPU 的地位

**题目：** 简述 CPU 在程序查询方式和中断方式中所处的地位。

**答案：**

程序查询方式中，CPU 处于主动地位。CPU 必须不断读取并检测外设状态，确认外设准备好后才进行数据传送。

中断方式中，CPU 处于被动/主导结合的地位。CPU 平时执行自己的程序，外设准备好后主动提出中断请求，CPU 响应后转去执行中断服务程序。

## 20. CPU 与外设之间的数据传送方式

**题目：** CPU 与外设之间有哪几种传送方式？各有什么特点？

**答案：**

- 无条件传送：最简单，默认外设始终就绪，CPU 直接读写，不检测状态。
- 查询传送：CPU 通过程序不断查询外设状态，外设准备好后再传送；硬件简单，但浪费 CPU 时间。
- 中断传送：外设准备好后向 CPU 发中断请求，CPU 响应后传送；减少 CPU 等待，提高利用率，但需要中断控制和现场保护。
- DMA 传送：数据在内存和外设之间直接传送，不经过 CPU 的寄存器；速度快，适合大批量数据传送，但需要 DMA 控制器接管总线。

## 21. 中断及其中断处理过程

**题目：** 什么是中断？简述中断的处理过程。

**答案：** 中断是 CPU 在执行当前程序时，由于内部或外部事件的请求，暂时停止当前程序，转去执行相应服务程序，处 理完后再返回原程序继续执行的过程。

中断处理过程通常包括：

```text
中断请求 -> 中断判优 -> 中断响应 -> 保护现场 -> 执行中断服务程序 -> 恢复现场 -> 中断返回
```

## 23. DMA 工作方式的主要特点

**题目：** 简述 DMA 工作方式的主要特点。

**答案：** DMA 方式的主要特点是数据在内存与外设之间直接高速传送，不经过 CPU 内部寄存器。传送过程中由 DMA 控制器接管总线控制权，从而提高大批量数据传输效率，并释放 CPU 的计算资源。

## 14. 异步通信中“异步”的含义

**题目：** 异步通信中，异步的含义是什么？

**答案：** 异步通信中，发送方和接收方不需要共用同一个同步时钟。每个字符独立发送，通常依靠起始位和停止位来标志一个字符的开始和结束，从而实现字符级同步。

## 7. 8253 的写命令

**题目：** 8253 有三条写命令，分别是 ①、②、③。

**答案：** ① 控制字命令；② 计数初值命令；③ 锁存命令

```text
计数初值命令：向指定计数器写入计数初值
锁存命令：在计数过程中锁存当前计数值，便于 CPU 读取
```

## 8. 定时或延时的实现方法

**题目：** 在微机应用系统中，实现定时或延时可采用三种方法实现：①、②、③。

**答案：** ① 软件延时；② 硬件定时；③ 中断定时

**解析：**

```text
软件延时：靠程序循环等待，占用 CPU，精度较低
硬件定时：由定时器/计数器完成，精度较高
中断定时：定时器到时发出中断，CPU 响应服务程序，效率较高
```
