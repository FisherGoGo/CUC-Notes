# N3小单元训练 08：遗失物与求助

目标：练习说明遗失情况、地点时间和礼貌求助，并通过短阅读理解找回过程。

## 本单元句型

- てしまう：遗憾...
- かもしれない：可能...
- たまま：保持...状态
- てもらう：请别人帮忙
- ようだ：好像...
- 見つかる：被找到

## 热身词句

- **財布**：钱包。例：財布をなくしてしまいました。
- **落とし物**：遗失物。例：落とし物センターへ行きます。
- **届ける**：送交。例：誰かが駅に届けてくれました。
- **探す**：寻找。例：かばんの中を探しました。
- **連絡先**：联系方式。例：連絡先を書いてください。
- **身分証**：身份证件。例：財布の中に身分証が入っています。

## 句子翻译

1. 我好像把钱包落在电车上了。（提示：ようだ / てしまう）
2. 钱包里可能有学生证。（提示：かもしれない）
3. 请帮我确认一下遗失物中心。（提示：てもらう）
4. 我没关包就跑上了电车。（提示：たまま）
5. 如果找到了，请联系这个号码。（提示：たら / てください）
6. 多亏有人送到车站，我找回了钱包。（提示：おかげで / 見つかる）

## 阅读理解

昨日、電車を降りたあとで財布がないことに気がつきました。かばんを閉めないまま急いで乗ったので、電車の中に落としてしまったのかもしれません。財布の中には学生証と銀行のカードが入っていたため、私はすぐ駅の事務室へ行きました。

駅員さんに説明すると、落とし物センターに連絡してくれました。まだ届いていないと言われましたが、連絡先を書いて待つことにしました。その日の夜、駅から電話があり、財布が見つかったそうです。知らない人が届けてくれたと聞いて、本当に安心しました。

词汇提示：事務室：办公室 / 銀行：银行 / 安心する：放心

## 输出小练习

用日语写 2-3 句：如果你丢了钱包，会怎么向车站工作人员说明？

## 参考答案

1. 財布を電車に落としてしまったようです。
2. 財布の中に学生証が入っているかもしれません。
3. 落とし物センターを確認してもらえませんか。
4. かばんを閉めないまま電車に乗ってしまいました。
5. 見つかったら、この番号に連絡してください。
6. 誰かが駅に届けてくれたおかげで、財布が見つかりました。

### 阅读答案

1. 下车后。文中说「電車を降りたあとで」。
2. 电车里。文中说「電車の中に落としてしまったのかもしれません」。
3. 学生证和银行卡。文中说「学生証と銀行のカード」。
4. 陌生人送到车站。文中说「知らない人が届けてくれた」。

### 输出参考

電車の中で財布を落としてしまったかもしれません。中に学生証が入っているので、見つかったら連絡していただけませんか。
