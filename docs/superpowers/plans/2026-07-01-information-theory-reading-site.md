# Information Theory Reading Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a stable, six-chapter Chinese information-theory reading site with academic editorial styling, static search, build-time math rendering, native expandable derivations, and shareable deep links.

**Architecture:** Create an isolated Astro project in `大二下/信息论与编码/05_网页`. Six independently maintained MDX chapters form a typed build-time content collection; Astro generates static chapter pages, KaTeX renders formulas during the build, and Pagefind indexes the completed HTML. The site ships no backend and uses client JavaScript only for search, mobile drawers, active headings, and copying links.

**Tech Stack:** Astro, TypeScript, MDX, KaTeX (`remark-math` + `rehype-katex`), Pagefind, Vitest, Playwright, GitHub Pages Actions.

- [ ] **Step 3: Implement the pure chapter helpers**

Create `src/lib/chapters.ts`:

```ts
export type ChapterEntry = {
  id: string;
  data: { order: number; title: string; summary?: string };
};

export type SequencedChapter<T extends ChapterEntry> = T & {
  previous: T | null;
  next: T | null;
};

export function buildChapterSequence<T extends ChapterEntry>(entries: T[]): SequencedChapter<T>[] {
  const sorted = [...entries].sort((a, b) => a.data.order - b.data.order);
  return sorted.map((entry, index) => ({
    ...entry,
    previous: sorted[index - 1] ?? null,
    next: sorted[index + 1] ?? null,
  }));
}

export function withBase(base: string, path: string): string {
  return `${base.replace(/\/$/, '')}/${path.replace(/^\//, '')}`;
}
```

```yaml
name: Deploy information theory site

on:
  push:
    branches: [main]
    paths:
      - '大二下/信息论与编码/05_网页/**'
      - '.github/workflows/information-theory-pages.yml'
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: withastro/action@v6
        with:
          path: 大二下/信息论与编码/05_网页

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```
