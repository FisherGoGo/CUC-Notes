# 第二幕中文分镜提示词（15秒版）

## 第二幕定位

承接第一幕结尾。第一幕最后是“影子活了、四人即将被吸入幕布”，第二幕负责完成转场：四人进入幕布内部的 2D 皮影戏风格世界。角色形象保持参考图设定，不需要变成传统皮影偶关节结构，也不需要像皮影偶一样僵硬活动。她们可以在平面化光影空间里自由走动、摔倒、观察和互动。

本幕暂时不完整展开《三打白骨精》，只在结尾露出“白虎岭影幕入口”，作为下一幕的过渡。

## 全局风格提示词

Q版卡通动画风格，中国传统皮影戏风格，暖黄色背光，白色半透明皮影幕布，红黑金彩绘皮影纹样，皮革镂空质感，2D 平面光影舞台，竹制操纵杆和皮影道具作为环境元素，轻松欢乐的奇幻冒险氛围。角色使用已有参考图形象，保持原本 Q版角色设计和服装，不要把角色改造成传统皮影偶，不要增加皮影关节。画面干净，动作清楚，角色可以自由活动，表情夸张可爱，光影柔和，不要写实摄影感。角色不说完整人话，只发出固定可爱叫声，字幕后期添加。

## 全局负面提示词

不要生成文字，不要生成字幕，不要水印，不要 logo，不要恐怖氛围，不要黑暗传送门，不要赛博霓虹，不要现代舞台灯，不要真实成人，不要多余人物，不要畸形脸，不要坏手，不要多手指，不要角色五官漂移，不要角色服装大幅变化，不要杂乱背景，不要塑料玩具感，不要 3D 手办感，不要完全写实皮影，不要把角色变成纯黑影，不要把角色变成有关节的皮影偶，不要让角色动作僵硬。

## 角色发声规则

- 西格莉卡只发出“西西”，字幕显示真实意思。
- 达妮娅只发出“娅娅”，字幕显示真实意思。
- 菲比只发出“菲比啾比”，字幕显示真实意思。
- 弗诺诺只发出“诺诺”，字幕显示真实意思。

## 第二幕大体场景生成提示词

用途：生成第二幕整体环境参考。这里是“幕布内部的影戏世界”，不是现实戏馆。

```text
Q版卡通动画风格的中国皮影戏幕布内部世界，整体像进入了发光的 2D 皮影舞台。背景是温暖的白色半透明幕布空间，四周有柔和的暖黄色背光，地面像浅色宣纸和木质戏台结合，远处漂浮着红黑金彩绘皮影纹样、云纹、灯影和竹制操纵杆的剪影。画面中央留出四个 Q版角色落下和自由活动的位置，右侧可以看到几根放大的竹制操纵杆作为环境道具，远景隐约有下一关“白虎岭”的剪影入口。整体氛围奇幻、温暖、可爱，不恐怖，不写实。不出现文字，不出现观众，不出现现代道具。
```

## 第二幕分镜

[0-2秒][全白转场到中景][白光渐弱]：承接第一幕最后的白光。画面先是柔和白光充满全屏，然后白光慢慢减弱，露出幕布内部的 2D 皮影舞台空间。四个 Q版角色已经站在舞台中央，不表现被吸入、不表现空中下落、不表现身体变形。角色保持参考图里的原本形象和服装，不要变成皮影偶。画面重点是“白光转场后已经进入幕布内部”，不要出现其他人物。字幕后期添加：“等一下，我们真的进来了？”实际发声：西格莉卡“西西？”

[2-4秒][远景][缓慢后退]：四个角色站在幕布内部的 2D 皮影舞台中央，背景是温暖的白色半透明空间，周围漂浮着红黑金皮影纹样、云纹剪影和竹制操纵杆剪影。角色保持原本 Q版参考图形象，只受到暖光和扁平化背景影响，不改变成皮影偶。画面重点是展示新环境，不做大幅动作。字幕后期添加：“这里是幕布里面？”实际发声：达妮娅“娅娅？”

[4-6秒][中景][固定]：四人保持清楚站位，不摔倒，避免动作混乱。西格莉卡站在前方中央抱着记录本，达妮娅站在左侧慢半拍抬头观察，菲比站在右前方靠近皮影道具，弗诺诺站在右后方看向四周。角色仍然保持参考图中的原本 Q版外观，只是处在皮影戏幕布内部的 2D 光影空间里。字幕后期添加：“这里像是幕布里面的舞台。”实际发声：弗诺诺“诺诺？”

[6-8秒][特写][从地面道具缓慢上移]：镜头特写地面上的皮影戏道具：彩绘皮影偶、竹制操纵杆、小锣鼓、红黑金镂空纹样。镜头从道具上移到四个角色的脚边，表现她们落在一个充满皮影元素的 2D 舞台空间里。角色可以自由活动，不表现皮影关节。画面重点是“皮影道具和舞台环境”。字幕后期添加：“这些都是皮影戏里的道具。”实际发声：西格莉卡“西西！”

[8-10秒][中近景][轻微横移到菲比]：菲比站在右前方，低头看到地面上的竹制操纵杆。她只用一只手轻轻拿起操纵杆，不挥舞，不做大动作。镜头右侧单独出现一个小型彩绘皮影偶，皮影偶因为操纵杆被轻轻拉动而小幅摆动一下。菲比表情从得意变成惊讶，其他三人只在背景看向她。画面重点是“操纵杆能控制皮影偶”，角色本身自由活动。字幕后期添加：“咦？这根杆子能让影偶动！”实际发声：菲比“菲比啾比！”

[10-12秒][中景][固定]：达妮娅抬头看向幕布上方的光源，发现光变强时地面上的皮影偶影子变大，光变弱时影子变淡。她懒懒但准确地指向光的方向，其他人顺着她看过去。画面重点是灯光和影子的关系，不改变角色形态。字幕后期添加：“影子的大小，跟灯光有关。”实际发声：达妮娅“娅娅。”

[12-15秒][广角中景][缓慢后退露出远景]：四人站稳，保持原本 Q版角色形象，望向远处。远处的幕布空间慢慢展开成一片皮影风格的山岭舞台布景，树木、山石、云纹都是红黑金皮影纹样，中央出现“白虎岭”风格的山路入口，但不要生成文字。入口处只有轻微白雾和暖光，不出现人形怪物，不出现清晰妖怪剪影，避免提前生成复杂角色。四人表情从惊慌变成紧张好奇。字幕后期添加：“前面好像还有一出戏在等我们。”实际发声：四人短促发出“西西、娅娅、菲比啾比、诺诺。”

## 剪辑顺序

[0-2秒] 白光转场，四人已进入幕布内部。  
[2-4秒] 展示幕布内部影戏世界。  
[4-6秒] 四人站定，观察舞台空间。  
[6-8秒] 特写皮影道具和舞台环境。  
[8-10秒] 菲比轻拿操纵杆，带动真正的皮影偶小幅摆动。  
[10-12秒] 达妮娅发现灯光影响影偶影子。  
[12-15秒] 远处出现白虎岭入口，过渡到下一幕。

## 生成建议

每次生成时复制：

1. 全局风格提示词。
2. 全局负面提示词。
3. 对应镜头的 `[时间][景别][运镜]：内容`。

这一幕可以尝试一次生成 15 秒完整视频，但更稳的做法仍然是拆成 2-3 段：`0-6秒`、`6-10秒`、`10-15秒`。如果软件对角色一致性不稳定，优先拆分。生成时使用你的角色参考图，提示词里不要再详细描述角色外观。
