# 第十章练习题（无答案版）

## 1. 10 位 D/A 转换器的分辨率

**题目：** 10 位 D/A 转换器的分辨率能给出满量程电压的（ ）。

**选项：**

- A. `1/256`
- B. `1/1024`
- C. `1/512`
- D. `1/10`

## 2. A/D 转换器向 CPU 发出的中断请求信号

**题目：** 当 CPU 使用中断方式从 A/D 转换器读取数据时，A/D 转换器向 CPU 发出中断请求的信号是（ ）。

**选项：**

- A. START
- B. EOC
- C. OE
- D. INTR

## 3. 启动 ADC0809 进行 A/D 转换的方法

**题目：** 启动 ADC0809 芯片开始进行 A/D 转换的方法是（ ）。

**选项：**

- A. ALE 引脚输入一个正脉冲
- B. START 引脚输入一个正脉冲
- C. ALE 引脚在 A/D 转换期间一直为高电平
- D. START 引脚在 A/D 转换期间一直为高电平

## 4. A/D 转换器分辨率与转换精度的关系

**题目：** A/D 转换器的分辨率与转换精度的关系是（ ）。

**选项：**

- A. 分辨率高，转换精度一定高
- B. 分辨率与转换精度没有关系
- C. 分辨率高，其转换精度不一定高
- D. 分辨率越高，转换精度越低

## 5. D/A 转换器稳定性的技术指标

**题目：** 反映一个 D/A 转换器稳定性的技术指标是（ ）。

**选项：**

- A. 转换速度
- B. 分辨率
- C. 输出阻抗
- D. 精度
