## 2.1 8086/8088 CPU 内部结构

### 2.1.1 功能结构

8086/8088 CPU内部由两个独立的功能部件组成：

| 部件 | 英文名 | 功能 |
|------|--------|------|
| **总线接口部件** | BIU (Bus Interface Unit) | 负责取指令、读写操作数（与外部总线打交道） |
| **执行部件** | EU (Execution Unit) | 负责执行指令（译码、运算等） |

**并行工作**：BIU和EU可并行工作——EU执行指令的同时，BIU预取后续指令到指令队列，提高CPU效率。

#### BIU 组成

- 指令队列（8086：6字节，8088：4字节）
- 段寄存器（CS、DS、SS、ES）
- 指令指针 IP
- 地址加法器（物理地址 = 段基址 × 16 + 偏移地址）
- 总线控制逻辑

#### EU 组成

- 通用寄存器（AX、BX、CX、DX）
- 指针和变址寄存器（SP、BP、SI、DI）
- 标志寄存器 FR
- ALU（算术逻辑单元）
- EU控制逻辑

### 2.1.2 8086 vs 8088

| 特性 | 8086 | 8088 |
|------|------|------|
| 内部结构 | 16位 | 16位（与8086相同） |
| 外部数据总线 | 16位 | **8位** |
| 指令队列 | 6字节 | 4字节 |
| 引脚数 | 40 | 40 |

> 8088内部16位，外部8位——称为准16位微处理器。

## 2.2 8086/8088 寄存器结构

### 2.2.1 通用寄存器

| 寄存器 | 高8位 | 低8位 | 主要用途 |
|--------|-------|-------|----------|
| **AX** (累加器) | AH | AL | 算术运算、I/O操作 |
| **BX** (基址寄存器) | BH | BL | 基址寻址 |
| **CX** (计数器) | CH | CL | 循环计数、移位次数 |
| **DX** (数据寄存器) | DH | DL | I/O端口地址、大数乘除 |

### 2.2.2 段寄存器

| 寄存器 | 全称 | 用途 |
|--------|------|------|
| **CS** | Code Segment | 代码段基址 |
| **DS** | Data Segment | 数据段基址 |
| **SS** | Stack Segment | 堆栈段基址 |
| **ES** | Extra Segment | 附加段基址 |

### 2.2.3 指针和变址寄存器

| 寄存器 | 用途 |
|--------|------|
| **SP** (Stack Pointer) | 堆栈指针，指向栈顶 |
| **BP** (Base Pointer) | 基址指针，常用于访问堆栈 |
| **SI** (Source Index) | 源变址寄存器 |
| **DI** (Destination Index) | 目的变址寄存器 |
| **IP** (Instruction Pointer) | 指令指针，指向下一条指令（不可直接访问） |

### 2.2.4 标志寄存器 FR (FLAGS)

16位标志寄存器，实际使用9位，分为**状态标志**和**控制标志**。

#### 状态标志（6个）

| 标志 | 位 | 名称 | 功能 |
|------|----|------|------|
| **CF** | D0 | 进位/借位标志 | 运算时最高位有进位/借位→1 |
| **PF** | D2 | 奇偶标志 | 结果低8位中1的个数为偶数→1 |
| **AF** | D4 | 辅助进位标志 | D3向D4有进位/借位→1（用于BCD调整） |
| **ZF** | D6 | 零标志 | 结果为零→1 |
| **SF** | D7 | 符号标志 | 结果的最高位（有符号数的符号） |
| **OF** | D11 | 溢出标志 | 有符号数运算溢出→1 |

#### 控制标志（3个）

| 标志 | 位 | 名称 | 功能 |
|------|----|------|------|
| **TF** | D8 | 陷阱/单步标志 | TF=1→每执行1条指令产生单步中断 |
| **IF** | D9 | 中断允许标志 | IF=1→开中断（响应INTR）；IF=0→关中断 |
| **DF** | D10 | 方向标志 | DF=0→串操作地址递增；DF=1→递减 |

## 2.3 存储器组织与分段

### 2.3.1 物理地址计算

8086/8088有20根地址线，可寻址 **1MB**(2^20) 存储空间（00000H~FFFFFH）。

内部寄存器只有16位，采用**分段**方式形成20位物理地址：

$$\text{物理地址} = \text{段基址} \times 16 + \text{偏移地址}$$

即：段寄存器内容左移4位（相当于×16）+ 16位偏移量。

> 例：(CS)=2000H, (IP)=0100H → 物理地址 = 20000H + 0100H = 20100H

### 2.3.2 逻辑地址

逻辑地址表示为：**段基址:偏移地址** （如 `2000H:0100H`）

### 2.3.3 四种段的默认组合

| 操作类型 | 默认段 | 默认偏移 | 可否跨段 |
|----------|--------|----------|----------|
| 取指令 | CS | IP | 否 |
| 堆栈操作 | SS | SP | 否 |
| 一般数据存取 | DS | 有效地址EA | 可 |
| BP间址 | SS | 有效地址EA | 可 |
| 串操作目的 | ES | DI | 否 |
| 串操作源 | DS | SI | 可 |

### 2.3.4 I/O 空间

8086/8088 I/O地址独立编址：**64KB**（0000H~FFFFH），通过M/IO（8086）或IO/M（8088）信号区分。

## 2.4 8086 引脚与总线周期

### 2.4.1 引脚功能分类

| 功能 | 信号 |
|------|------|
| 地址/数据复用 | AD15~AD0（8086）/ AD7~AD0（8088） |
| 地址/状态 | A19/S6 ~ A16/S3 |
| 控制信号 | RD, WR, M/IO, ALE, DEN, DT/R, INTR, INTA, NMI, RESET, READY, HOLD, HLDA |
| 电源与时钟 | VCC(+5V), GND, CLK |
| 模式选择 | MN/MX（最小/最大模式） |

### 2.4.2 最小模式与最大模式

| 模式 | MN/MX引脚 | 适用场景 |
|------|-----------|----------|
| **最小模式** | +5V | 单处理器系统 |
| **最大模式** | GND | 多处理器/协处理器系统 |

### 2.4.3 总线周期

一个基本总线周期由 **4个T状态**（T1~T4）组成：

| T状态 | 操作 |
|--------|------|
| **T1** | CPU发出地址信号，ALE锁存地址 |
| **T2** | CPU撤销地址，发出控制信号 |
| **T3** | 数据出现在数据总线上，检测READY |
| **T3w** | READY=0时插入等待周期Tw |
| **T4** | CPU读入/写出数据，结束总线周期 |

## 2.5 32位微处理器

### 2.5.1 80386 主要特性

- **32位**数据总线，**32位**地址总线
- 可直接寻址 **4GB**(2^32) 物理内存
- 支持**虚拟8086模式**（可同时运行多个8086程序）
- 引入**保护模式**（完善的多任务保护和虚拟内存支持）

### 2.5.2 80386 寄存器

| 寄存器类型 | 名称 | 位数 |
|------------|------|------|
| 通用寄存器 | EAX, EBX, ECX, EDX, ESI, EDI, EBP, ESP | 32位 |
| 段寄存器 | CS, DS, SS, ES, **FS, GS** | 16位（新增FS和GS） |
| 指令指针 | EIP | 32位 |
| 标志寄存器 | EFLAGS | 32位 |
| 控制寄存器 | CR0~CR3 | 32位 |

### 2.5.3 80386 工作模式

| 模式 | 说明 |
|------|------|
| **实模式** | 兼容8086，相当于快速8086，寻址1MB |
| **保护模式** | 支持4GB寻址、虚拟内存、多任务保护 |
| **虚拟8086模式** | 在保护模式下模拟多个8086环境 |

### 2.5.4 80486 改进

- 内置**8KB L1 Cache**（指令+数据统一）
- 集成**FPU（浮点运算单元）** → 相当于80386+80387
- 流水线优化（部分指令1个时钟周期）

## 2.6 典型的8086系统配置

### 2.6.1 最小模式系统

需要外接芯片：

| 芯片 | 功能 | 说明 |
|------|------|------|
| **8284A** | 时钟发生器 | 提供CLK、READY、RESET |
| **8282/8283** | 地址锁存器 | 锁存地址信号（ALE控制） |
| **8286/8287** | 数据总线收发器 | 双向数据驱动（DEN、DT/R控制） |

### 2.6.2 最大模式系统

额外增加：
- **8288 总线控制器**：根据CPU状态信号产生系统总线控制信号
- **8087 协处理器**：硬件浮点运算加速

## 2.7 复位与启动

- **RESET** 引脚高电平触发复位
- 复位后：CS=FFFFH, IP=0000H → 物理地址 **FFFF0H**
- FFFF0H处通常放一条JMP指令，跳转到系统初始化程序（BIOS入口）
- 复位后标志寄存器被清零（关中断、禁止单步等）
