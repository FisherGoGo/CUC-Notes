# 数字信号处理笔记独立完善版设计

在完全保留原始章节笔记的前提下，生成一套可直接用于期末复习的独立完善版。完善版以纠错为核心，补齐关键定义、公式条件、必要推导和易错点，但不扩写成教材式讲义。

## 输入范围

- 原始章节：`大二下/数字信号处理/01_章节笔记/` 中现有的 01、02、03、04、06、07、08 七章。
- 第五章依据用户提供的课程要求补写，覆盖：
  1. 序列插值与抽取的基本理论；
  2. 插值、抽取前后频谱的变化；
  3. 信号采样率的转换方法。
- 风格参考：`大二下/信息论与编码/01_笔记/` 下的章节笔记。
- 校核材料优先使用仓库内的课程资料、复习资料和教材；如仓库材料不足，再使用可靠的公开资料交叉核对。

## 内容处理规则

### 保留

- 保留原笔记的知识顺序、个人措辞和记忆线索，只在存在错误、歧义或明显跳跃时调整。
- 保留短段落、项目列表、公式块、引用式提醒和自查问题等写法。
- 保留课程常用符号；若同一符号在不同章节含义不同，则在首次出现处明确定义。

### 纠错

- 检查概念边界、变换定义、求和范围、索引、正负号、比例因子、收敛域、频率单位和适用条件。
- 检查推导中是否存在换元错误、符号复用、漏项或结论超出前提。
- 对有多种教材约定的写法，明确本笔记采用的约定，不把约定差异误判为错误。

### 补充

- 补足解题必须知道的定义、条件、推导连接和结论解释。
- 优先补充高频易错点、典型判断依据、公式之间的联系与本章自查问题。
- 不系统加入大量证明、冷门结论或成套例题；只有在原笔记容易产生误解时加入短例子。

## 章节写作风格

每章尽量沿用以下节奏，不强制套用完全相同的模板：

1. 章标题与一句话主线；
2. 按原笔记顺序组织知识点；
3. 定义后紧跟公式、符号解释和适用条件；
4. 在关键处给出物理意义或直观理解；
5. 用引用块标出易错点；
6. 章末保留或补充自查问题。

语言保持简洁、直接、适合复习，避免统一改写成正式教材腔。

## 第五章设计

第五章按照多采样率信号处理的基础链路展开：

1. 整数倍抽取：时域定义、频域表达、频谱压缩与混叠、抗混叠滤波器；
2. 整数倍插值：零值插入、频域表达、频谱镜像与抗镜像滤波器；
3. 有理数倍采样率转换：先插值后抽取、低通滤波器的位置及截止频率条件；
4. 采样率与数字频率、模拟频率之间的对应关系；
5. 常见画频谱题和流程图题的判断顺序；
6. 易错点与自查问题。

第五章的表述与前四章使用的 DTFT、DFT 和抽样概念保持一致，并与第六章滤波器内容自然衔接。

## 校核与验收

- 原始 `01_章节笔记` 目录内文件不发生修改。
- 完善版共八章，章节编号连续且 MOC 链接有效。
- 每章至少完成概念、公式、符号、条件和 Markdown/LaTeX 五类检查。
- 对重要公式进行跨章节一致性检查，尤其是角频率记号、DFT/DTFT 约定、卷积类型、滤波器指标和采样率转换比例。
- `完善说明.md` 中的纠错条目能对应到具体章节与知识点。
- 不确定或依赖教师特定口径的内容明确标注，不以猜测补齐。
