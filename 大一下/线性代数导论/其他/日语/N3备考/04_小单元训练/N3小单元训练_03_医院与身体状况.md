# N3小单元训练 03：医院与身体状况

目标：练习说明症状、接受建议、表达必要性，并通过短阅读理解原因和医生建议。

## 本单元句型

- たら：如果...
- ように言われる：被要求...
- ないようにする：尽量不...
- ために：为了...
- そうだ：听说/看起来
- なければならない：必须...

## 热身词句

- **熱**：发烧。例：昨日の夜から熱があります。
- **喉**：喉咙。例：喉が痛くて、話しにくいです。
- **薬**：药。例：この薬は食後に飲みます。
- **診察**：诊察。例：午前中に診察を受けました。
- **休む**：休息。例：今日は学校を休みました。
- **無理をする**：勉强硬撑。例：無理をしないでください。

## 句子翻译

1. 如果发烧了，最好早点去医院。（提示：たら / たほうがいい）
2. 医生让我今天不要勉强。（提示：ように言われる）
3. 为了不让喉咙变得更痛，我尽量少说话。（提示：ために / ないようにする）
4. 这个药听说一天要吃三次。（提示：そうだ / なければならない）
5. 因为明天有考试，所以我不能一直休息。（提示：ので / わけにはいかない）
6. 请在症状变严重之前联系老师。（提示：前に / てください）

## 阅读理解

昨日から喉が痛く、今朝は少し熱もありました。私は明日試験があるので、学校を休むかどうか迷いましたが、無理をして悪くなると困ると思い、病院へ行くことにしました。診察のあと、医者に「今日は早く帰って、できるだけ声を出さないようにしてください」と言われました。

薬は一日に三回、食後に飲まなければなりません。家に帰ってから友達に連絡すると、授業で配られたプリントの写真を送ってくれました。友達のおかげで、休んでも試験の準備が続けられそうです。

词汇提示：症状：症状 / 配る：分发 / おかげで：多亏

1. 作者为什么犹豫要不要休息？
   - 明天有考试
   - 医院很远
   - 药很贵
   - 朋友要来
2. 医生建议作者做什么？
   - 多运动
   - 尽量不要出声
   - 马上回学校
   - 不吃药
3. 药什么时候吃？
   - 饭前
   - 睡前
   - 饭后一天三次
   - 只在发烧时
4. 朋友帮作者做了什么？
   - 陪他去医院
   - 发送课堂资料照片
   - 替他考试
   - 买了药

## 输出小练习

用日语写 2-3 句：身体不舒服时，你会怎么安排学习？

## 参考答案

1. 熱が出たら、早めに病院へ行ったほうがいいです。
2. 医者に今日は無理をしないように言われました。
3. 喉がもっと痛くならないように、あまり話さないようにしています。
4. この薬は一日に三回飲まなければならないそうです。
5. 明日は試験があるので、ずっと休むわけにはいきません。
6. 症状がひどくなる前に、先生に連絡してください。

### 阅读答案

1. 明天有考试。文中说「明日試験があるので」。
2. 尽量不要出声。医生说「できるだけ声を出さないように」。
3. 饭后一天三次。文中说「一日に三回、食後に」。
4. 发送课堂资料照片。文中说「プリントの写真を送ってくれました」。

### 输出参考

体の調子が悪いときは、無理をしないようにします。大切なプリントだけ確認して、早く寝るつもりです。
