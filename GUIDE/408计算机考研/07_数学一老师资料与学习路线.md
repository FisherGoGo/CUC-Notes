# 数学一老师、资料与学习路线

> 整理时间：2026-07-16  
> 适用定位：计算机类专硕，暂按英语一、数学一、408 保留最大择校空间。  
> 说明：老师和习题评价带有很强的个人差异。本文件把网友经验当作样本，不把任何一位高分考生的题量和进度当作必须复制的标准。

## 一、先说结论

你提出的 **“基础张宇，强化武忠祥”是可行方案**，尤其适合以下情况：

- 高中和大学数学基础不算差；
- 能接受较大的基础阶段知识量；
- 听完课愿意自己复现推导和做题；
- 目前开始得早，不急着用最短时间结束基础。

推荐的默认搭配是：

| 模块       | 基础阶段           | 强化阶段               | 主练习                                      |
| -------- | -------------- | ------------------ | ---------------------------------------- |
| 高等数学     | 张宇基础课程与《基础30讲》 | 武忠祥强化课程与《高等数学辅导讲义》 | 基础阶段做配套题或《1000题》A组；强化以《880题》或《严选题》为主，二选一 |
| 线性代数     | 张宇、李永乐或姜晓千中选一位 | 原则上延续同一体系，确有困难再换   | 《880题》线代部分，配合主讲老师讲义例题                    |
| 概率论与数理统计 | 方浩、余丙森、李林等选一位  | 尽量不换体系             | 主讲讲义配套题 + 《880题》概率部分                     |

这不是唯一正确组合。比老师名字更重要的是：

1. 一门课程真正听完；
2. 例题能够合上书独立重做；
3. 一本主习题真正完成、复盘并重做错题；
4. 后期完成真题整套计时和稳定的计算训练。

如果试听后发现张宇的信息量让你长期跟不上，不要硬撑，可以直接改为武忠祥或汤家凤打基础。反过来，如果听武忠祥基础课后觉得框架不够完整、独立做题时知识缺口较多，也可以用《基础30讲》查漏，但没有必要再看一遍完整课程。

## 二、对网友经验的判断

### 1. 值得直接吸收的部分

- **听课时暂停并自己复现推导、例题。** 这比连续看完几个小时视频有效得多。
- **课后立即做对应题目。** 数学不能用“听懂了”代替“做得出”。
- **强化阶段减少被动听讲，增加独立研究答案的时间。**
- **把线性代数看成一个整体。** 行列式、矩阵、秩、方程组、特征值、二次型之间联系紧密。
- **真题和模拟卷必须限时完成，并完整复盘。**
- **某一知识点卡住时，可以搜索其他老师的专项讲解。** 这是局部补救，不是更换整套主线。
- **答案看懂后必须关掉答案重做。** 仅仅看懂解析会产生很强的“我已经会了”的错觉。

### 2. 可以采用，但需要修改的部分

#### 基础结束后先做一批真题

这个思路有价值，因为真题能告诉你“考试究竟怎样问”。但不建议在强化前就把近十年完整真题全部消耗掉。

更稳妥的做法：

- 基础完成后，用较早年份真题按章节或按模块做诊断；
- 最近 8—10 年真题尽量留到强化完成后，按完整试卷、3 小时计时；
- 提前做过的真题，后期仍然要二刷，但二刷分数不能当作真实模考水平。

#### 五分钟没有思路就看答案

基础阶段不必在一道陌生综合题上耗四五十分钟，但五分钟有时太短。

- 基础题：独立尝试约 10—15 分钟；
- 强化综合题：可尝试约 15—25 分钟；
- 若完全没有方向，先定位所考知识点，再看答案的第一步；
- 看完后合上答案，从头完整写出，不要抄题。

#### 线代基础和强化连在一起

线代确实适合连续学习，避免战线拖得太长；但不建议六章完全不做题。

可以采用：

1. 每章学习后做少量基础题，保证概念没有断层；
2. 六章学完后集中建立整体框架；
3. 再做一轮综合题和强化题。

### 3. 不建议直接照搬的部分

- **每天数学 4—5 小时、全年大量刷卷。** 这是正式备考年冲高分者的安排，不适合你目前提前准备阶段机械复制，还要给英语和408留出长期时间。
- **同时做两三本完整习题集。** 一本主练习吃透，通常优于三本各做一半。
- **听多个老师的完整基础课或强化课。** 局部补课可以，完整重复通常性价比很低。
- **认为数一“几乎没有难题”。** 数一的主体确实是基础与中档题，但高分仍要求应对新颖选择填空、综合计算和少量较难题，不能因此降低训练标准。
- **认为模拟卷刷得越多分数必然越高。** 模拟卷只有经过限时、订正、归因和重做才产生价值；只追求套数很容易变成机械消耗。
- **照抄149分考生的资料数量。** 高分经验存在基础差异、幸存者偏差和叙述遗漏，应该复制其学习闭环，而不是复制题量。

## 三、老师怎么选

### 1. 高等数学

#### 张宇

常见特点：

- 知识覆盖较广，强调概念、方法和一些拓展结论；
- 课堂节奏有趣，比较容易坚持；
- 课程和书的体系较完整；
- 内容量偏大，容易让学生产生“学了很多但题没做够”的问题。

更适合：

- 基础中等以上；
- 接受能力较强；
- 开始较早；
- 愿意筛掉偏难、偏技巧内容，不追求一次记住所有二级结论。

使用原则：

- 基础阶段第一次学习以概念、基本计算和常规题型为主；
- 对明显偏难的技巧先做标记，不要求当场全部掌握；
- 听课时间不要长期超过数学总学习时间的一半。

#### 武忠祥

常见特点：

- 逻辑清晰，重视概念条件、方法归纳和一题多解；
- 强化课程口碑较稳定；
- 课堂相对平稳，需要主动暂停、动笔，否则容易“听得很顺”但没有真正掌握。

更适合：

- 喜欢严谨、清晰的讲解；
- 希望围绕主干考点建立稳定方法；
- 基础一般，希望减少前期信息负担；
- 强化阶段需要深化概念和解题思路。

#### 汤家凤

常见特点：

- 讲解较慢、步骤较细；
- 重视基本计算和重复训练；
- 适合基础薄弱、需要被带着完成第一轮的学生；
- 如果本身基础较好，可能觉得节奏偏慢、题量偏重复。

#### 周洋鑫等其他老师

可以试听，但没有必要仅因网上出现新的高评价就更换主线。判断标准仍应是：听完一节后能不能独立完成对应基础题，而不是课堂上是否觉得“醍醐灌顶”。

### 2. 线性代数

线代老师可在张宇、李永乐、姜晓千等人中选择一位。不同老师的组织方式不同，但不建议频繁拼课。

- 张宇：体系和书面框架较完整，适合希望从概念联系理解线代的人；
- 李永乐：传统主流选择，重视题型、方法和知识联系；
- 姜晓千：不少经验认为讲解清楚、适合快速建立整体框架；
- “没咋了”等 B 站讲题作者：更适合在习题卡住时看题目解析，不建议代替完整主课。

线代学习时必须抓住以下主线：

> 初等变换 → 矩阵的秩 → 线性方程组 → 向量组相关性 → 特征值与相似 → 二次型

不要把六章记成六套互不相干的公式。

### 3. 概率论与数理统计

方浩、余丙森、李林、李良等都有人使用。概率论更应根据“是否讲清随机变量、分布、数字特征之间的关系”来选，而不是按网红排名选择。

选择标准：

- 能否解释随机事件和随机变量的建模含义；
- 一维、二维随机变量能否画出区域并正确分段；
- 条件分布、边缘分布、独立性的关系是否清楚；
- 期望、方差、协方差的计算是否形成稳定流程；
- 数理统计部分能否理解统计量与抽样分布，而不是只背公式。

建议完整试听“二维随机变量”一节再决定，因为这一章最能看出老师是否适合自己。

### 4. 专项老师和视频怎么用

专项课适合“确实存在单点薄弱”时再看：

- 曲线积分、曲面积分；
- 无穷级数；
- 中值定理与证明题；
- 线代二次型；
- 二维随机变量积分区域。

不建议现在就把李艳芳线面积分、各种证明题专题、不同老师的技巧课全部列入必看清单。先跟主线学习，做到对应章节后再判断是否需要补充。

## 四、资料怎么选

### 1. 最小够用资料包

正式开始备考后，先买或确定以下资料即可：

1. 一套主讲老师的基础讲义；
2. 一本基础/强化主习题；
3. 一本数学一历年真题；
4. 后期再买模拟卷；
5. 一个薄错题本或电子错题索引。

不要一开始同时购入《1000题》《880题》《660题》《330题》《1800题》《900题》和多套全书。

### 2. 主流习题的合理定位

#### 《1000题》

- 与张宇课程和讲义衔接较自然；
- 题目层次和技巧性较丰富；
- 基础阶段可优先做基础部分或 A 组；
- 强化部分不必为了完成率死磕所有偏难题。

#### 《880题》

- 难度总体较适中，适合作为强化阶段主练习；
- 可与武忠祥或其他老师搭配；
- 建议把会做但算错、思路模糊、完全不会分开标记；
- 与其盲目二刷全书，不如重点重做后两类题。

#### 《660题》《330题》

- 适合训练选择填空、概念辨析和部分强化题；
- 是否适合取决于当年版本和个人基础；
- 如果已经完整做《880题》，不必因为网络书单再强行全做。

#### 《1800题》

- 题量大，基础训练较充分；
- 更适合基础薄弱、需要大量常规计算训练的人；
- 基础较好或开始较晚时，不建议全做。

#### 《900题》

- 常被认为难度较高；
- 更适合基础和强化已经完成、目标高分且时间充足的人；
- 不是数一高分的必备资料。

### 3. 给你的推荐组合

如果试听后确定张宇适合你：

> 张宇基础30讲 + 配套例题/《1000题》基础部分  
> → 武忠祥高数强化讲义 + 《880题》或《严选题》二选一  
> → 数一真题  
> → 李林、合工大、张宇等模拟卷按当年评价选做

如果张宇基础阶段明显跟不上：

> 武忠祥或汤家凤基础课 + 配套基础题  
> → 武忠祥强化 + 《880题》  
> → 数一真题  
> → 模拟卷

线代和概率各自只选一位主讲老师，不必为了组成“全明星阵容”不断切换。

## 五、你现在应该怎么学

你目前还处于提前准备和保持择校空间的阶段，不需要立刻采用正式备考年每天 4—5 小时的强度。

### 推荐周安排

- 每周学习数学 6 天；
- 每天 1.5—2.5 小时；
- 其中课程/看讲义约 45—75 分钟；
- 独立做题约 45—75 分钟；
- 回顾前一天错题和公式约 15—20 分钟；
- 每周留半天，只复习本周错题和知识框架，不赶新课。

如果学校课程和其他任务较重，最低也应做到每周 8—10 小时稳定学习，而不是某天突击六小时后停几天。

### 一次学习的完整闭环

1. 开始前用 5—10 分钟重做昨天一道错题；
2. 看一小节课程或讲义；
3. 暂停视频，自己复现关键推导；
4. 合上答案重做老师例题；
5. 完成对应练习；
6. 标记错误原因；
7. 第二天、七天后再次重做关键错题。

错误原因建议只分五类：

- 概念不清；
- 方法不会；
- 条件遗漏；
- 计算错误；
- 时间分配或书写问题。

错题本不必完整抄题，只记录题号、错误原因、关键突破口和下次重做日期。

## 六、正式备考年的阶段安排

具体月份应根据你的报考年份调整，以下是相对顺序，不是死期限。

### 阶段 A：基础

目标：

- 数一全部章节学习一遍；
- 掌握基本概念、公式、定理条件；
- 基础计算能够独立完成；
- 完成一本主资料的基础部分。

验收方式：

- 随机抽取讲义例题能独立重做；
- 章节基础题正确率逐渐达到约 75%—85%；
- 能说清主要定理的使用条件；
- 不依赖视频也能连续做题 60—90 分钟。

### 阶段 B：强化

目标：

- 建立常见题型与方法框架；
- 训练综合题、选择填空和计算稳定性；
- 完成《880题》或另一套主强化习题；
- 系统回炉基础阶段的薄弱章节。

此阶段听课应减少，做题和复盘应成为主体。

### 阶段 C：真题

建议：

- 较早年份用于熟悉题型和章节诊断；
- 最近 8—10 年保留为完整限时套卷；
- 使用标准答题纸，严格计时 3 小时；
- 复盘时间通常不应少于做卷时间；
- 记录每套卷的失分结构，而不只记录总分。

重点统计：

- 选择填空概念错误；
- 不会的题；
- 会做但计算错；
- 时间不够；
- 书写不规范；
- 哪个章节连续失分。

### 阶段 D：模拟与冲刺

模拟卷每年质量会变化，不必提前认定某一套“必做”。通常可从以下系列中根据当年评价选取：

- 李林 6 套卷、4 套卷；
- 合工大共创卷、超越卷；
- 张宇 8 套卷、4 套卷；
- 其他当年口碑稳定、风格接近真题的试卷。

对同时准备408的计算机考生，建议先确保 **15—25 套高质量整卷真正完成并复盘**，不必以刷到四五十套为目标。

冲刺期仍要定期回到：

- 基础公式；
- 定理条件；
- 主讲讲义；
- 真题错题；
- 计算易错点。

## 七、两周试听与定路线方法

不要根据网友星级直接定老师。可以用同一章节完成一次小型对比：

1. 各试听张宇、武忠祥同一章节的 1—2 个小节；
2. 每次听完都做同一组 10—15 道基础题；
3. 第二天不看笔记，说出知识框架并重做两道例题；
4. 比较用时、正确率、回看次数和精神疲劳程度。

选择让你做到以下几点的老师：

- 听课时能理解；
- 第二天仍能复述；
- 离开视频能做题；
- 能长期稳定坚持；
- 不需要频繁回看才能继续下一节。

如果两位老师效果接近，直接选你更愿意长期听的一位，不再继续横向测评。

## 八、目前给你的个人建议

在还不了解你高数、线代成绩和遗忘程度之前，先给出如下默认判断：

- 你开始较早，又准备按数一保留哈工大、华科、南大等选择，学习范围应该完整；
- 可以先尝试 **张宇基础 + 武忠祥强化**；
- 高数基础阶段只做一套主练习，不同时铺开《1000题》和《880题》全部内容；
- 线代先选张宇、李永乐或姜晓千中的一位完整学，不必现在定专项补课；
- 概率论等高数进入稳定节奏后再选老师；
- 今年的首要目标是建立稳定学习习惯、补齐基本计算和概念，而不是提前耗尽真题和模拟卷。

等你提供自己的高考数学、大学高数/线代成绩，以及现在随手做极限、积分、矩阵题的感受后，再把方案收缩为具体老师、每天课时和题量。
