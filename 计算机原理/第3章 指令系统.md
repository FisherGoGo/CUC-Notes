# 第3章 16位/32位微处理器指令系统

## 基本概念

- **指令**：要求计算机执行各种特定操作的命令。
- **指令系统**：微机能够识别和执行的全部指令集合，不同微处理器对应不同指令系统。

---

## 3.1 指令的基本格式

### 3.1.1 指令的构成

指令包括两部分：
- **操作码**：表示操作性质或类型的编码
- **操作数**：操作对象

以8086/8088机器指令为例：第一字节=操作码，第二字节=寻址方式，第三~四字节=内存位移量或立即数，第五~六字节=立即数。

### 3.1.2 8086/8088的汇编指令格式

```
[标号:] 操作码助记符 目的操作数, 源操作数 [;注释]
```

| 组成部分 | 说明 |
|----------|------|
| **标号** | 符号地址，后跟冒号；字母开头，不能用保留字 |
| **操作码助记符** | 指示CPU执行什么操作 |
| **目的操作数** | 结果存放位置 |
| **源操作数** | 操作对象 |
| **注释** | 以分号开头，说明功能，不参与汇编 |

---

## 3.2 8086/8088的寻址方式

操作数的寻址方式是指寻找操作数位置的方式。共八种：

| 寻址方式 | 说明 | 示例 |
|----------|------|------|
| **立即寻址** | 操作数在指令中（立即数），只能作源操作数 | `MOV AL, 80H` |
| **寄存器寻址** | 操作数在CPU内部寄存器中 | `MOV AL, BL` |
| **直接寻址** | EA在指令中直接给出 | `MOV AX, [1000H]` |
| **寄存器间接寻址** | EA在BX/BP/SI/DI中 | `MOV AX, [BX]` |
| **基址寻址** | EA = BX/BP + 位移量 | `MOV AX, [BP+3000H]` |
| **变址寻址** | EA = SI/DI + 位移量 | `MOV AX, [SI+3000H]` |
| **基址变址寻址** | EA = BX/BP + SI/DI + 位移量 | `MOV AX, [BX+SI+8]` |
| **固定寻址（隐含寻址）** | 操作码隐含指明操作数地址 | `DAA`（隐含对AL操作） |

### 段基址默认规则

| 间址/基址/变址寄存器 | 默认段基址 | 可跨段 |
|----------------------|-----------|--------|
| BX, SI, DI | DS | 是 |
| BP | SS | 是 |

### 寻址方式例题

> 已知：`DS=2000H, SS=1000H, BX=0BBH, BP=02H, SI=0100H, DI=0200H`, 部分内存数据已知，填表如下：

| 指令 | 寻址方式 | AX结果 |
|------|---------|--------|
| `MOV AX, 1200H` | 立即寻址 | 1200H |
| `MOV AX, BX` | 寄存器寻址 | 0BBH |
| `MOV AX, [1200H]` | 直接寻址 | 4C2AH |
| `MOV AX, [BX]` | 寄存器间接寻址 | 231AH |
| `MOV AX, [BX+11H]` | 基址寻址 | 3F68H |
| `MOV AX, [BX+SI]` | 基址变址寻址 | 8934H |
| `MOV AX, [BX+SI+11H]` | 基址变址寻址 | 5B56H |
| `MOV AX, [BP+DI]` | 基址变址寻址 | 6778H |

## 3.3 指令系统

### 3.3.1 数据传送类指令

除标志寄存器传送指令外，**均不影响标志位**。

#### 1. 通用数据传送指令

##### MOV 传送指令

```
MOV OPD, OPS   ; OPS → OPD
```

**注意点：**
- 立即数、CS和IP **不能作为目的操作数**
- 两个段寄存器之间不能直接传送（需通过AX）
- 两个存储单元之间不能直接传送（需通过AX）
- 不能将立即数直接传送到段寄存器（需通过AX）
- 两个操作数的类型和长度必须一致

##### XCHG 交换指令

```
XCHG OPD, OPS   ; OPD ⇄ OPS
```

只能在通用寄存器之间、通用寄存器与存储器之间进行。

##### XLAT 换码指令

```
XLAT   ; AL ← [BX + AL]，查表指令
```

隐含寻址：表头地址→BX，表内位移→AL，结果→AL。

##### 堆栈操作指令

| 指令 | 格式 | 功能 |
|------|------|------|
| **PUSH** | `PUSH OPS` | (SP)-2→SP，字数据压入栈顶 |
| **POP** | `POP OPD` | 栈顶字数据→OPD，(SP)+2→SP |

- 操作数只能是**16位**，不能是8位
- PUSH源操作数不能为立即数
- POP目的操作数不能为CS、立即数
- 堆栈位于SS段，SP指向栈顶，**后进先出(LIFO)**

#### 2. 标志寄存器传送指令

| 指令 | 功能 |
|------|------|
| **LAHF** | FR低8位 → AH |
| **SAHF** | AH → FR低8位 |
| **PUSHF** | FR（16位）进栈 |
| **POPF** | 栈顶两字节 → FR |

#### 3. 目标地址传送指令

| 指令 | 格式 | 功能 |
|------|------|------|
| **LEA** | `LEA OPD, OPS` | 取源操作数的偏移地址→OPD（16位通用寄存器） |
| **LDS** | `LDS OPD, OPS` | 低两字节→OPD，高两字节→DS |
| **LES** | `LES OPD, OPS` | 低两字节→OPD，高两字节→ES |

> `LEA SI, TABLE` 等效于 `MOV SI, OFFSET TABLE`

#### 4. 输入/输出指令

| 指令 | 功能 |
|------|------|
| **IN** | `IN AL/AX, n/DX` — 从端口输入数据到AL/AX |
| **OUT** | `OUT n/DX, AL/AX` — 将AL/AX内容输出到端口 |

- 端口地址 > 255 时，**必须用DX** 指定端口地址
- 不影响标志位

### 3.3.2 算术运算类指令

#### 加法指令

| 指令 | 格式 | 功能 | 影响标志 |
|------|------|------|----------|
| **ADD** | `ADD OPD, OPS` | OPD+OPS→OPD | CF,AF,PF,SF,OF,ZF |
| **ADC** | `ADC OPD, OPS` | OPD+OPS+CF→OPD | CF,AF,PF,SF,OF,ZF |
| **INC** | `INC OPD` | OPD+1→OPD | AF,PF,SF,OF,ZF (**不影响CF**) |

> ADC常用于多字加法；INC不影响CF标志。

#### 减法指令

| 指令 | 格式 | 功能 | 影响标志 |
|------|------|------|----------|
| **SUB** | `SUB OPD, OPS` | OPD-OPS→OPD | CF,AF,PF,SF,OF,ZF |
| **SBB** | `SBB OPD, OPS` | OPD-OPS-CF→OPD | CF,AF,PF,SF,OF,ZF |
| **DEC** | `DEC OPD` | OPD-1→OPD | AF,PF,SF,OF,ZF (**不影响CF**) |
| **CMP** | `CMP OPD, OPS` | OPD-OPS（结果不回送） | CF,AF,PF,SF,OF,ZF |
| **NEG** | `NEG OPD` | 0-OPD→OPD（求补） | CF,AF,PF,SF,OF,ZF |

##### CMP 比较结果的判断

| 条件 | 判断依据 |
|------|----------|
| 两数相等 | ZF=1 |
| 无符号数 OPD > OPS | CF=0 |
| 无符号数 OPD < OPS | CF=1 |
| 有符号数 OPD > OPS | OF=SF |
| 有符号数 OPD < OPS | OF≠SF |

#### 乘法指令

| 指令 | 功能 | 说明 |
|------|------|------|
| **MUL OPS** | 无符号乘：`(AL)×OPS→AX`（字节）或 `(AX)×OPS→(DX,AX)`（字） | OPS不能是立即数 |
| **IMUL OPS** | 有符号乘：同上 | 仅影响CF、OF |

- 字节乘法：AH≠0 → CF=OF=1，否则CF=OF=0
- 字乘法：DX≠0 → CF=OF=1，否则CF=OF=0

#### 符号扩展指令

| 指令 | 功能 |
|------|------|
| **CBW** | AL→AX（字节扩展为字），AL最高位=0→AH=00H，=1→AH=FFH |
| **CWD** | AX→(DX,AX)（字扩展为双字） |

不影响标志位，用于有符号数除法前的准备。

#### 除法指令

| 指令 | 功能 |
|------|------|
| **DIV OPS** | 无符号除：`(AX)/OPS→AL(商),AH(余)`（字节）；`(DX,AX)/OPS→AX(商),DX(余)`（字） |
| **IDIV OPS** | 有符号除：同上 |

- OPS不能是立即数
- 除法指令**不影响标志位**
- 除0会导致溢出中断

#### 十进制调整指令

| 指令 | 用途 | 说明 |
|------|------|------|
| **DAA** | 压缩BCD码加法调整 | 紧跟在ADD/ADC后，调整AL |
| **AAA** | 非压缩BCD码加法调整 | |
| **DAS** | 压缩BCD码减法调整 | |
| **AAS** | 非压缩BCD码减法调整 | |
| **AAM** | 非压缩BCD码乘法调整 | |
| **AAD** | 非压缩BCD码除法调整 | |

DAA调整规则：
- AL低4位>9 或 AF=1 → AL+06H
- AL高4位>9 或 CF=1 → AL+60H

---

### 3.3.3 逻辑运算指令

| 指令 | 格式 | 功能 | 影响标志 |
|------|------|------|----------|
| **NOT** | `NOT OPD` | 按位取反 | 不影响 |
| **AND** | `AND OPD, OPS` | 按位与→OPD | SF,ZF,PF; OF=CF=0 |
| **TEST** | `TEST OPD, OPS` | 按位与（结果不回送） | SF,ZF,PF; OF=CF=0 |
| **OR** | `OR OPD, OPS` | 按位或→OPD | SF,ZF,PF; OF=CF=0 |
| **XOR** | `XOR OPD, OPS` | 按位异或→OPD | SF,ZF,PF; OF=CF=0 |

- **AND**：屏蔽不需要的位（某位&0=0）
- **OR**：将某位置1（某位|1=1）
- **XOR**：某数与自身异或=0，常用于清零或判等
- **TEST**：检测某位是否为1（不改变原值）

---

### 3.3.4 移位指令

移位次数=1时直接写；**>1时必须将次数放入CL**。影响除AF外的标志位。

| 指令 | 功能 | 图示说明 |
|------|------|----------|
| **SHL/SAL** | 逻辑/算术左移 | 高位→CF，低位补0 |
| **SHR** | 逻辑右移 | 低位→CF，高位补0 |
| **SAR** | 算术右移 | 低位→CF，高位**保持不变（符号扩展）** |

- 逻辑左移一位 = 无符号数乘2
- 逻辑右移一位 = 无符号数除2

---

### 3.3.5 循环移位指令

移位次数>1时必须放入CL。只影响CF、OF。

| 指令 | 功能 |
|------|------|
| **ROL** | 循环左移（不含CF） |
| **ROR** | 循环右移（不含CF） |
| **RCL** | 带进位循环左移（CF参与循环） |
| **RCR** | 带进位循环右移（CF参与循环） |

> 例：32位无符号数(DX:AX)除2：
> ```
> SHR DX, 1    ; DX逻辑右移1位
> RCR AX, 1    ; DX的移出位(CF)进入AX
> ```

---

### 3.3.6 串操作类指令

源串在**数据段(DS:SI)**，目的串在**附加段(ES:DI)**。

| DF | 方向 |
|----|------|
| DF=0 (CLD) | SI、DI自动**递增**（+1/+2） |
| DF=1 (STD) | SI、DI自动**递减**（-1/-2） |

#### 重复前缀

| 前缀 | 停止条件 |
|------|----------|
| **REP** | CX=0 |
| **REPE/REPZ** | CX=0 **或** ZF=0 |
| **REPNE/REPNZ** | CX=0 **或** ZF=1 |

#### 串操作指令

| 指令 | 功能 | 常用前缀 |
|------|------|----------|
| **MOVSB/MOVSW** | [DS:SI] → [ES:DI]，修改SI/DI | REP |
| **CMPSB/CMPSW** | [DS:SI] - [ES:DI]，不回送，影响标志 | REPE/REPNE |
| **SCASB/SCASW** | AL/AX - [ES:DI]，不回送，影响标志 | REPNE/REPZ |
| **LODSB/LODSW** | [DS:SI] → AL/AX，修改SI | 一般不连用 |
| **STOSB/STOSW** | AL/AX → [ES:DI]，修改DI | REP |

### 3.3.7 控制转移类指令

通过修改**CS和IP**来改变程序执行流程。

#### 无条件转移指令 JMP

| 类型 | 格式 | 转移范围 |
|------|------|----------|
| 段内直接短转移 | `JMP SHORT 标号` | -128~+127字节 |
| 段内直接转移 | `JMP (NEAR PTR) 标号` | -32768~+32767字节 |
| 段内间接转移 | `JMP WORD PTR OPD` | 64KB |
| 段间直接转移 | `JMP FAR PTR 标号` | 1MB |
| 段间间接转移 | `JMP DWORD PTR OPD` | 1MB |

#### 条件转移指令

转移范围**-128~+127字节**，不影响标志位。

| 类型 | 指令 | 条件 |
|------|------|------|
| **单标志位** | JZ/JE | ZF=1 |
| | JNZ/JNE | ZF=0 |
| | JC/JB/JNAE | CF=1 |
| | JNC/JNB/JAE | CF=0 |
| | JS | SF=1 |
| | JNS | SF=0 |
| | JO | OF=1 |
| | JNO | OF=0 |
| | JP/JPE | PF=1 |
| | JNP/JPO | PF=0 |
| **无符号数** | JA/JNBE | CF=0 且 ZF=0 (>) |
| | JAE/JNB/JNC | CF=0 (≥) |
| | JB/JNAE/JC | CF=1 (<) |
| | JBE/JNA | CF=1 或 ZF=1 (≤) |
| **有符号数** | JG/JNLE | SF=OF 且 ZF=0 (>) |
| | JGE/JNL | SF=OF (≥) |
| | JL/JNGE | SF≠OF (<) |
| | JLE/JNG | SF≠OF 或 ZF=1 (≤) |
| **CX测试** | JCXZ | CX=0 |

#### 循环转移指令

循环次数放在**CX寄存器**中，不影响标志位。

| 指令 | 格式 | 循环条件 |
|------|------|----------|
| **LOOP** | `LOOP 标号` | CX≠0 |
| **LOOPE/LOOPZ** | `LOOPE 标号` | CX≠0 **且** ZF=1 |
| **LOOPNE/LOOPNZ** | `LOOPNE 标号` | CX≠0 **且** ZF=0 |

> LOOP执行转移需9个时钟周期，退出循环需5个时钟周期（可用于延时）。

#### 子程序调用和返回指令

| 指令 | 类型 |
|------|------|
| **CALL 标号** | 段内直接调用 |
| **CALL WORD PTR OPD** | 段内间接调用 |
| **CALL FAR PTR 标号** | 段间直接调用 |
| **CALL DWORD PTR OPD** | 段间间接调用 |
| **RET** | 返回（弹出IP或IP+CS） |
| **RET n** | 带弹出值的返回（SP+n→SP） |

#### 中断和中断返回指令

| 指令 | 功能 |
|------|------|
| **INT n** | 软中断（n=0~0FFH），每个类型码在中断矢量表占4字节 |
| **IRET** | 中断返回（弹出IP、CS、FR） |
| **INTO** | 溢出中断（OF=1时触发，类型码=4） |

### 3.3.8 处理器控制类指令

#### 标志位操作指令

| 指令 | 功能 |
|------|------|
| **CLC** | CF=0 |
| **STC** | CF=1 |
| **CMC** | CF取反 |
| **CLI** | IF=0（关中断） |
| **STI** | IF=1（开中断） |
| **CLD** | DF=0（地址递增） |
| **STD** | DF=1（地址递减） |

#### 外部同步指令

| 指令 | 功能 |
|------|------|
| **NOP** | 空操作（仅占1字节，可用于延时填充） |
| **HLT** | 暂停（等待中断或复位） |
| **ESC** | 交权指令（用于协处理器） |
| **WAIT** | 等待（等待TEST信号有效） |

### 常见错误小结

| 错误示例 | 错误原因 |
|----------|----------|
| `MOV BL, [SI][DI]` | 不允许同时使用两个变址寄存器 |
| `MOV 45H, AX` | 目的操作数不能是立即数 |
| `INC 12` | 操作数不能是立即数 |
| `MOV [BX], [SI+BP+BUF]` | 两个操作数不能同为存储单元 |
| `MOV BL, AX` | 操作数类型不匹配 |
| `MOV CS, AX` | CS不能作为目的操作数 |
| `OUT 240H, AL` | 端口号>FFH时必须放入DX |
| `MOV SS, 2000H` | 段寄存器不能用立即数赋值 |
| `LEA BX, AX` | LEA源操作数必须是存储器操作数 |
| `XCHG AL, 78H` | 交换指令不能对立即数操作 |
