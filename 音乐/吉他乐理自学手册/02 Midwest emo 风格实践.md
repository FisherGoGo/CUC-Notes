# 02 Midwest emo 风格实践

## 写作工作流

### 第一步：定一个情绪

不要先问“我要用什么高级和弦”，先问：

- 是明亮但失落？
- 是安静压抑？
- 是青春感爆发？
- 是碎碎念式叙事？

情绪决定速度、音色、和弦密度。

### 第二步：选调和和弦

入门优先：

- E minor：适合电吉他 riff，开放弦多。
- G major：适合木吉他，明亮。
- D major：适合 capo 和开放和弦。
- A minor：适合阴郁一些的旋律。

可尝试的进行：

- G - D - Em - C
- Em - C - G - D
- D - A - Bm - G
- Cadd9 - G - Dsus4 - Em7
- Am - F - C - G

### 第三步：写节奏吉他

先用最简单版本：

- 每个和弦一小节；
- 8 分音符扫弦；
- 保留高音开放弦；
- 不要一开始就塞满所有音。

然后做变化：

- verse 改成分解和弦；
- chorus 改成全扫；
- bridge 减少低音；
- 最后一遍副歌叠加八度线。

### 第四步：写主吉他

主吉他不要总是 solo。Midwest emo 的主吉他常常更像“会唱的琶音”。

可用方法：

- 高把位三和弦分解；
- 八度音旋律；
- 两根弦上的双音；
- 滑音连接；
- 短小重复动机；
- 和人声错开，不抢同一频段。

### 第五步：写旋律

旋律可以先从和弦音写：

- 当前和弦是 G，就优先试 G、B、D；
- 当前和弦是 Em，就优先试 E、G、B；
- 想稳定，落在根音或五音；
- 想有情绪，落在三音或六音；
- 想悬着，落在二音、四音或七音。

先哼，再弹。不要先在指板上乱找。

### 第六步：录一个粗糙 demo

最低配置：

- 一轨节奏吉他；
- 一轨主吉他；
- 一轨哼唱旋律；
- 可选：节拍器或简单鼓点。

回听时只问三件事：

- 这首歌的最好听 2 小节在哪里？
- 有没有某一轨一直在抢空间？
- 副歌有没有比主歌更有能量？

## 开放调弦与变调夹

先把标准调弦学扎实，再逐步试开放调弦。开放调弦很容易让普通指法变好听，但也容易让人不知道自己在弹什么。

### 标准调弦 EADGBE

最适合入门和长期学习。

优点：

- 所有教材、tab、工具都默认支持；
- 方便理解 CAGED 和常规和弦；
- 适合木吉他和电吉他。

练习重点：

- 用开放和弦制造明亮感；
- 用高把位三和弦制造第二把吉他；
- 用 capo 保留开放和弦手感。

### 降半音 Eb Ab Db Gb Bb Eb

适合更松、更暗一点的电吉他手感。

用途：

- 人声觉得原调太高时可以降半音；
- 电吉他张力更松，推弦和大跨度按法更舒服；
- 保持标准调弦的指法逻辑。

### DADGAD

适合空旷、民谣、后摇一点的质感。

特点：

- 很容易得到 sus4、add9 一类悬浮声音；
- 适合分解和弦；
- 不适合一上来就乱按完整大横按。

练习：

- 只用 4-6 弦移动低音；
- 保持 1、2、3 弦开放；
- 录一段 4 小节循环，听开放弦如何连接和弦。

### FACGCE

这是 Midwest emo 里很有代表性的开放调弦之一，声音明亮、脆弱、很有空旷感。

注意：

- 调弦跨度比标准调弦大，先确认琴弦张力；
- 不要一开始追求复杂指法；
- 先用简单按法听开放弦之间的共鸣。

练习：

- 只按 6 弦和 5 弦，其他弦开放；
- 每个形状弹 8 个 8 分音符；
- 找一个能循环 30 秒不腻的进行。

### capo 的使用原则

capo 的核心用途不是升调，而是保留开放和弦的音色。

常见用法：

- Capo 2，用 G 指法，实际 A 调；
- Capo 4，用 C 指法，实际 E 调；
- Capo 5，用 G 指法，实际 C 调；
- Capo 7，用 D 指法，实际 A 调。

练习：

- 同一个进行分别用无 capo、capo 2、capo 4 弹；
- 听哪个位置更适合你的嗓音；
- 录下来比较高频是否太尖、低频是否太薄。

## 参考歌分析模板

风格学习最有效的方法不是收藏一堆歌名，而是拆解歌曲。每次只分析一首，控制在 20-30 分钟内。

| 项目 | 记录 |
|---|---|
| 歌名/乐队 |  |
| 大致调性 | 例如 G major / E minor / D major |
| 调弦/capo | 标准调弦、降半音、开放调弦、capo 几品 |
| BPM | 慢速、中速、快速也可以 |
| 主歌和弦 |  |
| 副歌和弦 |  |
| 最好听的 2 小节 | 时间点，例如 0:42-0:46 |
| 节奏吉他做了什么 | 扫弦、闷音、分解、开放弦 |
| 主吉他做了什么 | 琶音、八度、双音、滑音、短 riff |
| 可以偷学的点 | 只写一个，马上改造成自己的东西 |

### 分析顺序

1. 先听完整首，不拿琴。
2. 第二遍只听鼓和段落：哪里安静，哪里爆发。
3. 第三遍听节奏吉他：它在铺什么和弦。
4. 第四遍听主吉他：它有没有重复动机。
5. 最后拿琴，只扒最好听的 2 小节。

目标不是完整扒谱，而是建立自己的素材库。
