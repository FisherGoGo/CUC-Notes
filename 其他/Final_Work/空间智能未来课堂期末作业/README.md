# 空间智能未来课堂期末作业

本文件夹用于整理“空间智能系统场景设计”期末大作业，主题为：

**空间智能驱动的自适应未来课堂系统**

## 提交材料

- `畅课提交版.md`：适合直接复制到畅课说明文本框的标准版说明。
- `空间智能未来课堂系统设计说明.md`：完整报告版，覆盖背景、目标、架构、感知、推理、决策、行动、效果图说明、创新点、可行性和伦理约束。
- `系统流程图.mmd`：Mermaid 系统流程图源码。
- `效果图提示词.md`：用于 AI 绘图或二次出图的中文/英文提示词。
- `assets/智慧教室效果图.svg`：可直接打开或截图提交的设计效果图。

## 推荐提交方式

1. 将 `assets/智慧教室效果图.svg` 打开后截图，作为设计效果图上传。
2. 将 `畅课提交版.md` 的内容复制到畅课说明文本。
3. 如果需要更完整的附件，可同时上传 `空间智能未来课堂系统设计说明.md`。
