# N3小单元训练 04：图书馆与学习计划

目标：练习说明计划、习惯和学习方法，并通过阅读理解人物如何调整复习方式。

## 本单元句型

- ようになる：变得能够...
- ながら：一边...一边...
- ことにする：决定...
- ば...ほど：越...越...
- ても：即使...
- なかなか...ない：不容易...

## 热身词句

- **図書館**：图书馆。例：午後は図書館で勉強します。
- **予約する**：预约。例：静かな席を予約しました。
- **復習**：复习。例：授業の後で復習します。
- **集中する**：集中。例：音楽を聞くと集中できません。
- **貸し出し**：借出。例：この本は貸し出し中です。
- **締め切り**：截止日期。例：レポートの締め切りは金曜日です。

## 句子翻译

1. 我决定从今天开始每天在图书馆学习一小时。（提示：ことにする）
2. 越复习，越能看懂文章。（提示：ば...ほど / ようになる）
3. 即使很忙，也请不要忘记截止日期。（提示：ても / ないでください）
4. 我一边查词典一边读日语新闻。（提示：ながら）
5. 这个座位很安静，所以容易集中。（提示：ので / やすい）
6. 只背语法的话，不太能写出自然的句子。（提示：だけ / なかなか...ない）

## 阅读理解

私は今まで家で勉強していましたが、スマホを見てしまうことが多く、なかなか集中できませんでした。そこで、今週から授業の後で図書館へ行くことにしました。図書館ではまず宿題を終わらせ、そのあとN3の読解問題を二つ解きます。

最初は読むのに時間がかかりましたが、分からない言葉をすぐ調べすぎないようにしました。文全体の意味を考えながら読むと、少しずつ答えを選べるようになってきました。勉強すればするほど、自分に合う方法が分かってくると思います。

词汇提示：解く：解题 / 全体：整体 / 合う：适合

1. 作者以前在哪里学习？
   - 家里
   - 咖啡店
   - 图书馆
   - 教室
2. 作者为什么换到图书馆学习？
   - 家离学校远
   - 家里不容易集中
   - 图书馆有朋友
   - 老师要求
3. 作者在图书馆先做什么？
   - 读新闻

   - 查单词
   - 预约座位
4. 作者阅读时做了什么调整？

## 输出小练习

用日语写 2-3 句：你准备怎样安排 N3 学习时间？

## 参考答案

1. 今日から毎日図書館で一時間勉強することにしました。
2. 復習すればするほど、文章が読めるようになります。
3. 忙しくても、締め切りを忘れないでください。
4. 辞書を引きながら日本語のニュースを読んでいます。
5. この席は静かなので、集中しやすいです。
6. 文法だけ覚えても、なかなか自然な文は書けません。

### 阅读答案

1. 家里。文中说「今まで家で勉強していました」。
2. 家里不容易集中。文中说常看手机，难集中。
3. 完成作业。文中说「まず宿題を終わらせ」。
4. 先考虑整体意思。文中说「文全体の意味を考えながら読む」。

### 输出参考

授業の後で一時間ぐらいN3の勉強をすることにしました。単語を復習してから、短い文章を読むようにします。
