# JLPT N3 100句翻译题：中文到日文

题目为原创 N3 风格句子翻译练习，用于训练语法输出、词汇搭配和敬体表达；不是官方真题复制。

## 题目

### 日常生活

1. 把伞放在门口的话，可能会忘记拿。
   - 提示：ておく / てしまう / かもしれない
2. 我刚想出门，电话就响了。
   - 提示：ようとする / とき
3. 这家店不仅便宜，而且服务也很好。
   - 提示：だけでなく
4. 请你不要把窗户开着就睡觉。
   - 提示：たまま / ないでください
5. 因为最近很忙，所以没怎么做饭。
   - 提示：ので / あまり...ない
6. 我习惯了一个人吃饭。
   - 提示：ことに慣れる
7. 如果明天不下雨，我打算去洗衣服。
   - 提示：なければ / つもり
8. 这件衬衫看起来很贵，其实不贵。
   - 提示：そうだ / 実は
9. 我把钥匙弄丢了，进不了房间。
   - 提示：てしまう / 可能形
10. 请在饭变凉之前吃。
   - 提示：前に
11. 这台洗衣机用起来很方便。
   - 提示：やすい
12. 我每天尽量十一点以前睡觉。
   - 提示：までに / ようにする
13. 虽然很困，但还有作业要做。
   - 提示：けれど / なければならない
14. 请把垃圾按照种类分开扔。
   - 提示：によって / てください
15. 他好像把钱包忘在电车上了。
   - 提示：ようだ
16. 我本来想买这本书，可是卖完了。
   - 提示：ようと思う / ている
17. 如果冷的话，请打开暖气。
   - 提示：たら
18. 这个房间既安静又明亮。
   - 提示：し
19. 因为明天要早起，今天不能熬夜。
   - 提示：ので / できる
20. 请不要光吃甜食。
   - 提示：ばかり / ないでください

### 健康与社会
