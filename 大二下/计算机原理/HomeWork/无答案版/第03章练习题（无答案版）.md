# 第三章练习题（无答案版）

## 1. 条件转移与标志位

**题目：** 已知程序为：

```asm
ADD AL, BL
JNO L1
JNC L2
```

若 `AL` 和 `BL` 的内容有以下 4 组给定值，使程序转向 `L2` 执行的是（ ）。

**选项：**

- A. `(AL)=67H, (BL)=78H`
- B. `(AL)=0B6H, (BL)=87H`
- C. `(AL)=18H, (BL)=0F9H`
- D. `(AL)=81H, (BL)=0A5H`

## 2. JMP BX 指令

**题目：** 若 `(BX)=1224H`，`(IP)=3478H`，执行 `JMP BX` 指令后，寄存器变化正确的是（ ）。

**选项：**

- A. `(BX)=3478H, (IP)=3478H`
- B. `(BX)=1224H, (IP)=1224H`
- C. `(BX)=1224H, (IP)=3478H`
- D. `(BX)=3478H, (IP)=1224H`

## 3. 逻辑运算指令序列

**题目：** 执行下列指令后：

```asm
MOV AL, BL

XOR AL, BL
OR  BL, AL
```

**选项：**

- A. `0FFH, 0FFH`
- B. `11H, 0FFH`
- C. `0FFH, 11H`
- D. `00H, 00H`

## 4. PUSH 与栈顶物理地址

**选项：**

- B. `239B4H`
- C. `239AEH`
- D. `239B2H`

## 5. INC 指令不影响的标志

## 9. 物理地址对应的段地址和偏移地址

## 10. CALL 指令入栈与小端存储

## 11. ADD AH, AL 后的标志位
