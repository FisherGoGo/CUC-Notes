# 第四章练习题（无答案版）

## 1. 关系运算伪指令表达式

**题目：** 执行下面程序段后：

```asm
NUM=60
MOV BX, NUM LE 50
```

`BX` 的内容是（ ）。

**选项：**

- A. `1`
- B. `0FFFFH`
- C. `0`
- D. `50`

## 2. 计算机能直接执行的语言

**题目：** 计算机内部，计算机能够直接执行的程序语言是（ ）。

**选项：**

- A. C 语言
- B. 汇编语言
- C. 机器语言
- D. 高级语言

## 3. `DW` 数据定义与偏移地址

**题目：** 已知伪指令：

```asm
VAR DW 8, 156, $+2, 9, 7
```

若汇编 `VAR` 分配的偏移地址是 `0011H`，汇编 `0015H` 单元的内容是（ ）。

**选项：**

- A. `09H`
- B. `17H`
- C. `07H`
- D. `15H`

## 4. `DUP` 嵌套数据定义

**题目：** 使用 8086 汇编语言的伪指令定义：

```asm
VAR DB 2 DUP (1,2,3 DUP (3),2 DUP (1,0))
```

则在 `VAR` 存储区的前 11 个字节单元的内容是（ ）。

**选项：**

- A. `2,1,2,3,3,2,1,0,2,1,0`
- B. `1,2,3,3,3,2,1,0,1,2`
- C. `1,2,3,3,3,1,0,1,0,1,2`
- D. `1,2,3,3,2,1,0,1,2,3,1`

## 5. `LENGTH` 运算符

## 8. 串操作 `REP MOVSB`

**题目：** 已知 `(DS)=(ES)`，执行下列指令后：

```asm
BUF DB 1,3,4,5,6,7,9,8,9,10,11
MOV CX,10
MOV SI,OFFSET BUF+9
LEA DI,BUF+10
STD
REP MOVSB
MOV BX,OFFSET BUF
MOV AX,[BX]
```

`AX` 的内容是 ①，`CX` 的内容是 ②。

## 9. 指令序列跟踪

**题目：** 执行下列指令段后，`3004H` 单元的内容是 ①，`BX` 的内容是 ②，`CF` 是 ③。


## 10. `OFFSET`、`EQU` 与存储内容

**题目：** 设数据段定义如下：

```asm
DSEG SEGMENT
ORG 0100H
X1 DB 25,'35'
X2 DW ?
Y1 EQU X1
Y2 EQU $-Y1
DSEG ENDS
```

回答：

1. 执行 `MOV BX, OFFSET X1` 后，`BX` 的内容。
2. 汇编后 `Y2` 的值。
3. 执行 `MOV AL, Y1+1` 后，`AL` 的内容。

## 11. CBW、LEA 与字访问

**题目：** 执行下列指令段后：

```asm
VR1 DB 86H
VR2 DW 2005H,0021H,849EH

MOV AL,VR1
CBW
LEA BX,VR2
MOV DX,4[BX]
SUB AX,DX
```

`AX` 的内容是 ①，`DX` 的内容是 ②。

## 12. 循环程序跟踪

**题目：** 执行下列程序后，分析有关寄存器的内容：

```asm
CSEG SEGMENT
ASSUME CS:CSEG,DS:CSEG,SS:CSEG
ORG 100H
BEGIN:
    MOV AX, 02H
    MOV BX, 03H
    MOV DX, 05H
    MOV CX, 06H
    CLC
L20:
    INC AX
    ADC BX, AX
    SHR DX, 1
    LOOPNE L20
CSEG ENDS
END BEGIN
```

## 13. `TYPE`、`LENGTH`、`SIZE`
