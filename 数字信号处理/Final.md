《数字信号处理》期末总结第一章 绪论1. 理解数字频率的概念，掌握数字频率与模拟频率的关系$$\omega = \Omega T = 2\pi\frac{f}{f_{s}}$$2. 掌握序列周期性判断方法，会求周期正弦序列：$x(n) = A \sin(n\omega_{0}+\phi)$复指数序列：$x(n) = e^{j\omega_{0}n}$(判断 $\frac{2\pi}{\omega_0}$ 是否为有理数)3. 线性、时不变、因果、稳定系统的判断线性：满足叠加原理。时不变：系统特性不随时间平移而改变。因果：当前输出只与当前和过去的输入有关。稳定：有界输入产生有界输出 (BIBO)。第二章 离散时间傅里叶变换 (DTFT)1. 掌握序列的傅立叶变换 (DTFT) 的定义$$\begin{cases} 
X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x(n) e^{-j\omega n} \\ 
x(n) = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega 
\end{cases} $$对应关系：$x(n) \leftrightarrow X(e^{j\omega})$离散、非周期 的时域序列 $\leftrightarrow$ 周期 ($2\pi$)、连续 的频域频谱。2. 掌握序列的傅立叶变换 (DTFT) 与 Z变换 的关系$$X(z) \Big|_{z=e^{j\omega}} = X(e^{j\omega})$$(即 Z变换在单位圆上的取值)3. 掌握序列的傅立叶变换 (DTFT) 的性质线性性质、时域移位性质、频域移位性质帕斯瓦尔定理 (Parseval)：$$\sum_{n=-\infty}^{\infty} |x(n)|^{2} = \frac{1}{2\pi} \int_{-\pi}^{\pi} |X(e^{j\omega})|^{2} d\omega$$对称性质：$Re[x(n)] \leftrightarrow X_{ep}(e^{j\omega})$ (共轭偶对称部分)$x_{ep}(n) \leftrightarrow Re[X(e^{j\omega})]$$j Im[x(n)] \leftrightarrow X_{op}(e^{j\omega})$ (共轭奇对称部分)$x_{op}(n) \leftrightarrow j Im[X(e^{j\omega})]$其中：$$x_{ep}(n) = \frac{1}{2}[x(n) + x^{*}(-n)]$$$$x_{op}(n) = \frac{1}{2}[x(n) - x^{*}(-n)]$$第三章 离散傅里叶变换 (DFT)1. 理解4种形式的傅立叶变换的两个域之间的对应关系连续 $\leftrightarrow$ 非周期离散 $\leftrightarrow$ 周期性2. 掌握离散傅里叶变换的定义，理解DFT隐含周期性$$\begin{cases} 
X(k) = \sum_{n=0}^{N-1} x(n) W_{N}^{nk}, \quad 0 \le k \le N-1 \\ 
x(n) = \frac{1}{N} \sum_{k=0}^{N-1} X(k) W_{N}^{-nk}, \quad 0 \le n \le N-1 
\end{cases} $$直流分量与初始值：$X(0) = \sum_{n=0}^{N-1} x(n)$， $x(0) = \frac{1}{N} \sum_{k=0}^{N-1} X(k)$注意：$x(n)$ 的 DFT 结果与变换区间长度 $N$ 的取值有关。3. 掌握 DFT 与 Z变换、DTFT 的关系$$X(k) = X(e^{j\omega}) \Big|_{\omega=\frac{2\pi}{N}k} = X(z) \Big|_{z=e^{j\frac{2\pi}{N}k}}$$4. 离散傅里叶变换的性质及应用圆周移位：$y(n) = x((n-m))_{N} R_{N}(n) \leftrightarrow Y(k) = X(k) W_{N}^{km}$对偶性：$x(n) \xrightarrow{DFT} X(k)$$X(n) \xrightarrow{DFT} N \cdot x((-k))_{N} R_{N}(k)$对称性质：$Re[x(n)] \leftrightarrow X_{ep}(k)$$x_{ep}(n) \leftrightarrow Re[X(k)]$$j Im[x(n)] \leftrightarrow X_{op}(k)$$x_{op}(n) \leftrightarrow j Im[X(k)]$其中：$x_{ep}(n) = \frac{1}{2}[x(n) + x^{*}(N-n)]$， $x_{op}(n) = \frac{1}{2}[x(n) - x^{*}(N-n)]$DFT形式下的帕斯瓦尔定理：$$\sum_{n=0}^{N-1} |x(n)|^{2} = \frac{1}{N} \sum_{k=0}^{N-1} |X(k)|^{2}$$圆周卷积定理：$x_{1}(n) \otimes x_{2}(n) \xrightarrow{DFT} X_{1}(k) X_{2}(k)$$x_{1}(n) x_{2}(n) \xrightarrow{DFT} \frac{1}{N} X_{1}(k) \otimes X_{2}(k)$圆周卷积与线性卷积的关系：$x_{1}(n) \otimes x_{2}(n) = ((x_{1}(n) * x_{2}(n)))_{N} R_{N}(n)$5. 掌握频域采样理论频域采样序列：$X(k) \xleftarrow{N\text{点DFT}} x(n)$恢复时域信号：$x_{N}(n) = x((n))_{N} R_{N}(n)$结论：只有当频域采样点数 $N$ 满足 $N \ge M$ ($M$为原序列长度) 时，才不会发生时域混叠，即 $x_{N}(n) = x((n))_{N} R_{N}(n) = x(n)$。6. 利用 DFT 逼近模拟信号傅立叶变换时的误差理解存在的三种误差（混叠现象、泄漏现象、栅栏效应）及其形成的原因、改进的办法。7. 掌握参数定义及关系$T_{0}$: 信号记录长度$F_{0}$: 频率分辨力 (Hz)$N$: 采样点数$T$: 时域采样间隔$f_{h}$: 信号最高频率$f_{s}$: 信号采样频率关系式：$$F_{0} = \frac{1}{T_{0}} = \frac{f_{s}}{N}$$$$N = \frac{T_{0}}{T} = \frac{f_{s}}{F_{0}}$$$$f_{s} \ge 2f_{h} \text{ (奈奎斯特采样定理)}$$第四章 快速傅里叶变换 (FFT)1. 理解 DIT (时间抽取) 基-2 FFT 算法原理，掌握流图蝶形运算符号 (奇偶分)：$$\begin{cases} 
X(k) = X_{1}(k) + W_{N}^{k} X_{2}(k) \\ 
X(k+\frac{N}{2}) = X_{1}(k) - W_{N}^{k} X_{2}(k) 
\end{cases} 
\quad (k=0,1,...,\frac{N}{2}-1)$$2. 理解 DIF (频率抽取) 基-2 FFT 算法原理，掌握流图蝶形运算符号 (前后分)：$$\begin{cases} 
x_{1}(n) = x(n) + x(n+N/2) \\ 
x_{2}(n) = [x(n) - x(n+N/2)] \cdot W_{N}^{n} 
\end{cases} 
\quad (n=0,1,...,\frac{N}{2}-1)$$$$\begin{cases} 
X(2r) = \sum_{n=0}^{N/2-1} x_{1}(n) W_{N/2}^{nr} \\ 
X(2r+1) = \sum_{n=0}^{N/2-1} x_{2}(n) W_{N/2}^{nr} 
\end{cases} 
\quad (r=0,1,...,\frac{N}{2}-1)$$3. 掌握运算量计算直接计算 DFT 与基-2 FFT 算法的复数乘法和加法次数比较（$O(N^2)$ 与 $O(N \log_2 N)$）。4. 掌握 IDFT 的快速计算方法重点强调如何用 FFT 实现 IFFT：$x(n) = \frac{1}{N} \left[ \text{FFT}[X^*(k)] \right]^*$5. 掌握 FFT 算法的应用实序列的 FFT 算法（利用对称性简化）。线性卷积的 FFT 算法（重叠相加法、重叠保留法）。第五章 数字滤波器基本结构掌握 IIR 滤波器和 FIR 滤波器的定义及各自的特点。掌握 IIR 滤波器结构：直接 I 型、直接 II 型 (典范型)、级联型、并联型结构。掌握 FIR 滤波器结构：直接型、级联型、线性相位型结构。第六章 IIR 数字滤波器设计1. 掌握最小相位系统的概念，零极点分布特性（全部零极点都在单位圆内的系统）。2. 全通系统概念、零极点分布特性（零极点互为共轭倒数）及应用。系统函数：$$H_{ap}(z) = \pm \frac{z^{-N} + a_{1}z^{-N+1} + a_{2}z^{-N+2} + \dots + a_{N}}{1 + a_{1}z^{-1} + a_{2}z^{-2} + \dots + a_{N}z^{-N}}$$3. 设计模拟低通滤波器根据设计指标：通带截止频率 $\Omega_{p}$、通带衰减 $\delta_{p}$；阻带截止频率 $\Omega_{s}$、阻带衰减 $\delta_{s}$。计算滤波器阶数 $N$ (以巴特沃斯为例)：$$N \ge \frac{\lg \left( \sqrt{\frac{10^{0.1\delta_{s}}-1}{10^{0.1\delta_{p}}-1}} \right)}{\lg(\Omega_{s}/\Omega_{p})}$$计算截止频率 $\Omega_{c}$：$$\Omega_{c} = \frac{\Omega_{p}}{\sqrt[2N]{10^{0.1\delta_{p}}-1}} \quad \text{或} \quad \Omega_{c} = \frac{\Omega_{s}}{\sqrt[2N]{10^{0.1\delta_{s}}-1}}$$查表得到归一化系统函数 $H_{aN}(s)$。去归一化得到系统函数 $H(s)$：代入 $s \leftarrow s/\Omega_{c}$。4. 模拟滤波器转化为数字滤波器：$H(s) \rightarrow H(z)$冲激响应不变法：$$h(n) = T \cdot h_{a}(t) \Big|_{t=nT}$$$$H(s) = \sum_{k=1}^{N} \frac{A_{k}}{s-s_{k}} \Rightarrow H(z) = \sum_{k=1}^{N} \frac{T A_{k}}{1 - e^{s_{k}T}z^{-1}}$$优点：频率变换呈线性关系 $\omega = \Omega T$。缺点：存在频率混叠失真。双线性变换法：$$H(z) = H_{a}(s) \Big|_{s=\frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}}$$频率映射关系：$\Omega = \frac{2}{T} \tan(\frac{\omega}{2})$优点：消除了频率混叠失真。缺点：存在严重的非线性频率变换 (频率翘曲)。5. 设计 IIR 数字滤波器的完整步骤确定所需的选频滤波器（高、带、阻）设计指标。转换为低通数字滤波器的设计指标（若用双线性法，需进行预畸变）。转换为模拟低通滤波器设计指标。设计模拟低通滤波器 (巴特沃斯、切比雪夫等)。将模拟低通转换为数字低通 ($S \rightarrow Z$)。数字域频带转换，得到目标数字选频滤波器。第七章 FIR 数字滤波器设计1. 掌握 FIR 滤波器具有线性相位的条件前提条件：$h(n)$ 是实数序列。对称条件：$h(n) = \pm h(N-1-n)$2. 掌握线性相位 FIR 滤波器相位特性偶对称：$h(n) = h(N-1-n) \Rightarrow \theta(\omega) = -\tau\omega$奇对称：$h(n) = -h(N-1-n) \Rightarrow \theta(\omega) = \beta - \tau\omega$  (其中 $\tau = \frac{N-1}{2}$, $\beta = \frac{\pi}{2}$)$$H(e^{j\omega}) = H(\omega)e^{j\theta(\omega)}$$3. FIR 分四种类型根据长度 $N$（奇/偶）和 对称性（偶对称/奇对称）分为 4 种类型。掌握不同类型的零点分布特点及应用场景（例如：第 II 型不能做高通，第 III、IV 型不能做低通等）。4. 掌握 FIR 滤波器的窗函数设计方法设计思路：$H_{d}(e^{j\omega}) \Rightarrow h_{d}(n) \Rightarrow h(n) = h_{d}(n)w(n)$参数选择：根据阻带衰减选定窗函数的类型（矩形窗、汉宁窗、海明窗、布莱克曼窗等）；根据过渡带宽确定窗口长度 $N$ 值。加窗影响：加窗处理对理想频率响应会产生吉布斯效应（主瓣变宽，旁瓣引起波动）。第八章 多抽样率数字信号处理基础1. 理解序列插值与抽取的基本理论2. 掌握序列插值、抽取前后频谱的变化信号的“抽取” (Decimation / Downsampling)：$$x_{d}(n) = x(Dn)$$采样率变化：$f_{s} \rightarrow f_{s}/D$频谱变化：频域展开拉伸，幅度减小。如果不加抗混叠前置低通，容易发生混叠。信号的“插值” (Interpolation / Upsampling)：$$x_{e}(n) = \begin{cases} x(n/I), & n = 0, \pm I, \pm 2I \dots \\ 0, & \text{其他} \end{cases}$$采样率变化：$f_{s} \rightarrow I \cdot f_{s}$频谱变化：频域被压缩（出现镜像频谱），需要加插值后置低通滤波器滤除镜像。3. 掌握信号抽样率的转换方法（抽取器、插值器、以及有理数因子的转换率）。
