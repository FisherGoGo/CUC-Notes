# 第6章 输入/输出与中断

## 6.1 输入/输出接口概述

### 为什么需要I/O接口

- CPU和外设的速度差异非常大
- CPU不能和外设直接通过引脚连接
- I/O接口是CPU与外设信息交换的**桥梁**

### 6.1.1 I/O接口的功能

| 功能 | 说明 |
|------|------|
| **I/O地址译码与设备选择** | 同一时刻只允许一个外设与CPU进行数据传送 |
| **信息的输入/输出** | CPU可写命令字、读状态、收发数据；外设可发中断请求 |
| **缓冲与锁存** | 缓存CPU→外设和外设→CPU的信息 |
| **信息转换** | 格式变换、电平转换、码制转换、传送管理等 |

### 6.1.2 I/O接口之间的信息

CPU与I/O接口通信通过I/O接口内部的一组**寄存器（I/O端口）**实现。

#### 三类信息

| 信息类型 | 说明 | 示例 |
|----------|------|------|
| **数据信息** | 数字量（二进制）、模拟量（经A/D转换）、开关量（2状态） | 传感器、开关 |
| **状态信息** | 外设当前状态 | 输入：READY（准备好）；输出：BUSY（忙） |
| **控制信息** | CPU发出的控制命令 | 启动、停止、工作方式 |

#### I/O端口分类

| 端口类型 | 功能 |
|----------|------|
| **数据端口** | CPU与外设交换数据 |
| **状态端口** | 读入设备当前状态 |
| **控制端口** | 向外设发出控制命令 |

> 一个I/O接口可能包含其中一类、两类或全部三类端口。

### 6.1.3 I/O端口的编址方式

| 方式 | 统一编址 | 独立编址 |
|------|----------|----------|
| **别名** | 存储器映射编址 | I/O独立编址 |
| **原理** | I/O端口=存储单元，统一编址 | 内存和外设地址空间独立 |
| **8086/8088** | — | 内存：1M(00000H~FFFFFH)，I/O：64K(0000H~FFFFH) |
| **区分方式** | 同一条指令 | 不同控制信号（M/IO 或 IO/M） |
| **优点** | 指令丰富、寻址灵活、信号共用 | 程序清晰、I/O指令短而快、不占内存 |
| **缺点** | 占用内存地址、不易区分操作对象 | 需专用IN/OUT指令、需额外控制信号 |
| **典型代表** | MCS-51, MC6800, MC68000 | 8086/8088 |

## 6.2 CPU与外设之间的数据传送方式

| 方式 | 特点 | 适用场景 |
|------|------|----------|
| **无条件方式** | 外设始终"准备好"，数据交换与指令**同步** | 开关、LED等简单设备 |
| **查询方式** | CPU不断查询外设状态，就绪才传送 | 外设速度不确定 |
| **中断方式** | 外设主动请求，CPU才响应 | 多外设、实时性要求高 |
| **DMA方式** | 硬件控制，外设与内存直接传送，不经过CPU | 高速外设、批量数据 |

### 6.2.1 无条件传送方式

- 用于外部状态固定且已知的简单外设
- 输入：IN指令 → 选中端口 → RD=0期间读入三态缓冲器数据
- 输出：OUT指令 → 写信号有效 → 数据写入输出锁存器
- 优点：程序简单，硬件少，速度快
- 缺点：必须在确信外设准备好的情况下使用，否则出错

### 6.2.2 查询方式

#### 两个环节

| 环节 | 操作 |
|------|------|
| **查询** | 寻址状态端口 → 读取状态位 → 未就绪则循环检测 |
| **传送** | 寻址数据端口 → 输入(IN)或输出(OUT)数据 |

#### 查询式输入程序段

```asm
MOV  BX, 0           ; 初始化指针
MOV  CX, COUNT_1     ; 字节数
READ_S1:
  MOV  DX, PORT_S1
  IN   AL, DX        ; 读状态位
  TEST AL, 01H       ; 数据准备好否？
  JZ   READ_S1       ; 否，循环检测
  MOV  DX, PORT_IN
  IN   AL, DX        ; 读入数据
  MOV  [BX], AL      ; 存入缓冲区
  INC  BX
  LOOP READ_S1
```

#### 查询式输出程序段

```asm
MOV  BX, 2000H       ; 初始化地址指针
MOV  CX, COUNT_2
READ_S2:
  MOV  DX, PORT_S2
  IN   AL, DX        ; 读状态位
  TEST AL, 80H       ; 忙否？
  JNZ  READ_S2       ; 忙，循环检测
  MOV  AL, [BX]      ; 取数据
  MOV  DX, PORT_OUT
  OUT  DX, AL        ; 输出
  INC  BX
  LOOP READ_S2
```

> **缺点**：CPU大量时间用在读取和检测外设状态上，效率低。

### 6.2.3 中断传送方式

- 外设准备好时主动向CPU发出**中断请求**
- CPU响应后暂停当前程序，转去执行**中断服务程序**，完成后返回断点
- 优点：提高CPU效率，可实时响应外设请求

### 6.2.4 DMA传送方式

- **Direct Memory Access**：直接存储器存取
- 由**DMA控制器**接管总线，控制外设与内存直接传送
- **不经过CPU**，整个过程由硬件完成，传输率高

#### DMA工作过程

| 步骤 | 操作 |
|------|------|
| 1 | 外设→DMA控制器：DRQ（DMA请求） |
| 2 | DMA控制器→CPU：HOLD（总线请求） |
| 3 | CPU完成当前周期后→HLDA（总线响应），释放总线 |
| 4 | DMA控制器接管总线→DACK（DMA响应信号）→传输数据 |
| 5 | 传输完成→撤销HOLD→CPU恢复总线控制 |

## 6.3 中断技术

### 6.3.1 中断基本概念

**中断**：程序执行中，出现紧急事件，CPU暂停当前程序，转去执行中断服务程序，执行完返回断点继续执行。

#### 中断源分类

| 分类 | 说明 | 示例 |
|------|------|------|
| **内部中断** | CPU内部产生 | 除法错、单步(TF=1)、INT n指令 |
| **外部中断—可屏蔽** | 可延时处理 | 打印机中断（通过INTR引脚） |
| **外部中断—不可屏蔽** | 必须立即处理 | 电源掉电、内存奇偶校验错（通过NMI引脚） |

#### 中断处理基本过程

```
中断请求 → 中断判优 → 中断响应 → 中断服务 → 中断返回
```

### 6.3.2 中断处理过程

#### 1. 中断请求

| 来源 | 说明 |
|------|------|
| CPU内部中断 | 不需外部请求信号，内部逻辑直接处理 |
| 外部中断 | 通过INTR（可屏蔽）和NMI（不可屏蔽）引脚 |

**中断请求触发器**：每个中断源锁存自己的中断请求信号，CPU响应后才清除。

**中断允许触发器**（CPU内部）：
- =1：开中断（允许响应）
- =0：关中断（中断被屏蔽）
- CPU复位时自动关中断；中断响应时自动关中断
- 可用STI/CLI指令设置

#### 2. 中断判优

多个中断源同时请求时，CPU按优先级顺序响应。

| 判优方法 | 原理 | 特点 |
|----------|------|------|
| **软件判优** | 程序逐位查询中断请求寄存器，先查的优先级高 | 实现简单、灵活，中断多时速度慢 |
| **硬件判优—菊花链** | 中断响应信号链式传递，前级截获即封锁后级 | 硬件固定优先级 |
| **硬件判优—中断控制器(8259A)** | 自动判别最高优先级，提供中断向量码 | 灵活可编程，可级联 |

#### 3. 中断响应

CPU发出中断响应信号，同时：
1. **关中断**
2. **保护现场和断点**（寄存器、IP、CS、FR入栈）
3. **获得中断服务程序入口地址**

#### 4. 中断服务程序结构

```asm
INTPROC:
  PUSH  ...         ; 保护现场
  STI               ; 开中断（允许中断嵌套）
  ...               ; 中断服务程序主体
  CLI               ; 关中断
  POP   ...         ; 恢复现场
  IRET              ; 中断返回
```

### 6.3.3 8086/8088 中断系统

#### 中断向量表

| 项目 | 数值 |
|------|------|
| 总中断数 | 256个 |
| 每中断向量字节 | 4字节（段基址2 + 偏移地址2） |
| 向量表总大小 | 1KB |
| 向量表位置 | 内存 00000H ~ 003FFH |
| 向量地址 | **中断类型码 × 4** |

#### 中断向量表结构

```
地址        内容
00000H     类型0 偏移地址（低字节）
00001H     类型0 偏移地址（高字节）
00002H     类型0 段基址（低字节）
00003H     类型0 段基址（高字节）
00004H     类型1 ...
...        ...
00080H     类型32（20H）——用户中断开始
```

> 例：INT 21H的向量地址 = 21H × 4 = 84H

#### 中断类型分配

| 类型码 | 用途 |
|--------|------|
| 0 | 除法错中断 |
| 1 | 单步中断（TF=1时） |
| 2 | 非屏蔽中断（NMI） |
| 3 | 断点中断（INT3，代码0CCH） |
| 4 | 溢出中断（INTO，OF=1时触发） |
| 5~31 | Intel保留（微处理器专用） |
| **32~255** | **用户中断（含INT n软中断和INTR硬件中断）** |

#### 设置/清除TF标志位

```asm
; 置TF=1（开启单步中断）
PUSHF
POP  AX
OR   AX, 0100H     ; D8位置1
PUSH AX
POPF

; 清TF=0（禁止单步中断）
PUSHF
POP  AX
AND  AX, 0FEFFH    ; D8位清0
PUSH AX
POPF
```

#### 中断向量的设置方法

**方法一：MOV指令直接设置**

```asm
MOV  AX, 0
MOV  ES, AX
MOV  BX, n*4
MOV  AX, OFFSET INTPROC
MOV  ES:WORD PTR [BX], AX     ; 偏移量 → 4n
MOV  AX, SEG INTPROC
MOV  ES:WORD PTR [BX+2], AX   ; 段基址 → 4n+2
```

**方法二：DOS功能调用（推荐）**

```asm
; AH=25H, AL=中断类型码, DS:DX=中断向量
MOV  AX, SEG INTPROC
MOV  DS, AX
MOV  DX, OFFSET INTPROC
MOV  AL, n
MOV  AH, 25H
INT  21H
```

## 6.4 中断控制器 8259A

### 概述

- **8位可编程**中断控制器
- 单片8级优先权控制，**级联最多64级**
- 可向CPU提供不同的中断类型码
- 可屏蔽指定的中断源

### 内部结构

| 部件 | 功能 |
|------|------|
| **数据总线缓冲器** | 8位双向三态，与系统数据总线接口 |
| **读/写控制逻辑** | 确定2个端口地址，实现寄存器读写 |
| **级联缓冲/比较器** | 实现芯片级联（主片/从片） |
| **优先级判别器(PR)** | 判定最高优先级，决定是否向CPU发请求 |
| **中断服务寄存器(ISR)** | 记录正在处理的中断（对应位=1） |
| **中断请求寄存器(IRR)** | 保存IR0~IR7的中断请求信号 |
| **中断屏蔽寄存器(IMR)** | 存放屏蔽字，某位=1则屏蔽对应IR |

### 8259A 引脚

| 引脚 | 功能 |
|------|------|
| D7~D0 | 双向三态数据线 |
| IR0~IR7 | 8条外部中断请求输入线 |
| $\overline{RD}$, $\overline{WR}$ | 读/写命令 |
| $\overline{CS}$ | 片选 |
| A0 | 选择内部寄存器（通常接地址总线A0） |
| INT | 向CPU发中断请求 |
| $\overline{INTA}$ | 接收CPU中断响应信号 |
| CAS2~CAS0 | 级联信号线（主片输出，从片输入） |
| $\overline{SP}/EN$ | 主从/缓冲控制 |

### 工作方式

#### 1. 优先级管理

| 方式 | 说明 |
|------|------|
| **完全嵌套** | 固定优先级，IR0最高→IR7最低（默认） |
| **自动循环** | 刚被服务的中断降为最低，轮转 |
| **特殊完全嵌套** | 用于级联情况 |

#### 2. 屏蔽管理

| 方式 | 说明 |
|------|------|
| **普通屏蔽** | IMR某位=1，屏蔽对应IR |
| **特殊屏蔽** | 允许低优先级中断打断当前正在服务的高优先级中断 |

#### 3. 中断结束(EOI)管理

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **普通EOI** | 复位ISR中已置位的最高级别位 | 全嵌套方式 |
| **特殊EOI(SEOI)** | 指定复位ISR中的某一位 | 非全嵌套方式 |
| **自动EOI(AEOI)** | 第二个INTA后沿自动清ISR | 仅用于**无嵌套**情况 |

### 8259A 编程

#### 初始化命令字(ICW)

| 命令字 | 写入地址 | 功能 |
|--------|----------|------|
| **ICW1** | 偶地址 | 确定触发方式、单片/级联、是否需要ICW4 |
| **ICW2** | 奇地址 | 设置中断类型码高5位(T7~T3) |
| **ICW3** | 奇地址 | 级联时使用，主片标记哪个IR有从片 |
| **ICW4** | 奇地址 | EOI方式、嵌套方式、缓冲方式 |

> 初始化写入顺序严格：ICW1 → ICW2 → ICW3 → ICW4

#### 操作命令字(OCW)

| 命令字 | 写入地址 | 功能 |
|--------|----------|------|
| **OCW1** | 奇地址 | 中断屏蔽字 |
| **OCW2** | 偶地址 | 发EOI命令、优先级循环控制 |
| **OCW3** | 偶地址 | 屏蔽方式、状态读出控制 |

### 8259A 应用示例

IBM PC/XT中单片8259A，以IR0~IR7分别连接：
日历时钟、键盘、保留、网络通信、异步通信、硬盘、软盘、打印机中断。

初始化示例：
```asm
MOV  AL, 13H   ; ICW1: 单片,边沿触发,需要ICW4
OUT  20H, AL
MOV  AL, 8     ; ICW2: 中断类型码从08H开始
OUT  21H, AL
MOV  AL, 0DH   ; ICW4: 缓冲方式,8088/8086配置
OUT  21H, AL
```
