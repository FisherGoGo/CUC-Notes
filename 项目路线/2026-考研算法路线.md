## 三、各阶段详解

### 阶段 0：ACM 区域赛（2026.06 — 2026.12）

> 此阶段 ML 学习仅维持最低感知，不设硬性目标。

#### 区域赛核心

```
├── 队内训练赛 + 模拟赛（主力）
├── 专题突破：图论、DP、字符串、计算几何
├── 往年区域赛真题复盘
└── 保持 Codeforces / AtCoder 手感
```

#### ML 最低维持（每周 ≤2 小时，纯放松向）

```
├── 吴恩达 ML 课程（慢速看，不赶进度）
├── Python 基础熟悉（NumPy 为主）
└── 关注 arXiv 感兴趣方向的论文标题（不深读）
```

> 区域赛结束后，ACM 的算法能力会直接迁移到 ML 工程实现中——这是你相比纯 ML 方向考生的独特优势。

### 阶段 1：ML/DL 筑基 + 方向探索（2027.01 — 2027.06）

#### 理论学习

```
顺序：
① 吴恩达 Machine Learning（建立直觉，2-3 周）
② 李宏毅 Deep Learning（加深理论，4-6 周）
③ 李沐《动手学深度学习》（代码同步，6-8 周）
④ 经典论文精读（Transformer / ResNet / GAN / Diffusion，持续）
```

#### 工程基础

```
├── Python 科班化：NumPy / Pandas / 类型注解 / 单元测试
├── PyTorch 手写：CNN → RNN → Transformer（逐层实现）
├── Linux + Git + Conda 工作流
└── CUDA 基础（了解即可，不深入）
```

#### 方向探索

结合「数媒专业 + 音乐兴趣」，优先探索以下方向：

| 方向 | 契合点 | 探索任务 |
|------|--------|----------|
| 🎵 **音频 AI** | 你有音乐底子，竞争小 | 跑通一个音乐分类/生成 demo |
| 🎨 **多模态/AIGC** | 数媒对口，热度高 | 复现一篇文生图论文 |
| 👁️ **计算机视觉** | 成熟、资料多、稳妥 | 跑通 ResNet + YOLO |

> 阶段 1 结束前，确定 1 个深耕方向。

#### 产出目标

- [ ] Kaggle 入门赛（Titanic 起步，建立完整 ML pipeline）
- [ ] 1 篇经典论文的完整复现（含代码 + 笔记）
- [ ] 确定目标方向

### 阶段 2：深度项目 + 数学一轮（2027.07 — 2027.12）

#### 深度项目（选一个深耕）

| 项目类型 | 要求 | 价值 |
|------|------|------|
| **Kaggle 竞赛** | 银牌以上 | 复试硬通货 |
| **论文复现 + 改进** | 完整复现 + 至少一个改进点 | 证明科研潜力 |
| **导师课题参与** | 提前联系目标院校导师 | 复试最大加分项 |
| **自研项目** | 音频生成 / 音乐风格迁移等 | 差异化，展示兴趣 |

#### 数学一轮

```
├── 高等数学（同济 / 张宇）
├── 线性代数（MIT 18.06 / 李永乐）
├── 概率论与数理统计（浙大 / 王式安）
└── 目标：基础概念 + 常规题型全覆盖
```

#### 目标院校调研

```
├── 确定 3-5 所目标院校（冲/稳/保）
├── 调研考试科目（数一/数二？408/自命题？）
├── 关注目标导师的研究方向 + 论文
```

## 四、方向选择决策矩阵

| 方向 | 竞争度 | 与你契合度 | 资料丰富度 | 推荐 |
|------|------|------|------|------|
| 🎵 音频 AI | 🟢 低 | ⭐⭐⭐⭐⭐ | 🟡 中 | 🔥 首选 |
| 🎨 多模态/AIGC | 🔴 高 | ⭐⭐⭐⭐ | 🟢 高 | 备选 |
| 👁️ CV | 🔴 极高 | ⭐⭐⭐ | 🟢 极高 | 稳妥 |
| 📊 NLP | 🟡 中 | ⭐⭐ | 🟢 高 | 不推荐 |

> **建议主攻音频 AI，CV 作为备选。** 音频方向竞争远小于 CV/NLP，但市场需求在增长（语音助手、音乐生成、TTS）。你有吉他基础和信号处理直觉，这是纯 CS 考生不具备的交叉优势。

## 五、与工程路线的协作

```
工程路线（Go/TS/Rust）  →  就业安全网，考研不顺时的 Plan B
                        →  每周 ≤4 小时低强度维持
                        →  维持 GitHub 活跃度

考研路线（ML/DL/数学）  →  主线，大三大四全力冲刺
                        →  区域赛后正式启动
                        →  目标：一战上岸
```

两条线不冲突——工程项目的工程化能力（Docker、CI/CD、API 设计）在 ML 项目中一样要用。
