# N3 小单元训练

这组资料按“小单元”组织，每套约 20-30 分钟：

1. 本单元句型
2. 热身词句
3. 句子翻译
4. 阅读理解
5. 输出小练习
6. 参考答案

建议做法：先完成 PDF 前两页，不看答案；再用第三页批改，把翻译错句和阅读误判点整理进错题本或 Anki。

## 单元目录

| 单元 | 主题 | 训练重点 |
| --- | --- | --- |
| 01 | 便利店与打工 | 工作安排、请求、原因说明 |
| 02 | 租房与搬家 | 条件比较、确认、选择理由 |
| 03 | 医院与身体状况 | 症状说明、医生建议、必要性 |
| 04 | 图书馆与学习计划 | 学习计划、习惯、阅读方法 |
| 05 | 电车与外出 | 路线、换乘、突发情况 |
| 06 | 餐厅预约 | 礼貌请求、预约变更、人数时间 |
| 07 | 活动准备 | 分工、提前准备、临时变更 |
| 08 | 遗失物与求助 | 遗失说明、地点时间、求助表达 |
| 09 | 面试与自我介绍 | 经验、理由、长处、计划 |
| 10 | 垃圾分类与环保 | 规则说明、建议、原因结果 |

## 文件说明

- `*.pdf`：适合打印、平板书写或直接做题。
- `*.md`：适合修改题目、摘抄错题、继续扩展。
- `../03_脚本/generate_n3_units_10.py`：批量生成这 10 套资料。
- `../03_脚本/generate_n3_unit_sample.py`：版式和单套样张脚本。
