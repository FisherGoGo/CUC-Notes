# N3小单元训练 07：活动准备

目标：练习任务分工、提前准备和临时变更，并通过阅读理解活动准备流程。

## 本单元句型

- ておく：提前...
- ことになった：决定/安排为...
- ように：为了...
- までに：在...之前
- 代わりに：代替...
- おかげで：多亏...

## 热身词句

- **準備**：准备。例：発表の準備をしています。
- **担当**：负责。例：私は受付を担当します。
- **資料**：资料。例：資料を印刷しておきます。
- **受付**：接待，签到处。例：受付は入口の近くです。
- **知らせる**：通知。例：変更をみんなに知らせました。
- **手伝う**：帮忙。例：友達が準備を手伝ってくれました。

## 句子翻译

1. 请在活动开始前把资料打印好。（提示：前に / ておく）
2. 我负责入口处的接待。（提示：担当）
3. 因为老师不能来，所以我代替老师说明。（提示：ので / 代わりに）
4. 请在星期五之前通知大家时间变更。（提示：までに / てください）
5. 多亏朋友帮忙，准备顺利完成了。（提示：おかげで）
6. 为了让参加者容易明白，我做了简单的说明图。（提示：ように）

## 阅读理解

今週の金曜日に、日本語クラスで交流会を開くことになりました。私は受付を担当するので、参加者の名前が書いてある紙と案内の資料を準備しておきました。発表をする友達は、木曜日までにスライドを先生に送ることになっています。

ところが、前の日に先生から、急な用事で少し遅れると連絡がありました。そのため、最初の説明は私が先生の代わりにすることになりました。少し緊張しましたが、友達が一緒に練習してくれたおかげで、当日は落ち着いて話すことができました。

词汇提示：交流会：交流会 / 案内：引导，说明 / 落ち着く：冷静

   - 周三
   - 周五
   - 周六
   - 下周一
2. 作者负责什么？
   - 制作幻灯片
   - 接待
   - 买饮料
   - 拍照
3. 老师发生了什么事？
   - 不能来
   - 会迟到一点
   - 提前到
   - 取消活动
4. 作者为什么当天能冷静说明？
   - 完全不紧张
   - 朋友陪他练习
   - 老师写了稿子
   - 参加者很少

## 输出小练习

用日语写 2-3 句：如果你负责一个活动，会提前准备什么？

## 参考答案

1. イベントが始まる前に、資料を印刷しておいてください。
2. 私は入口の受付を担当します。
3. 先生が来られないので、私が先生の代わりに説明します。
4. 金曜日までに、時間の変更をみんなに知らせてください。
5. 友達が手伝ってくれたおかげで、準備が順調に終わりました。
6. 参加者に分かりやすいように、簡単な説明図を作りました。

### 阅读答案

1. 周五。文中说「今週の金曜日」。
2. 接待。文中说「受付を担当」。
3. 会迟到一点。文中说「少し遅れる」。
4. 朋友陪他练习。文中说「友達が一緒に練習してくれたおかげで」。

### 输出参考

イベントの前に、資料と参加者の名前を確認しておきます。みんなが分かりやすいように、案内も作りたいです。
