# 第5章 存储器

## 5.1 存储器概述

**存储器(Memory)** 是用来存储程序和数据的部件。从与CPU的关系分为：

| 类型 | 位置 | 组成 | 用途 |
|------|------|------|------|
| **内存（主存）** | 主机内部 | 半导体存储器 | 存放当前正在执行的程序和数据 |
| **外存（辅存）** | 主机外部 | 磁盘、SSD等 | 存放暂不使用的程序和数据，需先调入内存 |

### 5.1.1 半导体存储器的分类

```
半导体存储器
├── 随机存储器 RAM（易失性）
│   ├── 静态RAM (SRAM)
│   └── 动态RAM (DRAM)
├── 只读存储器 ROM（非易失性）
│   ├── 掩膜式ROM (Masked ROM)
│   ├── PROM
│   ├── EPROM（紫外光擦除）
│   └── EEPROM（电擦除）
└── 闪存 Flash（非易失性）
```

#### RAM 对比

| 特性 | SRAM | DRAM |
|------|------|------|
| **存储原理** | 双稳态触发器 | 电容存储电荷 |
| **速度** | 快 | 较慢 |
| **刷新** | 不需要 | 需要（几ms刷新一次） |
| **集成度** | 较低 | 较高 |
| **容量** | 较小 | 较大 |
| **功耗** | 较大 | 较低 |
| **成本** | 较高 | 较低 |
| **读操作** | 不破坏原有数据 | 破坏性读出 |

#### ROM 类型对比

| 类型 | 写入方式 | 擦除方式 | 可重写 |
|------|----------|----------|--------|
| **掩膜式ROM** | 厂家生产时一次性写入 | 不可更改 | 否 |
| **PROM** | 用户用编程器一次性写入 | 不可更改 | 否 |
| **EPROM** | 专用编程器写入 | 紫外光擦除 | 多次 |
| **EEPROM** | 电信号写入 | 电信号擦除（不必取出芯片） | 多次 |

#### 闪存 Flash

- 可读写、非易失性
- 速度快、集成度高、功耗低、可靠性高
- 应用：计算机BIOS、固态存储器（SSD）等

### 5.1.2 主要性能指标

| 指标 | 公式/说明 |
|------|-----------|
| **存储容量** | $2^M \times N$，M=地址数，N=每个存储单元位数。例：16位地址、8位字长 → $2^{16}\times8\text{b}=64\text{KB}=512\text{Kb}$ |
| **存取时间 $T_A$** | 从启动一次存储操作到完成该操作的时间 |
| **存储周期 $T_M$** | 两次独立存储器操作之间的最小时间间隔 |
| **功耗** | 工作时功耗 + 维持功耗 |

单位换算：$1B=8\text{bit}$，$1KB=2^{10}B$，$1MB=2^{10}KB$，$1GB=2^{10}MB$，$1TB=2^{10}GB$

### 5.1.3 典型半导体存储器芯片

| 芯片 | 类型 | 容量 | 地址线 | 数据线 |
|------|------|------|--------|--------|
| **HM6116** | SRAM | 2K×8位 | A0~A10 (11根) | I/O1~I/O8 (8根) |
| **Intel 2164** | DRAM | 64K×1位 | A0~A7 (8根，行/列复用) | Din, Dout (各1根) |
| **Intel 2732A** | EPROM | 4K×8位 | A0~A11 (12根) | O0~O7 (8根) |

#### 控制信号（以HM6116为例）

| 信号 | 功能 |
|------|------|
| $\overline{CS}$ | 片选，低电平有效 |
| $\overline{WE}$ | 写允许，低电平有效 |
| $\overline{OE}$ | 输出允许，低电平有效 |

> Intel 2164 特有：$\overline{RAS}$（行地址选通）、$\overline{CAS}$（列地址选通），外接多路开关实现行/列地址选通。

## 5.2 半导体存储器的基本结构

```
CPU → 地址总线 → MAR(地址寄存器) → 地址译码器 → 存储体
CPU ← 数据总线 ← MDR(数据寄存器) ← 读/写驱动器 → 存储体
```

### 读操作过程

1. CPU通过地址总线将地址送入MAR
2. 使读相关控制信号有效
3. MAR中地址码经地址译码器译码，选中对应存储单元
4. 读/写驱动器将选中单元数据送入MDR
5. CPU通过数据总线读入数据

### 写操作过程

1. CPU将地址送入MAR
2. CPU将数据通过数据总线送入MDR
3. 使写相关控制信号有效
4. 地址译码后选中对应存储单元
5. 读/写驱动器将MDR数据送入选中存储单元

## 5.3 半导体存储芯片的使用

### CPU与存储器连接的四要素

1. **CPU的负载能力**
2. **各种信号线的连接**（数据线、地址线、控制线）
3. **CPU时序与存储器存取速度的配合**
4. **存储器的地址分配及片选信号的产生**

### 三总线连接

| 总线 | 连接方式 |
|------|----------|
| **数据线** | 芯片数据线**直接**与CPU数据线相连 |
| **地址线** | 低位→芯片地址线（片内译码）；高位→地址译码器产生**片选信号** |
| **控制线** | $\overline{RD}$/$\overline{WR}$ → 芯片 $\overline{OE}$/$\overline{WE}$；$\overline{M/IO}$ → 地址译码器控制信号 |

## 5.4 微机系统中的存储器接口

### 地址对齐

| CPU | 字长 | 数据对齐要求 |
|-----|------|-------------|
| 8086 | 16位 | 地址为2的倍数（偶数，$A_0=0$） |
| 80386 | 32位 | 地址为4的倍数（$A_1A_0=00$） |

### 8086 存储器的奇偶分体

8086 1MB存储空间分为两个512KB的存储体：
- **偶体**：与低8位数据线(D7~D0)相连，A0=0选中
- **奇体**：与高8位数据线(D15~D8)相连，$\overline{BHE}$（总线高允许）选中

### 80386 存储器的四体结构

4GB存储空间分成4个1GB存储体，按地址 mod 4 分配给不同体：
- 体0：4n+0
- 体1：4n+1
- 体2：4n+2
- 体3：4n+3

## 5.5 存储器容量的扩展

### 三种扩展方法

| 方法 | 适用场景 | 核心操作 |
|------|----------|----------|
| **位扩展** | 芯片位数不足 | 地址线/片选并联，数据线分高低位 |
| **字扩展** | 芯片存储字数量不足 | 地址线/数据线并联，片选分别控制 |
| **字位扩展** | 位和字都不足 | 分组后：组内位扩展 + 组间字扩展 |

#### 位扩展连接要点

| 信号线 | 连接方式 |
|--------|----------|
| 地址线 | 全部并联 |
| 数据线 | 分高低位，分别与对应CPU数据线位连接 |
| 读/写控制 | 并联 |
| 片选信号 | 并联 |

#### 字扩展连接要点

| 信号线 | 连接方式 |
|--------|----------|
| 地址线 | 全部并联 |
| 数据线 | 全部并联 |
| 读/写控制 | 并联 |
| 片选信号 | **分别**接高位地址线或地址译码器输出端 |

## 5.6 片选信号的三种产生方式

### 对比总结

| 方法 | 实现 | 优点 | 缺点 |
|------|------|------|------|
| **线选法** | 高位地址线直接作片选信号 | 结构简单 | 地址空间浪费大，可能出现地址不连续 |
| **部分译码法** | 部分高位地址参与译码，产生片选 | 译码电路简化 | 同一存储单元对应多个地址（地址重叠），空间部分浪费 |
| **全译码法** | 除片内地址外全部高位地址参与译码 | **地址唯一**，无地址重叠 | 电路较复杂 |

### 常用译码器

**74LS138**：3-8译码器，3位输入→8个片选输出。

## 5.7 存储芯片的地址范围计算

给定片选逻辑和地址线连接，可以确定每片芯片的地址范围。

**基本方法**：
1. 确定片内地址线位数（如6264: 8K=2^13 → A0~A12）
2. 确定片选信号由哪些高位地址线产生
3. 片选有效时，高位地址线固定值 + 片内地址变化 = 地址范围

> 全译码法中每个存储单元的**地址是唯一的**，无地址重叠问题。
