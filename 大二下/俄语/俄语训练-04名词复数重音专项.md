# 俄语训练 04：名词复数与重音专项

> 目标：把单数名词变成复数，并在复数中标出重音。重音题一定要出声读。

## 速记规则

| 类型 | 常见变化 | 例子 |
| --- | --- | --- |
| 阳性辅音 | 加 -ы / -и | стол -- столы́，банк -- ба́нки |
| 阴性 -а | -а 变 -ы / -и | кни́га -- кни́ги，су́мка -- су́мки |
| 阴性 -я | -я 变 -и | неде́ля -- неде́ли |
| 中性 -о | -о 变 -а | окно́ -- о́кна |
| 中性 -е | -е 变 -я | мо́ре -- моря́ |
| -й / -ь | 变 -и | музе́й -- музе́и，слова́рь -- словари́ |
| г к х ж ч ш щ 后 | 通常用 -и | врач -- врачи́，нож -- ножи́ |
