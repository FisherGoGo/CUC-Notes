# 第十章练习题

## 1. 10 位 D/A 转换器的分辨率

**题目：** 10 位 D/A 转换器的分辨率能给出满量程电压的（ ）。

**选项：**

- A. `1/256`
- B. `1/1024`
- C. `1/512`
- D. `1/10`

**答案：B**

**解析：** D/A 转换器的分辨率通常为：

$$
\frac{1}{2^n}
$$

其中 $n$ 为转换器位数。10 位 D/A 转换器的分辨率为：

$$
\frac{1}{2^{10}}=\frac{1}{1024}
$$

**干扰项分析：**

- A 是 8 位转换器的分辨率。
- C 是 9 位转换器的分辨率。
- D 把“10 位”误理解成了十分之一。

> 易错点：位数是指数，不是分母本身。10 位对应 $2^{10}$ 个量化等级。

## 2. A/D 转换器向 CPU 发出的中断请求信号

**题目：** 当 CPU 使用中断方式从 A/D 转换器读取数据时，A/D 转换器向 CPU 发出中断请求的信号是（ ）。

**选项：**

- A. START
- B. EOC
- C. OE
- D. INTR

**答案：D**

**解析：** `INTR` 是中断请求信号，用于通知 CPU 转换结果已经可以读取。CPU 在中断服务程序中读取 A/D 转换后的数字量。

**干扰项分析：**

- A `START` 是启动转换信号。
- B `EOC` 是转换结束信号，常可经逻辑处理后作为中断请求来源，但它本身不是中断请求端名。
- C `OE` 是输出允许信号，用来控制转换结果输出到数据总线。

> 易错点：`EOC` 表示转换结束，`INTR` 表示向 CPU 请求中断。

## 3. 启动 ADC0809 进行 A/D 转换的方法

**题目：** 启动 ADC0809 芯片开始进行 A/D 转换的方法是（ ）。

**选项：**

- A. ALE 引脚输入一个正脉冲
- B. START 引脚输入一个正脉冲
- C. ALE 引脚在 A/D 转换期间一直为高电平
- D. START 引脚在 A/D 转换期间一直为高电平

**答案：B**

**解析：** ADC0809 中，`ALE` 用于锁存通道地址，`START` 用于启动 A/D 转换。启动转换时，应在 `START` 引脚输入一个启动脉冲。

**干扰项分析：**

- A 错，`ALE` 的作用是地址锁存，不是启动转换。
- C 错，`ALE` 不需要在转换期间一直保持高电平。
- D 错，`START` 需要的是启动脉冲，不是在整个转换期间一直保持高电平。

> 易错点：`ALE` 锁存通道地址，`START` 启动转换，`EOC` 表示转换结束，`OE` 控制数据输出。

## 4. A/D 转换器分辨率与转换精度的关系

**题目：** A/D 转换器的分辨率与转换精度的关系是（ ）。

**选项：**

- A. 分辨率高，转换精度一定高
- B. 分辨率与转换精度没有关系
- C. 分辨率高，其转换精度不一定高
- D. 分辨率越高，转换精度越低

**答案：C**

**解析：** 分辨率表示转换器能分辨的最小输入变化量；转换精度表示转换结果与真实值的接近程度。分辨率高只能说明量化等级多，但若器件线性误差、零点误差、增益误差等较大，转换精度仍可能不高。

**干扰项分析：**

- A 错，分辨率高不代表误差一定小。
- B 错，分辨率会影响量化误差，与精度有关，但不是唯一因素。
- D 错，分辨率提高通常有利于减小量化误差，不会必然降低精度。

> 易错点：分辨率是“能分多细”，精度是“测得准不准”。

## 5. D/A 转换器稳定性的技术指标

**题目：** 反映一个 D/A 转换器稳定性的技术指标是（ ）。

**选项：**

- A. 转换速度
- B. 分辨率
- C. 输出阻抗
- D. 精度

**答案：D**

**解析：** D/A 转换器的稳定性通常反映在输出值是否准确、是否随时间或环境变化产生偏差等方面，和精度指标关系最密切。

**干扰项分析：**

- A 表示转换快慢。
- B 表示最小可分辨输出变化量。
- C 表示输出端等效阻抗，影响带负载能力。

## 6. ADC0809 的类型与量化误差

**题目：** A/D 转换器 ADC0809 为 ① 型的 A/D 转化器，当其参考电压为 5V 时，其量化误差为 ② mV。

**答案：** ① 逐次逼近型；② 严格按最大量化误差为 `±9.77 mV`。若题库把 1 个 LSB 量化间隔称为量化误差，则填 `19.53 mV`。

**解析：** ADC0809 是 8 位逐次逼近型 A/D 转换器。8 位转换器共有：

$$
2^8=256
$$

个量化等级。当参考电压为 `5V` 时，1 个 LSB 对应的电压为：

$$
\frac{5V}{256}=0.01953V=19.53mV
$$

严格意义上的最大量化误差一般取半个 LSB：

$$
\pm \frac{1}{2}LSB=\pm 9.77mV
$$

> 易错点：很多题库把“量化间隔 1LSB”和“量化误差”混用。严格概念是最大量化误差为半个 LSB。

## 7. D/A 转换器的主要性能指标

**题目：** 模/数转换器的性能指标主要有：①、②、③ 和量程。

**答案：** ① 分辨率；② 转换精度；③ 转换时间

**解析：** 题干写“模/数转换器”时，通常指 A/D 转换器。A/D 转换器的常见性能指标包括分辨率、转换精度、转换时间和量程。

> 易错点：如果题目实际想问 D/A 转换器，则常见指标中也会出现“建立时间”。但本题已给出“量程”，按 A/D 性能指标填“转换时间”更稳。

## 8. A/D 转换器的主要性能指标

**题目：** 数/模转化器的性能指标主要有：①、②、③。

**答案：** ① 分辨率；② 转换精度；③ 建立时间

**解析：** 题干写“数/模转换器”，即 D/A 转换器。D/A 转换器的主要性能指标包括分辨率、转换精度和建立时间。建立时间表示输入数字量变化后，模拟输出达到规定精度范围所需的时间。

> 易错点：A/D 常说“转换时间”，D/A 常说“建立时间”。两者容易互换写错。
