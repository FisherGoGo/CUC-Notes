# N3 20 天冲刺手册：写作规范

用途：后续把 TRY N4、TRY N3 每一课整理成单元学习手册时，统一内容深度、题型、解释方式和复习节奏。目标是 20 天内应对 JLPT N3，不做百科式语法书，而做能看完、能记住、能做题的冲刺资料。

## 总原则

1. 以考试掌握为目标，不追求完整学术解释。
2. 每课必须能在 45-70 分钟内完成。
3. 每条语法都要服务于三件事：看懂意思、知道接续、能在题目和阅读里认出来。
4. 优先讲高频、易混、容易在阅读中卡住的表达。
5. 解释要短，例句要实用，练习要接近 N3/N4 文法题和阅读理解。
6. 所有手册默认面向中文学习者，说明用中文，例句用日语，必要处附中文意思。
7. 不堆冷门知识，不展开过细的语法史、语感史、敬语体系理论。

## 每课手册结构

每个单元文件使用以下结构：

```markdown

## 本课目标

## 考试优先级

## 语法速学

### 1. 语法项

## 阅读拆句训练

## 本课练习

## 答案与解析

## 复习清单
```

## 本课目标写法

用 3-5 条说明本课要掌握什么，不写空泛目标。

示例：

```markdown
## 本课目标

- 能看懂表示原因、决定、传闻的基础表达。
- 能区分 `そうだ` 的样态、推测、传闻用法。
- 能在阅读中识别句子名词化和条件表达。
```

## 考试优先级

每课开头标出本课语法的优先级：

- **A 必会**：N3 阅读和文法题中常见，必须掌握意思和接续。
- **B 应会**：常见但题目中不一定高频，至少要能看懂。
- **C 认识即可**：出现时能大致理解即可，不必花大量时间输出。

格式：

```markdown
## 考试优先级

| 优先级 | 语法 |
| --- | --- |
| A | `～ておく`、`～かもしれない` |
| B | `～といい`、`～ことになる` |
| C | 本课无 |
```

## 每条语法的固定写法

每条语法控制在 120-220 字左右，特殊易混语法可稍长。

固定结构：

```markdown
### 1. `～ておく`

**意思**：提前做好某事；让某状态保持下去。

**接续**：动词て形 + おく

**例句**

- 試験の前に、文法を復習しておきます。  
  考试前先把语法复习好。
- ドアを開けておいてください。  
  请把门开着。

**考试注意**：常和准备、预约、确认、保存状态一起出现。不要只理解成“放置”，很多时候是“提前做”。
```

### 必须包含

每条语法必须包含：

1. **意思**
2. **接续**
3. **2 个例句**
4. **考试注意或易错点**

### 可以包含

只在需要时加入：

1. **相近表达**
2. **常见搭配**
3. **阅读中怎么拆**

### 不要包含

1. 不写太长的理论解释。
2. 不列 5 个以上例句。
3. 不写超出 N3 太多的拓展。
4. 不把相似表达展开成小论文。

## 例句要求

例句必须满足：

1. 日常、学习、打工、出行、预约、健康、面试等 N3 常见场景。
2. 每句尽量短，避免一个例句塞多个难语法。
3. 日语后面必须有中文意思。
4. 同一课内例句主题可以连贯，但不能机械重复。
5. 尽量复用 JLPT 阅读常见词：予定、理由、場合、必要、確認、連絡、説明、準備、参加、経験、問題、方法等。

## 易混点写法

每课必须有“本课易混点”，重点整理 2-4 组。

格式：

```markdown
## 本课易混点

### `そうだ` vs `ようだ` vs `らしい`

| 表达 | 核心区别 | 例句 |
| --- | --- | --- |
| `そうだ` | 看起来；或听说，取决于接续 | 雨が降りそうです。 |
| `ようだ` | 根据感觉、情况推测 | 誰か来たようです。 |
| `らしい` | 根据信息判断；也可表示典型特征 | 明日は雨らしいです。 |
```

易混点解释要直接给判断方法，不写成抽象定义。

## 阅读拆句训练

每课放 3-5 句阅读拆句训练。

每句包含：

1. 日语原句
2. 句子骨架
3. 关键语法
4. 中文意思

格式：

```markdown
### 句子 1

試験の前に復習しておいた文法が、読解問題で役に立ちました。

- 骨架：文法が役に立ちました
- 关键：`～ておく` 表示提前做；`読解問題で` 表示场合
- 中文：考试前提前复习过的语法，在阅读题里派上了用场。
```

## 练习题配置

每课放 10-15 题。20 天冲刺优先保证完成率，不做过量题海。

推荐配置：

```text
一、选择题：6-8 题
二、排序题：2-3 题
三、阅读理解/句子理解：2-4 题
```

### 选择题要求

1. 每题 4 个选项。
2. 错误选项要有迷惑性，但不能故意刁钻。
3. 题干尽量使用 N3 常见场景。
4. 每题只考一个核心点。

格式：

```markdown
1. 明日の会議で使う資料を、今日中にコピーして（　）。
   1) あります
   2) おきます
   3) しまいます
   4) みます
```

### 排序题要求

1. 每课 2-3 题即可。
2. 句子不要太长。
3. 重点训练接续和句子骨架。

格式：

```markdown
9. 試験の前に＿＿ ＿＿ ＿＿ ＿＿。
   1) ほうがいい
   2) 復習した
   3) 文法を
   4) もう一度
```

### 阅读理解要求

每课放 1 段短文或 2-4 个句子理解题。

要求：

1. 不超过 250 日文字符。
2. 复现本课重点语法。
3. 题目问句意、原因、人物态度、下一步行动等 N3 常见方向。

## 答案解析写法

答案解析必须短而明确。

每题解析包含：

1. 正确答案
2. 为什么正确
3. 如果容易错，说明一个干扰项为什么不对

格式：

```markdown
1. 答案：2

`～ておく` 表示提前做好准备。这里是“今天之内先把明天会议要用的资料复印好”。`～てある` 更强调结果状态，不符合“自己提前做准备”的语气。
```

## 复习清单

每课最后放一个自检清单。

格式：

```markdown
## 复习清单

- [ ] 本课 A 级语法能说出意思。
- [ ] 每条语法知道前面接什么形。
- [ ] 易混点能用一句话区分。
- [ ] 选择题错题已标记。
- [ ] 阅读拆句能找出主干。
```

## 20 天学习节奏

推荐节奏：

| 天数 | 内容 |
| --- | --- |
| 第 1-5 天 | 快速补 TRY N4 语法，每天 2 课 |
| 第 6-15 天 | 主攻 TRY N3 语法，每天 1 课左右 |
| 第 16-17 天 | 复盘 N4/N3 易混语法 |
| 第 18 天 | 文法题、排序题集中训练 |
| 第 19 天 | 阅读中语法拆句训练 |
| 第 20 天 | 模拟题、错题、轻复习 |

如果时间不够：

1. 优先完成 N3 每课 A/B 级语法。
2. N4 只补自己不熟的基础语法。
3. 每课练习至少做选择题和阅读拆句，排序题可后补。

## 优先级判断规则

### A 必会

符合任一条件就标 A：

1. N3 文法题常见。
2. 阅读中经常决定句子意思。
3. 和多个易混表达有关。
4. 接续容易错。

### B 应会

符合任一条件就标 B：

1. 常见但题目不一定直接考。
2. 主要影响阅读理解。
3. 学会后能帮助理解更高一级语法。

### C 认识即可

符合任一条件就标 C：

1. 固定寒暄、固定敬语表达。
2. 出现频率相对低。
3. 对 N3 语法主线帮助不大。

## 输出质量检查

每个单元写完后检查：

1. 编号是否和总清单一致。
2. 每条语法是否都有意思、接续、例句、考试注意。
3. 是否有本课易混点。
4. 是否有阅读拆句训练。
5. 是否有练习题和答案解析。
6. 是否控制在可完成的长度。
7. 是否没有明显超纲或过细内容。
