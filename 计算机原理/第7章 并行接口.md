# 第7章 并行接口

## 7.1 简单并行接口

### 基本概念

**并行通信**：将一个字符的各位用若干根数据线**同时**传输。

实现方式：

| 方式 | 典型芯片 | 特点 |
|------|----------|------|
| **通用TTL芯片** | 74LS373, 74LS244, 74LS245 | 不可编程，结构简单，功能固定 |
| **可编程并行接口芯片** | 8255A, 8155 | 可通过编程灵活配置 |

### 三种基本并行接口类型

| 类型 | 核心部件 | 典型芯片 | 适用场景 |
|------|----------|----------|----------|
| **三态缓冲器接口** | 三态门（无锁存能力） | 74LS244 (单向8位) | 输入 |
| | | 74LS245 (双向8位收发器) | 双向 |
| **数据锁存器接口** | D触发器/锁存器 | 74LS273 (8位) | 输出 |
| **缓冲器+锁存器** | 锁存器+三态缓冲器 | 74LS373 | 输入/输出 |

#### 74LS244（三态缓冲器）

- 由8个三态门构成
- 1G、2G=0 → 导通；=1 → 高阻态

#### 74LS273（触发器锁存器）

- 由8个D触发器构成
- $\overline{MR}$：复位端（低有效）
- CP：上升沿锁存输入数据
- 常作为并行输出接口

#### 74LS373（锁存器+三态缓冲器）

- 8个D触发器 + 8个三态缓冲器
- G（锁存允许）：高电平=透明（D→Q），低电平=锁存
- $\overline{OE}$（输出允许）：低电平有效

### 应用示例

#### 开关状态读取（74LS244，端口80H）

```asm
MOV  BX, 2000H
MOV  CX, 100
LOP:
  IN   AL, 80H       ; 读入8个开关状态
  MOV  [BX], AL      ; 保存
  INC  BX
  CALL DELAY5M       ; 延时5分钟
  LOOP LOP
```

#### LED间隔发光（74LS373，端口40H）

```asm
MOV  CX, 7200        ; 10×60×60/5=7200次
MOV  AL, 55H         ; 01010101B，间隔亮灭
LOP:
  OUT  40H, AL
  CALL DELAY5S
  XOR  AL, 0FFH      ; 取反，变换状态
  LOOP LOP
```

## 7.2 可编程并行接口 8255A

### 7.2.1 内部结构和引脚

#### 内部结构

| 部件 | 功能 |
|------|------|
| **双向三态8位数据缓冲器** | 与系统数据总线连接 |
| **读/写控制逻辑** | A0、A1、RD、WR、CS确定端口地址和操作 |
| **PA口** | 有输入锁存器+输出锁存器/缓冲器，可用于双向传输 |
| **PB口** | 有输入缓冲器+输出锁存器/缓冲器，输出时数据受锁存 |
| **PC口** | 有输入缓冲器+输出锁存器/缓冲器；也可作为PA/PB的控制和状态信号 |

#### 引脚

| 引脚 | 功能 |
|------|------|
| PA7~PA0 | A端口数据线，与外设相连 |
| PB7~PB0 | B端口数据线，与外设相连 |
| PC7~PC0 | C端口数据线，与外设相连 |
| D7~D0 | 双向三态数据线，与系统数据总线相连 |
| A0, A1 | 端口选择 |
| $\overline{RD}$, $\overline{WR}$ | 读/写控制 |
| $\overline{CS}$ | 片选 |
| RESET | 复位 |

#### 8255A与8088/8086的连接

| CPU | 连接方式 |
|-----|----------|
| **8088** (8位数据总线) | A1A0→8255A的A1A0，4个相邻地址 |
| **8086** (16位数据总线) | D7~D0接低8位，A2A1→8255A的A1A0，A0始终=0，4个相邻偶地址 |

### 7.2.2 控制字

#### 方式选择控制字

将PA、PB、PC分为两组：
- **A组**：PA + PC高4位(PC7~PC4)
- **B组**：PB + PC低4位(PC3~PC0)

控制字格式（8位）：`1 D6D5 D4 D3 D2 D1 D0`

| 位 | 含义 |
|----|------|
| D7 | 特征位=1 |
| D6D5 | A组方式(00=方式0, 01=方式1, 1X=方式2) |
| D4 | PA方向(1=入, 0=出) |
| D3 | PC7~4方向 |
| D2 | B组方式(0=方式0, 1=方式1) |
| D1 | PB方向 |
| D0 | PC3~0方向 |

**例**：PA→方式0输出，PB→方式1输入，PC全输出 → `10000001B = 81H`

```asm
MOV  AL, 86H    ; 如86H
OUT  46H, AL    ; 46H为控制端口地址
```

#### 端口C置1/置0控制字

可单独设置PC的某一位为1或0，配合PA/PB工作。

控制字格式：`0 0 0 0 D3 D2 D1 D0`

| 位 | 含义 |
|----|------|
| D7 | 特征位=0 |
| D3D2D1 | 选择PC的位号(000=PC0 ~ 111=PC7) |
| D0 | 0=置0，1=置1 |

**例**：PC6置0 → `00001100B = 0CH`，PC3置1 → `00000111B = 07H`

### 7.2.3 工作方式

| 方式 | 名称 | 适用端口 | 特点 |
|------|------|----------|------|
| **方式0** | 基本输入输出 | PA, PB, PC | 无条件或查询传送，PC可作状态位 |
| **方式1** | 选通输入输出 | PA, PB | PC部分位作为联络控制信号 |
| **方式2** | 双向传输 | **仅PA** | CPU既可发也可收，PC3~PC7作控制信号 |

#### 方式0

- 三个端口都可独立设为输入或输出
- PC的高4位和低4位可独立使用
- 无条件传送：直接读写
- 查询传送：PC部分位作状态/联络信号

#### 方式1 — 选通输入输出的控制信号

##### 输入模式

| 信号 | 对应引脚(A口) | 对应引脚(B口) | 说明 |
|------|------------|------------|------|
| **STB** (选通) | PC4 | PC2 | 外设→8255A：数据已准备好 |
| **IBF** (输入缓冲满) | PC5 | PC1 | 8255A→外设：已接收数据 |
| **INTR** (中断请求) | PC3 | PC0 | 8255A→CPU：请求取数 |
| **INTE** (中断允许) | PC4(设) | PC2(设) | 通过置/复位控制 |

##### 输出模式

| 信号 | 对应引脚(A口) | 对应引脚(B口) | 说明 |
|------|------------|------------|------|
| **OBF** (输出缓冲满) | PC7 | PC1 | 8255A→外设：CPU已输出数据 |
| **ACK** (响应) | PC6 | PC2 | 外设→8255A：已接收数据 |
| **INTR** (中断请求) | PC3 | PC0 | 8255A→CPU：请求再次输出 |
| **INTE** (中断允许) | PC6(设) | PC2(设) | 通过置/复位控制 |

> 方式1下，PA和PB都可工作时，PC有6位被占用（作控制信号），剩余2位可作方式0输入/输出。

#### 方式2 — 双向传输（仅PA）

控制信号（PC3~PC7）：

| 信号 | PC位 | 方向 | 说明 |
|------|------|------|------|
| INTR | PC3 | →CPU | 中断请求（输入+输出共用一个INTRA） |
| STB | PC4 | ←外设 | 选通 |
| IBF | PC5 | →外设 | 输入缓冲满 |
| ACK | PC6 | ←外设 | 数据接收应答 |
| OBF | PC7 | →外设 | 输出缓冲满 |

- **INTE1**（输出中断允许）：通过PC6设置
- **INTE2**（输入中断允许）：通过PC4设置

### 7.2.4 8255A 编程及应用

#### 打印机接口示例

8255A端口分配：
- **PA**：方式0，输出（传送打印字符）
- **PC3**：输入（BUSY信号）
- **PC6**：输出（STB信号）
- 方式控制字：`10000001B = 81H`

#### 打印流程

1. 查询BUSY信号（PC3），忙则等待
2. 将打印字符送入PA口
3. STB（PC6）输出负脉冲：先置0再置1

```asm
PRINT:
  MOV  DX, 0C006H
  MOV  AL, 81H        ; 方式控制字
  OUT  DX, AL
  MOV  AL, 0DH        ; PC6置1 (STB初始化高电平)
  OUT  DX, AL
LP:
  MOV  DX, 0C004H
  IN   AL, DX         ; 检测BUSY
  AND  AL, 08H        ; PC3
  JNZ  LP             ; 忙则等待
  MOV  AL, CL         ; 取打印字符
  MOV  DX, 0C000H
  OUT  DX, AL         ; 送PA口
  MOV  DX, 0C006H
  MOV  AL, 0CH        ; PC6置0
  OUT  DX, AL
  MOV  AL, 0DH        ; PC6置1 (形成负脉冲)
  OUT  DX, AL
```

## 7.3 键盘接口

### 键盘类型

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| **独立连接键盘** | 连线方便、编程简单；键多时引线多、占用I/O口多 | 按键少的场合 |
| **矩阵式键盘** | m×n键仅需m+n条引线 | 按键较多的场合 |

### 矩阵键盘编程三要素

| 问题 | 解决方法 |
|------|----------|
| **按键识别** | 行扫描法：依次在各行输出0，读列线确定按键位置 |
| **消除抖动** | 硬件消抖（R-S触发器）或软件消抖（延时10~20ms后再次确认） |
| **生成键码** | 坐标组合→特征码→查表→键码 |

### 行扫描法识别步骤

#### 第一步：判断是否有键按下

```asm
WAIT:
  MOV  AL, 00H
  MOV  DX, OUTPORT
  OUT  DX, AL          ; 所有行输出0
  MOV  DX, INPORT
  IN   AL, DX          ; 读列值
  CMP  AL, 0FFH
  JZ   WAIT            ; 全1=无键，继续等待
DONE:
  CALL DELAY           ; 延时20ms消抖
```

#### 第二步：判断哪个键被按下

逐行输出0，读列线，确定具体行列位置。

```asm
  MOV  BL, 0           ; 键号初值
  MOV  CL, 0FEH        ; 扫描模式（第一行为0）
  MOV  DL, 8           ; 行数
FROW:
  MOV  AL, CL
  OUT  ROWPORT, AL     ; 输出行扫描值
  ROL  AL, 1           ; 为下一行准备
  MOV  CL, AL
  IN   AL, COLPORT     ; 读列
  CMP  AL, 0FFH
  JNZ  FCOL            ; 有键，找列位置
  MOV  AL, BL
  ADD  AL, 08H         ; 键号+8
  MOV  BL, AL
  DEC  DL
  JNZ  FROW
  JMP  DONE
FCOL:
  RCR  AL, 1           ; 逐列检查
  JNC  PROCE           ; 该列为0，找到
  INC  BL              ; 键号+1
  JMP  FCOL
PROCE:
  ...                  ; 键命令处理
```

## 7.4 LED显示器接口

### 7.4.1 LED数码管工作原理

| 类型 | 公共端 |
|------|--------|
| **共阳极** | 所有阳极并接，低电平点亮 |
| **共阴极** | 所有阴极并接，高电平点亮 |

### 显示译码

要显示一个数字，需将4位二进制数转换为7位段选码（a~g）。

| 方法 | 说明 |
|------|------|
| **专用芯片(7447)** | 4位输入→7位输出，只对0~9有效（不能译码>9） |
| **软件译码** | 查表法(XLAT)转换，灵活可扩展 |

#### 软件译码示例

```asm
DISP:
  MOV  BX, OFFSET DATA
  MOV  AL, [BX]
  MOV  BX, OFFSET LEDADD   ; 段码表首址
  XLAT                      ; 查表得段码
  OUT  DX, AL
LEDADD:
  DB  40H   ; 0
  DB  79H   ; 1
  DB  24H   ; 2
  ...
  DB  0EH   ; F
```

### 7.4.2 静态显示 vs 动态显示

| 特性 | 静态显示 | 动态显示 |
|------|----------|----------|
| **原理** | 每位独立输出口恒定供电 | 逐位轮流点亮，利用视觉暂留 |
| **接口** | 每个数码管需一个8位口 | 所有数码管共用一个段口+一个位口 |
| **优点** | 稳定、亮度大、CPU效率高 | 电路简单、成本低 |
| **缺点** | 位数多时接口多、成本高 | 有闪烁、需刷新、编程复杂 |

#### 动态显示实例（8位LED）

```asm
DISINT:
  MOV  DX, 00C6H
  MOV  AL, 80H       ; 8255A方式字：A、B口方式0输出
  OUT  DX, AL
DIS:
  MOV  BH, 80H       ; 位选初值（第一位）
  MOV  BL, 8         ; 8位
  MOV  SI, OFFSET DISBUF
DISLOP:
  MOV  AL, BH
  MOV  DX, 00C0H
  OUT  DX, AL        ; A口送位选
  MOV  DX, 00C2H
  MOV  AL, [SI]
  OUT  DX, AL        ; B口送段码
  SHR  BH, 1         ; 位选右移
  INC  SI
  CALL DL1MS         ; 延时1ms
  DEC  BL
  JNZ  DISLOP
  JMP  DIS           ; 循环刷新

DISBUF:
  DB  3FH, 06H, 5BH, 4FH, 66H, 6DH, 7DH, 07H  ; 01234567
```

## 7.5 微型打印机接口

### 接口信号

| 信号 | 方向 | 功能 |
|------|------|------|
| **STB** (STroBe) | CPU→打印机 | 数据选通输入，低电平后打印机接收数据并启动打印 |
| **BUSY** | 打印机→CPU | 高电平=忙，低电平=空闲 |
| **ACK** (ACKnowledge) | 打印机→CPU | 应答信号，打印完一字符后发一个负脉冲 |

### 打印过程

1. CPU查询BUSY信号
   - BUSY=1（忙）→ 等待
   - BUSY=0（空闲）→ 继续
2. 输出字符到数据口
3. STB输出负脉冲（先0后1），触发打印
4. 打印机接收数据后，BUSY变高，开始打印
5. 打印完成后BUSY变低，ACK发负脉冲
