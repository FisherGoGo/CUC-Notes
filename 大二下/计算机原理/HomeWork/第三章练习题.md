# 第三章练习题

## 1. 条件转移与标志位

**题目：** 已知程序为：

```asm
ADD AL, BL
JNO L1
JNC L2
```

若 `AL` 和 `BL` 的内容有以下 4 组给定值，使程序转向 `L2` 执行的是（ ）。

**选项：**

- A. `(AL)=67H, (BL)=78H`
- B. `(AL)=0B6H, (BL)=87H`
- C. `(AL)=18H, (BL)=0F9H`
- D. `(AL)=81H, (BL)=0A5H`

**答案：A**

**解析：** 程序要转向 `L2`，必须满足：

```text
JNO L1 不跳转 -> OF=1
JNC L2 跳转   -> CF=0
```

选项 A：

```text
67H + 78H = DFH
```

无符号角度：结果小于 `100H`，没有进位，所以 `CF=0`。有符号角度：`67H` 和 `78H` 都是正数，相加后得到 `DFH`，最高位为 1，变成负数，发生溢出，所以 `OF=1`。因此先不执行 `JNO L1`，再执行 `JNC L2`，转向 `L2`。

> 易错点：`CF` 看无符号进位，`OF` 看有符号溢出。两个正数相加得到负数时，`OF=1`。

## 2. JMP BX 指令

**题目：** 若 `(BX)=1224H`，`(IP)=3478H`，执行 `JMP BX` 指令后，寄存器变化正确的是（ ）。

**选项：**

- A. `(BX)=3478H, (IP)=3478H`
- B. `(BX)=1224H, (IP)=1224H`
- C. `(BX)=1224H, (IP)=3478H`
- D. `(BX)=3478H, (IP)=1224H`

**答案：B**

**解析：** `JMP BX` 是寄存器间接转移，表示把 `BX` 中的内容送入 `IP`，作为新的指令偏移地址。`BX` 本身不变。

```text
执行前：BX=1224H, IP=3478H
执行后：BX=1224H, IP=1224H
```

> 易错点：`JMP BX` 改变的是 `IP`，不是把 `IP` 送入 `BX`。

## 3. 逻辑运算指令序列

**题目：** 执行下列指令后：

```asm
MOV AL, BL
NOT AL
XOR AL, BL
OR  BL, AL
```

寄存器 `(AL)=（ ）`，`(BL)=（ ）`。

**选项：**

- A. `0FFH, 0FFH`
- B. `11H, 0FFH`
- C. `0FFH, 11H`
- D. `00H, 00H`

**答案：A**

**解析：** 设原来 `BL=x`。

```text
MOV AL, BL  -> AL=x
NOT AL      -> AL=~x
XOR AL, BL  -> AL=(~x) XOR x = FFH
OR BL, AL   -> BL=x OR FFH = FFH
```

所以最后 `AL=0FFH`，`BL=0FFH`。

> 易错点：任意二进制数和它按位取反后的数异或，结果全为 1。

## 4. PUSH 与栈顶物理地址

**题目：** 设 `(SS)=238BH`，`(SP)=0100H`，执行 `PUSH BX` 和 `PUSHF` 两条指令后，堆栈顶部的物理地址是（ ）。

**选项：**

- A. `239ACH`
- B. `239B4H`
- C. `239AEH`
- D. `239B2H`

**答案：A**

**解析：** 8086 中栈按字操作，执行一次 `PUSH`，`SP` 先减 2，再写入一个字。连续执行两次 `PUSH`：

```text
初始 SP = 0100H
PUSH BX 后 SP = 00FEH
PUSHF 后 SP = 00FCH
```

栈顶物理地址为：

$$
SS \times 10H + SP = 238BH \times 10H + 00FCH = 238B0H + 00FCH = 239ACH
$$

> 易错点：`PUSH` 是先让 `SP-2`，再存数据；堆栈顶部地址由 `SS:SP` 决定。

## 5. INC 指令不影响的标志

**题目：** `INC` 指令不影响（ ）标志。

**选项：**

- A. `SF`
- B. `ZF`
- C. `OF`
- D. `CF`

**答案：D**

**解析：** `INC` 是加 1 指令，会影响 `SF`、`ZF`、`OF`、`AF`、`PF` 等标志，但不影响进位标志 `CF`。

> 易错点：`INC` 和 `ADD 1` 很像，但 `INC` 不影响 `CF`。

## 6. 将 CF 置 1 的指令

**题目：** 能够将 `CF` 置 1 的指令是（ ）。

**选项：**

- A. `CLC`
- B. `STD`
- C. `STC`
- D. `CMC`

**答案：C**

**解析：** `STC` 表示 Set Carry Flag，用于将进位标志 `CF` 置 1。

**干扰项分析：**

- `CLC`：清 `CF`，使 `CF=0`。
- `STD`：置方向标志 `DF=1`。
- `CMC`：对 `CF` 取反。

> 易错点：`STC` 置进位，`CLC` 清进位，`CMC` 进位取反。

## 7. 取变量偏移地址

**题目：** 将变量 `BUF` 的偏移地址送入 `DI` 的正确指令是（ ）。

**选项：**

- A. `LEA DI, BUF`
- B. `MOV [DI], BUF`
- C. `MOV OFFSET BUF, DI`
- D. `MOV DI, BUF`

**答案：A**

**解析：** `LEA` 指令用于取有效地址。`LEA DI, BUF` 的含义是把变量 `BUF` 的偏移地址送入 `DI`。

```asm
LEA DI, BUF
```

等价理解为：

```text
DI <- OFFSET BUF
```

> 易错点：`MOV DI, BUF` 通常表示把 `BUF` 所在内存单元的内容送入 `DI`，不是送偏移地址。

## 8. 会影响标志位的指令

**题目：** 下列指令执行后，能够影响标志位的指令是（ ）。

**选项：**

- A. `MOV AX, 2400H`
- B. `ADD AL, AH`
- C. `JNZ NEXT`
- D. `LOOPNZ NEXT`

**答案：B**

**解析：** 算术运算指令通常会影响标志位。`ADD AL, AH` 会根据运算结果影响 `CF`、`OF`、`ZF`、`SF`、`AF`、`PF` 等标志。

**干扰项分析：**

- `MOV` 传送数据，不影响标志位。
- `JNZ` 根据 `ZF` 判断是否转移，但本身不改变标志位。
- `LOOPNZ` 根据 `CX` 和 `ZF` 判断循环，但不改变标志位。

> 易错点：条件转移指令“使用”标志位，不等于“修改”标志位。

## 9. 物理地址对应的段地址和偏移地址

**题目：** 已知某操作数的物理地址是 `4117AH`，则它的段地址和偏移地址可能是（ ）。

**选项：**

- A. `3E00H; 317AH`
- B. `4025H; 0F0AH`
- C. `4000H; 007AH`
- D. `4108H; 002AH`

**答案：A**

**解析：** 8086 物理地址计算公式：

$$
物理地址 = 段地址 \times 10H + 偏移地址
$$

验证 A：

$$
3E00H \times 10H + 317AH = 3E000H + 317AH = 4117AH
$$

因此 A 正确。

> 易错点：同一个物理地址可以由多组“段地址:偏移地址”表示，但必须满足 `段地址 × 10H + 偏移地址 = 物理地址`。

## 10. CALL 指令入栈与小端存储

**题目：** 已知 `(SS)=2000H`，`(SP)=2000H`，`(BX)=283FH`，指令 `CALL WORD PTR [BX]` 的机器代码是 `1234H`，该指令的起始地址为 `1000H`，试问执行该指令后，内存单元 `21FFFH` 的内容是（ ）。

**选项：**

- A. `3FH`
- B. `28H`
- C. `02H`
- D. `10H`

**答案：D**

**解析：** `CALL WORD PTR [BX]` 是近调用，会把返回地址压入栈。该指令机器代码为 2 字节，起始地址是 `1000H`，所以返回地址为：

```text
1000H + 2 = 1002H
```

执行 `CALL` 入栈时：

```text
SP = 2000H - 2 = 1FFEH
```

8086 按小端方式存储字数据，低字节放低地址，高字节放高地址：

```text
2000H:1FFEH -> 02H
2000H:1FFFH -> 10H
```

物理地址 `21FFFH` 对应：

$$
2000H \times 10H + 1FFFH = 21FFFH
$$

所以该单元内容为 `10H`。

> 易错点：近调用压入的是返回偏移地址；8086 字数据按小端存储，低地址放低字节。

## 11. ADD AH, AL 后的标志位

**题目：** 设 `(AX)=0B53FH`，在执行指令 `ADD AH, AL` 后，相应的状态为（ ）。

**选项：**

- A. `CF=0, OF=0, ZF=0`
- B. `CF=1, OF=1, ZF=1`
- C. `CF=0, OF=1, ZF=1`
- D. `CF=1, OF=0, ZF=0`

**答案：A**

**解析：** `(AX)=0B53FH`，所以：

```text
AH = B5H
AL = 3FH
```

执行：

```asm
ADD AH, AL
```

计算：

```text
B5H + 3FH = F4H
```

结果没有超过 `FFH`，所以 `CF=0`；结果不是 0，所以 `ZF=0`。从有符号角度看，`B5H` 是负数，`3FH` 是正数，异号相加不会溢出，所以 `OF=0`。

> 易错点：`OF` 看有符号溢出，异号相加一定不会产生有符号溢出。

## 12. PUSH AX 后字节存放地址

**题目：** 假定 `(SP)=0200H`，`(AX)=2A57H`，执行指令 `PUSH AX` 后，存放数据 `2AH` 和 `57H` 的偏移地址是（ ）。

**选项：**

- A. `01FCH, 01FEH`
- B. `01FFH, 01FEH`
- C. `01FEH, 01FCH`
- D. `01FEH, 01FFH`

**答案：B**

**解析：** `PUSH AX` 时，`SP` 先减 2：

```text
SP = 0200H - 2 = 01FEH
```

`AX=2A57H`，其中高字节是 `2AH`，低字节是 `57H`。8086 小端存储：

```text
01FEH -> 57H
01FFH -> 2AH
```

所以 `2AH` 的偏移地址是 `01FFH`，`57H` 的偏移地址是 `01FEH`。

> 易错点：PUSH 字数据后，低字节在低地址，高字节在高地址。

## 13. PUSH AX 后高字节地址

**题目：** 假定 `(SP)=0100H`，`(AX)=2107H`，执行指令 `PUSH AX` 后，存放数据 `21H` 的偏移地址是（ ）。

**选项：**

- A. `00FEH`
- B. `0110H`
- C. `00FFH`
- D. `0101H`

**答案：C**

**解析：** 执行 `PUSH AX` 后：

```text
SP = 0100H - 2 = 00FEH
```

`AX=2107H`，低字节 `07H` 放在低地址，高字节 `21H` 放在高地址：

```text
00FEH -> 07H
00FFH -> 21H
```

所以 `21H` 的偏移地址为 `00FFH`。

> 易错点：栈向低地址增长，但字内部仍是小端存储。

## 14. 求相反数指令

**题目：** 若 `(AX)=-15H`，要得到 `(AX)=15H` 应执行的指令是（ ）。

**选项：**

- A. `NEG AX`
- B. `NOT AX`
- C. `DEC AX`
- D. `INC AX`

**答案：A**

**解析：** `NEG` 指令用于求操作数的补码相反数，即执行：

```text
目标操作数 <- 0 - 目标操作数
```

因此 `NEG AX` 可以把 `-15H` 变为 `15H`。

> 易错点：`NOT` 是按位取反，不等于求相反数；补码求相反数应使用 `NEG`。

## 15. RCR 循环右移通过进位

**题目：** 设 `AL` 中的值为 `82H`，`CF=1`，执行 `RCR AL,1` 指令后，`AL` 中的值和 `CF` 分别为（ ）。

**选项：**

- A. `0C2H, 0`
- B. `0C1H, 0`
- C. `41H, 1`
- D. `41H, 0`

**答案：B**

**解析：** `RCR AL,1` 是带进位循环右移 1 位，参与循环的是 `CF` 和 `AL` 的 8 位。

```text
执行前：CF=1, AL=82H=1000 0010B
右移后：原 CF 进入最高位，原 AL bit0 进入 CF
```

`AL` 的最低位原来是 0，所以新 `CF=0`；原 `CF=1` 进入最高位，其余位右移：

```text
AL = 1100 0001B = C1H
```

所以结果为 `AL=0C1H, CF=0`。

> 易错点：`RCR` 不是普通右移，`CF` 也参与循环；原最低位进入新的 `CF`。

## 16. 不能清零 AX 的指令

**题目：** 将累加器 `AX` 中的内容清零的错误指令是（ ）。

**选项：**

- A. `SUB AX, AX`
- B. `XOR AX, AX`
- C. `CMP AX, AX`
- D. `AND AX, 0`

**答案：C**

**解析：** `CMP AX, AX` 只做比较，本质上执行减法以影响标志位，但不保存结果，因此不会把 `AX` 改成 0。

其他选项：

```asm
SUB AX, AX  ; AX=0
XOR AX, AX  ; AX=0
AND AX, 0   ; AX=0
```

> 易错点：`CMP` 只影响标志位，不改变操作数内容。

## 17. 寻址方式与物理地址

**题目：** 已知 8086 寄存器的值如下：

```text
DS=2000H, SS=1500H, ES=3000H
SI=00F0H, BX=1000H, BP=0020H
```

回答以下问题：

1. `MOV AX, [BP+20H]` 的源操作数寻址方式和物理地址。
2. `MOV AX, [SI+50H]` 的源操作数寻址方式和物理地址。
3. `MOV AX, 8[BX][SI]` 的源操作数寻址方式和物理地址。

**答案：**

| 指令 | 寻址方式 | 默认段 | 有效地址 | 物理地址 |
|---|---|---|---|---|
| `MOV AX, [BP+20H]` | 基址寻址 | `SS` | `0020H+20H=0040H` | `15040H` |
| `MOV AX, [SI+50H]` | 变址寻址 | `DS` | `00F0H+50H=0140H` | `20140H` |
| `MOV AX, 8[BX][SI]` | 基址变址寻址 / 相对基址变址寻址 | `DS` | `1000H+00F0H+8H=10F8H` | `210F8H` |

**解析：** 8086 中，只要有效地址中使用 `BP` 作基址，默认段寄存器就是 `SS`；使用 `BX`、`SI`、`DI` 时默认段寄存器通常是 `DS`。

物理地址计算公式：

$$
物理地址 = 段地址 \times 10H + 有效地址
$$

> 易错点：`[BP+位移]` 默认用 `SS`，不是 `DS`。这是本题最容易错的地方。

## 18. BCD 调整指令 DAA

**题目：** 设 `(AX)=0219H`，试分析执行下列程序段后，`AX`、`CF` 和 `AF` 的内容分别是 ①、②、③。

```asm
MOV CH, AH
ADD AL, AH
DAA
XCHG AL, AH
ADC AL, 25H
DAA
XCHG AH, AL
HLT
```

**答案：** ① `2721H` ② `0` ③ `0`

**解析：** 这段程序使用 `DAA` 对压缩 BCD 加法结果进行十进制调整。初值 `AX=0219H`，即 `AH=02H`、`AL=19H`。

关键过程：

```text
ADD AL, AH  -> 19H + 02H = 1BH
DAA         -> 调整为 21H
XCHG AL,AH  -> AH=21H, AL=02H
ADC AL,25H  -> 02H + 25H + CF = 27H
DAA         -> 27H 已是合法 BCD，不再调整
XCHG AH,AL  -> AX=2721H
```

最终 `AX=2721H`，且 `CF=0`、`AF=0`。

> 易错点：`DAA` 用于调整 `AL` 中的 BCD 加法结果，不是普通二进制加法都要用。

## 19. 移位、减 1 与无符号乘法程序

**题目：** 执行下列程序段后，寄存器 `AH`、`AL`、`DX` 和 `CF` 的值分别是 ①、②、③、④。

```asm
MOV AX,2255H
MOV CL,2
ROL AX,CL
DEC AX
MOV CX,16
MUL CX
HLT
```

**平台答案：** ① `95H` ② `30H` ③ `0008H` ④ `0`

**按 8086 标准语义推导：**

```text
MOV AX,2255H       -> AX=2255H
MOV CL,2           -> CL=2
ROL AX,CL          -> AX=8954H
DEC AX             -> AX=8953H
MOV CX,16          -> CX=0010H
MUL CX             -> DX:AX = 8953H * 0010H = 0008H:9530H
```

所以 `AH=95H`，`AL=30H`，`DX=0008H`。

关于 `CF`：按 8086 的 `MUL` 指令规则，若乘积高半部分 `DX` 非 0，则 `CF=OF=1`；本题 `DX=0008H` 非 0，因此标准指令语义下 `CF` 应为 `1`。但课程平台截图给出的正确答案为 `0`，考试或平台提交时应以平台答案为准。

> 易错点：`ROL AX,CL` 是 16 位循环左移；`MUL CX` 的结果放在 `DX:AX` 中。此题平台的 `CF` 答案和标准 8086 规则存在冲突。

## 20. 指定段超越与寻址方式

**题目：** 已知 8086 寄存器的值如下：

```text
DS=2000H, SS=1500H, ES=3000H
SI=00F0H, BX=1000H, BP=0020H
```

回答以下问题：

1. `MOV AX, DS:[0100H]` 的源操作数寻址方式和物理地址。
2. `MOV AX, ES:[SI]` 的源操作数寻址方式和物理地址。
3. `MOV AX, [BP][SI]` 的源操作数寻址方式和物理地址。

**答案：**

| 指令 | 寻址方式 | 段寄存器 | 有效地址 | 物理地址 |
|---|---|---|---|---|
| `MOV AX, DS:[0100H]` | 直接寻址 | `DS` | `0100H` | `20100H` |
| `MOV AX, ES:[SI]` | 寄存器间接寻址 | `ES` | `00F0H` | `300F0H` |
| `MOV AX, [BP][SI]` | 基址变址寻址 / 相对基址变址寻址 | `SS` | `0020H+00F0H=0110H` | `15110H` |

**解析：** `DS:[0100H]` 直接给出偏移地址；`ES:[SI]` 使用段超越前缀，强制用 `ES` 作为段地址；`[BP][SI]` 中含有 `BP`，默认段为 `SS`。

> 易错点：带 `ES:`、`DS:` 这类段超越前缀时，按显式写出的段寄存器计算物理地址。

## 21. PUSHF、POPF 与 CF

**题目：** 分析执行下列程序段后的结果：

```asm
MOV SP, 5000H
PUSHF
POP AX
OR AL, 01H
PUSH AX
POPF
```

寄存器 `(SP)=①`；标志位 `CF=②`。

**答案：** ① `5000H` ② `1`

**解析：** `PUSHF` 把标志寄存器压栈，`POP AX` 又把它弹到 `AX`，所以 `SP` 先减 2 再加 2，恢复为 `5000H`。随后：

```asm
OR AL, 01H
```

把 `AL` 的最低位置 1，而标志寄存器最低位就是 `CF`。之后 `PUSH AX` 和 `POPF` 把修改后的标志值写回标志寄存器，因此 `CF=1`。最终 `PUSH AX` 使 `SP-2`，`POPF` 又使 `SP+2`，所以 `SP=5000H`。

> 易错点：`PUSHF/POPF` 可以通过栈间接读写标志寄存器；`CF` 是标志寄存器的最低位。

## 22. SHR 与 ADD 程序跟踪

**题目：** 分析下面的程序段，程序运行后 `AL`、`BL` 中的内容分别是 ①、②，`CF` 的值是 ③。

```asm
MOV AL,200
SHR AL,1
MOV BL,AL
MOV CL,2
SHR AL,CL
ADD AL,BL
```

**答案：** ① `7DH` ② `64H` ③ `0`

**解析：**

```text
MOV AL,200     -> AL=200=0C8H=11001000B
SHR AL,1       -> AL=01100100B=64H, CF=0
MOV BL,AL      -> BL=64H
MOV CL,2       -> CL=2
SHR AL,CL      -> AL=00011001B=19H, CF=0
ADD AL,BL      -> AL=19H+64H=7DH, CF=0
```

因此最终 `AL=7DH`，`BL=64H`，`CF=0`。

> 易错点：`SHR` 右移时，移出的最低位进入 `CF`；最高位补 0。

## 23. 源操作数寻址方式

**题目：** 指出下列各命令中源操作数的寻址方式。

```asm
(1) MOV AL, BL
(2) MOV AX, BUFA
(3) MOV AL, 22H
(4) MOV AX, ES:[SI]
(5) MOV BX, [BX+SI+6]
```

**答案：**

| 指令 | 源操作数 | 寻址方式 |
|---|---|---|
| `MOV AL, BL` | `BL` | 寄存器寻址 |
| `MOV AX, BUFA` | `BUFA` | 直接寻址 |
| `MOV AL, 22H` | `22H` | 立即寻址 |
| `MOV AX, ES:[SI]` | `ES:[SI]` | 寄存器间接寻址 |
| `MOV BX, [BX+SI+6]` | `[BX+SI+6]` | 基址变址寻址 / 相对基址变址寻址 |

**解析：** 判断源操作数寻址方式时，只看逗号右边的操作数。寄存器名是寄存器寻址，常数是立即寻址，变量名直接作为地址是直接寻址，方括号中只有寄存器是寄存器间接寻址，`基址+变址+位移` 属于基址变址类寻址。

> 易错点：题目问的是“源操作数”，也就是逗号右边；不要把目的操作数的寻址方式也算进去。
