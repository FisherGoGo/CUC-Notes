# 第4章 汇编语言程序设计

## 4.1 汇编语言概述

### 三种程序语言

| 语言 | 特点 | 示例 |
|------|------|------|
| **机器语言** | 二进制代码，计算机直接识别 | `1000 1001 1101 1000` |
| **汇编语言** | 助记符表示操作码，面向机器 | `MOV AX, BX` |
| **高级语言** | 接近自然语言，独立于机器 | PASCAL, C语言 |

### 汇编过程

```
.ASM源程序 → [汇编程序MASM] → .OBJ目标文件 → [连接程序LINK] → .EXE可执行文件
```

1. 用编辑程序（EDIT）建立 `.ASM` 源程序文件
2. 用汇编程序（MASM）汇编成 `.OBJ` 文件
3. 用连接程序（LINK）转换成 `.EXE` 文件
4. 在DOS下直接键入文件名执行

## 4.2 汇编语言的语句格式

### 三种基本语句

| 语句类型 | 说明 |
|----------|------|
| **指令语句** | 产生目标代码，对应CPU机器指令 |
| **伪指令语句** | 不产生目标代码，指示汇编程序如何汇编 |
| **宏指令语句** | 以宏名定义的一段指令序列的扩展 |

### 指令语句格式

```
[标号:] 助记符 [操作数] [;注释]
```

### 伪指令语句格式

```
[名称] 定义符 [参数][,…参数] [;注释]
```

### 标识符命名规则

- 第一个字符必须是：字母、`?`、`@` 或下划线
- 后续字符：字母、`?`、`@`、下划线或数字
- 不能是保留字（如MOV、STACK）

### 操作数的五种类型

| 类型 | 说明 |
|------|------|
| **常量** | 数值常量（以B/D/H结尾，十六进制字母开头需加前导0如`0F5H`）；字符常量（用单引号，如`'A'`） |
| **变量** | 可变值，有三种属性：段属性、偏移量属性、类型属性（BYTE/WORD/DWORD等） |
| **标号** | 有三种属性：段属性、偏移量属性、类型属性（NEAR/FAR） |
| **寄存器** | AX、BX、SI等 |
| **表达式** | 由运算符（算术、逻辑、关系）和操作符（分析、合成）组成 |

### 表达式运算符示例

| 示例 | 结果 |
|------|------|
| `MOV AL, 10 MOD 4` | (AL)=2 |
| `MOV AX, 789AH XOR 000FH` | (AX)=7895H |
| `MOV AL, 5 NE 2` | 关系成立，(AL)=0FFH |
| `MOV AL, 5 LT 2` | 关系不成立，(AL)=00H |
| `MOV SI, OFFSET BUF` | 等价于 `LEA SI, BUF` |
| `MOV AX, SEG BUF` | 取BUF所在段的段基址 |

## 4.3 汇编语言源程序格式

### 分段式结构

一个汇编源程序由若干段组成，一般有四种类型：**数据段、代码段、附加段、堆栈段**。

- 每个段：`段名 SEGMENT … 段名 ENDS`
- 整个源程序：以 `END` 结束
- 每个段均有若干行指令

### 完整程序模板

```asm
DSEG SEGMENT          ; 数据段
  DATA1 DB 15H
  SUM   DB 00H
DSEG ENDS

CSEG SEGMENT          ; 代码段
  ASSUME CS:CSEG, DS:DSEG
START:
  MOV AX, DSEG
  MOV DS, AX          ; 装入DS初值（段寄存器不能直接赋立即数）
  MOV AL, DATA1
  ADD AL, 12H
  MOV SUM, AL
  HLT
CSEG ENDS
END START              ; 源程序结束
```

> 数据段、扩展段、堆栈段寄存器的初值需在代码段中写入；CS由系统自动装入。

### `$` 和 ORG

- **`$`**：当前汇编地址计数器的值（当前地址）
- **`ORG 数值表达式`**：设置当前汇编地址计数器

```asm
ORG 10H
BUF  DB '1234'    ; BUF从偏移地址10H开始存放
ORG  $+5           ; 跳过5字节
NUM  DW 50         ; NUM在偏移地址19H
```

## 4.4 伪指令

### 符号定义伪指令

| 伪指令 | 格式 | 特点 |
|--------|------|------|
| **EQU** | `符号名 EQU 表达式` | 不能对同一符号重复定义 |
| **=** | `符号名 = 表达式` | **可重复定义**（与EQU唯一区别） |

### 数据定义伪指令

| 伪指令 | 类型 | 字节数 |
|--------|------|--------|
| **DB** | 字节(BYTE) | 1 |
| **DW** | 字(WORD) | 2 |
| **DD** | 双字(DWORD) | 4 |
| **DQ** | 四字(QWORD) | 8 |
| **DT** | 十字节(TBYTE) | 10 |

表达式可以包括：

| 形式 | 说明 | 示例 |
|------|------|------|
| 常量 | 数值或常量表达式 | `DB 08H` |
| ASCII串 | 字符或字符串 | `DB 'HELLO'` |
| 问号 `?` | 初值未定，预留空间 | `SUM DW ?` |
| DUP子句 | `N DUP (表达式)`，可嵌套 | `N DB 3 DUP (01H, 02H)` |
| 地址表达式 | 用变量名表示地址 | `SA_BUF DW BUF1` |

> **注意**：`BUF DB 'AB'` 存储 `42H 41H`；`BUF DW 'AB'` 存储 `42H 41H`（存储顺序相同）

### 段定义伪指令

```asm
段名 SEGMENT [定位方式] [组合方式] ['类别']
  ...
段名 ENDS
```

**ASSUME** 伪指令：建立段与段寄存器的对应关系（只指定对应，不装入段基址）。

```asm
ASSUME 段寄存器名:段名 [,段寄存器名:段名]
```

### 过程定义伪指令

```asm
过程名 PROC [NEAR/FAR]    ; 默认NEAR
  ...
过程名 ENDP
```

### 源程序结束伪指令

```asm
END [标号/过程名]    ; 标号=程序起始地址
```

多模块时，只有**主模块**需指定标号。

## 4.5 程序设计基本结构

程序设计的6个基本步骤：
1. 分析问题，建立数学模型
2. 确定算法
3. 绘制流程图
4. 分配存储器及寄存器
5. 编制程序
6. 调试程序

程序三种基本结构：**顺序、分支、循环**。

### 4.5.1 顺序结构

完全按照指令存放顺序逐条执行，是最基础的复杂程序组成单元。

**例**：将一字节无符号数拆成两个十六进制位。

```asm
MOV  AL, DATA      ; 取数
MOV  AH, AL        ; 保存副本
AND  AL, 0FH       ; 屏蔽高4位 → 低位十六进制
MOV  HEX, AL
AND  AH, 0F0H      ; 屏蔽低4位
MOV  CL, 4
SHR  AH, CL        ; 右移4位 → 高位十六进制
MOV  HEX+1, AH
```

### 4.5.2 分支结构

| 类型 | 说明 |
|------|------|
| **不完全分支** | 条件不满足时跳过部分语句 |
| **完全分支（二路分支）** | 分支1执行后需加**无条件转移指令**跳过另一分支 |

**注意点**：
1. 选择合适的转移指令
2. 每个分支均应能执行到程序结束
3. 公共部分提到分支前或分支后

**例（不全分支）**：若 X>Y 则结果=X+Z，否则结果=X
```asm
MOV AL, X
CMP AL, Y
JBE NEXT      ; X≤Y则跳过加法
ADD AL, Z
NEXT: MOV DL, AL
```

### 4.5.3 循环结构

两个基本结构：**先处理后判断(DoWhile)** 和 **先判断后处理(WhileDo)**。

#### 循环结构五部分

| 阶段 | 功能 |
|------|------|
| 初始化 | 地址指针赋初值、设置循环次数(CX)、累加器清0 |
| 循环体 | 重复执行的操作 |
| 修改部分 | 修改计数器、地址指针、恢复参数 |
| 控制部分 | 判断循环是否结束（LOOP/条件跳转） |
| 结束处理 | 对结果进行处理 |

**例**：统计一个字中含1的个数（移位+判CF法）
```asm
XOR BL, BL       ; 计数器清0
MOV AX, DA1
LP:
  AND AX, AX     ; 判AX是否为0
  JZ  DONE
  SHL AX, 1      ; 左移一位→CF
  JNC LP         ; CF=0跳过计数
  INC BL
  JMP LP
DONE: MOV DA2, BL
```

**例**：统计能被3整除的数据个数（除法+判余数）
```asm
LEA SI, DATA
MOV CX, 10       ; 10个数据
MOV DX, 0        ; 计数器
MOV BL, 3
LP:
  MOV AL, [SI]
  MOV AH, 0
  DIV BL
  AND AH, AH
  JNZ NEXT       ; 余数≠0则跳过
  INC DX
NEXT:
  INC SI
  LOOP LP
MOV COUNT, DX
```

## 4.6 子程序结构

### 基本概念

- **CALL** 调用子程序，**RET** 返回主程序
- 子程序可调用其他子程序（嵌套）
- 子程序使主程序结构清晰，节省内存

### 参数传递方法

| 方法 | 适用场景 |
|------|----------|
| **寄存器传递法** | 参数较少时，通过寄存器传递 |
| **存储器传递法** | 参数较多时，在内存开辟区域传递 |

### 保护和恢复现场

"现场"指调用前CPU状态：标志寄存器、通用寄存器、段寄存器、IP等。

- 进入子程序时**PUSH**保存
- 返回前**POP**恢复（逆序弹出）

```asm
SUBP PROC
  PUSH AX
  PUSH BX
  PUSHF          ; 保护现场
  ...            ; 子程序主体
  POPF
  POP BX
  POP AX         ; 恢复现场
  RET
SUBP ENDP
```

**例**：寄存器传参——判断是否小写字母
- 入口：AL ← 待判断字符
- 出口：CF=0（是小写字母），CF=1（不是）
- 核心逻辑：比较是否在'a'~'z'范围内

## 4.7 系统功能调用

调用方式：**软中断指令 `INT n`**

| n的范围 | 服务程序 |
|---------|----------|
| 5H ~ 1FH | BIOS |
| 20H ~ 3FH | DOS |

### INT 21H — DOS系统功能调用

| 功能号(AH) | 功能 | 入口/出口 |
|------------|------|-----------|
| **01H** | 读取键盘单字符并回显 | 出口：AL=ASCII码 |
| **02H** | 屏幕输出单字符 | 入口：DL=ASCII码 |
| **05H** | 打印机输出单字符 | 入口：DL=ASCII码 |
| **09H** | 屏幕输出字符串（以`$`结尾） | 入口：DS:DX→字符串 |
| **0AH** | 键盘输入字符串 | 入口：DS:DX→缓冲区 |
| **4CH** | 返回操作系统 | 无入口参数 |

### 0AH功能缓冲区格式

```
缓冲区首字节[N]  → 最大可接收字符数（1~255）
第二字节[实际数] → 实际输入字符数（由系统填入）
第三字节开始     → 存放接收的字符（含回车符）
```

### BIOS 系统功能调用

- 驻留在ROM中（地址0FE00H起的8KB）
- 提供系统加点自检、引导装入、I/O处理、接口控制等功能
- DOS的系统功能一般通过调用BIOS实现
