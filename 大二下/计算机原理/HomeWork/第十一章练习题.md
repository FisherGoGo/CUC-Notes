# 第十一章练习题

## 1. USB 总线的特点

**题目：** USB 总线的特点是（ ）。

**选项：**

- A. 不支持热插拔
- B. 需要插在主板上 196 脚插槽中
- C. 串行总线
- D. 双绞线通信

**答案：C**

**解析：** USB 是 Universal Serial Bus，即通用串行总线。它采用串行传输方式，并支持热插拔、即插即用等特点。

**干扰项分析：**

- A 错，USB 支持热插拔。
- B 错，196 脚插槽不是 USB 的特点。
- D 表述不准确，USB 的核心分类特征是串行总线。

> 易错点：USB 名字里的 `Serial Bus` 就是“串行总线”。

## 2. 主流微机中不包含的总线标准

**题目：** 当前的主流微机中通常采用不含（ ）的三种总线标准。

**选项：**

- A. PCI
- B. PC
- C. EISA
- D. ISA

**答案：B**

**解析：** ISA、EISA、PCI 都是微机系统中常见的总线标准，而 PC 不是一种总线标准。

**干扰项分析：**

- A PCI 是高性能局部总线标准。
- C EISA 是扩展工业标准结构总线。
- D ISA 是工业标准结构总线。

## 3. 微机与其他系统之间的总线标准

**题目：** 微机系统之间或者微机系统与其他系统（仪器、仪表等）之间采用的总线标准有（ ）。

**选项：**

- A. 片总线
- B. RSC-232C
- C. ISA 总线
- D. PCI

**答案：B**

**解析：** 题目中的 `RSC-232C` 通常应写作 `RS-232C`，它是常用的串行通信接口标准，可用于微机与外部设备、仪器仪表之间的通信。

**干扰项分析：**

- A 片总线主要用于芯片内部或芯片之间的信息通路。
- C ISA 总线主要用于微机内部扩展。
- D PCI 主要是微机内部高速局部总线。

> 易错点：RS-232C 是外部串行通信接口标准，不是微机内部扩展总线。

## 4. 早期 ISA 总线引脚组成

**题目：** 早期的 ISA 总线有（ ）个基本引脚，可传送数据线（ ）条、地址线（ ）条、控制线（ ）条。在 16 位 CPU 出现后，ISA 总线扩展的 36 条信号线中，数据/地址线 8 条，最高地址线 7 条，控制信号线 19 条，电源和地线 2 条。

**选项：**

- A. 62，20，8，22
- B. 22，8，20，62
- C. 8，62，22，20
- D. 62，8，20，22

**答案：D**

**解析：** 早期 ISA 总线有 62 个基本引脚，其中数据线 8 条，地址线 20 条，控制线 22 条。

**干扰项分析：**

- A 把数据线和地址线数量对调了。
- B、C 把“总引脚数”和各类信号线数量混在了一起。

## 5. 同步总线协议的特点

**题目：** 下列各项中，（ ）不是同步总线协议的特点。

**选项：**

- A. 不需要应答信号
- B. 总线长度较短
- C. 各部件间的存取时间比较接近
- D. 总线周期长度可变

**答案：D**

**解析：** 同步总线采用统一的时钟信号控制，总线周期通常固定，因此“不需要应答信号”“总线长度较短”“各部件存取时间较接近”都是同步总线常见特点。总线周期长度可变更符合异步总线的特点。

**干扰项分析：**

- A 是同步总线常见特点，因为各操作按固定时序进行。
- B 是同步总线常见限制，长度过长会影响同步时序。
- C 是同步总线适用条件，各设备速度差异不能太大。

> 易错点：同步总线靠统一时钟，周期通常固定；异步总线靠握手，应答使周期可变。

## 6. CAN 通信总线的应用

**题目：** CAN 通信总线多用于连接（ ）。

**选项：**

- A. CPU 与内存
- B. 软盘驱动器与主板
- C. 靠近的两台 PC
- D. 工业现场设备

**答案：D**

**解析：** CAN 总线抗干扰能力强，可靠性高，常用于汽车电子、工业控制和现场设备之间的通信。

**干扰项分析：**

- A CPU 与内存通常通过系统总线或存储器总线连接。
- B 软盘驱动器不是 CAN 的典型应用。
- C 两台 PC 之间通信一般不用 CAN。

## 7. EISA 总线位数

**题目：** EISA 总线是一种支持多处理器的高性能的（ ）位标准总线。

**选项：**

- A. 128
- B. 32
- C. 64
- D. 16

**答案：B**

**解析：** EISA 是 Extended Industry Standard Architecture，即扩展工业标准结构总线，是一种 32 位标准总线，并兼容 ISA。

**干扰项分析：**

- C 容易误选，但 EISA 不是 64 位总线。
- D 是早期 ISA 扩展后的位宽特征，不是 EISA 的标准位数。

> 易错点：ISA 常见 8/16 位，EISA 是 32 位，PCI 常见 32/64 位扩展。

## 8. 直接通过芯片级总线与 CPU 相连的部件

**题目：** 下列部件中，直接通过芯片级总线与 CPU 相连的是（ ）。

**选项：**

- A. U 盘
- B. 键盘
- C. 显示器
- D. 内存

**答案：D**

**解析：** 内存与 CPU 之间通过系统总线或存储器总线进行高速数据交换，是 CPU 直接访问的重要部件。

**干扰项分析：**

- A U 盘通常通过 USB 接口连接。
- B 键盘属于外部输入设备。
- C 显示器通过显示接口或显卡连接，不直接通过芯片级总线与 CPU 相连。

## 9. 片内总线、内总线、外总线

**题目：** ① 总线在集成电路芯片内部，用来连接各功能单元的信息通路。② 总线主要用于各芯片之间的相互连接，是微型计算机系统的核心部件。③ 总线用于微机系统之间，是微机系统与其他微机设备之间的通信通道。

**答案：** ① 片内总线；② 内总线；③ 外总线

**解析：**

```text
片内总线：芯片内部各功能单元之间的信息通路
内总线：微机内部各芯片或部件之间的信息通路
外总线：微机系统与外部设备或其他微机系统之间的通信通道
```

## 10. PCI 总线

**题目：** PCI 属于高性能 ① 总线，其独立于微处理器的设计，可以保证其适应微处理器的不断升级换代，并可以和 ISA 等局部总线 ②。

**答案：** ① 局部；② 兼容

**解析：** PCI 是一种高性能局部总线。它不依赖某一种具体微处理器，具有较好的兼容性和扩展性，可以适应处理器升级，并能与 ISA 等总线系统共存。

> 易错点：PCI 的重点是“高性能局部总线”和“独立于处理器”。

## 11. AGP 的含义

**题目：** AGP（Accelerated Graphics Port），即 ①，是一种为了提高视频带宽而设计的 ②。

**答案：** ① 加速图形端口（或加速图形接口）；② 总线接口

**解析：** AGP 是专为图形显示系统设计的高速接口，用于连接主板与显卡，目的是提高图形和视频数据的传输带宽。

> 易错点：AGP 主要服务于图形显示，不是通用外设总线。

## 12. 总线、内总线、外总线的概念

**题目：** 阐述总线、内总线、外总线的概念。

**答案：**

总线是计算机系统中各功能部件之间传送信息的一组公共信号线，是多个部件共享的数据传输通路，用来传送数据、地址和控制信息。

内总线是计算机主机内部各部件之间进行信息交换的总线，通常用于 CPU、存储器、接口电路以及其他内部部件之间的连接。

外总线是微机系统与外部设备或其他微机系统之间进行通信的总线，用于系统扩展以及与外界进行信息交换。

**解析：** 总线按位置和作用范围可分为片内总线、内总线和外总线。本题重点区分“主机内部连接”和“系统对外通信”。

## 13. AGP 总线及其主要作用

**题目：** 什么是 AGP 总线？试说明 AGP 总线的主要作用。

**答案：**

AGP 是 Accelerated Graphics Port，即加速图形端口，也可称为加速图形接口。它是一种为提高图形和视频数据传输带宽而设计的高速图形接口，主要用于连接主板和显卡。

AGP 的主要作用是为图形系统提供比传统 PCI 总线更高的传输带宽，使显卡能够更快地传输图形数据并访问内存，从而提高图像显示速度和三维图形处理性能。

**解析：** AGP 的核心不是连接普通外设，而是专门面向图形显示系统，提高显卡与系统之间的数据传输能力。

## 14. PCI 总线的主要特点

**题目：** 试说明 PCI 总线的主要特点。

**答案：**

PCI 总线是一种独立于具体微处理器的高性能局部总线。它具有传输速度快、数据吞吐量大、兼容性好、支持即插即用、支持总线主控和突发传送等特点。

由于 PCI 不依赖某一种处理器，因此能够适应处理器的升级换代，也便于连接多种高速外部设备，在微型计算机系统中应用广泛。

**解析：** PCI 常考关键词包括：局部总线、高性能、独立于处理器、即插即用、总线主控、突发传送、兼容性好。
