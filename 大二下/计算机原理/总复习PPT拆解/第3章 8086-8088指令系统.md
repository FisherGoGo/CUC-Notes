# 第3章 8086/8088 指令系统

> 本章只整理 8086/8088 常用指令。寻址方式已单独拆到《第3章 8086-8088寻址方式》。

## 指令系统总目录

| 大类     | 练习题涉及的重点指令                                                        | 复习时抓什么                |
| ------ | ----------------------------------------------------------------- | --------------------- |
| 数据传送类  | `MOV`、`XCHG`、`LEA`、`PUSH`、`POP`、`PUSHF`、`POPF`、`IN`、`OUT`         | 数据传到哪里，是否改 `SP/FLAGS` |
| 算术运算类  | `ADD`、`ADC`、`INC`、`SUB`、`SBB`、`DEC`、`CMP`、`NEG`、`MUL`、`DIV`、`DAA` | 结果是否回写，`CF/OF/ZF` 怎么变 |
| 逻辑与移位类 | `NOT`、`AND`、`TEST`、`OR`、`XOR`、`SHR`、`SAR`、`ROL`、`RCR`             | 按位结果、移出位和 `CF`        |
| 控制转移类  | `JMP`、`JNO`、`JNC`、`JNZ`、`LOOPNZ`、`CALL`、`RET`、`INT`、`IRET`        | 是否改 `CS:IP`，是否看标志位    |
| 处理器控制类 | `CLC`、`STC`、`CMC`、`CLD`、`STD`、`HLT`                               | 直接改标志位或控制 CPU 状态      |

做题时按这个顺序查：

```text
1. 指令属于哪一类
2. 操作数是否合法
3. 是否访问内存/堆栈/端口
4. 是否影响 FLAGS
5. 是否改变 IP、SP、CX、SI、DI
```

## 数据传送类指令

### 数据传送类指令概述（重点）

- 数据传送是计算机中最基本、最重要的一类操作。
- 数据传送指令也是最常使用的一类指令。
- **除标志寄存器传送指令外，数据传送类指令一般不影响标志位。**

本部分主要包括：

- 通用数据传送指令
- 标志寄存器传送指令
- 目标地址传送指令
- 输入/输出指令

### MOV 传送指令（必考）

`MOV` 用于把源操作数传送到目的操作数。

```asm
MOV 目的操作数, 源操作数
```

使用注意：

| 限制 | 说明 |
|---|---|
| 立即数不能作目的操作数 | 例如不能写 `MOV 80H, AL` |
| `CS` 和 `IP` 不能作目的操作数 | 不能直接用 MOV 修改 |
| 两个段寄存器之间不能直接传送 | 需要借助通用寄存器中转 |
| 两个存储单元之间不能直接传送 | 内存到内存不能直接 MOV |
| 不能把立即数直接送入段寄存器 | 需要借助通用寄存器中转 |
| 两个操作数类型和长度必须一致 | 8 位对 8 位，16 位对 16 位 |

错误例子：

```asm
MOV BX, AL      ; 错误，BX 是 16 位，AL 是 8 位
MOV AL, 256     ; 错误，AL 是 8 位，256 超出 8 位范围
```

> 易错：`MOV` 看起来简单，但最常考的是“哪些传送不允许”。

### XCHG 交换指令（重点）

`XCHG` 用于交换两个操作数的内容。

格式：

```asm
XCHG OPD, OPS
```

功能：

```text
OPD 与 OPS 内容互换
```

例：

```asm
XCHG AL, AH
```

执行后，`AL` 和 `AH` 的内容互换。

使用注意：

- 两个操作数位数必须一致。
- 不能直接交换两个内存单元。
- `XCHG` 不影响标志位。

> 易错：`XCHG AL, AH` 是交换，不是单向传送；执行后两个寄存器的原内容都会改变。

### LEA 有效地址传送指令（重点）

`LEA` 的全称是 **Load Effective Address**，用于把源操作数的**有效地址 EA**送入目的寄存器。

格式：

```asm
LEA 目的寄存器, 源操作数
```

功能：

```text
源操作数的有效地址 -> 目的寄存器
```

注意这里传送的不是内存单元中的内容，而是“地址本身”。

例：

```asm
LEA BX, [SI+3000H]
```

若：

```text
SI = 1200H
```

则：

```text
BX = 1200H + 3000H = 4200H
```

它不会去访问 `DS:4200H` 这个内存单元，只是把算出来的偏移地址 `4200H` 放入 `BX`。

和 `MOV` 对比：

```asm
LEA BX, [SI+3000H]    ; BX = SI + 3000H
MOV BX, [SI+3000H]    ; BX = DS:[SI+3000H] 中的内容
```

| 指令 | 传送内容 | 是否访问内存数据 |
|---|---|---|
| `LEA BX, [SI+3000H]` | 有效地址 `SI+3000H` | 不访问内存内容 |
| `MOV BX, [SI+3000H]` | 内存单元中的数据 | 访问内存内容 |

常见用途：

- 取得变量、数组元素、缓冲区的偏移地址。
- 做地址计算，例如 `BX+SI+位移量`。
- 给后续间接寻址、串操作或子程序传参准备地址。

使用限制：

- 目的操作数必须是 16 位通用寄存器。
- 源操作数必须写成存储器操作数形式，也就是能计算有效地址的形式。
- `LEA` 不影响标志位。

例：

```asm
LEA SI, BUFFER
```

含义：

```text
SI = BUFFER 的偏移地址
```

之后可以用：

```asm
MOV AL, [SI]
```

访问 `BUFFER` 中的数据。

> 易错：`LEA` 取的是有效地址，不是取内存内容；`LEA AX, [BX]` 的效果是 `AX=BX`，不是 `AX=[BX]`。

> 易错：`LEA BX, AX` 是错的，因为 `AX` 是寄存器操作数，不是存储器操作数形式。

### PUSH 入栈与 POP 出栈指令（必考）

堆栈是一个**后进先出 LIFO** 的主存区域，位于堆栈段中。

- `SS`：记录堆栈段的段基址。
- `SP`：指向栈顶。
- 堆栈的存取操作都发生在栈顶。

#### PUSH 入栈

格式：

```asm
PUSH OPS
```

功能：

```text
SP - 2 -> SP
将 OPS 指定的一个字数据压入栈顶
```

注意：

- 源操作数只能是 16 位，不能是 8 位。
- 源操作数不能是立即数。

#### POP 出栈

格式：

```asm
POP OPD
```

功能：

```text
将栈顶的一个字数据送至 OPD
SP + 2 -> SP
```

注意：

- 目的操作数只能是 16 位，不能是 8 位。
- 立即数、`CS`、`IP` 不能作为目的操作数。

> 易错：8086 中一次 PUSH/POP 操作的是一个字，即 16 位，所以 SP 每次变化 2。

### PUSHF 标志寄存器入栈指令（重点）

`PUSHF` 用于保存标志寄存器 `FLAGS` 的当前内容。

格式：

```asm
PUSHF
```

功能：

```text
SP = SP - 2
FLAGS 入栈
```

常见用途：

- 在子程序或中断处理过程中保存现场。
- 临时保存当前标志位状态，之后可配合 `POPF` 恢复。

对比：

| 指令 | 功能 |
|---|---|
| `PUSH AX` | 把 `AX` 压入堆栈 |
| `PUSHF` | 把 `FLAGS` 压入堆栈 |
| `POPF` | 从栈顶弹出一个字送入 `FLAGS` |

> 易错：`PUSHF` 压入的是整个 16 位 `FLAGS`，不是某一个标志位。

#### POPF 标志寄存器出栈

`POPF` 用于从栈顶弹出一个字，送入标志寄存器 `FLAGS`。

格式：

```asm
POPF
```

功能：

```text
FLAGS = 栈顶字数据
SP = SP + 2
```

例：

```asm
PUSHF
POP AX
OR AL, 01H
PUSH AX
POPF
```

这段代码通过栈间接修改 `FLAGS`，其中 `OR AL, 01H` 会把 `FLAGS` 的最低位 `CF` 置 1。

> 易错：`POPF` 会改变多个标志位，不只是改变 `CF`。

### 输入/输出指令 IN、OUT（重点）

- 输入/输出指令用于完成 I/O 端口和累加器 `AL/AX` 之间的数据传送。
- 包括输入指令 `IN` 和输出指令 `OUT`。
- 输入/输出指令对标志寄存器没有影响。
- 端口地址大于 `255` 时，必须用 `DX` 指定端口地址。

#### IN 输入指令

格式：

```asm
IN OPD, OPS
```

功能：

- 从端口输入 8 位数据到 `AL`。
- 或从端口输入 16 位数据到 `AX`。

例：

```asm
IN AL, 40H
```

从 `40H` 端口读入一个字节送入 `AL`。

```asm
IN AX, 80H
```

从 `80H` 端口读入一个字节送 `AL`，从 `81H` 端口读入一个字节送 `AH`。

```asm
MOV DX, 8F00H
IN AL, DX
```

从 `8F00H` 端口读入一个字节送入 `AL`。

#### OUT 输出指令

格式：

```asm
OUT OPD, OPS
```

功能：

- 将 `AL` 中的 8 位数据输出到端口。
- 或将 `AX` 中的 16 位数据输出到端口。

例：

```asm
OUT 40H, AL
```

将 `AL` 内容送到 `40H` 端口。

```asm
OUT 80H, AX
```

将 `AL` 内容送到 `80H` 端口，将 `AH` 内容送到 `81H` 端口。

```asm
MOV DX, 8F00H
OUT DX, AL
```

将 `AL` 内容送到 `8F00H` 端口。

> 易错：IN 是端口到 AL/AX；OUT 是 AL/AX 到端口。端口地址超过 8 位时，必须先放入 DX。

## 算术运算类指令

### 算术运算类指令概述（重点）

算术运算类指令主要包括：

- 加法指令
- 减法指令
- 乘法指令
- 符号扩展指令
- 除运算指令
- 十进制调整指令

> 注意：算术运算类指令通常会影响标志位，复习时要关注结果对标志寄存器 `FLAGS` 的影响。常用标志位含义见第 2 章“标志寄存器 FLAGS”。

### ADD 加法指令（必考）

`ADD` 用于把源操作数加到目的操作数上，结果回送到目的操作数。

格式：

```asm
ADD OPD, OPS
```

功能：

```text
OPD = OPD + OPS
```

影响标志位：

```text
CF、AF、PF、SF、OF、ZF
```

例：

```asm
ADD AL, BL
```

含义是 `AL = AL + BL`。

做题重点：

- `CF` 看无符号进位。
- `OF` 看有符号溢出。
- `ZF` 看结果是否为 0。

> 易错：两个正数相加得到负数，或两个负数相加得到正数，说明有符号溢出，`OF=1`。

### ADC 带进位加法指令（重点）

`ADC` 用于做带进位加法，常用于多字节或多字数据相加。

格式：

```asm
ADC OPD, OPS
```

功能：

```text
OPD = OPD + OPS + CF
```

影响标志位：

```text
CF、AF、PF、SF、OF、ZF
```

例：

```asm
ADD AX, BX
ADC DX, CX
```

含义：

```text
先把低 16 位 AX 和 BX 相加
再把高 16 位 DX 和 CX 相加，同时加上低位产生的进位 CF
```

> 易错：`ADC` 会把原来的 `CF` 一起加进去；普通 `ADD` 不会加 `CF`。

### INC 加 1 指令（重点）

格式：

```asm
INC OPD
```

功能：

- 将目的操作数 `OPD` 的内容加 1。
- 结果回送到目的操作数。

影响标志位：

- 影响：`AF、PF、SF、OF、ZF`
- **不影响：`CF`**

例：

```asm
INC AX
```

`AX` 中内容加 1，结果送回 `AX`。

```asm
INC BL
```

`BL` 中内容加 1，结果送回 `BL`。

```asm
INC BYTE PTR [SI]
```

将 `SI` 所指内存字节单元的内容加 1，并回存。

> 易错：`INC` 会影响多个标志位，但不影响 `CF`。如果要影响进位标志，不能只靠 `INC`。

### SUB 减法指令（重点）

`SUB` 用于从目的操作数中减去源操作数，结果回送到目的操作数。

格式：

```asm
SUB OPD, OPS
```

功能：

```text
OPD = OPD - OPS
```

影响标志位：

```text
CF、AF、PF、SF、OF、ZF
```

例：

```asm
SUB AX, AX
```

执行后：

```text
AX = 0
ZF = 1
CF = 0
```

> 易错：`SUB AX, AX` 会把 `AX` 清零；`CMP AX, AX` 只影响标志位，不会把 `AX` 清零。

### SBB 带借位减法指令（重点）

`SBB` 用于做带借位减法，常用于多字节或多字数据相减。

格式：

```asm
SBB OPD, OPS
```

功能：

```text
OPD = OPD - OPS - CF
```

影响标志位：

```text
CF、AF、PF、SF、OF、ZF
```

例：

```asm
SUB AX, BX
SBB DX, CX
```

含义：

```text
低 16 位先相减
高 16 位相减时，再减去低位产生的借位 CF
```

> 易错：`SBB` 会额外减去 `CF`；如果只是普通减法，用 `SUB`。

### DEC 减 1 指令（重点）

`DEC` 用于把目的操作数减 1，结果回送到目的操作数。

格式：

```asm
DEC OPD
```

功能：

```text
OPD = OPD - 1
```

影响标志位：

- 影响：`AF、PF、SF、OF、ZF`
- **不影响：`CF`**

例：

```asm
DEC AX
```

执行后，`AX` 的内容减 1。

> 易错：`DEC` 和 `INC` 一样，不影响 `CF`。

### CMP 比较指令（必考）

格式：

```asm
CMP OPD, OPS
```

功能：

- 用目的操作数 `OPD` 减去源操作数 `OPS`。
- 只影响标志位，结果不回送。

```text
OPD - OPS
```

影响标志位：

```text
CF、AF、PF、SF、OF、ZF
```

例：

```asm
CMP AL, 09H
```

将 `AL` 的内容和 `09H` 比较，结果只影响标志位。

判断规则：

- `ZF=1`：两数相等。
- `ZF=0`：两数不等。
- 对无符号数：`CF=0` 表示 `OPD >= OPS`，`CF=1` 表示 `OPD < OPS`。
- 对有符号数：`OF=SF` 表示 `OPD >= OPS`，`OF≠SF` 表示 `OPD < OPS`。

> 易错：`CMP` 会做减法并影响标志位，但不会保存减法结果。

### NEG 求补/变号指令（重点）

`NEG` 用于对操作数求补，也可以理解为把数变成相反数。

格式：

```asm
NEG OPD
```

功能：

```text
OPD = 0 - OPD
```

影响标志位：

```text
CF、AF、PF、SF、OF、ZF
```

例：

```asm
MOV AL, 05H
NEG AL
```

执行后：

```text
AL = FBH
```

因为 `FBH` 是 -5 的补码表示。

`CF` 的规律：

- 若原操作数为 0，执行后 `CF=0`。
- 若原操作数不为 0，执行后 `CF=1`。

> 易错：`NEG` 不是简单按位取反；按位取反是 `NOT`。`NEG OPD` 等价于 `0 - OPD`。

### MUL 无符号乘法指令（重点）

`MUL` 用于无符号数乘法。它有隐含操作数。

格式：

```asm
MUL OPS
```

功能按操作数位数分两种：

| 源操作数 | 隐含被乘数 | 结果位置 |
|---|---|---|
| 8 位 | `AL` | `AX` |
| 16 位 | `AX` | `DX:AX` |

例：

```asm
MUL CX
```

含义：

```text
DX:AX = AX * CX
```

标志位：

- 若结果高半部分为 0，则 `CF=OF=0`。
- 若结果高半部分不为 0，则 `CF=OF=1`。
- 其他标志位无定义。

> 易错：`MUL CX` 不是 `CX=CX*AX`，而是隐含用 `AX` 乘 `CX`，结果放到 `DX:AX`。

### DIV 无符号除法指令（重点）

`DIV` 用于无符号数除法，也有隐含操作数。

格式：

```asm
DIV OPS
```

功能按除数位数分两种：

| 除数 | 隐含被除数 | 商 | 余数 |
|---|---|---|---|
| 8 位 | `AX` | `AL` | `AH` |
| 16 位 | `DX:AX` | `AX` | `DX` |

例：

```asm
DIV CX
```

含义：

```text
DX:AX / CX
商放 AX
余数放 DX
```

注意：

- `DIV` 的标志位结果无定义。
- 如果除数为 0，或商超过目标寄存器能表示的范围，会产生除法错误中断。

> 易错：16 位除法的被除数不是单独的 `AX`，而是 `DX:AX`。

### DAA 十进制调整指令（了解但易考）

`DAA` 用于对 `AL` 中的压缩 BCD 加法结果进行十进制调整，通常紧跟在 `ADD` 或 `ADC` 后面。

格式：

```asm
DAA
```

隐含操作数：

```text
AL
```

典型用法：

```asm
MOV AL, 56H
ADD AL, 35H
DAA
```

解释：

```text
56H 和 35H 按压缩 BCD 看，表示十进制 56 和 35
ADD 后得到的二进制结果不一定是合法 BCD
DAA 负责把 AL 调整成合法的压缩 BCD 结果
```

调整规则简记：

| 条件 | 动作 |
|---|---|
| `AL` 低 4 位大于 9，或 `AF=1` | `AL = AL + 06H` |
| `AL` 高 4 位大于 9，或 `CF=1` | `AL = AL + 60H` |

> 易错：`DAA` 只调整 `AL`，不能写成 `DAA AX`；它通常跟在 `ADD/ADC` 后，单独使用没有意义。

## 逻辑运算指令

### 逻辑运算指令概述（重点）

- 逻辑运算指令可以对字节或字按位进行逻辑运算。
- 常见逻辑运算指令包括：

| 指令 | 含义 |
|---|---|
| `NOT` | 非运算 |
| `AND` | 与运算 |
| `TEST` | 测试指令 |
| `OR` | 或运算 |
| `XOR` | 异或运算 |
| `SHR` | 逻辑右移 |

> 注意：逻辑运算是按位运算，每一位独立参与计算。

### NOT、AND、OR、XOR 逻辑运算指令（重点）

这几条指令都按二进制位逐位运算。

| 指令 | 功能 | 结果是否回写 | 常见用途 |
|---|---|---|---|
| `NOT OPD` | 按位取反 | 回写 `OPD` | 求反码 |
| `AND OPD, OPS` | 按位与 | 回写 `OPD` | 清零某些位、保留某些位 |
| `OR OPD, OPS` | 按位或 | 回写 `OPD` | 置 1 某些位 |
| `XOR OPD, OPS` | 按位异或 | 回写 `OPD` | 翻转某些位、清零寄存器 |

标志位：

- `AND`、`OR`、`XOR` 会影响 `SF、ZF、PF`，并使 `CF=0、OF=0`。
- `NOT` 不影响标志位。

典型例子：

```asm
MOV AL, BL
NOT AL
XOR AL, BL
OR  BL, AL
```

若原来 `BL=x`：

```text
MOV AL, BL  -> AL=x
NOT AL      -> AL=~x
XOR AL, BL  -> AL=(~x) XOR x = FFH
OR BL, AL   -> BL=x OR FFH = FFH
```

所以最后 `AL=FFH`，`BL=FFH`。

常见清零写法：

```asm
XOR AX, AX
SUB AX, AX
AND AX, 0
```

> 易错：`CMP AX, AX` 不能清零 `AX`；它只影响标志位，不保存结果。

### TEST 测试指令（重点）

格式：

```asm
TEST OPD, OPS
```

功能：

- 将目的操作数 `OPD` 与源操作数 `OPS` 按位相与。
- 结果不送回目的操作数，只影响标志位。

影响标志位：

- 影响：`SF、ZF、PF`
- 置 0：`OF=0、CF=0`
- `AF` 无定义

例：

```asm
TEST AL, 80H
```

若执行前：

```text
AL = 39H = 0011 1001B
80H = 1000 0000B
```

按位与结果：

```text
0011 1001
1000 0000
---------
0000 0000
```

所以 `ZF=1`，说明 `AL` 的最高位为 0。

用途：

- 常用于判断某一位是否为 1。

> 易错：`TEST` 和 `AND` 都做按位与，但 `TEST` 不保存结果，`AND` 会保存结果。

### SHR 逻辑右移指令（重点）

`SHR` 用于把操作数按位向右移动，左边高位补 0。

格式：

```asm
SHR OPD, 1
SHR OPD, CL
```

功能：

```text
每右移 1 位：
最低位移入 CF
最高位补 0
```

例：

```asm
MOV AL, 9AH      ; 1001 1010B
SHR AL, 1
```

执行后：

```text
AL = 4DH         ; 0100 1101B
CF = 0           ; 原最低位为 0
```

使用限制：

- 移动 1 位时，可以直接写 `1`。
- 移动多位时，次数必须放在 `CL` 中。

例：

```asm
MOV CL, 3
SHR AX, CL
```

常见用途：

- 无符号数右移。
- 无符号数除以 2、4、8 等 2 的幂。

> 易错：`SHR` 高位补 0，适合无符号数；`SAR` 高位补符号位，适合有符号数。

### SAR 算术右移指令（重点）

`SAR` 用于算术右移，右移时最高位补原来的符号位。

格式：

```asm
SAR OPD, 1
SAR OPD, CL
```

功能：

```text
每右移 1 位：
最低位移入 CF
最高位补原符号位
```

例：

```asm
MOV AL, 84H      ; 1000 0100B，按有符号数看是负数
SAR AL, 1
```

执行后：

```text
AL = C2H         ; 1100 0010B
CF = 0
```

和 `SHR` 对比：

| 指令 | 最高位补什么 | 适合对象 |
|---|---|---|
| `SHR` | 补 0 | 无符号数 |
| `SAR` | 补原符号位 | 有符号数 |

> 易错：负数右移时，如果要保持符号，应该用 `SAR`，不是 `SHR`。

### ROL 和 RCR 循环移位指令（重点）

循环移位会把移出去的位再送回参与循环，常考 `CF` 的变化。

#### ROL 循环左移

`ROL` 表示循环左移。

```asm
ROL OPD, 1
ROL OPD, CL
```

执行规则：

```text
最高位移入最低位
最高位同时送入 CF
```

例：

```asm
MOV AX, 2255H
MOV CL, 2
ROL AX, CL
```

`AX` 作为 16 位整体循环左移 2 位。

#### RCR 带进位循环右移

`RCR` 表示通过进位标志循环右移，`CF` 也参与循环。

```asm
RCR OPD, 1
RCR OPD, CL
```

执行规则：

```text
原 CF 进入最高位
最低位移入 CF
```

例：

```asm
MOV AL, 82H      ; 1000 0010B
STC              ; CF=1
RCR AL, 1
```

执行后：

```text
AL = C1H         ; 1100 0001B
CF = 0           ; 原 AL 最低位为 0
```

> 易错：`RCR` 不是普通右移，`CF` 会参与循环；`ROL` 不通过 `CF` 循环，但移出的最高位会送入 `CF`。

## 控制转移类指令

### 控制转移类指令概述（重点）

- 控制转移指令用于控制程序的执行流程。
- 程序执行顺序的改变，*本质上是通过修改代码段寄存器* `CS` 和指令指针 `IP` 的内容实现的。
- 8086/8088 正常顺序执行时，CPU 执行完一条指令后，`IP` 自动指向下一条指令；控制转移指令则人为改变这个“下一条指令”的地址。

主要包括：

- 无条件转移指令
- 条件转移指令
- 循环转移指令
- 子程序调用和返回指令
- 中断和中断返回指令

> 注意：普通顺序执行时，CPU 按 `CS:IP` 取下一条指令；发生转移时，就是改变 `CS`、`IP` 或 `IP` 的值。

控制转移先分清两个维度：

| 维度 | 含义 | 典型指令 |
|---|---|---|
| 段内转移 | 只改变 `IP`，仍在当前 `CS` 代码段内执行 | `JMP 标号`、`JZ 标号`、`CALL 标号` |
| 段间转移 | 同时改变 `CS` 和 `IP`，跳到另一个代码段 | `JMP FAR PTR 标号`、`CALL FAR PTR 标号`、`INT n` |

简单记：

```text
段内：只换 IP
段间：CS 和 IP 都换
```

### 无条件转移指令 JMP（必考）

`JMP` 表示无条件跳转。只要执行到 `JMP`，CPU 就一定转到目标地址继续执行，不需要判断标志位。

#### JMP 的基本作用

```asm
JMP NEXT

MOV AX, 1      ; 这条会被跳过

NEXT:
MOV AX, 2
```

执行 `JMP NEXT` 后，`IP` 被改成 `NEXT` 对应的偏移地址，程序直接执行 `MOV AX, 2`。

> 易错：`JMP` 不保存返回地址。跳过去之后不能靠 `RET` 自动回来；能回来的是 `CALL/RET`。

#### 段内直接转移

段内直接转移的目标地址直接写在指令中，通常用标号表示。

| 类型 | 格式 | 改谁 | 范围 |
|---|---|---|---|
| 短转移 | `JMP SHORT 标号` | `IP` | 相对当前 `IP` 的 -128 到 +127 字节 |
| 近转移 | `JMP NEAR PTR 标号` | `IP` | 相对当前 `IP` 的 -32768 到 +32767 字节 |

说明：

- `SHORT` 和 `NEAR` 都是段内转移，不改变 `CS`。
- 两者主要区别是转移距离不同。
- 汇编器通常可以根据标号距离自动判断，但考试常要求知道范围。

例子：

```asm
START:
    CMP AX, 0
    JZ  ZERO
    JMP NEXT

ZERO:
    MOV BX, 0

NEXT:
    MOV CX, BX
```

这里 `JMP NEXT` 是段内无条件转移，只修改 `IP`。

#### 段内间接转移

段内间接转移的目标偏移地址不直接写在指令里，而是放在寄存器或内存单元中。

```asm
JMP BX
JMP WORD PTR [2000H]
```

含义：

- `JMP BX`：把 `BX` 的内容送入 `IP`。
- `JMP WORD PTR [2000H]`：从内存字单元取出一个 16 位偏移地址送入 `IP`。

> 易错：段内间接转移只取 16 位偏移地址，所以只改 `IP`，不会改 `CS`。

#### 段间直接转移

段间直接转移会同时改变 `CS` 和 `IP`。

```asm
JMP FAR PTR DEST
```

执行后：

```text
CS = DEST 所在段地址
IP = DEST 的偏移地址
```

这种转移用于跳到另一个代码段。

#### 段间间接转移

段间间接转移的目标地址从内存中的双字单元取得。

```asm
JMP DWORD PTR [BX]
```

内存中 4 个字节的含义：

```text
低地址 2 字节：目标 IP
高地址 2 字节：目标 CS
```

例如：

```text
DS = 5000H
BX = 2000H

5000:2000  存放 0200H
5000:2002  存放 3000H
```

执行：

```asm
JMP DWORD PTR [BX]
```

结果：

```text
IP = 0200H
CS = 3000H
```

于是 CPU 转到 `3000:0200` 继续执行。

#### JMP 小结

| 类型 | 格式 | 修改内容 |
|---|---|---|
| 段内直接短转移 | `JMP SHORT 标号` | `IP` |
| 段内直接近转移 | `JMP NEAR PTR 标号` | `IP` |
| 段内间接转移 | `JMP WORD PTR OPD` | `IP` |
| 段间直接转移 | `JMP FAR PTR 标号` | `CS、IP` |
| 段间间接转移 | `JMP DWORD PTR OPD` | `CS、IP` |

> 易错：`JMP WORD PTR [BX]` 是段内间接转移；`JMP DWORD PTR [BX]` 才是段间间接转移。

### 条件转移指令 Jcc（必考）

条件转移指令的特点是：满足条件就跳转，不满足条件就顺序执行下一条指令。

```asm
CMP AX, BX
JZ  EQUAL
```

执行逻辑：

```text
先用 CMP 设置标志位
再由 JZ 根据 ZF 判断是否跳转
```

条件转移指令本身不改变标志位，它只是检查标志位。

> 注意：8086/8088 的条件转移都是短转移，范围是 -128 到 +127 字节。

#### 根据单个标志位判断

| 指令 | 条件 | 含义 | 常见用途 |
|---|---|---|---|
| `JZ` / `JE` | `ZF=1` | 结果为零 / 相等 | `CMP` 后判断相等 |
| `JNZ` / `JNE` | `ZF=0` | 结果非零 / 不相等 | `CMP` 后判断不等 |
| `JC` | `CF=1` | 有进位 / 有借位 | 无符号运算溢出或小于 |
| `JNC` | `CF=0` | 无进位 / 无借位 | 无符号运算未溢出 |
| `JO` | `OF=1` | 有溢出 | 有符号运算溢出 |
| `JNO` | `OF=0` | 无溢出 | 有符号运算未溢出 |
| `JS` | `SF=1` | 结果为负 | 看结果符号位 |
| `JNS` | `SF=0` | 结果非负 | 看结果符号位 |
| `JP` / `JPE` | `PF=1` | 偶校验 | 结果低 8 位中 1 的个数为偶数 |
| `JNP` / `JPO` | `PF=0` | 奇校验 | 结果低 8 位中 1 的个数为奇数 |

例子：

```asm
CMP AL, 0
JZ  IS_ZERO
```

`CMP AL, 0` 相当于做 `AL - 0`，如果结果为 0，则 `ZF=1`，于是 `JZ` 跳转。

特别记住这两个：

| 指令 | 判断条件 | 常见含义 |
|---|---|---|
| `JNC` | `CF=0` | 无进位、无借位；无符号比较中表示大于等于 |
| `JNO` | `OF=0` | 无溢出；常用于有符号运算后判断没有溢出 |

例：

```asm
ADD AL, BL
JNO NO_OVERFLOW
```

如果加法没有产生有符号溢出，即 `OF=0`，则跳到 `NO_OVERFLOW`。

```asm
CMP AX, BX
JNC ABOVE_OR_EQUAL
```

如果把 `AX`、`BX` 当作无符号数，`CF=0` 表示 `AX >= BX`，所以 `JNC` 会跳转。

> 易错：`JNC` 看 `CF`，常和无符号数有关；`JNO` 看 `OF`，常和有符号溢出有关。

`JNZ` 也很常考：

```asm
JNZ NEXT
```

含义：

```text
若 ZF=0，则跳转到 NEXT
若 ZF=1，则顺序执行下一条
```

> 易错：`JNZ` 只是检查 `ZF`，本身不修改 `ZF`。

#### 无符号数比较转移

无符号数比较主要看 `CF` 和 `ZF`。

| 比较关系 | 常用指令 | 条件 | 含义 |
|---|---|---|---|
| 等于 | `JE` / `JZ` | `ZF=1` | equal |
| 不等于 | `JNE` / `JNZ` | `ZF=0` | not equal |
| 小于 | `JB` / `JNAE` / `JC` | `CF=1` | below |
| 小于等于 | `JBE` / `JNA` | `CF=1 或 ZF=1` | below or equal |
| 大于 | `JA` / `JNBE` | `CF=0 且 ZF=0` | above |
| 大于等于 | `JAE` / `JNB` / `JNC` | `CF=0` | above or equal |

例子：

```asm
CMP AL, BL
JB  SMALLER
```

若把 `AL` 和 `BL` 当作无符号数，`JB` 表示：

```text
AL < BL 时跳转
```

因为 `CMP AL, BL` 本质是做 `AL - BL`，无符号小于时会产生借位，即 `CF=1`。

#### 有符号数比较转移

有符号数比较主要看 `SF` 和 `OF`，有时还要结合 `ZF`。

| 比较关系 | 常用指令 | 条件 | 含义 |
|---|---|---|---|
| 等于 | `JE` / `JZ` | `ZF=1` | equal |
| 不等于 | `JNE` / `JNZ` | `ZF=0` | not equal |
| 小于 | `JL` / `JNGE` | `SF != OF` | less |
| 小于等于 | `JLE` / `JNG` | `ZF=1 或 SF != OF` | less or equal |
| 大于 | `JG` / `JNLE` | `ZF=0 且 SF=OF` | greater |
| 大于等于 | `JGE` / `JNL` | `SF=OF` | greater or equal |

例子：

```asm
CMP AL, BL
JL  LESS
```

若把 `AL` 和 `BL` 当作有符号数，`JL` 表示：

```text
AL < BL 时跳转
```

> 易错：同样是 `CMP AL, BL`，后面接 `JB` 是按无符号数小于判断，接 `JL` 是按有符号数小于判断。

#### 条件转移做题方法

遇到条件转移题，按下面顺序判断：

```text
1. 看前一条是否是 CMP/TEST/算术逻辑指令
2. 算出它对标志位的影响
3. 看条件转移指令检查哪个标志位
4. 满足则跳，不满足则继续向下执行
```

典型例子：

```asm
MOV AL, 05H
CMP AL, 08H
JB  L1
MOV BL, 0
JMP DONE

L1:
MOV BL, 1

DONE:
```

分析：

```text
CMP AL, 08H -> 05H - 08H
无符号数 5 < 8，所以 CF=1
JB 条件成立，跳到 L1
最终 BL=1
```

### 循环控制指令 JCXZ 和 LOOP 系列（重点）

循环转移指令常用于控制重复执行某段程序。8086/8088 中这类指令默认使用 `CX` 作为循环计数器。

#### JCXZ 指令

`JCXZ` 的格式：

```asm
JCXZ 标号
```

功能：

```text
如果 CX = 0，则跳转到标号；
如果 CX != 0，则顺序执行下一条指令。
```

特点：

- `JCXZ` 在执行时不修改 `CX`。
- `JCXZ` 不检查标志位。
- 常用于进入循环前判断 `CX` 是否为 0，避免循环次数异常。

例子：

```asm
MOV CX, COUNT
JCXZ DONE

AGAIN:
    ; 循环体
    LOOP AGAIN

DONE:
```

若 `COUNT=0`，程序直接跳到 `DONE`，不会进入循环体。

#### LOOP 指令

`LOOP` 的格式：

```asm
LOOP 标号
```

执行过程：

```text
1. CX = CX - 1
2. 若 CX != 0，则转移到标号
3. 若 CX = 0，则顺序执行下一条指令
```

例子：

```asm
MOV CX, 5

AGAIN:
    INC AX
    LOOP AGAIN
```

执行结果：

```text
循环体执行 5 次
每次先执行 INC AX
再由 LOOP 令 CX 减 1 并判断是否继续
```

> 易错：`LOOP` 是先让 `CX` 减 1，再判断 `CX` 是否为 0。

#### LOOPE/LOOPZ 与 LOOPNE/LOOPNZ

这几条指令同时看 `CX` 和 `ZF`。

| 指令 | 执行动作 | 继续循环条件 | 常见含义 |
|---|---|---|---|
| `LOOP` | `CX=CX-1` | `CX != 0` | 只按次数循环 |
| `LOOPE` / `LOOPZ` | `CX=CX-1` | `CX != 0 且 ZF=1` | 相等/为零时继续 |
| `LOOPNE` / `LOOPNZ` | `CX=CX-1` | `CX != 0 且 ZF=0` | 不等/非零时继续 |

说明：

- `LOOPE` 和 `LOOPZ` 是同义指令。
- `LOOPNE` 和 `LOOPNZ` 是同义指令。
- 它们都会先修改 `CX`，但不修改标志位。
- 其中 `ZF` 通常由循环体里的 `CMP`、`TEST`、`SCASB`、`CMPSB` 等指令产生。

例子：

```asm
MOV CX, 10

NEXT:
    CMP AL, [SI]
    INC SI
    LOOPNE NEXT
```

含义：

```text
每次比较 AL 和 [SI]
只要 CX 还没减到 0，并且 ZF=0（还没相等），就继续循环
```

> 易错：`LOOPNE` 的判断条件不是“CX 不等于 0”这么简单，而是 `CX != 0 且 ZF=0`。

#### LOOPNZ 指令单独记忆

`LOOPNZ` 和 `LOOPNE` 完全等价。

```asm
LOOPNZ 标号
```

执行过程：

```text
1. CX = CX - 1
2. 如果 CX != 0 且 ZF = 0，则跳转
3. 否则顺序执行下一条指令
```

适合场景：

- 在一串数据中查找某个值。
- 只要还没找到，即 `ZF=0`，并且次数还没用完，就继续循环。

> 易错：`LOOPNZ` 的 `NZ` 看的是 `ZF=0`，但它同时还要求 `CX != 0`。

### 子程序调用与返回指令 CALL/RET（重点）

`CALL` 用于调用子程序。执行 CALL 时，会先把返回地址压入堆栈，再转到子程序执行。

`RET` 用于从子程序返回。执行 `RET` 时，会从堆栈中弹出返回地址，恢复到调用点后面的指令继续执行。

#### 段内调用

段内调用只改变 `IP`，不改变 `CS`。

| 类型 | 格式 | 功能 |
|---|---|---|
| 段内直接调用 | `CALL 标号` | 将返回地址的 16 位偏移地址压栈，再把标号的偏移地址送入 `IP` |
| 段内间接调用 | `CALL WORD PTR OPD` | 将返回地址压栈，再把 `OPD` 指定的 16 位偏移地址送入 `IP` |

段内调用执行过程：

```text
SP = SP - 2
返回 IP 入栈
IP = 子程序入口偏移地址
```

#### 段间调用

段间调用会改变 `CS` 和 `IP`。

| 类型 | 格式 | 功能 |
|---|---|---|
| 段间直接调用 | `CALL FAR PTR 标号` | 将断点地址 `CS、IP` 压栈，再把目标段基址送入 `CS`，目标偏移地址送入 `IP` |
| 段间间接调用 | `CALL DWORD PTR OPD` | 将断点地址 `CS、IP` 压栈，再把有效地址指定的 4 个字节送入 `IP、CS` |

段间调用执行过程：

```text
SP = SP - 2，CS 入栈
SP = SP - 2，IP 入栈
CS = 子程序入口段地址
IP = 子程序入口偏移地址
```

> 说明：从最终栈顶看，返回 `IP` 在栈顶，返回 `CS` 在其上方的高地址处，这样 `RET FAR` 可以先弹 `IP`，再弹 `CS`。

#### CALL 压栈规律

| 调用类型 | 压栈内容 | 修改内容 |
|---|---|---|
| 段内调用 | 返回地址的 `IP` | 只改 `IP` |
| 段间调用 | 返回地址的 `CS` 和 `IP` | 改 `CS` 和 `IP` |

> 易错：段内调用和段间调用的区别在于是否跨代码段。段内只保存/修改 `IP`，段间要保存/修改 `CS:IP`。

理解例子：

```asm
1000:0100  CALL SUB1
1000:0103  MOV AX, BX

1000:0200  SUB1:
           ...
           RET
```

执行 `CALL SUB1` 时：

- CPU 先把返回地址 `0103` 压入堆栈。
- 再把 `IP` 改成 `0200`，转去执行 `SUB1`。

执行到 `RET` 时：

- CPU 从堆栈中弹出返回地址 `0103`。
- 回到 `1000:0103` 继续执行 `MOV AX, BX`。

简单记：

```text
CALL：保存返回地址，然后跳过去
RET：取回返回地址，然后跳回来
```

#### RET 和 RET n

| 指令 | 功能 |
|---|---|
| `RET` | 从栈顶弹出返回地址，返回调用点 |
| `RET n` | 先返回，再使 `SP = SP + n`，常用于清除堆栈中的参数 |

段内返回：

```text
POP IP
```

段间返回：

```text
POP IP
POP CS
```

`RET n` 的 `n` 通常是偶数，因为 8086/8088 中常以字为单位压入参数。

例子：

```asm
CALL SUB1

SUB1 PROC
    ; 子程序内容
    RET
SUB1 ENDP
```

若子程序用堆栈传参：

```asm
PUSH AX
PUSH BX
CALL SUB2

SUB2 PROC
    ; 使用调用者压入的两个字参数
    RET 4
SUB2 ENDP
```

`RET 4` 表示返回后再让 `SP` 加 4，相当于清除两个字参数。

> 易错：`CALL` 与 `JMP` 都会跳转，但 `CALL` 会保存返回地址，`JMP` 不保存返回地址。

### 中断与中断返回指令 INT/IRET/INTO（重点）

中断指令会使 CPU 暂停当前程序，转去执行中断服务程序。中断服务程序执行结束后，再通过 `IRET` 回到原程序。

#### INT n

`INT n` 是软件中断指令。

```asm
INT n
```

其中 `n` 是中断类型码，范围为：

```text
00H ~ FFH
```

执行 `INT n` 时，CPU 主要完成这些动作：

```text
1. FLAGS 入栈
2. CS 入栈
3. IP 入栈
4. 根据中断类型码 n 查中断向量表，取出新的 CS:IP
```

进入中断服务程序后：

```text
CS:IP = 中断服务程序入口地址
```

#### 中断向量表

8086/8088 的中断向量表位于内存最低地址区域。

```text
起始物理地址：00000H
每个中断向量占 4 字节
共有 256 个中断类型
```

对中断类型码 `n`：

```text
中断向量地址 = n * 4
```

4 个字节的含义：

```text
n*4     低 2 字节：IP
n*4+2   高 2 字节：CS
```

例子：

```text
INT 21H
中断向量地址 = 21H * 4 = 84H

0000:0084  存放中断服务程序 IP
0000:0086  存放中断服务程序 CS
```

> 易错：中断向量表中低地址存 `IP`，高地址存 `CS`，不要反过来。

#### IRET

`IRET` 是中断返回指令。中断服务程序的最后通常用 `IRET` 返回。

执行过程：

```text
POP IP
POP CS
POP FLAGS
```

也就是说，`IRET` 不仅恢复程序执行地址，还恢复中断发生前的标志寄存器。

对比：

| 指令 | 返回时恢复内容 | 用途 |
|---|---|---|
| `RET` | `IP` 或 `CS:IP` | 子程序返回 |
| `IRET` | `IP、CS、FLAGS` | 中断服务程序返回 |

> 易错：中断服务程序不能用普通 `RET` 代替 `IRET`，因为普通 `RET` 不会恢复 `FLAGS`。

#### INTO

`INTO` 是溢出中断指令，用于检查 `OF`。

```asm
INTO
```

执行逻辑：

```text
如果 OF = 1，则产生类型 4 中断；
如果 OF = 0，则顺序执行下一条指令。
```

例子：

```asm
ADD AL, BL
INTO
```

如果 `ADD` 产生有符号溢出，即 `OF=1`，则 `INTO` 会触发 4 号中断。

> 易错：`INTO` 只看 `OF`，不是看 `CF`。它用于有符号数溢出检查。

### 控制转移类指令总表

| 类别 | 指令 | 核心作用 | 是否改 `CS:IP` | 是否用栈 |
|---|---|---|---|---|
| 无条件转移 | `JMP` | 无条件跳到目标地址 | 段内改 `IP`，段间改 `CS:IP` | 不用 |
| 条件转移 | `Jcc` | 根据标志位决定是否跳转 | 只改 `IP` | 不用 |
| 循环转移 | `JCXZ` | `CX=0` 时跳转 | 只改 `IP` | 不用 |
| 循环转移 | `LOOP` 系列 | `CX` 减 1 后按条件跳转 | 只改 `IP` | 不用 |
| 子程序调用 | `CALL` | 保存返回地址并转到子程序 | 段内改 `IP`，段间改 `CS:IP` | 用 |
| 子程序返回 | `RET` | 从子程序返回 | 恢复 `IP` 或 `CS:IP` | 用 |
| 中断 | `INT n` / `INTO` | 转到中断服务程序 | 改 `CS:IP` | 用 |
| 中断返回 | `IRET` | 从中断服务程序返回 | 恢复 `CS:IP` | 用 |

### 本节易错点汇总

- `JMP` 不保存返回地址，`CALL` 才保存返回地址。
- 条件转移指令本身不改变标志位，只检查标志位。
- 8086/8088 条件转移范围是 -128 到 +127 字节。
- 无符号数比较用 `JA/JAE/JB/JBE`，有符号数比较用 `JG/JGE/JL/JLE`。
- `LOOP` 系列都是先 `CX=CX-1`，再判断是否继续循环。
- `JCXZ` 只判断 `CX` 是否为 0，不修改 `CX`。
- 段内转移只改 `IP`，段间转移改 `CS` 和 `IP`。
- `JMP WORD PTR OPD` 是段内间接转移，`JMP DWORD PTR OPD` 是段间间接转移。
- 中断向量表中每个向量占 4 字节，低 2 字节是 `IP`，高 2 字节是 `CS`。
- 中断返回用 `IRET`，不是 `RET`，因为 `IRET` 还要恢复 `FLAGS`。

## 处理器控制类指令

### 标志位操作指令 CLC、STC、CMC、CLD、STD（重点）

这类指令不做普通数据运算，而是直接控制 `FLAGS` 中的某些标志位。

| 指令 | 全称/含义 | 功能 | 常见用途 |
|---|---|---|---|
| `CLC` | Clear Carry Flag | `CF=0` | 清除进位标志 |
| `STC` | Set Carry Flag | `CF=1` | 设置进位标志 |
| `CMC` | Complement Carry Flag | `CF` 取反 | 改变当前进位状态 |
| `CLD` | Clear Direction Flag | `DF=0` | 串操作按地址递增方向处理 |
| `STD` | Set Direction Flag | `DF=1` | 串操作按地址递减方向处理 |

#### CLC 清进位标志

```asm
CLC
```

执行后：

```text
CF = 0
```

常用于执行依赖 `CF` 的运算前，先把进位标志清干净。

#### STC 置进位标志

```asm
STC
```

执行后：

```text
CF = 1
```

常用于人为设置进位状态，配合 `ADC`、`SBB` 等带进位/借位指令。

#### CMC 进位标志取反

```asm
CMC
```

执行后：

```text
如果原来 CF=0，则变为 CF=1
如果原来 CF=1，则变为 CF=0
```

> 易错：`CMC` 不是清零，也不是置 1，而是把当前 `CF` 反过来。

#### CLD 清方向标志

```asm
CLD
```

执行后：

```text
DF = 0
```

`CLD` 常用于串操作前，让 `SI`、`DI` 按地址递增方向移动。

#### STD 置方向标志

```asm
STD
```

执行后：

```text
DF = 1
```

`DF` 用于控制串操作中 `SI`、`DI` 的变化方向：

| `DF` | 字节串操作后 | 字串操作后 | 常用指令 |
|---|---|---|---|
| `0` | `SI/DI` 加 1 | `SI/DI` 加 2 | `CLD` |
| `1` | `SI/DI` 减 1 | `SI/DI` 减 2 | `STD` |

> 易错：`STD` 不是“停止”，而是 `Set Direction Flag`，让串操作从高地址向低地址方向处理。

### HLT 停机指令（了解）

`HLT` 用于使 CPU 进入暂停状态，直到外部中断、复位等事件使 CPU 继续工作。

格式：

```asm
HLT
```

常见用途：

- 程序结束时停机。
- 调试或教材例题中表示程序段到此结束。

> 易错：`HLT` 不是普通跳转或返回指令，它不会自动回到上一条程序流程。
